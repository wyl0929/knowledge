## 摘要（这张卡解决什么）

一步工作该用「工程」的方式治理（事前写死、批量、机检验收），还是用「研究」的方式治理（假设驱动、逐结果交互、人判验收）？判断依据一句话：**看这一步的「下一步」能否在开工前写出来。** 能 → 工程（逼近已知）；不能、要由上一个结果引出 → 研究（探索未知）。这个二分决定了工作的容器（stage vs 假设图）、完成定义（客观 vs 主观）、失败含义（bug vs 证伪）。

---

## 1. 名称 + 一句话意图

**「工程/研究二分——逼近已知 vs 探索未知」**：用「下一步可知性」把工作分成两类，从而决定它的容器、验收标准与评审分工。

## 2. 触发条件（适用性）

撞到下列症状时翻这张卡：

- 要判断一步工作「是工程还是研究」、决定它该用什么容器组织；
- 要给任务定「完成」标准，犹豫该客观（可机检）还是主观（人判）；
- 要分评审/验收分工，犹豫哪些交给 AI、哪些留给人类；
- 要选方法论，犹豫该用因子筛选（#92）还是假设驱动；
- 发现某个 stage/phase 里的任务「什么性质都有」、越积越多（→ 结合 #112 做重组）。

## 3. 系统建模 / 为何有效（核心）

### 3.1 本质区别：逼近已知 vs 探索未知

| | 工程链路 | 研究循环 |
|---|---|---|
| 目标 | 已知（复现 XQ_Li、收敛到容差） | 未知（"边态存在吗？"） |
| 任务 | 把已知目标落地 | 产生新知识 |
| 下一步 | **可知**，可事前写死 | **由上一个结果引出，事前不可知** |
| 敌人 | bug（可修复） | 错误假设（证伪也是产出） |
| 信息量 | 不增（复现已知） | 增加（产出新结论） |

### 3.2 判据：下一步可知性

**「这一步的下一步能否在开工前写出来？」** 这是二分的操作化判据，比「抽象 vs 具体」「难 vs 易」更可靠——工程也有难到爆的（m=12 超胞 31M 轨道），研究也有机械执行的（跑一个固定参数），**难易不是判据，下一步是否可知才是**。

### 3.3 六执行维度推论（二分决定了什么）

| 维度 | 工程链路 | 研究循环 |
|------|---------|---------|
| 任务清单 | 事前写死 | 事后补（假设引出） |
| 推进方式 | 批量、可自动化（哨兵/批提交/夜间跑） | 逐假设、强交互 |
| 失败含义 | bug → 修复重跑 | 证伪 → 也是交付 |
| 完成定义 | 客观（golden/级差收敛/RMSD） | 主观（问题被回答） |
| 进度度量 | 客观可数（x/N done） | 只能事后知（假设图展开到哪） |
| 评审 | 证据可信性 | 结论正确性/新颖性 |

> 这六列是「二分 → 治理方式」的桥梁：§4 的规则正是把「性质」映射到「容器/验收/评审」。

## 4. 规则 / 步骤

- **R1 先判性质**：问「下一步能否事前写出」，把工作归入工程或研究。
- **R2 按性质选治理**：工程 → stage（线性 + 门禁）+ 客观验收；研究 → 假设依赖图（分叉 + 增长）+ 人判验收。
- **R3 一类工作一个闭包**：若一个 phase 同时含两类（客观完成 + 主观完成），拆成两个 phase（方法建设 / 研究应用）——操作细节见 #112 §6.3。

## 5. 反例与失效模式（禁忌）

二分是**启发式，不是二分法**，以下情形会失效：

- **探索性工程**（如「调到一个能跑的配置」）：下一步不可知，但目标仍是「能用」而非「新知识」——按研究的方式探索、按工程的方式验收；
- **参数标定**（如 E_F 定标）：下一步可知（扫描网格），但验收含「该定哪个值」的主观判断——客观跑、主观定；
- **文献调研 / 方法论选型**：介于两者，宜按 #98/#105 的「系统辨识」范式处理，不硬套；
- **混合型任务**：一个任务里既有复现又有假设检验——先拆开再分别归类（这正是 #112 triage 第一问做的事）。

## 6. 证据等级 / 验证程度

- **单来源**：目前只从 R02 Stage 3 一个案例抽离（#112 §3.1 的 5 工程 + 5 研究分类），**未做跨案例交叉验证**。
- **理论类比**（支撑但非证明）：Simon《人工科学》工程=满足性设计/科学=发现；论文 Methods（验证可信）vs Results（新结论）；控制论开环（跟踪已知目标）vs 闭环（探索未知目标）。

## 7. 速查表（30 秒）

| 问 | 答 |
|---|---|
| 下一步能否事前写出？ | 能=工程（stage + 客观验收）/ 不能=研究（假设图 + 人判） |
| 一个 phase 混了两种？ | 拆两个 phase（方法建设 / 研究应用） |
| 任务「难」就是研究吗？ | 不是，难易不是判据，**下一步可知性**才是 |
| 研究性工作怎么算完成？ | 问题被回答（证伪也算），不由 golden/级差判定 |
