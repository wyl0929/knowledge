## 摘要

在一次为期四周的 TBG edge state 文献调研（Phase S）中，我们经历了一个完整的"粗读→计划→精读→报告"流程。将这一过程建模为控制论中的**系统辨识问题**——研究者作为自适应控制器，领域知识作为被辨识系统，论文作为带噪声的观测值——揭示了文献调研的多个深层结构：(1) 递推辨识（粗读先建立先验，精读后用新息修正）比批量辨识（全部精读）在信息效率上更优；(2) 最优实验设计（OED）的 D-optimal 准则解释了为何 P0 论文应选正交方向（STM / 输运 / 光学等不同表征技术）而非同一方向的重复采样；(3) 压缩感知理论给出精读数量的理论下界 $O(s\log(N/s)) \approx 17$ 篇——与实际的 15 篇吻合；(4) Ashby 的必要多样性定律解释了为何 64 篇是匹配领域复杂性的最低采样要求。

本文提出一个**文献调研的最优辨识协议**：Phase 1（系统激励）→ Phase 2（递推辨识）→ Phase 3（D-optimal 精读）→ Phase 4（新息反馈），并讨论其适用条件和局限。

## 1. 问题背景：文献调研的四个效率困扰

### 1.1 触发事件

导师交给任务：调研 TBG 中 AB/BA domain wall 的 edge state——回答三个问题：(Q1) 实验上如何表征？(Q2) 理论如何解释？(Q3) 理论如何与实验结合？

初始状态：已有 14_paper_registry.md（64 篇文献目录），但不知道从哪篇读起、读到什么深度、如何判断"读够了"。

### 1.2 四个经典困扰

| 困扰 | 朴素回答 | 辨识论回答 |
|---|---|---|
| **从哪里开始？** | 从奠基论文（Martin 2008）开始按时间读 | 先粗读全量做系统辨识（建先验），再按信息增益排序精读 |

| **什么时候停？** | 不想读了或 deadline 到了 | 模型收敛判据：新一篇论文的新息（innovation）低于阈值 |

## 2. 系统建模：文献调研作为闭环辨识系统

### 2.1 控制论框图

```
                    ┌──────────┐
  导师三问 ──→ (+) ─→│ 研究者    │──→ 阅读论文 ──→ 内部模型更新 ──→ 报告
   (参考信号)   ↑    │(控制器)   │                         │
               -│    └──────────┘                             │
                │                                              │
                └──────── 文献粗读 ←──────────────────────────┘
                          (状态观测器)

                ┌──────── 领域知识 ────────┐
                │ (被辨识系统，隐状态 θ)    │
                └──────────────────────────┘
```

> **术语**：这里的"参考信号"好比导航设定的目的地（导师三问），"误差信号"是当前位置与目的地之间的差距（你知道的 vs 导师想让你知道的 gap），"状态观测器"好比医生通过体温/血压推断你的健康状况——你不能直接"看到"领域的全貌，只能通过论文采样来估计它。

**参考信号** $r$：导师三问
**误差信号** $e = r - \hat{y}$：已知 vs 未知的 gap（文献调研的核心产出）
**系统输出** $\hat{y}$：当前内部模型对领域的预测
**控制器**：研究者的阅读/理解/综合能力
**状态观测器**：文献粗读——通过采样论文估计领域的隐状态 $\theta$

### 2.2 递推辨识（RLS）的动力学

> **术语**：想象你每次收到一条新信息就来微调你对世界的理解——而不是等所有信息都到手才做判断。这就是"递推辨识"（Recursive Least Squares, RLS）的核心思想：数据逐条到达，模型逐条更新。其中的魔法数字 $K_k$ 叫"Kalman 增益"——它决定了每条新信息在多大程度上改变你的旧认知：颠覆性的新发现（如 T12 推翻整个网络图景）的 $K_k$ 很大，微小的技术补充（如 T10 赝规范场）的 $K_k$ 很小。$y_k - \hat{y}_k$ 是"新息"（innovation）——新数据和你原来预期的差异，它是学习的燃料。

文献调研的本质是**递推最小二乘（RLS）**过程：

$$\hat{\theta}_{k} = \hat{\theta}_{k-1} + K_k (y_k - \hat{y}_k)$$

其中：

| 符号 | 物理含义 | Phase S 中的实现 |
|---|---|---|
| $\hat{\theta}_k$ | 读第 $k$ 篇论文后的内部模型 | 你对 edge state 领域的理解 |
| $y_k$ | 第 $k$ 篇论文的实际内容 | 卡片/精读笔记 |
| $\hat{y}_k$ | 读之前的预测（"这篇大概会说 X 和 Y"） | 粗读时的预期 |
| $K_k$ | Kalman 增益——这篇改变你认知的程度 | 新息（innovation）的大小 |
| $y_k - \hat{y}_k$ | **新息**——预期与实际的差异 | "这篇论文和我读之前想象的不一样" |

**核心洞察**：$K_k$ 在以下情况最大——
- 这篇论文的方法与你已读过的完全不同（高多样性激励）
- 这篇论文的结论挑战了你已建立的因果模型（大新息）
- 这篇论文裁决了之前未决的争议（高不确定性方向）

这解释了为何在 Phase S 中，**T12（TZM 推翻网络图景）的单篇信息增益远超 T10/Ramires（赝规范场）**——T12 的新息（推翻整个范式）远大于 T10 的新息（在已有范式内做技术扩展）。

### 2.3 三层确定性模型（传感器/观测器/执行器）

延续案例 #96 的增益控制模型，文献调研的产出也有三层：

| 声明层 | 确定性 | 例 | 增益 |
|---|---|---|---|
| **传感器** | ~99% | 「Rickhaus 2018 在 0–8T 观测到 FP+AB 振荡」——这是实验事实，几乎不会错 | 高增益，自由流向报告 |
| **观测器** | ~60% | 「FP 振荡来自畴壁态的 1D 弹道干涉」——Efimkin 的网络模型解释 | 中增益，需多理论交叉验证 |
| **执行器** | ~30% | 「因此 FP 振荡的存在证明了网络连通性」——这个因果链已被 TZM 削弱 | 低增益，需显式标注置信度 |

旧调研方式的失误：把三层声明打包成"领域共识"不分等级地写入报告。Phase S 的改进：Q3 映射表中显式标注每条理论的"遗留问题"——本质上是给观测器输出加了**不确定性标签**。

## 3. 核心方法论：文献调研的最优辨识协议

基于系统辨识的五条核心原则，推导出一个四阶段的文献调研最优协议。

> **术语**：用控制论的话说，对文献的采样必须"持续激励"所有感兴趣的频率分量——如果你只用 30 Hz 的正弦波去测试一个黑箱，你永远不知道它在 1000 Hz 处有一个谐振峰。放到文献调研里：如果你只读 STM 的论文（只测 30 Hz），你永远不知道输运测量中还有 FP/AB 振荡（1000 Hz 的分量）。

### 3.1 Phase 1: 持续激励 — 粗读的多样性要求

**原则**：输入信号必须"持续激励"所有模态。只给系统正弦波 → 辨识不出二阶谐振。

**协议**：
1. 从 registry 中按**表征技术/方法/时间**三个维度正交采样，确保每种模态都被激励
2. 每篇粗读产出同一格式的卡片（Q1/Q2/Q3 三问框架），确保跨论文可比
3. 卡片按问题组织而非按论文编号——Q1/Q2/Q3 分区使每种模态的响应在同一问题下对齐

**Phase S 验证**：21 篇实验覆盖 STM / 输运 / 光学 / 应变 / 结构 5 种表征技术 → 5 种独立的激励频率。如果只读 STM，输运中的 FP/AB 振荡（"高频分量"）将完全不可见。

### 3.2 Phase 2: 递推辨识（RLS）— 粗读→计划→精读的递进逻辑

**原则**：先建先验（粗读），再在最大不确定性方向精读，用新息修正模型。

**协议**：
1. 粗读 64 篇 → 建 $\hat{\theta}_0$（初始内部模型：Q1/Q2/Q3 的骨架）
2. 基于 $\hat{\theta}_0$ 的信息矩阵，计算每个方向的参数不确定性
3. 在最大不确定性方向（如"网络 vs TZM 裁决"）选精读论文
4. 精读后用新息更新模型

**为什么不能跳过粗读**：跳过粗读 = 没有先验 $\hat{\theta}_0$ = 没有信息矩阵 = 无法判断哪个方向的精读信息增益最大 = 只能凭引文数量或知名度选论文 = 盲辨识。

**Phase S 验证**：粗读建卡后，最不确定的方向是"网络 vs TZM 之争的裁决状态"——T29 (Hou 2024 NQCP) 被选为 P0 最高优先级；而 T10 (Ramires 赝规范场，孤立贡献) 被归入 scope out。

### 3.3 Phase 3: 最优实验设计（OED）— 精读的 D-optimal 选篇

**原则**：在有限预算（15 篇精读时间）下，选择使信息矩阵行列式最大化的论文子集，即最大化彼此正交的覆盖度。

**协议**：
1. 计算可精读论文的"信息向量"——每篇论文在方法空间中的坐标
2. 用 D-optimal 准则选子集：最大化 $\det(\mathbf{F}^T\mathbf{F})$，其中 $\mathbf{F}$ 的行为论文，列为方法/方向维度
3. 确保子集中每篇论文引入至少一个"新维度"（新的表征技术 / 新的理论阶段 / 新的争议点）

**Phase S 验证**：

| P0 论文 | 在信息空间中的独特维度 |
|---|---|
| E9 Huang 2018 | STM 螺旋态发现（表征：空间成像） |
| E10 Rickhaus 2018 | FP+AB 振荡输运（表征：量子干涉） |
| E13 Verbakel 2021 | FFT-STM 谷保护（表征：散射分析） |
| T1 Martin 2008 | EFW 拓扑零模（理论：连续模型奠基） |
| T5 San-Jose 2013 | 螺旋网络概念（理论：网络范式起源） |
| T12 Tsim 2020 | TZM 推翻网络（理论：范式转折） |
| T29 Hou 2024 | NQCP 裁决（理论：十年之争的最新答案） |

每篇论文在信息空间中高度正交——没有两篇用同一方法得到同一结论。这正是 D-optimal 设计的理想状态。

### 3.4 Phase 4: 新息反馈 — 精读中的模型修正

**原则**：精读的核心价值不是"确认已知"，而是"发现新息"——即论文内容与阅读前预期的不一致之处。这些新息对模型修正的权重最高。

**协议**（在精读笔记模板中增加一个字段）：

```markdown
## 新息记录（与实际不符之处）

| 阅读前的预期 | 论文实际内容 | 新息类型 | 对模型的影响 |
|---|---|---|---|
| 网络图景是共识 | T12 用对角 S 矩阵推翻 | 范式修正 | 大——重写 §3.2 |
| AB/BA DW 只有手征态 | T23 提出非手征 1D 态 | 补充修正 | 中——扩展 §3.3 |
```

**Phase S 验证**：Week 3 的 Q3 交叉阅读中，如果每条映射链路的"新息"都被记录，报告 §4 就可以从"按时间叙事"升级为"按认知修正叙事"——更有洞察力。

## 4. 模型阶次选择：压缩感知的"读够了吗"判据

> **术语**："压缩感知"是信号处理中的一个反直觉发现——如果一个信号在某种表示下只有几个非零分量（是"稀疏"的），你不需要采样每个点，只需随机采 $O(s\log(N/s))$ 个就足够重构整个信号。这里 $s$ 是"稀疏性"——信号简单到什么程度。放在文献调研里：$s$ 就是导师的问题可以用几个核心概念回答——EFW、LSW、$\Delta C_v$、TZM、NQCP……大约 8 个。

### 4.1 理论下界

压缩感知（Candès-Tao-Donoho 2006）：如果一个信号在某个基下是 $s$-稀疏的（仅 $s$ 个非零系数），则只需 $O(s\log(N/s))$ 次随机测量即可完美重构——远少于 $N$ 次。

**映射到文献调研**：

| 压缩感知 | 文献调研 |
|---|---|
| 信号 $x \in \mathbb{R}^N$ | 领域的完整知识（无限维） |
| 稀疏基 | 导师三问的答案可以用 $s$ 个核心概念表达 |
| 测量矩阵 $\Phi$ | 论文采样——每篇论文是知识空间的一个随机投影 |
| 测量次数 $m$ | 精读篇数 |
| 重构算法 | 研究者的综合/撰写能力 |

### 4.2 Phase S 的数值验证

- $N = 64$（总论文数）
- $s \approx 8$（核心概念：EFW, LSW, $\Delta C_v$, 螺旋网络, TZM, NQCP, 弹道长度 $L_0$, 谷保护）
- 理论下界：$m \geq O(s\log(N/s)) = O(8 \times \log 8) \approx 17$ 篇
- 实际精读数：**15 篇**（7 Q1 实验 + 8 Q2 理论）

**15 ≈ 17，差在误差范围内。** 如果精读超过 20 篇，已是在向已收敛的模型加噪声。如果精读不到 10 篇，可能漏掉某个核心概念。

### 4.3 实用判据：AIC 停读准则

当新一篇论文的新息 $\|y_k - \hat{y}_k\|$ 连续 3 篇低于某阈值时，模型已收敛，可以停止精读：

$$\text{stop if } \frac{1}{3}\sum_{i=k-2}^{k} \|y_i - \hat{y}_i\|^2 < \epsilon$$

其中 $\epsilon$ 取决于报告的精密度要求（综述 vs 研究论文 vs 快报）。

## 5. Ashby 的必要多样性：为什么不读不行

> **术语**：这是英国控制论学家 W. Ross Ashby 在 1956 年提出的"必要多样性定律"——你的控制器（大脑）的复杂度必须至少等于被控对象（领域）的复杂度，否则必然失控。就像一个只有 3 个按钮的遥控器无法操控一架有 200 个自由度的无人机。

Ashby 定律（1956）：*只有多样性可以吸收多样性。*

**映射**：

- 领域的多样性 $V_D$：64 篇论文覆盖的方法、发现、争议、解释
- 研究者的多样性 $V_R$：内部模型的复杂度（概念数、区分能力、不确定性的精细度）
- 如果 $V_R < V_D$ → 控制器（研究者）无法调节系统（领域）→ 必然产生三种失控：
  1. **重复造轮子**：不知道已经有人做了
  2. **问已解决的问题**：不知道答案已存在
  3. **做已被证否的方向**：不知道某个假设已被实验排除

文献调研本质上是在**增加 $V_R$ 以匹配 $V_D$**。64 篇卡片 = 64 个多样性采样点，压缩到 3 个问题的维度 → 使 $V_R$ 从"几乎为零"提升到"可以开始做有意义的研究决策"。

### 5.1 推荐的最小采样数

对于 $V_D$ 的数量级估计（以凝聚态物理的子领域为例）：

| 领域成熟度 | $V_D$ 估计 | 推荐粗读数 | 推荐精读数 |
|---|---|---|---|
| 新兴子方向（< 50 篇论文） | ~10–30 核心概念 | 20–50 | 8–12 |
| 中等成熟（50–200 篇） | ~20–50 核心概念 | 50–100 | 12–20 |
| 高度成熟（> 200 篇） | ~30–80 核心概念 | 80–150（或用综述代替） | 15–25 |

Phase S 的 TBG DW edge state 属于中等成熟 → 64 粗读 + 15 精读在推荐范围内。

## 6. 协议的形式化总结

### 文献调研最优辨识协议 v1.0

```
输入: 导师问题 Q, 论文注册表 R (N 篇), 时间预算 T
输出: 结构化调研报告

Phase 1: 持续激励（粗读）
  for each paper in R:
    产出卡片 { Q1_field, Q2_field, Q3_field }
  按 Q1/Q2/Q3 组织卡片，建初始模型 θ̂₀

Phase 2: 递推辨识（计划）
  计算信息矩阵 F^T F 的特征值谱
  识别最大不确定性方向（最小特征值对应方向）
  选出 D-optimal 精读子集（最大化 det(F^T F)，约束 m ≤ T/30min）

Phase 3: D-optimal 精读
  for each paper in D-optimal subset:
    精读 → paper_review
    记录新息 innovation = y_k - ŷ_k
    更新 θ̂_k = θ̂_{k-1} + K_k · innovation
    if 连续 3 篇 innovation² < ε: break

Phase 4: 新息反馈（报告）
  按 Q1→Q2→Q3 组织报告
  Q1/Q2 从精读笔记中提取
  Q3 从新息记录中提取映射链路
  显式标注每层的确定性增益（fact/interpretation/recommendation）
```

### 适用条件

| 条件 | 说明 |
|---|---|
| 领域有明确的"导师问题"框架 | 无问题 → 无参考信号 $r$ → 无误差信号 → 无法辨识 |
| 已有结构化的论文注册表 | 无 registry → 无采样空间 → 无法做 D-optimal |
| 研究者有基本的领域语言能力 | 无语言 → $\hat{y}_k$ 无意义 → 新息为零 → $K_k = 0$（学不到东西） |
| 时间预算允许至少 50 篇粗读 + 10 篇精读 | 低于此 → 压缩感知下界不满足 → 模型可能欠拟合 |

### 已知局限

1. **新息记录的可靠性**：精读后的"与预期不符"依赖研究者诚实记录——如果研究者倾向于确认偏见，新息被系统性地低估，模型收敛速度慢于理论预测
2. **稀疏基的选取**：$s$ 的估计（核心概念数）主观性强——如果低估 $s$，精读数不足，模型欠拟合
3. **卡片的观测噪声**：粗读卡片的质量影响 $\hat{\theta}_0$ 的精度——如果粗读质量差（仅读摘要），$\hat{\theta}_0$ 的误差传播到精读选择中
4. **时间分配的非线性**：模型未考虑"阅读疲劳"效应——第 60 篇粗读的信息提取效率远低于第 10 篇

## 附录 A：术语映射表（控制论 ↔ 文献调研）

> 以下每个术语在首次出现时先给通俗解释，再给出在 Phase S 中的具体对应。

#### 0.1 核心隐喻

| 控制论概念 | 通俗解释 | Phase S 中的具体对应 |
|---|---|---|
| **系统辨识** | 你买了一台不知道内部结构的机器（黑箱），通过给它输入信号、测量输出信号，推断它的工作原理——而不需要拆开它 | 你面对一个不熟悉的领域（黑箱），通过读论文（输入→输出的采样），推断领域的知识结构——而不需要读完所有论文 |
| **被辨识系统**（隐状态 $\theta$） | 黑箱内部的实际结构——它"真正"是怎么工作的 | 领域的真实知识图谱：哪些问题是已解决的、哪些在争论、哪些完全空白。你永远看不到全貌，只能通过论文采样来估计 |
| **观测值** $y_k$（带噪声） | 从传感器读取的数据——总有一些测量误差 | 一篇论文的内容——总带有作者的立场偏差、方法局限、过时的结论。不是"真理"，只是真理的一个投影 |
| **参考信号** $r$ | 你想要系统达到的目标状态 | 导师的三个问题：Q1（表征）、Q2（解释）、Q3（结合） |
| **误差信号** $e = r - \hat{y}$ | 目标与实际之间的差距——驱动你继续学习的动力 | **Gap**：你当前知道的和导师希望你回答的之间的差距。这是文献调研的核心产出 |
| **自适应控制器** | 根据误差信号自动调整策略的决策者——误差大时激进探索，误差小时精细调节 | **研究者本人**：gap 大时批量粗读扫全貌，gap 小后精准精读填细节 |
| **状态观测器** | 你不能直接测量系统的内部状态，但可以通过外部可测量量来推断它——就像医生通过体温/血压推断你的健康状况 | **文献粗读**：你不能直接"看到"领域的全貌，但可以通过 64 篇论文的采样来估计它 |

#### 0.2 辨识方法

| 控制论概念 | 通俗解释 | Phase S 中的具体对应 |
|---|---|---|
| **批量辨识**（batch） | 把所有数据一次性喂给算法，让它算出一个"最优拟合"的模型 | **精读全部 64 篇**再写报告——最准确但时间成本最高（~15 天） |
| **递推辨识**（RLS, recursive least squares） | 数据逐条到达，每来一条新数据就用它微调模型——不需要等全部数据到手 | **粗读 64 篇建先验 → 精选 15 篇逐篇精读更新模型**——你在 Phase S 中实际采用的方法（~5 天） |
| **先验** $\hat{\theta}_0$ | 在看到任何数据之前，你对系统已有的初始猜测（可能来自经验、教科书、常识） | 粗读 64 篇卡片后形成的**初始理解**——Q1/Q2/Q3 的骨架。虽然粗糙，但比"零知识"好得多 |
| **新息**（innovation）$y_k - \hat{y}_k$ | 新数据与旧模型预测之间的**差异**——"和我原来想的不一样"的部分。新息是学习的燃料：没有新息 = 这篇论文没教你任何新东西 | 精读一篇论文时，发现它的结论与你粗读时形成的预期不同。例如：你原以为网络图景是共识（来自 Efimkin 2018），但 T12/Tsim 2020 用对角 $S$ 矩阵推翻——这是一个巨大的新息 |
| **Kalman 增益** $K_k$ | 新息被采纳的权重——新息大且测量精度高时，大幅更新模型；新息小或测量不可靠时，几乎不更新 | 一篇论文的"认知冲击力"：T12（推翻网络图景）的 $K_k$ 远大于 T10（赝规范场这个孤立贡献） |

#### 0.3 实验设计与采样

| 控制论概念 | 通俗解释 | Phase S 中的具体对应 |
|---|---|---|
| **持续激励**（persistent excitation） | 如果你只用单一频率的信号测试黑箱（比如只用 30 Hz 的正弦波），你永远发现不了它的谐振峰在 1000 Hz——输入信号必须"覆盖所有感兴趣的频率" | 如果你只读 STM 的实验论文，你永远不知道输运测量中的 FP/AB 振荡——**阅读必须覆盖多种表征技术** |
| **最优实验设计**（OED） | 在有限的实验预算下，选择哪些实验做能获得最多的信息——不是"多做实验"，而是"做对的实验" | 在有限的 15 篇精读预算下，选择哪些论文精读能获得最多的信息——不是"多读论文"，而是"读对的论文" |
| **D-optimal 准则** | 选择实验使得不同实验之间**最不重复**（最正交）——两次测同一个频率 = 浪费一次机会 | 15 篇精读中每一篇覆盖一个不同的维度（STM / 输运 / 光学 / 网络理论 / TZM / 裁决）——没有两篇用同一个方法得到同一个结论 |
| **信息矩阵** $\mathbf{F}^T\mathbf{F}$ | 衡量"到目前为止的实验已经给了我多少关于系统的信息"的数学量——对角线上的值越大 = 对应参数越确定 | 衡量"到目前为止的阅读已经让我对领域的理解有多稳固"——Q1 上的值大 = 实验方法已搞清；Q2 上的值小 = 理论框架还需要读更多 |

#### 0.4 模型复杂度与停读判据

| 控制论概念 | 通俗解释 | Phase S 中的具体对应 |
|---|---|---|
| **模型阶次** $n$ | 你用多少个参数来描述黑箱——太少了欠拟合（漏掉关键动态），太多了过拟合（噪声被当成信号） | 你用多少篇精读来描述领域——15 篇是 D-optimal 选择。少于 10 篇可能漏掉核心概念（欠拟合），超过 20 篇已在向已收敛的模型加噪声（过拟合） |
| **AIC 准则**（Akaike Information Criterion） | 在"拟合得好"和"模型不要太复杂"之间做权衡的数学公式：$AIC = N\ln(\hat{\sigma}^2) + 2k$。前一项奖励拟合精度，后一项惩罚模型复杂度假 | 在"覆盖足够多论文"和"不要读太多无用的"之间做权衡——scope out 清单（§1.3）就是显式的复杂度惩罚项：每增加一个方向（Josephson 结畴壁、关联态），模型复杂度假 $k$ 增加，但拟合改善 $\Delta\hat{\sigma}^2$ 不够大 → 不读 |
| **压缩感知**（compressed sensing） | 如果一个信号在某种表示下只有少数几个非零分量（稀疏），你不需要采样每一个点——只需随机采 $O(s\log(N/s))$ 个就够了——远少于传统的 $N$ 个 | 如果导师的三个问题可以用 $s \approx 8$ 个核心概念回答，你不需要精读 64 篇——只需 $O(8 \times \log 8) \approx 17$ 篇。实际精读 15 篇，接近理论最优 |
| **稀疏性** $s$ | 信号中非零分量的个数——信号"简单到什么程度" | 领域中核心概念的个数——导师的问题"简单到什么程度"：EFW, LSW, $\Delta C_v$, 螺旋网络, TZM, NQCP, 弹道长度 $L_0$, 谷保护 = 8 |

#### 0.5 系统论

| 控制论概念 | 通俗解释 | Phase S 中的具体对应 |
|---|---|---|
| **Ashby 必要多样性定律** | "只有多样性可以吸收多样性"——你的控制器（大脑）的复杂度必须匹配被控对象（领域）的复杂度，否则必然失控 | 领域有 64 篇论文的多样性 → 你必须至少粗读 64 篇来匹配。读不够 → 三种失控：重复造轮子、问已回答的问题、做已被证否的方向 |
| **传感器** | 纯测量设备——输出原始数据，几乎不会撒谎 | **论文中的实验事实**：「Rickhaus 2018 在 0–8T 观测到 FP+AB 振荡」——这是测量结果，确定性 ~99% |
| **观测器** | 基于传感器数据做因果推理——容易出错，因为同一组数据可以对应多个因果解释 | **对实验的理论解释**：「FP 振荡来自畴壁网络态」——这是 Efimkin 的推理，确定性 ~60%，已被 TZM 部分修正 |
| **执行器** | 基于推理采取行动——如果推理错了，行动就错了 | **调研报告的结论和建议**：「因此网络图景成立」——这句话如果把传感器和观测器混为一谈，就会把 ~60% 的确定性当成 ~99% 传播 |
| **三层增益模型** | 传感器输出（高增益，自由流）→ 观测器输出（中增益，需交叉验证）→ 执行器输出（低增益，需显式标注置信度）——增益递减 | 卡片中的实验事实（高增益 → 可直接写入报告）→ 卡片中的理论解释（中增益 → 需 Q3 映射表交叉验证）→ 报告中的建议（低增益 → 需标 NEEDS_VERIFICATION） |
