# 案例库经验编译索引（触发条件主键）

> **用途**：解决「经验太多记不住 / 太杂稀释注意力」的问题。把案例库从"叙事归档"编译成"用时检索"——**你撞到什么症状，就查什么触发条件，得到对应规则。**
> **三层结构**（对应 #107 的"捕捉 → 编译"）：
>   - **案例**（`NN_case_study_*.md`）= 叙事，溯源用；
>   - **本索引** = 编译，把案例压成「触发条件 → 规则 → 来源」；
>   - **SKILL** = 触发器，已嵌入 skill 的规则会在使用点自动生效，无需检索。
> **检索法**：先在 §1 跨阶段元原则里找（重蹈覆辙重灾区），再在 §2 阶段导航里找。
> **维护**：新增案例后同步更新本索引 + `README.md` 注册表 + `99_update_log.md`。
