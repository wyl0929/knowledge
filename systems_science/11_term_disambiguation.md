# 11 Term Disambiguation / 术语澄清与概念边界

## 使用说明

本文档是 **Concept Boundary Gate** 的产出。在生成 frontier、gap、project 或 MVP 之前，必须在此澄清核心术语的边界、相邻领域的区别，以及本领域内常见的错误等同。

每个条目包含：

## 1. 核心术语三角：控制论 / 系统工程 / 系统科学

### 1.1 控制论（Cybernetics）

**定义**：研究动物和机器中**通信、反馈和控制**的统一科学。核心问题是"系统如何通过信息反馈来调节自身行为以达到目标"。

**边界**：
- 控制论 ≠ 控制工程。控制论是更基础的科学（像理论物理），控制工程是应用（像工程设计）。
- 控制论 ⊃ 自动控制理论。控制论还包括生物控制论（homeostasis）、社会控制论、管理控制论。
- 控制论的独特贡献是**跨领域统一视角**——它声称恒温器、人体血糖调节和市场价格机制本质上是同一种反馈逻辑。

**常见错误等同**：
- ❌ "控制论 = 机器人学" → 控制论远不止机器人，它是一种一般的调节逻辑。
- ❌ "控制论 = AI" → 控制论比 AI 更老、更基础。但 AI 中的强化学习确实有控制论的血统。

**物理连接**：反馈回路就是物理中的封闭因果链。SCF 迭代、Le Chatelier 原理、Lenz 定律都是控制论的基本逻辑在物理中的体现。

### 1.2 系统工程（Systems Engineering）

**定义**：一种跨学科的方法论，用于**设计、集成和管理复杂系统**在其整个生命周期中的全过程。核心问题是"如何让一堆必须协同工作的部件变成一个可靠的、可维护的、满足需求的整体"。

**边界**：
- 系统工程 ≠ 控制论。控制论关心 regulation（调节），系统工程关心 design（设计）。
- 系统工程 ≠ 软件工程。软件工程是系统工程的一种具体实现手段。
- 系统工程的核心是**需求追踪**和**V&V**（验证与确认），不是任何一种特定技术。

**常见错误等同**：
- ❌ "系统工程 = 写文档" → 文档是手段，真正的系统工程是"确保设计在做该做的事，而且没做不该做的事"。
- ❌ "系统工程 = 做复杂项目" → 不是所有复杂项目都有系统工程——区别在于是否有形式化的需求→验证链路。

**物理连接**：你做 TBPM 计算的完整 workflow（构建哈密顿量 → 演化 → 关联函数 → 傅里叶变换 → 物理量）就是一个小型系统工程。V&V 对应你的收敛性测试和基准对比。

### 1.3 系统科学（Systems Science）

**定义**：研究**一般系统**的性质、行为和规律的跨学科学问。它试图找出适用于所有类型系统（物理、生物、社会、工程）的普适原理。

**边界**：
- 系统科学 ⊃ 控制论 + 系统工程 + 复杂系统理论 + 一般系统论。
- 系统科学 vs 物理学：物理学研究特定类型的系统（物理系统）；系统科学研究所有系统的共性（层级结构、涌现、自组织、适应）。

**常见错误等同**：
- ❌ "系统科学 = 系统论" → 系统论（General System Theory，von Bertalanffy）是系统科学的一个历史分支，不是全貌。

**物理连接**：凝聚态物理中的"more is different"（Anderson, 1972）就是系统科学的核心命题——在层级跃迁时出现全新的有效规律，不能从微观方程推导。

## 2. 反馈相关术语

### 2.1 反馈（Feedback）

**定义**：将系统输出的一部分（经过处理后）回送到输入端的机制。

**类型区分**：

| 类型 | 数学符号 | 效果 | 物理例子 |
|------|---------|------|---------|
| 负反馈 | $u = -Ke$ | 抑制偏差，维持稳定 | Le Chatelier、Lenz 定律、SCF mixing |
| 正反馈 | $u = +Ke$ | 放大偏差，驱动转变 | 核链式反应、激光、相变的临界涨落 |
| 前馈（feedforward） | $u = f(r)$ | 基于预期而非误差做预判 | 你根据经验设 SCF 初始密度（而不是零） |

**常见错误等同**：
- ❌ "反馈就是循环" → 不是所有循环都是反馈。反馈必须包含**比较**（与目标的差异）。
- ❌ "负反馈就是坏东西" → 负反馈是稳定性的来源——没有它就没有恒温、没有 homeostasis、没有收敛的 SCF。

### 2.2 开环（Open-loop）vs 闭环（Closed-loop）

**定义**：
- 开环控制：不依赖输出测量，按预设指令运行 → $u(t) = f(t)$
- 闭环控制：依赖输出测量，根据误差实时调整 → $u(t) = f(e(t))$

**关键区分**：闭环可以抵抗扰动和模型不确定，开环不行——但开环没有稳定性问题。

**物理连接**：
- 开环 = 你做 TBPM 时对初态演化 10000 步直接算（不检查中间结果）
- 闭环 = SCF 迭代（每一步都检查收敛）

## 3. 系统表示相关术语

### 3.1 传递函数（Transfer Function）

**定义**：线性时不变系统在零初始条件下，输出拉普拉斯变换与输入拉普拉斯变换之比 $G(s) = Y(s)/U(s)$。

**边界**：
- 传递函数只能描述**线性时不变**（LTI）系统。
- 传递函数只描述**输入-输出关系**，不描述内部状态。

**物理连接**：传递函数 $G(s)$ ↔ 格林函数 $G(E) = (E-H)^{-1}$。两者都描述系统对"点源"的响应。$s$ 是复频率（$s = \sigma + i\omega$），$E$ 是复能量（$E = \epsilon + i\eta$）。

### 3.2 状态空间（State Space）

**定义**：用一阶微分方程组描述系统的方法。系统行为由状态向量 $\mathbf{x}$ 的演化完全刻画。

$$\dot{\mathbf{x}} = A\mathbf{x} + B\mathbf{u}$$
$$\mathbf{y} = C\mathbf{x} + D\mathbf{u}$$

**边界**：
- 状态空间可以处理多输入多输出（MIMO）和非零初始条件，传递函数不行。
- 状态空间不唯一——同一输入输出行为可以有无穷多种状态空间实现。

**物理连接**：
- $\dot{\mathbf{x}} = A\mathbf{x}$ ↔ 薛定谔方程 $i\hbar\partial_t|\psi\rangle = H|\psi\rangle$
- 矩阵指数 $e^{At}$ ↔ 传播子 $e^{-iHt/\hbar}$
- 状态的可控/可观性 ↔ 量子控制中哪些态可以通过外场达到/测量

### 3.3 稳定性（Stability）

**定义**：有多种稳定性概念，需要区分。

| 概念 | 定义 | 数学判据 |
|------|------|---------|
| Lyapunov 稳定 | 从足够近的初态出发，轨迹始终保持在目标附近 | $\forall \epsilon>0, \exists \delta>0$ |
| 渐近稳定 | 不仅保持在附近，而且 $t\rightarrow\infty$ 时趋于目标 | 上条 + $\lim_{t\rightarrow\infty}\|x(t)\|=0$ |
| BIBO 稳定 | 有界输入 → 有界输出 | 传递函数所有极点在左半平面 |
| 指数稳定 | 趋向目标的速度有指数下界 | $\|x(t)\| \leq Me^{-\alpha t}$ |

**边界区分**：
- Lyapunov 稳定 ≠ 渐近稳定。一个无摩擦的摆是 Lyapunov 稳定但不渐近稳定（它会一直摆，不会停）。
- BIBO 稳定 ≠ 内部稳定。一个系统可以 BIBO 稳定但内部有不稳定模态被不可控/不可观"隐藏"了。

**物理连接**：
- Lyapunov 函数 ↔ 物理中的势函数或自由能。如果 $V(x) > 0$ 且 $\dot{V}(x) < 0$，系统必然走向 $V=0$ 的平衡点——这就是热力学第二定律的数学形式。
- 线性稳定性分析 ↔ 你在凝聚态中判断一个相的稳定性：算 Hessian 矩阵的本征值，如果有虚频 → 不稳定。

## 4. 信息相关术语

### 4.1 熵（Entropy）

**定义**：
- 热力学熵（Clausius）：$dS = \delta Q_{rev}/T$
- 统计力学熵（Boltzmann）：$S = k_B \ln \Omega$
- 信息论熵（Shannon）：$H = -\sum p_i \log p_i$

**边界**：
- 这三个熵是同一个数学结构应用于不同对象。但不代表它们完全等同——热力学熵有量纲（$k_B$），信息熵无量纲（bit）。
- Shannon 熵衡量的是**不确定性**，不是"混乱程度"——后者是通俗但不精确的说法。

**常见错误等同**：
- ❌ "熵 = 混乱" → 更精确：熵 = 可能微观状态数的对数。高熵意味着"我不知道系统具体在哪个微观态"。
- ❌ "信息 = 负熵" → 这说法（Brillouin / Schrödinger）引起了很多混淆。现代观点：信息是概率分布更新的度量，不是一种"东西"。

### 4.2 信道容量（Channel Capacity）

**定义**：在给定噪声模型下，信息可以以任意小的错误概率通过信道传输的最大速率。

$$C = \max_{p(x)} I(X;Y)$$

**物理连接**：香农信道容量公式 $C = B\log_2(1 + \text{SNR})$ 和 Arrhenius 反应速率 $k = Ae^{-E_a/k_BT}$ 有结构上的相似——都有一个"资源"（带宽/指前因子）乘以一个"对抗障碍"的对数项（信噪比/激活能）。

## 5. 本领域最常被混淆的概念对

| 概念 A | 概念 B | 为什么容易混 | 实际区别 |
|--------|--------|------------|---------|
| 控制论 Cybernetics | 控制理论 Control Theory | 名字重叠 | 控制论 = 跨领域统一科学（Wiener）；控制理论 = 数学/工程学科 |
| 系统工程 Systems Eng. | 系统科学 Systems Sci. | 都研究"系统" | 系统工程 = 做（如何设计）；系统科学 = 理解（一般规律） |
| 反馈 Feedback | 循环 Recursion | 都有"回去"的动作 | 反馈必须有目标和比较；循环不一定 |
| 复杂性 Complexity | 复杂化 Complicatedness | 日常混用 | 复杂（complex）= 部件交互产生不可预测的涌现行为；复杂化（complicated）= 零件多但行为可预测 |
| 鲁棒性 Robustness | 弹性 Resilience | 都涉及对抗扰动 | 鲁棒 = 扛住扰动不变；弹性 = 被扰动变形后能恢复原状 |
| 最优控制 Optimal Ctrl | 鲁棒控制 Robust Ctrl | 都追求"好" | 最优 = 在已知模型下最好；鲁棒 = 在模型有误差时还能用 |
| 自适应控制 Adaptive Ctrl | 学习控制 Learning Ctrl | 都依赖数据 | 自适应 = 在线调参数（控制器结构固定）；学习 = 学习整个策略（结构可变） |

## 7. 与相邻领域的边界

```
         ┌──────────────────────────────────────────┐
         │            系统科学 (Systems Science)      │
         │    ┌──────────┐  ┌──────────┐            │
         │    │  控制论   │  │ 系统工程  │            │
         │    │Cybernetics│  │Systems   │            │
         │    │           │  │  Eng.    │            │
         │    └─────┬─────┘  └────┬─────┘            │
         │          │             │                  │
         └──────────┼─────────────┼──────────────────┘
                    │             │
    ┌───────────────┼─────────────┼───────────────┐
    │               │             │               │
    │  物理学       │  信息论     │  运筹学        │
    │  (动力学系统) │  (Shannon)  │  (优化)        │
    │               │             │               │
    └───────────────┴─────────────┴───────────────┘
```

- **控制论 vs 物理学**：物理学问"系统自然地做什么"；控制论问"我如何改变系统行为"。交汇点在动力学系统理论。
- **控制论 vs 信息论**：信息论提供"不确定性"的度量，控制论使用这个度量来设计反馈。
- **系统工程 vs 运筹学**：运筹学优化已有系统的运行；系统工程设计新系统。交汇点在最优控制和资源配置。
