# 02 Frontier Compass / 边界罗盘

Last updated: 2026-06-21

---

## 使用说明

本文档明确划分：
- **内圈 (Core)**：这个领域已经消化的、写入教材的、不需要怀疑的知识
- **中圈 (Mature Baseline)**：已确立但在不同子领域仍在活跃使用和发展的方法
- **边界 (Frontier)**：当前正在被推进的、尚未闭合的问题
- **伪缺口 (Pseudo-gap)**：看似开放但实为已知问题重新包装的领域
- **你的切口 (Personal Entry Points)**：结合用户计算物理背景的具体切入点

---

## 1. 内圈知识（Core）—— 已经闭合并写入教材的

这些是系统科学中不再需要"研究"的知识——它们已经成为工具箱。你要做的是**学会使用**，不是做出新贡献。

| 知识点 | 成熟标志 | 你需要学到什么程度 |
|--------|---------|-----------------|
| 线性系统的可控性与可观性判据 | Kalman 秩条件（1960），所有控制教材第一章 | 会用矩阵秩判断 |
| LQR（线性二次型调节器） | 解析解，Riccati 方程已完全解决 | 理解代价函数权重选择的意义 |
| Kalman 滤波器 | 1960 年代完成，递推最小方差估计 | 理解预测-更新两步，和贝叶斯推断的关系 |
| PID 控制 | 1920s-1940s 成型，主导 90%+ 工业控制 | 理解 P/I/D 各自的作用和调参直觉 |
| Nyquist 稳定性判据 | 1932 年，复数分析的直接应用 | 理解围线映射和闭环极点的关系 |
| 线性系统传递函数与极点/零点 | 1960s 前已完全清楚 | 能和格林函数 $G(E) = (E-H)^{-1}$ 互译 |
| 线性二次型高斯（LQG） | 分离定理（1960s），估计+控制可分离设计 | 知道分离定理的成立条件 |
| 最小二乘参数估计 | 1800s Gauss 就完成了，统计推断的基础 | 已掌握（物理训练自带） |

## 2. 中圈成熟 Baseline —— 可放心使用但仍在局部发展

这些是可靠的、有标准做法的方法，但在特定子问题上仍在改进。你可以把它们当作黑箱工具，也可以深入研究其内部。

| 方法/框架 | 成熟阶段 | 你的相关性 |
|-----------|---------|----------|
| 模型预测控制（MPC） | 工业成熟（化工、过程控制），理论仍在细化 | ⭐⭐⭐⭐⭐ SCF 加速的直接候选 |
| H∞ 鲁棒控制 | 线性部分成熟（1980s-1990s），非线性仍在发展 | ⭐⭐⭐ 量化计算误差传播 |
| 子空间系统辨识（N4SID） | 1990s 确立，已是标准工具箱 | ⭐⭐⭐ 哈密顿量学习 |
| Lyapunov 稳定性理论 | 1892 年创立，直接法成熟，构造方法仍在发展 | ⭐⭐⭐⭐ 相变分析、收敛性保证 |
| 反步法（Backstepping） | 1990s 确立的非线性控制设计方法 | ⭐⭐ 特定非线性物理系统 |
| 滑模控制（Sliding Mode） | 1970s 苏联发展，理论成熟，应用仍在扩展 | ⭐⭐ 对匹配扰动免疫——可能用于噪声鲁棒计算 |
| 自适应控制（MRAC, STR） | 1980s 确立框架，稳定性保证仍在细化 | ⭐⭐⭐⭐ SCF mixing 自适应调参 |
| 迭代学习控制（ILC） | 1980s 确立，重复任务的误差学习 | ⭐⭐⭐ 迭代求解器的加速 |

## 3. 真正边界（Frontier）—— 当前正在被推进的

这些是"如果你解决了其中任何问题，就是重大贡献"的开放问题。

### 3.1 非线性系统的高效最优控制

**问题**：Bellman 方程在高维状态空间中不可解。现有的近似方法（微分动态规划 DDP、iLQR、轨迹优化）在非线性强、时域长、维度高的情况下要么不收敛，要么收敛到很差的局部最优。

**物理连接**：这个问题和你在多体量子力学中遇到的"指数墙"完全相同——只是从希尔伯特空间换成了状态空间。张量网络方法（MPS/MPO 对价值函数的低秩近似）和神经网络方法（用 NN 做价值函数的 Ansatz）是两条正在竞争的前沿路线。

**状态**：🔥 非常活跃（控制+ML 交叉）

### 3.2 安全关键系统中的学习控制

**问题**：强化学习可以在仿真中学会控制，但如何保证部署到真实系统时不会做出灾难性错误决策？如何给出形式化的安全性保证（如 barrier 函数、可达集分析）？

**物理连接**：你在做 SCF 时可以通过监控能量变化来判断是否"跑飞了"——这是最简单的 safety monitor。但形式化地保证"学习到的 mixing 策略永远不会导致发散"是硬问题。

**状态**：🔥🔥 极热门（自动驾驶、机器人、医疗设备驱动）

### 3.3 物理驱动的系统辨识

**问题**：现有系统辨识方法要么是纯黑箱（神经网络），精度高但不可解释且违背守恒律；要么是纯白箱（第一性原理），可解释但模型误差难量化。灰箱辨识——在物理结构约束下从数据学习——是物理+ML 的前沿。

**物理连接**：你学一个哈密顿量 $H(\theta)$ 让它的谱匹配实验数据。关键问题——哪些参数可以从哪些观测量中唯一确定（可辨识性）——和你的物理训练完美对接。

**状态**：🔥🔥 极热门（科学机器学习 SciML 的核心问题）

### 3.4 网络系统的可控性

**问题**：给定一个复杂网络（电网、神经元网络、社交网络），最少需要控制多少个节点才能让整个网络达到任意期望状态？答案不仅依赖于动力学，还严重依赖于**网络拓扑**——而现实网络的拓扑往往是不完全已知的。

**物理连接**：你的紧束缚晶格是精确已知拓扑的网络。在无序系统中（Anderson 局域化），网络的有效拓扑发生变化——这是拓扑 ↔ 可控性映射的绝佳物理案例。

**状态**：🔥 活跃（Liu et al. 2011 *Nature* 开创，理论框架仍在发展中）

### 3.5 涌现的形式化理论

**问题**：什么样的微观规则会导致什么样的宏观涌现？能否有一个"涌现的相图"——在参数空间中标出涌现的可能性区域？重整化群是一个成功的特例（来自物理学），但能否推广到非物理系统（生态系统、经济系统）？

**物理连接**：这是你最能贡献的边界——因为你每天都在和"已知微观规则、计算宏观行为"的系统打交道。凝聚态物理中的拓扑序、自发对称破缺、普适类——这些是涌现理论的黄金标准案例，系统科学尚未完全消化。

**状态**：🔥 活跃但分散（多学科各自为战）

## 4. 伪缺口（Pseudo-Gap）—— 看着像开放问题但实际不是

| 伪缺口 | 为什么不是真缺口 |
|--------|---------------|
| "如何控制非线性系统" | 不是单一缺口——非线性是一个谱（弱非线性→强非线性→混沌），每段有不同的适用工具。不存在"非线性系统统一理论"，也不应该有。 |
| "AI 替代 PID" | PID 在绝大多数工业场景中已经是接近最优的。不是 PID 不够好，是调参的人不够好。深度学习控制器的价值在"无法建立模型"的场景，不是"替换 PID"。 |
| "万物皆可控" | 有些系统天然有不可控子空间（对应量子力学中的暗态/禁戒跃迁）。这不是控制技术的缺陷，是物理约束。 |
| "更大模型 = 更好辨识" | 过参数化导致过拟合——这是统计学习的基本事实，不是系统辨识特有的挑战。 |

## 5. 你的个人切口（Personal Entry Points）

基于你的计算物理背景，以下是五个按"可行性 × 影响力"排序的切口：

### 🥇 切口 1：用 PID/MPC 加速 SCF 收敛

- **可行性**：⭐⭐⭐⭐⭐ 极高。你已有 SCF 代码，只需替换 mixing 逻辑。
- **影响力**：⭐⭐⭐ 中等。可以改善你每天的迭代效率，但不是"发表级"成果（除非找到新的通用 mixing 策略）。
- **第一步**：用 Python 实现一个简单的 PID controller，在简单的自洽方程（如 $x = f(x) = x^2 + c$ 的不动点迭代）上测试，对比线性混合和 Pulay。

### 🥈 切口 2：从 TBPM 数据学习紧束缚参数（系统辨识）

- **可行性**：⭐⭐⭐⭐ 高。你有 TBPM 代码（产生数据），有紧束缚框架（参数化模型）。
- **影响力**：⭐⭐⭐⭐ 高。如果能在"哪些 TB 参数可以从哪些观测量中唯一确定"上做出清晰判断，有发表价值。
- **第一步**：选一个最简单的体系（如单层石墨烯），从已知 TB 参数出发，加噪声生成"伪实验数据"，然后尝试用最小二乘/极大似然反推参数——这就是系统辨识的 hello world。

### 🥉 切口 3：量子最优控制（QOC）数值实验

- **可行性**：⭐⭐⭐ 中等。需要学习 GRAPE/CRAB 算法，但你的 TBPM 时间演化代码是现成的。
- **影响力**：⭐⭐⭐⭐⭐ 很高。量子最优控制是一个明确的发表方向，且与量子计算/量子传感紧密相关。
- **第一步**：在两能级系统上实现 GRAPE 算法（这是 QOC 的"氢原子"）。用 Python 从头写不超过 100 行。

### 切口 4：KPM kernel 的自适应选取

- **可行性**：⭐⭐⭐⭐ 高。代码改动很小。
- **影响力**：⭐⭐⭐ 中等。对 KPM community 有实用价值，但学术贡献有限。
- **第一步**：在简单解析 DOS（如一维紧束缚链）上测试不同 kernel 的 Gibbs 抑制效果，量化"谱分辨率 vs 振荡抑制"的 trade-off。

### 切口 5：计算工作流的系统工程化

- **可行性**：⭐⭐⭐⭐⭐ 极高。不需要写新算法，只需要重新组织已有代码。
- **影响力**：⭐⭐ 个人效率提升为主，不是发表方向。
- **第一步**：把你最常用的计算流程写成带输入验证和输出检查的标准化脚本，加入自动收敛检测和异常报告。

## 6. 行动建议

如果你是**想快速体会控制论的思想** → 从切口 1（PID mixing）开始，半天就能跑通。

如果你是**想往量子技术方向走** → 从切口 3（QOC）开始，这是一条有明确前景的研究路线。

如果你是**想利用已有优势做有发表价值的工作** → 从切口 2（哈密顿量学习）开始，它结合你最熟悉的工具（TBPM + 紧束缚）和系统科学中最活跃的前沿（SciML）。

如果你是**想先建立全景理解再动手** → 按 `01_research_overview.md` 末尾的阅读路径，先花 2 周读 Wiener + Åström & Murray，然后在切口 1-3 中选一个做 mini-project。
