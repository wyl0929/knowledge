## TL;DR

**本文想解决的问题**（问题句式）：镜像对称魔角三层石墨烯（MATTG）的超导相图里，是否真的存在由平带内部某种填充结构劈裂出的"双穹顶超导"，其两个穹顶的填充位置、位移场依赖与正常态（自旋/能带占据）结构有何对应，从而判别配对机制？

**主结果**（数字带不确定度标注）：
1. 空穴侧观测到**双穹顶超导**：最优掺杂 ν ≈ −2.3、Tc ≈ 2.5 K（📜Q[~]，txt L255–256）；超导在 ν* = −2.6 处被强烈抑制（📜Q，txt L256–257），形成左穹顶（−3.2 < ν < −2.6）与右穹顶（−2.6 < ν < −2）（📜Q，txt L259–260）。左穹顶最大上临界场可达 400 mT（📜Q[~]，txt L254），超过右穹顶；但右穹顶 Tc 更高（📜Q[相对]，txt L251–254）。
2. **位移场可调**：低 |D|（区域 I，如 D = −0.09 V nm⁻¹）单穹顶、Dirac 带朗道能级可见；中等 |D|（区域 II，D = −0.35 V nm⁻¹）Dirac–平带强杂化、**双穹顶出现**；高 |D|（区域 III，D = −0.45 V nm⁻¹）又回到单穹顶并随 |D| 增大收缩消失（📜Q，txt L473–505 及 Fig. 4 caption L477–478）。
3. 电子侧超导弱得多（30 mT / 100 nA @ν = 2.74，📜Q[~]，txt L245–246），仅在 SI 见弱的"类双穹顶"特征（📜Q，txt L349–350）。
4. 两穹顶行为不对称：右穹顶 I–V 磁滞（−2.4 < ν < −2.1，最大 ~60 nA，📜Q[~]，txt L375–376）、正常态 R–T 线性（📜Q，txt L262–269）；左穹顶无磁滞、正常态 R–T 非线性。配套 HF 计算给出正常态为**非公度 Kekulé 螺旋（incommensurate Kekulé spiral, IKS）**，其有效自旋极化楔形区与超导抑制区重合（📜Q，txt L559–568, L586–588）。

**结论/意义**（保留作者措辞强度 📜Q）：作者称这是 MATTG 中双穹顶超导的"直接观测"（"direct observation of two domes of superconductivity"，摘要 L23–24）；关联态与超导态"独立且可能竞争"（L259）；双穹顶或源于 ν* 附近的**竞争序**，或源于两穹顶**超导序本质的内在差异**（L265–269）；理论猜测右穹顶 = 稳健无节点偶宇称配对（inter-effective-spin，广义 Anderson 定理保护），左穹顶 = 较弱 nodal 奇宇称配对（L591–595）——"conjecture"，非实测。

## 2. 结果与机制（按论文自身论证结构）

### 2.1 超导态与关联态的存在性（Fig. 1）📜Q

- 构型：三层石墨烯首尾同取向、中间层扭 ≈1.55°，零位移场下镜像对称，λ ≈ 9.1 nm（正文 L154–158 + Fig. 1a caption L132）。与 MATBG 不同处：**平带旁还有一条 Dirac 带**，零位移场下二者解耦；加位移场破坏镜像对称 → 平带–Dirac 带杂化（L160–164），即导师假说关注的可调性来源。
- Landau fan（Fig. 1b，Vtg = 0）：电阻峰在 ν = ±4（带隙）、ν = 0（电荷中性点）外，还有 ν = 1, ±2, 3（L150–152）——非单粒子能带可解释，判为相互作用驱动的关联态（L152–153）；朗道能级从这些关联态出发，由 Streda 公式得 Chern 数 |C| = 2，且该 C 来自 **Dirac 带朗道能级**而非平带拓扑（L156–158, refs 32）。
- Hall 密度 nH（Fig. 1d caption）：ν = 0、±4 处"gap/Dirac"行为；ν = 1、±2、3 处"reset（复位）"；**范霍夫奇点（VHS）位于 −4 与 −3 之间、1 与 2 之间、3 与 4 之间**（L131–132, 依据 ref 11 的图像）。空穴侧超导相被 **VHS 与复位点**夹住；电子侧被**两个复位点**夹住（L133–136；正文 L160–164；"in agreement with previous works11,12,15"）。
- 超导出现于 |ν| ≈ 2（半填充）两侧（L159）。空穴侧强：ν = −2.37 处上临界场可达 400 mT、临界电流 ~800 nA（通道宽 1 μm）（L165–167）；电子侧弱得多：ν = 2.74 处仅 30 mT、100 nA（L245–246）。两处都无 Fraunhofer 干涉（L140）。

### 2.2 双穹顶（Fig. 2）📜Q

- 温度依赖（Fig. 2a）：最优掺杂 ν ≈ −2.3、Tc ≈ 2.5 K；在 **ν* = −2.6** 被强烈抑制 → 双穹顶，此前实验未直接见到（L255–258）。左穹顶 −3.2 < ν < −2.6；右穹顶 −2.6 < ν < −2（L259–260）。
- 正常态 R–T：右穹顶线性（虚线拟合）、左穹顶偏离线性；SI（Supplementary Fig. 3）用拟合决定系数 Dfitting 与残差定量化，线性 R–T 只出现在右穹顶正常态（L262–269）。
- 磁场依赖（Fig. 2c/d）：两穹顶最大临界场都 > 300 mT，左穹顶最高 400 mT、**超过右穹顶**；但左穹顶最大 Tc 低于右穹顶（L236–237 caption, L251–254）。B = 0 时超导区延伸至 ν < −3 与 ν > −2；B = 0.1 T 双侧收缩并在 ν* 附近出现小电阻峰；B = 0.2 T 该峰增强且 ν = −2 关联态出现（L237–241 caption; L260–265）。
- 判别性语句：磁场既压制 ν* 附近超导又诱导 ν = −2 关联态 → **关联态与超导态独立且可能竞争**（L257–259）。ν* 电阻峰或为竞争序（把单穹顶劈成两半），或为两穹顶超导序本质的内在改变（L265–269）。

### 2.3 偏置电流依赖与 I–V 磁滞（Fig. 3）📜Q

- dVxx/dI vs (ν, Idc) 在 0.3 / 1 / 1.8 K（Fig. 3a–c）：可见清晰 Ic 特征的填充区间为 **−3 < ν < −2.8 与 −2.5 < ν < −2.1**（caption L342–343）。左穹顶 Ic ≈ 500 nA（L357）；右穹顶 Ic 随空穴掺杂先增后减 → 右穹顶独立演化（L358–360）。ν* 中心区低 Idc 电阻为零但转正常态不锐利；高 Idc 处有 kink 状特征贯穿三个温度、且弱温度依赖 → 更像能带结构而非超导（L362–369）。
- 1.8 K：左穹顶超导几乎消失，右穹顶临界电流仅略降（L363–365）。
- **磁滞只在右穹顶**：I–V 磁滞（开关电流与回捕电流不同）出现在 −2.4 < ν < −2.1、最大 ~60 nA（L370–376, L341–342 caption）；左穹顶与中心区无磁滞（L372–373）。Fig. 3e（ν = −2.84，左）无磁滞；Fig. 3f（ν = −2.26，右）明显磁滞（caption L343–344）。
- 机制讨论：排除非均匀约瑟夫森网络（无 Fraunhofer、高开关电流、大临界场、磁滞随掺杂系统变化，L377–384）；自加热备择（refs 36–38）用外部 STM（ref 29）的 **U 形→V 形能隙转变**排除：ν ≈ −3 处 V 形（低能准粒子多 → 冷却好 → 无磁滞，= 左穹顶），ν ≈ −2 处 U 形（全能隙、准粒子少 → 热平衡差 → 磁滞，= 右穹顶）（L350–368）。

### 2.4 位移场调控（Fig. 4）📜Q

- ν–D 相图（B = 0，Fig. 4a）分三区：
  - **区域 I（低 |D|，如 D = −0.09 V nm⁻¹）**：Dirac 带与平带未完全杂化，Dirac 带朗道能级可见（Fig. 4c 中 ν–B 平面左下弯曲特征源于两套朗道能级在固定总密度下电荷转移；HF 支持 Dirac/平带扇区间电荷转移级联，ref 39，L479–489）。**单穹顶**，且从 ν = −2.35 起 Ic 与 Bc 随掺杂增加急剧下降（L489–491）。
  - **区域 II（中等 |D|，D = −0.35 V nm⁻¹）**：Dirac 带与平带强杂化，Dirac 朗道能级特征消失（Fig. 4d）；**双穹顶在 Idc 与磁场两个依赖中都出现**（L492–496）。
  - **区域 III（高 |D|，D = −0.45 V nm⁻¹）**：杂化更强，Dirac 朗道能级特征仍缺席（Fig. 4e）；回到**单穹顶**，随 |D| 增大收缩直至消失；此单穹顶的 Ic 随掺杂先增后缓降——与区域 I"急降"迥异（L497–505）。
- B = 0.1 T 的 ν–D 图（Fig. 4b）再分三区：|D| < D1：左侧超导已被毁而右侧仍在（与 Fig. 4c 左瓣很弱一致）；D1 < |D| < D2：两穹顶被 ν* 附近电阻区桥接；D2 < |D| < D3：单穹顶收缩；|D| > D3：消失（L507–508, L489–493）。边界 D1/D2/D3 数值仅在图。
- 作者的提取信息：(1) D 增大 → Dirac 带逐渐与平带杂化；(2) 双穹顶出现在 Dirac 带朗道能级消失的同时。**保留意见**：D 不仅改杂化还改平带带宽与相互作用强度，故杂化对超导的作用"尚待完全理解"（L494–501）。

### 2.5 正常态 Hartree–Fock 研究（Fig. 5）📜Q（理论部分）

- 动机：Fig. 2b 中 ν = −2.2 与 −2.8 的 R–T 在远高于 Tc 处已明显不同 → 正常态跨 ν* 改变（L571–572）。用 HF 算正常态基态与 Fermi 面。
- 基态：加入实验现实应变（ε = 0.15%，为同时复现 ν = −2 处二重朗道扇简并与 ν = 0 处无强绝缘）后，所有非零整数填充的正常态为 **IKS（incommensurate Kekulé spiral）**（L574–579, ref 39）；IKS 在 MATBG 也普遍（ref 40），由空间调制的谷间相干（IVC）构成多尺度序（石墨尺度的 Kekulé 电荷图样 × 摩尔尺度的非公度螺旋旋转），已在 MATBG/MATTG 的 STM 直接观测（refs 41, 42）。
- 图 5 相图：有效自旋极化 vs (ν, ΔV)（ΔV = 层间势，代理 D）。中性能级以下每有效自旋扇区有上/下两条 IKS 带。ν = −3、小 ΔV：单条下 IKS 带（↑）填满（inset i）；大 ΔV：两条下带间电荷转移、ν = −3 有小 Fermi 面（inset ii）——与实验"ν = −3 复位行为只在小位移场出现"一致（L594–598）。
- 从 ν = −3 向中性掺杂：小 ΔV（区域 A）↑ 扇区的**上 IKS 带**开始填充（inset iii）；大 ΔV（区域 B）↓ 扇区**下 IKS 带**开始填充（inset v）；ν > ν*（区域 C）两扇区下 IKS 带等占据（inset vi）（L561–573 caption+正文）。
- 抑制区解释：**超导抑制区 = 有效自旋极化峰值的楔形区（区域 A）= Fermi 面落在上 IKS 带的区域** → 上带占据"不利于强超导形成"（L586–588）。区域 A/B 单有效自旋味 → 只允许奇宇称配对；区域 C 双有效自旋味 → 偶、奇宇称皆可（L574–577）。
- 配对猜测（conjecture）：右穹顶（区域 C）= 稳健 nodeless 偶宇称配对（inter-effective-spin，比 intra- 更稳健）；左穹顶（区域 B）= 较弱 nodal 奇宇称配对；左穹顶的配对对称性是右穹顶的子集 → 右穹顶 Tc 更高自洽（L583–595）。修正时间反演 𝒯̃ = exp(iΔϕIVC·s_zτ_z)𝒯 给出**广义 Anderson 定理**：𝒯̃ 保持的无序（摩尔尺度无序）不破坏能隙 → 右穹顶对摩尔尺度无序稳健、左穹顶不稳健（L712–728; 与 MATBG Kramers-IVC 的 Anderson 定理 ref 52 不同，L733–737）。
- 可检验预言：假设谷间反铁磁 Hund 耦合（ref 43）→ 有效自旋极化 = 两谷相反自旋极化。**未来实验**：衬底诱导自旋轨道耦合 + 位移场方向控制，应 favor 区域 A、disfavor 区域 C → 右穹顶收缩（L597–606）。

## 3. 实验方法

### 3.1 器件（Methods）📜Q
干法转移（dry transfer）：单层石墨烯/hBN 在 SiO2/Si 上剥离，选 hBN 10–50 nm（L676–677）；用 AFM 针尖把大单层石墨烯预切成三块（而非用 hBN 切）以降应变（L679–680）；自制 PC/PDMS 依次拾取：顶石墨 ~100 °C → 顶 hBN ~70 °C → 第一层石墨烯 50 °C → 微台旋转 **1.6°–1.65°** 拾第二层 → 转回原位拾第三层 → 底 hBN/窄底石墨（L683–690）；Hall bar 由电子束光刻 + 反应离子刻蚀定义，5 nm/60 nm Cr/Au 一维接触（L692–694）。正文主器件 Trilayer0，其余 ZK33/Trilayer11 数据在 SI（L167–168）。

### 3.2 静电学与转角标定（推导见通用方法；本文数值在此）📜Q
n = (CtgVtg + CbgVbg)/e；满带密度 Nf = 8θ²/(√3a²)，a = 0.246 nm（L709–711）；利用 ν ≈ 0 处 nH = n 定底栅绝对电容（L714–716），由 Fig. 1b 的满带 Vbg(full) 反推转角 **1.54° = 作者所称 TTG 魔角**（L719–720）。Hall 密度用反对称化 Rxy = (Rxy(B)+Rxy(−B))/2（L707–708）。双栅（两台 Yokogawa GS200）独立控制 n 与 D（L700–702）。

### 3.3 测量
稀释制冷机基温 100 mK；温度依赖在 3He 冰箱做（L697–698）；标准锁相 10 nA a.c. @ 17 Hz，电压信号放大 100 倍（L699–703）。Tc 定义：Rxx(T) = x·Rxx(normal)，x = 10%，正常态电阻由高温段线性拟合 Rxx(normal) = AT + B 外推（左穹顶正常态非线性但仍用同法，L723–728）；误差带用 x = 6%/14% 评估（L735–737）。ξGL：Tc/Tc0 = 1 − (2πξGL/Φ0)B 线性拟合，Φ0 = h/2e；ξGL vs ν 曲线在 SI（Supplementary Fig. 9），正文无数值（L729–737）。面内磁场：8T–2T–2T 三轴磁体 + Bz 补偿标定（L674–687）。

### 3.4 理论计算（Methods）📜Q
非相互作用能带 = 三层推广的 Bistritzer–MacDonald 连续模型（ref 44）；栅屏蔽库仑相互作用走自洽 HF（详见 ref 39）；参数 d = 25 nm、εr = 20、θ = 1.56°、单轴应变 ε = 0.15%（沿 x 轴，x ⊥ 部分 C–C 键）（L693–695）。两个器件特征判为应变证据：电荷中性点无强绝缘 + ν = −2 处二重朗道扇简并（未计入应变的理论模型无法复现）（L700–703）。HF 在 10 × 10 动量网格上做、插值到 50 × 50 网格构 Fermi 面（L704–705）。𝒯̃ = exp(iΔϕIVC s_z τ_z)𝒯；数值上区域 C 小范围内 𝒯̃ 破缺态可与 IKS 竞争，但 IKS 在区域 C 大部稳健（L712–713, L729–732）。

## 5. 主要结论

1. **MATTG 空穴侧存在位移场可调的双穹顶超导**（作者称 direct observation，摘要 L23–24）；分裂点 ν* ≈ −2.6 两侧超导强度、上临界场、温度行为、I–V 磁滞、正常态 R–T 均不同（📜Q，§2.2–2.3）。——作者强度：报告/指示（report/indicate），非 prove。
2. **电子侧超导弱且仅类双穹顶**（📜Q，L245–246, L349–350 + SI）。
3. **关联态（ν = −2）与超导态独立、可能竞争**：B 诱导关联态的同时压制超导（📜Q，L257–265，作者用 demonstrate）。
4. **位移场经"Dirac–平带杂化"调控穹顶数目**：单→双→单的演化与杂化强度锁步（📜Q，§2.4）；但杂化非唯一作用变量（带宽/相互作用同变，作者明言未完全理解，L498–501）。
5. **正常态为 IKS + 有效自旋结构决定配对约束（理论）**：超导抑制区 = 自旋极化楔形（上 IKS 带占据）；猜测右穹顶 nodeless 偶宇称（inter-effective-spin、𝒯̃ 保护）、左穹顶 nodal 奇宇称（📜Q，作者用 conjecture/conjecture；§2.5）。

## 6. 局限与未解决

- **单一主器件定量**：正文定量基本来自 Trilayer0；ZK33/Trilayer11 在 SI，本文无从核对其数值（⚠️ SI 未精读）。
- **全文无误差棒**：Bc/Ic/Tc 为 "could be/around/up to" 式单值；Tc 依赖操作定义（x = 10%）；ξGL 数值只出现在 SI，正文无法做 dome 间 ξGL 定量对比（而 ref 11 报道的 ν = −2.6 处 ξGL 突变是外部工作）。
- **配对机制是猜测而非测量**：偶/奇宇称、nodeless/nodal 均来自"正常态 HF + 自洽性论证"，无相敏测量；磁滞/能隙形状是间接代理。
- **ν* 抑制的两解释未判别**：竞争序 vs 两穹顶超导本质改变（作者并列提出，L265–269）；HF 楔形区给出支持后者的正常态机制，但实验未直接观测该楔形序（无 ν* 处自旋/能带直接证据）。
- **杂化 vs 带宽混淆**：D 同时改变杂化、带宽与相互作用，作者自认杂化的作用"remains to be fully understood"（L498–501）——对导师"可调性来源"因果链是重要限定。
- **无 Fraunhofer/无相敏探针**：排除了网络伪影，但也意味着没有对配对对称性的直接检验；自加热排除依赖跨论文 STM 能隙形状论证。
- **面内场/Pauli 极限**：面内场仅方法提及（三轴磁体补偿），正文无 B∥ 依赖数据 → 无 Pauli 极限违背类信息。
- **关闭世界假设**：现象学结论在"本器件 + 本转角（≈1.54°，靠近魔角）"上成立；应变存在性由 HF 拟合推断（💭I：正文以两个输运特征"strongly indicate"应变，L700–703）。

## 8. 对后续研究的影响

1. **把"位移场"确立为超导穹顶结构的控制轴**：后续理论需解释为何穹顶数目在杂化强度窗口内"单→双→单"。
2. **给出正常态 IKS 相图的实验锚点**：有效自旋极化楔形 ↔ 超导抑制区，为 HF/更高级多体计算提供 ν–D 平面的可对标目标（区域 A/B/C 的 Fermi 面占据图像）。
3. **配对机制的可证伪预言**：𝒯̃-Anderson 定理 → 右穹顶抗摩尔尺度无序；SOC + D 方向实验应缩小右穹顶——这是罕见的、可直接检验的预言（L597–606）。
4. **为"双穹顶=两种配对"谱系提供 moiré 新成员**（引言列出的 cuprate/重费米子/铁硫族/kagome 皆有双穹顶，L36–43）：MATTG 或可成为在单一可调平台内研究 competing order 与配对对称性转变的载体。
5. 对计算侧：ε = 0.15% 应变 + d = 25 nm + εr = 20 是复现实验的 HF 参数模板；ν* = −2.6、VHS ∈ (−4,−3)、reset @ ±2/1/3 是能带/相互作用模型必须复现的特征清单（→ §9）。
