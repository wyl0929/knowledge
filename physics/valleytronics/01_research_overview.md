# 01 Research Overview / 研究总述报告

Last updated: 2026-09-02

## 0. 阅读定位

这篇文档是谷电子学/QVH field pack 的主报告。它不是正式综述，也不是 registry/gap/project 的替代品；它的任务是把结构化材料改写成一篇能从头读到尾的领域入门报告：先建立直觉，再建立版图，最后走到边界和用户切入点。

## 1. 一句话理解这个方向

- **初学者版一句话**：石墨烯有两个"镜像"的谷（K 和 K′），加电场把它们不对称地掰开，两个谷会各自带上一股反向的"几何涡旋"——净电流是零，但把两个谷分开看，各有一股不抵消的横向流，而且这股谷流在平滑扰动下很难被打散。谷电子学就是把这个"谷"当成可编码、可输运、可探测的自由度。

- **研究者版一句话**：量子谷霍尔效应（QVH）是时间反演对称下、以谷为内部量子数的能带拓扑现象——总霍尔电导 $\sigma_{xy}=0$，但单谷谷陈数 $N_\nu=\pm1$ 非零，畴壁两侧谷陈数跳变 $\Delta N_\nu=\pm2$ 束缚出谷锁定的螺旋边界态；谷电子学把这套现象用于谷流产生、检测与保护。

## 2. 这个方向在更大链条中的位置

```text
上游：二维材料 + 破反演对称场/堆垛（开隙）
  -> 抽象模型：单谷 Berry 曲率 / 谷陈数 N_ν
  -> 本领域核心环节：谷陈数跳变 → 畴壁边界模；intervalley 背散射抑制 → 谷保护
  -> 工具/实验/指标：STM LDOS、FT-STM QPI、谷霍尔输运、Kubo-Bastin
  -> 下游系统表现：谷流器件、谷阀、无耗散（软）输运通道
```

这一层之所以不可跳过，是因为"能带几何"与"谷选择性输运"之间隔着两件事：一是谷陈数如何转成边界模（体-边对应），二是这些边界模到底有没有被保护（散射陈述）。把这两件事讲清，才能判断"畴壁态能否当器件用"。

## 3. 它不只是 X：先纠正常见误解

1. **它不是 QHE 的"零场版"**：QHE 靠磁场破时间反演，总 $\sigma_{xy}$ 严格量子化；QVH 保持时间反演，总 $\sigma_{xy}=0$，只有谷分辨电导非零。把两者混为一谈，会去算一个恒为零的总霍尔电导。
2. **它的畴壁态不是"手征"而是"螺旋"**：helical 是谷锁定、反向传播（K 前进 K′ 后退），保护弱于 chiral（单向）。摘要常误写 "chiral 1D states"。
3. **"看到畴壁态"不等于"证了保护"**：存在性（STM LDOS、输运有通道）是平衡陈述；保护是散射陈述。观测到形态一致只是"必要 + 一致"，不是充分。
4. **"谷保护"不是免死金牌**：它只挡平滑势，靠的是动量失配；原子尺度的缺陷是白谱，一个就够打开 intervalley 散射、破坏保护。

## 4. 主流路线谱系

谱系按"内部量子数"和"证据强度"两条轴组织（详见 `12_field_map.md` 第 5 节）。四条方法族：

### 路线 1：谷陈数框架（成熟）

**它是什么**：用单谷 Berry 曲率积分给畴壁态"编号"。gapped 双层单谷谷陈数 $N_\nu=-\nu\,\mathrm{sgn}(\Delta)=\pm1$，畴壁跳变 $\Delta N_\nu=\pm2$，束缚每谷每自旋 2 条边界模。

**为什么重要**：它是所有通道计数与器件设计的定义基础。

**常见方法/工具**：两带/四带连续模型、紧束缚 + Fukui-Hatsugai-Suzuki 离散积分。

**成熟度**：mature（双层）。

**局限**：谷陈数依赖谷守恒，不是严格拓扑不变量；armchair 边界、原子缺陷可使其失效。

**和用户背景的关系**：tbplas 可直接对标（ZMM 2013 LSW 每谷 2 模是现成 benchmark）。

### 路线 2：谷输运（双层成熟 / 三层 emerging）

**它是什么**：谷流如何产生、检测。谷霍尔电导 $\sigma_{xy}^V=N_\nu e^2/h$（谷守恒近似），总 $\sigma_{xy}=0$。

**为什么重要**：谷电子学器件的核心指标。

**常见方法/工具**：s-SNOM 可视化（Ju 2015）、纯谷流产生/检测（Shimazaki 2015）、栅控畴壁输运（Li 2016）。

**成熟度**：mature（双层）/ emerging（trilayer）。

**局限**：谷不守恒 → 谷霍尔电导无法严格量子化。

**和用户背景的关系**：数值上需谷分辨 Kubo-Bastin（G-003）。

### 路线 3：谷保护（active frontier）

**它是什么**：intervalley 背散射是否被抑制、在什么条件下失效。

**为什么重要**："protected" 一词是否成立，全看这一层。

**常见方法/工具**：FT-STM 散射空间判据（Verbakel 2021）、螺旋网络模型。

**成熟度**：active frontier。

**局限**：唯一直接证据是 E13 FFT（间接、局域探针）；级④抗无序量化未闭环。

**和用户背景的关系**：TBPM 算 LDOS → 2D FFT 可直接对标 E13 判据。

### 路线 4：泛化 trilayer/TMD（emerging）

**它是什么**：三层（ABC/ABA）与 TMD 的谷物理。三层每谷预计 3 模，但谷陈数约定（$C_v=\pm3$ vs $N/2$ 半整数）待核。

**为什么重要**：TMBG 是本 field 的第二个服务对象。

**成熟度**：emerging。

**局限**：无三层直接实验；ZMM 2013 明言 ABA 三层谷陈数难定义。

**和用户背景的关系**：纯文献核对先行（Chen 2021 / Phong 2026），数值后置。

## 5. 领域已经做到什么程度

| 层面 | 已经成熟的内容 | 仍然不足的地方 | 对新项目意味着什么 |
|---|---|---|---|
| 算法/方法 | 谷陈数分类、单谷谷陈数解析、总电导 Kubo-Bastin | 谷分辨电导、无序下谷投影 | 谷分辨读出是首个要打通的工具 |

| 实验/benchmark | 双层畴壁存在性（E9）、谷保护 FFT（E13） | 三层畴壁、级④抗无序量化 | 计算侧是空档 |
| 系统级应用 | 谷流检测（Shimazaki） | 谷阀器件（Phong 2026 预印本）、无耗散输运 | 器件化尚早，先做基准 |

## 6. 代表性工作、研究组与工具生态

**理论主线**：MacDonald（UT Austin）贯穿 valley-Hall kink → 谷陈数分类 → 螺旋网络；Zhang-MacDonald-MeLe 2013 PNAS 是"罗塞塔石碑"；San-Jose & Prada 2013 是螺旋网络奠基；Guinea/Fal'ko/Koshino 各自在应变、非手征畴壁态、moiré 边缘态上延展。

**实验主线**：Ju 2015（Feng Wang 组，s-SNOM）开创性地可视化畴壁谷输运；Huang 2018（LeRoy 组，STM）给出 mTBG 双线螺旋态的突破性观测；Verbakel 2021（Zandvliet 组，室温 FT-STM）给出谷保护的唯一直接证据。这些实验组谱系见 `13_actor_map.md`。

**工具生态**：用户已有 tbplas + Kubo-Bastin + TBPM（见 `15_tool_registry.md`），是谷陈数/谷保护数值对标的现成方法栈。

## 7. 当前领域最关心的问题

领域正从"能看到畴壁态"（2015–2018）走向"能证明并量化保护"（2021–现在）。上一阶段的指标——"看到态 + 形态一致"——已经不够，因为它推不出保护。新问题是如何把"保护"从间接 FFT 判据推进到"抗无序 + 量化输运"的直接证据，以及如何把双层结论可靠地推广到三层/TMD。现有方法（FFT、输运）各只能覆盖证据阶梯的一级，尚无单一实验/计算能同时闭合"存在性 + 谷保护 + 抗无序量化"。

## 8. 主要困难与瓶颈

### 瓶颈 1：谷保护的级④未闭环

**普通话解释**："保护"最硬的证据——态在有缺陷下还活着、电导还量化——没人做出来。

**为什么难**：输运级谷分辨测量难；无序建模 + 量化判据的精度门槛高。

**已有 workaround**：E13 FFT（级③，间接）。

**最小验证**：双层畴壁 + 受控缺陷密度的电导退化曲线（计算侧）。

**证据状态**：confirmed（级④两侧空白）。

### 瓶颈 2：谷不守恒 → 谷霍尔电导无严格量子化

**普通话解释**：谷霍尔电导只在"谷不翻"的近似下才量子化，现实中翻谷总有，所以没有 QHE 式的精确平台。

**为什么难**：谷不是守恒量子数，定义本身有歧义。

**已有 workaround**：用"有/无"判据（FFT）而非精确值。

**最小验证**：谷分辨 σ_xy^V 随 intervalley 散射强度的偏离曲线。

**证据状态**：source_checked（是定义边界，非可填缺口）。

### 瓶颈 3：三层约定悬空

**普通话解释**：三层谷陈数写 ±3 还是半整数，没人钉死，无直接实验。

**为什么难**：ZMM 明言 ABA 三层谷陈数难定义。

**已有 workaround**：先做文献核对（Chen/Phong 原文）。

**最小验证**：grep 原文约定。

**证据状态**：suspected。

## 9. 入门者最重要的理解框架

```text
内部量子数：谷（QVH，软保护） <-> 自旋（QSHE，软保护） <-> 总电荷（QHE，强保护）
证据强度：存在性 -> 形态一致 -> 谷保护(FFT) -> 抗无序量化(未闭环)
平台：双层 AB/BA（成熟） -> 三层 ABC/ABA（emerging） -> 单层/TMD（材料泛化）
```

读任何一篇 QVH 论文时，先问三件事：它的拓扑不变量是哪个内部量子数？它的证据落在阶梯的哪一级？它做的是双层还是三层？

## 10. 和用户背景的连接

- **最匹配的用户资产**：tbplas + kubo_bastin.h + TBPM（紧束缚输运全栈）。
- **最值得优先看的子方向**：谷陈数框架 + 谷保护（都有现成 benchmark 与可复现参数）。
- **最可能重复造轮子的方向**：双层畴壁存在性/形态（E9/E1 已充分覆盖）。
- **第一周最小动作**：code audit 谷分辨能力 + 均匀 gapped 双层算单谷谷陈数 ±1。
- **一个月内可形成的 MVP**：谷分辨读出打通 + AB/BA 畴壁每谷 2 模复现（见 `23_mvp_experiment_plan.md`）。

## 11. 初步候选方向

1. **双层畴壁谷陈数/软保护数值对标**（P-001，priority）：先打通谷分辨读出，再复现每谷 2 模 + 单缺陷 FFT 软保护。baseline = ZMM 2013 LSW / E13 三对照；指标 = 单谷谷陈数 ±1、边界模数、FFT 斑有/无；风险 = 谷投影方法；止损 = 投影不稳则改路线。
2. **三层 C_v 约定核对**（P-002）：grep Chen 2021 / Phong 2026 原文，钉死三层约定。baseline = ZMM $C_K=N/2$；指标 = 三层通道数一致性；止损 = 核对不出则标 NEEDS_VERIFICATION。
3. **谷霍尔电导偏离度基准**（P-003，低优先级）：谷分辨 σ_xy^V 随散射强度的偏离曲线。止损 = 无良定义指标则标 not-a-gap。

## 13. 小结：边界在哪里，下一步验证什么

- 内圈：QVH 总 σ_xy=0、每谷谷陈数 ±1、每谷每自旋 2 模、谷保护是软保护。
- 中圈：ZMM 分类、螺旋网络模型、E9 LDOS、E13 FFT、Kubo-Bastin。
- 边界：级④抗无序量化（B-001）、三层约定（B-002）、谷分辨读出（B-003）。
- 用户切口：从谷分辨读出打通，走 P-001 计算对标。
- 下一步验证：先 code audit 谷分解能力（C-007），再算单谷谷陈数 ±1。

## 14. 边界与风险

- 未核验：三层 $C_v$ 约定与谷保护软性（C-006，NEEDS_VERIFICATION）；谷分辨 Kubo-Bastin 现状（C-007）；Chen 2021 期刊/DOI。
- suspected gap：G-002（三层）、G-003（谷分辨读出）。
- 不应过度声称：谷霍尔电导严格量子化；三层已证；谷保护 = 无耗散。
- 来自用户资产而非领域事实的判断：priority project 定在"计算对标"而非"新物理"，是资产匹配结论，非领域结论。
