## 3. 边界：当前真正卡住的问题

### Boundary Question B-001：谷保护的级④（抗无序 + 量化输运）能否闭合？

**一句话解释：** "protected" 最硬的证据——态在有缺陷/无序下存活且电导量化——至今实验与数值都缺。

**为什么重要：** 级④是"谷保护是否真能用"的定论证据；缺了它，"protected" 只能是理论进口标签。

**已有工作做到哪里：** E9（存在）、E10/E12（弹道/相干）、E13（FFT，级③）。

**还不清楚什么：** 缺陷浓度 → intervalley 散射 → 输运退化的定量曲线；局域化阈值。

**为什么难：** 输运级谷分辨测量难；无序建模 + 量化判据的数值精度门槛高。

**最小验证：** 双层畴壁 TB + 受控缺陷密度，算畴壁电导退化曲线，看是否存在 ~4e²/h 平台（计算侧）。

**证据状态：** confirmed（作为 gap：级④两侧空白）。

### Boundary Question B-002：三层（ABC/ABA）谷陈数约定与谷保护是否同构双层？

**一句话解释：** tMBG 谷陈数写 ±3 还是 $N/2$（半整数）？trilayer 谷保护是否还"软"？

**为什么重要：** TMBG 是本 field 第二个服务对象；约定不定，三层项目悬空。

**已有工作做到哪里：** Chen 2021、Phong 2026（理论/预印本）；无直接实验。

**还不清楚什么：** 三层每谷通道数、谷陈数约定、谷保护失效方式。

**为什么难：** ZMM 明言 ABA 三层谷陈数难定义；无实验对标；三层体系算力压力大。

**最小验证：** Chen 2021 / Phong 2026 原文 pdftotext+grep 核约定（先文献后数值）。

**证据状态：** suspected（NEEDS_VERIFICATION）。

### Boundary Question B-003：谷分辨电导的数值读出

**一句话解释：** 现有 Kubo-Bastin 算总电导；谷分解是否现成未知。

**为什么重要：** 它是 B-001 计算侧与谷霍尔电导数值的前置。

**已有工作做到哪里：** 总电导 Kubo-Bastin 已可用。

**还不清楚什么：** 谷投影方法（k 窗口 vs 实空间谷算符）在无序下是否稳定。

**为什么难：** 无序破坏平移对称 → k 窗口模糊。

**最小验证：** 均匀 gapped 双层算单谷谷陈数 = ±1。

**证据状态：** suspected（NEEDS_VERIFICATION，code audit 后定）。

## 6. 三条下一步路线

### Route A：保守路线（先打通谷分辨读出）

- 目标：P-001 第一阶段（单谷谷陈数 = ±1）。
- 第一周动作：code audit + 均匀双层 TB + 谷投影 + 单谷谷陈数。
- 成功信号：$N_K=\mp1$、$N_{K'}=\pm1$、Δ 反号符号反号。
- 止损信号：1 月内投影不稳定 → 改实空间谷算符或退回 k 分类。

### Route B：中等路线（读出一条边界 → 数值对标）

- 目标：P-001 第二阶段（AB/BA 畴壁每谷 2 模）+ P-002（三层约定核对）。
- 第一周动作：Route A 打通后，做畴壁超胞边界模计数；并行 grep Chen/Phong 原文。
- 成功信号：隙内每谷 2 模复现；三层约定定稿或明确标 NEEDS_VERIFICATION。
- 止损信号：畴壁边界模数≠2 且排 bug 无果 → 停在读出层，不发散。

### Route C：激进路线（直接啃级④抗无序量化）

- 目标：G-001 完整（畴壁电导 vs 缺陷密度退化曲线）。
- 第一周动作：Route A/B 打通后，加受控缺陷密度扫描。
- 成功信号：低缺陷密度下 ~4e²/h 平台 + 阈值。
- 止损信号：谷标签在无序下失效 → 标 C-007 blocked，退回 Route B。
