## 缺口条目

### G-001：谷保护证据阶梯第④级（抗无序 + 量化输运）未闭环

**所在领域位置：** 谷保护（evidence ladder）。

**人话解释：** 大家都说畴壁态"受拓扑保护"，但"保护"最硬的证据——在有缺陷/无序下态仍存活、电导量化——至今没人做出来。现有证据最强只到"FFT 无 intervalley 斑"（间接、局域探针）。

**现有工作做到哪里：** E9（存在性+形态）、E10/E12（弹道/相干）、E13（谷保护 FFT，级③）。

**已解决的部分：** 存在性、形态一致、intervalley 背散射抑制的显微证据。

**关键假设：** 谷保护 = 抗无序量化输运；FFT 证据可外推到器件级输运。

**仍然不清楚的问题：** 缺陷浓度 → intervalley 散射 → 输运退化的定量关系；畴壁态在有限无序下的局域化阈值。

**现有逻辑链条哪里承重不足：** "FFT 无斑（级③）" 到 "器件级抗无序量化输运（级④）" 缺一环：局域探针散射证据 ≠ 非局域输运量化。

**为什么重要：** 级④是"谷保护是否真能用"的定论性证据；缺了它，"protected" 只能是理论进口标签。

**为什么困难：** 输运级谷分辨测量难（谷不守恒）；无序建模 + 量子化判据的数值实现有精度门槛。

**与用户资产的关系：** 强——用户有 tbplas/Kubo-Bastin + TBPM，可做"畴壁态在无序下的输运/局域化"数值，正是级④的**计算侧**（非实验侧）。

**可行性：** 1–3 月（数值侧）。

**证据状态：** confirmed（作为 gap：级④的实验与数值都缺，可直接查证）。

**最小验证实验：** 在 gapped 双层畴壁 TB 模型中加受控点缺陷密度，算畴壁通道电导随缺陷密度的退化曲线，看是否存在"谷保护平台"（电导在低缺陷密度下保持 ~4e²/h 直到阈值）。

**对比基线：** ZMM 2013 LSW（无缺陷 4e²/h）+ 单缺陷破坏谷保护的 Verbakel 2021 机制。

**评价指标：** 畴壁电导 vs 缺陷密度；局域化长度；intervalley 散射率。

**风险：** 若数值无法分辨"谷保护平台"与"普通 1D 态"，需先做谷分辨投影（G-003）。

**止损条件：** 若 3 个月做不出稳定的谷分辨输运读出，降级为"先做 G-003 谷分辨读出"。

**优先级：** 高。

### G-002：三层（ABC/ABA）$C_v=\pm3$ 约定与谷保护待核

**所在领域位置：** 泛化 trilayer。

**人话解释：** 三层畴壁（tMBG）的谷陈数到底该写 ±3 还是别的、畴壁有几条通道、谷保护是否还"软"，目前没有直接实验，理论约定也不一致。

**现有工作做到哪里：** Chen 2021（tMBG 关联+拓扑态）、Phong 2026（菱方畴壁谷阀）为理论/预印本；无三层畴壁输运/STM 直接实验。

**已解决的部分：** 双层 AB/BA 的谷陈数约定已定稿（C-002）。

**关键假设：** 三层谷陈数 $C_v=\pm3$、每谷 3 模；谷保护软性同双层。

**仍然不清楚的问题：** 三层每谷通道数是 3 还是别的；谷陈数是 $N/2$ 半整数约定还是"每谷 N 模"约定；trilayer 谷保护失效方式。

**现有逻辑链条哪里承重不足：** [PHY-BERRY] 直接写 $C_v=\pm3$，但 ZMM 2013 对 chirally-stacked N 层给 $C_K=N/2$（N=3 半整数）且明言"ABA 三层谷陈数无法定义"——两者对不上。

**为什么重要：** TMBG 是本 field 的第二个服务对象；不确定约定就无法设计三层数值/实验。

**为什么困难：** 三层体系 TBPM 规模压力更大（M≤2560）；无直接实验可对标。

**与用户资产的关系：** 中——用户有三层石墨烯平台 field（multilayer_graphene/subfields/tmbg），但本 gap 是理论约定核对 + 数值对标，非新实验。

**可行性：** 1 月（文献核对）+ 3 月（数值对标，若算力允许）。

**证据状态：** suspected（NEEDS_VERIFICATION）。

**最小验证实验：** 用 Chen 2021 / Phong 2026 原文 pdftotext+grep 核三层 $C_v$ 约定与通道数表述；再决定是否做三层畴壁 TB 计算。

**对比基线：** ZMM 2013 的 $C_K=N/2$ 公式。

**评价指标：** 三层每谷通道数的理论/数值一致性。

**风险：** 若原文未明写约定，只能标 NEEDS_VERIFICATION 并退回双层。

**止损条件：** 核对不出约定 → 标记为 open question，不强行做三层数值。

**优先级：** 中。

### G-003：谷分辨 Kubo-Bastin 读出缺失（工具层）

**所在领域位置：** 谷输运 / 工具。

**人话解释：** 现有 kubo_bastin.h 算的是总电导；要算"谷霍尔电导"或"谷分辨输运"，得先把哈密顿量/观测量投影到 K/K′ 谷子空间——这一步是否现成未知。

**现有工作做到哪里：** QHE field 的 Kubo-Bastin（总 σ_xx/σ_xy）已可用；谷分解未见登记。

**已解决的部分：** 总电导的线性标度 Kubo-Bastin。

**关键假设：** 谷子空间投影在无序下仍良定义（弱无序 + 谷间散射弱）。

**仍然不清楚的问题：** 投影方法（k 空间谷窗口 vs 实空间谷算符）；无序下谷标签的稳定性。

**现有逻辑链条哪里承重不足：** G-001 的"谷保护平台"数值判据依赖谷分辨读出；读不出就做不了级④计算。

**为什么重要：** 它是 G-001 和谷霍尔电导 MVP 的前置依赖。

**为什么困难：** 无序破坏平移对称 → k 空间谷窗口模糊；需实空间谷算符或谷投影的近邻定义。

**与用户资产的关系：** 强——用户有 kubo_bastin.h + tbplas，这是纯代码/方法问题。

**可行性：** 1 月（code audit + 最小实现）。

**证据状态：** suspected（NEEDS_VERIFICATION：需 code audit 确认）。

**最小验证实验：** 在均匀 gapped 双层上实现谷投影，算单谷谷陈数，与解析 $\pm1$ 对标。

**对比基线：** 解析 $N_\nu=\pm1$、ZMM 2013 LSW 每谷 2 模。

**评价指标：** 单谷谷陈数数值 vs 解析值；谷投影在弱无序下的稳定性。

**风险：** 无序下谷标签退化，投影失效。

**止损条件：** 若弱无序下谷投影已不稳定，改做"动量空间谷分辨"或"谷极化算符"替代。

**优先级：** 高（是 G-001 的前置）。

### G-004：谷霍尔电导无严格量子化的定量基准缺失

**所在领域位置：** 谷输运。

**人话解释：** 谷霍尔电导只在谷守恒近似下量子化；"偏离量子化的程度"没有一个定量数值基准可对标。

**现有工作做到哪里：** Shimazaki 2015（纯谷流）、Su 2015（非局域谷霍尔）；均定性/半定量。

**已解决的部分：** 谷流可产生、可检测。

**关键假设：** 谷霍尔电导的软量子化程度可用数值刻画。

**仍然不清楚的问题：** intervalley 散射如何定量偏离 $\sigma_{xy}^V=N_\nu e^2/h$。

**为什么重要：** 若能量化"偏离度"，谷电子学器件的性能就有了可比较的指标。

**为什么困难：** 谷不守恒 → 无守恒流 → 定义本身有歧义。

**与用户资产的关系：** 中（需先过 G-003）。

**可行性：** 3 月（在 G-003 之后）。

**证据状态：** weak（边界多于 gap，可能是"本领域定义边界"而非可填补缺口）。

**最小验证实验：** 在 gapped 双层加受控 intervalley 散射，算 $\sigma_{xy}^V$ 随散射强度的偏离曲线。

**对比基线：** 谷守恒极限 $\sigma_{xy}^V=N_\nu e^2/h$。

**评价指标：** 偏离度 vs 散射强度。

**风险：** 定义歧义导致无法复现。

**止损条件：** 若 3 个月无法给出良定义指标，标为 not-a-gap（是定义边界）。

**优先级：** 低。
