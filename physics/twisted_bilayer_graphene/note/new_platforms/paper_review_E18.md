## 1. 核心贡献

STM/STS 结合应变调控 mTBG。展示应变作为调控 mTBG 畴壁拓扑态的自由度——应变改变 moire 周期和畴壁网络几何，进而调制畴壁 LDOS。这是应变电子学方向的重要实验进展。

## 2. 物理机制 / 实验方法

- 低温 STM/STS + 原位应变装置
- 应变通过弯曲衬底或压电驱动器施加
- 追踪同一区域在递增应变下的结构 (moire 周期) 和电子 (LDOS) 变化
- 应变范围 ~0-0.5%

## 3. 关键结果

1. 应变 ~0.3% → moire 周期变化 ~5% → 畴壁密度改变
2. 畴壁 LDOS 随应变连续可调——证实应变调控畴壁态
3. 应变方向依赖：单轴 vs 双轴应变产生不同的网络重构
4. 应变可逆——弹性范围内畴壁网络恢复

## 4. 局限与开放问题

- 应变范围受限于样品断裂 (~0.5%)
- STM 扫描范围有限 (~100 nm)——仅覆盖部分网络
- 未同时做输运——结构-电子关联 vs 输运的桥未建立

## 5. 与用户研究的相关性

- TBPM 可引入应变 → 计算应变依赖的畴壁输运 → 对标本文 STM 结果
- 若 DW 项目探索应变调控，本文是实验基准

## Phase S 补充 (2026-08-11): Q1/Q2/Q3

### Q1: edge state 实验上如何表征?
STM/STS + 原位应变调控。核心可观测量：应变依赖的 moire 周期和畴壁 LDOS 调制。通过应变梯度线上的拓扑态 vs 均匀区体态区分边缘 vs 体。应变可连续调控畴壁态——验证应变作为外部调控自由度。
