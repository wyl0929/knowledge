## TL;DR

**本文想解决的理论问题**：带隙 BLG 的堆叠畴壁（AB↔BA）通常只在**保持子格对称性**（无原子缺陷）时预言承载拓扑隙态；含原子尺度拓扑缺陷（五边形-八边形）的**晶界**是否必然杀死拓扑隙态？

**主结果**：① **推翻"原子缺陷 → 谷间散射 → 拓扑态消失"的直觉**：在顶层含 8-55（八边形-双五边形）缺陷线的 BLG 晶界上，尽管缺陷混合子格（子格对称性不守恒），**拓扑保护隙态仍存活**——每栅压极性下总有**一条**保持纯拓扑特征的态（$V>0$ 时 S1，$V<0$ 时 S4，均连接价带与导带连续区）📜Q；② **隙态数目依赖栅压极性**：$V=+0.3$ eV 有 3 条（D 平带、S1 拓扑、S2-D 杂化），$V=-0.3$ eV 有 2 条（D-S3 杂化、S4 拓扑）→ 栅压反转产生**不对称电导**（差一个电导量子 $2e^2/h$）📜Q；③ **杂化选择定则**：同层 + 同（连接/非连接）子格 → 强杂化；拓扑态（S1/S4）与缺陷带 D 子格分布正交 → 不杂化、保持拓扑特征 📜Q。

**结论/意义**：把拓扑保护畴壁态的存在区间从"无缺陷畴壁"拓宽到"**含原子缺陷的晶界**"——解释了真实 CVD 样品中仍观测到导电通道的原因，并预言栅压极性控制的电导不对称可做**电开关**。⚠️ 全文为紧束缚计算 + 预言，作者用词 demonstrate / show / propose / should be detectable，非实验验证。

## 1. 模型白箱（理想系统 + 假设清单）

### 1.1 哈密顿量

单轨道最近邻紧束缚 📜Q：

$$
H=-\sum_{\langle i,j\rangle}\gamma_{i,j}\,c_i^\dagger c_j+\sum_i V_i\,c_i^\dagger c_i
$$

- 层内跃迁 $\gamma_0=-2.66$ eV；层间跃迁（仅正对节点）$\gamma_1=0.1\gamma_0=-0.266$ eV 📜Q。
- 栅压 $V=\pm0.3$ eV 加在**底层**（无缺陷层）📜Q；屏蔽效应主要缩小能隙、可视作 $V$ 的标度，不影响隙态全局特征（ref 20）📜Q。
- 体系：上层含 8-55（八边形-双五边形）缺陷线（沿 zigzag 方向），下层完整石墨烯；缺陷线两侧分别为 AB 与 BA 堆叠 → 晶界型畴壁 📜Q。
- 计算 LDOS$(E,k)$ 用 Green 函数匹配法（refs 23–25），晶界方向平移对称 → LDOS 在该方向 $k$ 依赖 📜Q。

### 1.2 参数分册

| 类 | 内容 |
|----|------|
| **自由参数（旋钮）** | 栅压 $V$（±0.3 eV）、能量 $E$、波矢 $k$ |
| **导出量（由旋钮+常数算出）** | 能隙（由 $V$ 与 $\gamma_1$ 开）、缺陷平带 D |
| **模型内部量（解的性质）** | 隙态数目（3 vs 2）、LDOS 层/子格分布、杂化 |
| **固定常数** | $\gamma_0=-2.66$ eV、$\gamma_1=0.1\gamma_0$ |
| **预言量（可检验）** | 栅压极性控制电导不对称（$2e^2/h$ 差）、电开关 |

> 无"反推量 θ̂"层。**符号防混**：$\gamma_0,\gamma_1$ 带负号（紧束缚约定）；连接子格（connected，正对原子）vs 非连接子格（unconnected，六角心）；mixing nodes（五边形共享边两原子）∈ 非连接子格、Z-nodes（zigzag 节点）∈ 连接子格。

### 2.0 总览

| 层 | 论文节 | 输入 | 输出 | 所用假设/定理 | 合法域 |
|---|---|---|---|---|---|
| 前提定理层 | 3 Ingredients（背景成分） | 单层 8-55 缺陷带 D + 无缺陷堆叠畴壁拓扑带 S1–S4 | 两类带的独立特征 | 已有研究（refs 18,19,26–29 / 10） | 无缺陷/单层 |

### 2.1 前提定理层：两类成分的独立特征

- **单层 8-55 缺陷带 D**（Fig. 2(a)）：无限单层含 8-55 边界时，缺陷平带 D 从 $k=0$ 费米能级延伸到 Dirac 点、再在 BZ 边缘升到 0.8 eV 📜Q。Dirac 点左侧的 D 带来自面对面的 zigzag 边缘（经 mixing nodes 连接）📜Q。
- **无缺陷堆叠畴壁拓扑带**（Fig. 2(b)）：栅压 $V$ 下 AB/BA 堆叠畴壁出现拓扑隙态，正压标 S1,S2、负压标 S3,S4；这些态沿边界载谷极化电流，速度符号随栅压反转（ref 10）📜Q。

### 2.2 模型层：含 8-55 缺陷的晶界

- **输入**：上层 8-55 缺陷线 + 下层完整 + 栅压；**输出**：晶界区 LDOS$(E,k)$。
- mixing nodes 混子格 → 顶层两子格无法唯一标记 → 几何挫折（geometrical frustration）📜Q。

### 2.3 推导层：隙态数目与杂化选择定则

- **隙态数目**（Fig. 3）：$V=+0.3$ eV 有 3 条（D 平带钉在 0 eV、S1 拓扑、S2-D 杂化）；$V=-0.3$ eV 有 2 条（D-S3 杂化、S4 拓扑）📜Q。
- **S1/S4 的拓扑特征**：连接价带与导带连续区（标准 AB/BA 畴壁无隙态特征）→ 保持纯拓扑 📜Q。
- **S2-D / D-S3 的杂化**：D 带与 S2（正压）或 S3（负压）杂交，产生混合特征带（对某些 $k$ 呈 D 样、另一些 $k$ 呈 S 样）📜Q。
- **杂化选择定则**（Fig. 4/5）：
  - 正压：D 带（顶导带连续区同局域，主要在顶连接子格）与 S2（顶非连接子格）杂化 → S2-D；S1 主要在**非连接**子格，与 D（连接）**正交** → 不杂化、与 D 平行延伸 📜Q。
  - 负压：D 与 S3 同顶连接子格 → 强反交叉成 D-S3；S4 在底层、两子格都有权重 → 保持拓扑 📜Q。
- **mixing nodes 低能反常大 LDOS**：源于 AB/BA 堆叠畴壁 + 子格挫折的协同（单层 8-55 无此现象）——隙模生活在非连接子格（mixing nodes 处挫折）📜Q。

### 2.4 边界层：电导不对称与电开关

- 隙态数目 3 vs 2 → 沿晶界电导与隙内交叉态数目成正比 → 栅压反转产生**一个电导量子 $2e^2/h$ 的显著变化** 📜Q。
- 晶界方向缺陷周期延伸 → 两谷倒空间分离 → 传播态可无谷间背散射传输 📜Q。
- 预言：此不对称电导特征可在类 ref 15（Ju 2015）装置中检验，并可做**电开关**（栅压符号控制输运）📜Q。

### 5.1 可检验性（预言靶标）

- 栅压反转 → 晶界电导不对称（差 $2e^2/h$），类 Ju 2015 装置可测 📜Q。
