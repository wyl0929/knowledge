## TL;DR

**本文想解决的问题**：能否用 Fabry-Pérot（FP）相位相干干涉作为**非侵入探针**，探测大转角 tBLG 器件的内部势剖面，从而定位并量出**非故意局域掺杂**所定义的隐腔体（hidden cavity）？

**主结果**：① 名义单极（unipolar）区的反常电阻振荡被溯源到**非故意局域掺杂形成的隐腔体**——从次级 Dirac 峰电压偏移提取密度位移 1.8×10¹²（单栅区）/1.6×10¹² cm⁻²（双栅区）📜Q[~]；② **磁输运区分局域腔模与全局共振**——长腔（L≈650 nm）干涉条纹在 |B|≳0.2 T 色散消失（回旋截止），短腔（L≈150 nm）存活到测量上限 0.6 T 之外（理论截止 0.8 T）；Klein 隧穿 π 相移在 50 mT（L≈500 nm）与 70 mT（L≈350 nm）处出现，标度比 50×500/350≈71 mT 自洽 📜Q[~]；③ 用提取的掺杂剖面 ni(x) 做自洽量子电容 + 紧束缚 Landauer-Büttiker 模拟，**复现实验特征**，论证干涉谱学是定位隐缺陷/内部势垒的简单非侵入探针（空间分辨 tens-of-nm 尺度）📜Q。

**结论/意义**：把 FP 干涉从"研究相位相干输运现象"拓展为"**干涉谱学探针**"——在大转角（层间退耦）tBLG 中定位被器件结构掩埋的隐势垒。⚠️ 作者明说提取的掺杂剖面是"highly constrained model"而**非严格唯一解**（not a strictly unique mathematical solution）📜Q。

## 1. 模型白箱（理想系统 + 假设清单）

> 本文研究对象 = 大转角 tBLG 器件（实验）+ 作者自写的**模拟模型**（白箱）。本节写两件事：**写下模型**（§1.1–1.2），**列出它成立的全部假设**（§1.3）。

### 1.1 器件与静电模型（白箱 ①：量子电容模型，SI S1–S9）

**器件几何**（正文 Fig. 1c + SI Fig. S5）：大转角 tBLG 夹在 hBN 中，全局背栅 VBG + 局域顶栅 VTG 把沟道分为单栅区 B、B′（长度 130 nm / 360 nm）与双栅区 T（500 nm），接触区 C。顶/底 hBN 厚度 38/32 nm，SiO₂ 285 nm（ε_SiO₂=3.9），ε_hBN=3.7。

**电容耦合**（SI S1-B，从量子霍尔朗道能级提取）：沿 D=0 线两层等填充，n_tot = 2C_BG V_BG/e；线性拟合得 C_BG = 1.08×10⁻⁴ F/m²，斜率比 C_BG/C_TG = 0.128 → C_TG = 8.87×10⁻⁴ F/m² 📜Q[~]。总载流子密度 n_SG = (C_BG V_BG)/e、n_DG = (C_BG V_BG + C_TG V_TG)/e 📜Q。

**量子电容模型**（SI S4-A，零温零场）：
$$
n(E) = \mathrm{sgn}(E)\frac1\pi\left(\frac{E}{\hbar v_F}\right)^2 \qquad (S1)
$$
本征掺杂 ni 时准费米能 Ei 由 $n_i=\mathrm{sgn}(E_i)\frac1\pi(E_i/\hbar v_F)^2$ 定（S2）。含 N 个栅的自部分电容：$n_G=\frac{\rho_G}{-e}=\sum_{j=1}^N\frac{C_{jG}}{e}(V_j-V_G)$（S3），自洽条件 $n_i+n_G=n(E_i+eV_G)$（S4）。

**两层自洽耦合**（SI S4-B）：大转角两层退耦 → 视为无限平行电容器，层间电容 $C_G=\epsilon_0\epsilon_G/d_G$，取 ϵ_G=1、d_G=0.12 nm → C_G/e = 460.53×10¹⁵ V⁻¹m⁻² 📜Q。顶/底层电势 V_Gt/V_Gb 互为有效栅压，迭代自洽解（S5–S6）。具体器件项（S7–S8）含 C_TG,Gt、C_C,Gt、C_BG,Gb、C_C,Gb。

**非故意掺杂剖面**（SI S4-C，S9）：
$$
n_i(x)=\frac{n_L}{2}\left[\tanh\frac{x-x_1}{d_s}+\tanh\frac{-x+x_2}{d_s}\right]+\frac{n_R}{2}\left[\tanh\frac{x-x_2}{d_s}+\tanh\frac{-x+x_3}{d_s}\right]
$$
光滑参数 d_s=100 nm，位置 x₁=0、x₂=155 nm、x₃=345 nm；优化得 n_L=0.8×10¹²、n_R=1×10¹² cm⁻²（每层）→ 两层求和 2n_L=1.6×10¹²、2n_R=2×10¹² cm⁻² 📜Q[~]。接触诱导 n 掺杂用有效接触电压 V_C=3.35 V（C_C/e=ϵ₀ϵ_hBN/(e d_hBN,b)=0.531×10¹² cm⁻²）📜Q。

### 1.2 量子输运模型（白箱 ②：紧束缚 + Landauer-Büttiker，SI S4-D/E）

**紧束缚 Hamiltonian**（S10）：
$$
H=-\sum_{\langle i,j\rangle}t_{ij}c_i^\dagger c_j+\sum_i V(x_i,y_i)c_i^\dagger c_i
$$
用 scalable 紧束缚（monolayer 石墨烯）：晶格常数 a=a₀·sf（a₀=0.142 nm），最近邻跳跃 t=t₀/sf（t₀=3 eV），保持低能能带不变；横磁 B=(0,0,B) 时跳跃 $t_{ij}=t\,e^{i\phi}$，Peierls 相位 $\phi=(-e/\hbar)\int_{r_i}^{r_j}\mathbf A\cdot d\mathbf r$ 📜Q。sf=8；器件几何 w=514 nm、W=697 nm、l₁=353 nm、l₂=595 nm（SI Fig. S6）。

**Landauer-Büttiker**（S11–S14）：多端散射用波函数匹配法，电导 $G_{kl}=2(e^2/h)T_{lk}$；构 N×N 电导矩阵 G（对角 G_kk=ΣG_kl），Kirchhoff 定律消一端 → 反演 R=G⁻¹；4 点电阻 R_kl,mn=(V_m−V_n)/I_k。零场 2 端用周期边界跳跃法，$G=(W/3\pi\,s_f a_{CC})(g_b+g_t)$，$g_j=(e^2/h)\int_{-k_F}^{k_F}T(k_y)dk_y$，W=700 nm 📜Q。

**FP/Klein 解析要素**（正文 + SI S6）：FP 共振条件 $k_F\cdot 2L=2\pi N$；回旋半径 $r_c=\hbar k_F/eB$；Klein 隧穿透射 $T_\pm(k_{eff})=\exp(-\pi\hbar v_F k_{eff}^2/eE)$、$R_\pm=\mathrm{sgn}(k_{eff})\sqrt{1-T^2}$（S15），$k_{eff}=k_y-\Delta k_y$，$\Delta k_y=eBL/\hbar$ 📜Q。

### 2.1 器件表征 → 电容标定（SI S1）

输入=3 T 朗道能级交叉（层极化 LL 交叉，大转角 tBLG 已知特征）；沿 D=0 线 n_tot=2C_BG V_BG/e → 线性拟合 C_BG=1.08×10⁻⁴ F/m²，斜率 C_BG/C_TG=0.128 → C_TG=8.87×10⁻⁴ F/m² 📜Q[~]。

### 2.2 反常振荡溯源 + 密度/位置提取（正文 §II-A）

- 0 T、2.4 K 的 R(V_BG,V_TG) map 中，**名义单极区**（ppp/nnn）出现反常电阻振荡——单极区本不应有 FP 干涉（FP 需要 p-n 界面）📜Q。次级竖直峰（V_BG≈−20 V）+ 次级对角峰（主脊下方）→ 归因于非故意局域掺杂 📜Q。
- **密度位移**：次级竖直/对角中性点电压偏移 → 1.8×10¹²（单栅区）/1.6×10¹²（双栅区）cm⁻²，量级相当 → 共同掺杂源跨单栅-双栅边界 📜Q[~]。
- **空间定位**：次级竖直峰只依赖 V_BG → 在单栅区；次级对角峰来自双栅区掺杂 📜Q。
- **多接触一致性**（SI S3）：接触对 5–17、2–20 都见同样次级峰 + FP 图案 → 掺杂高度空间相关（非随机点缺陷）→ 系统性（制造相关）📜Q。

### 2.3 FP 腔长提取（正文 §II-A）

FP 相长干涉条件 k_F·2L=2πN → 从竖直条纹间距得 L≈150 nm；B′ 有效长度 ~300 nm → 被分成两段（一 n 一 p）各 ~150 nm，串联腔产生竖直干涉 📜Q[~]。长中央 p 型腔 L≈650 nm（双栅区 T）。三腔串联：B′ 内短 n 腔 + 短 p 腔 + 中央长 p 腔。

### 2.4 磁输运区分局域腔模与全局共振（正文 §II-B）

- **回旋截止判据**：r_c=ℏk_F/eB。长腔（650 nm）条纹在 |B|≳0.2 T 快速色散消失（r_c<腔长 → 轨迹弯曲破坏共振）；短腔（150 nm）存活到更高场 📜Q。
- **Klein π 相移**：零场近正入射近完美透射（Klein）→ 反射弱 → FP 振幅被抑制；弱场弯曲轨迹 → 增大偏轴反射 → 优化干涉可见度；特征 π 相移在 50 mT（circle, L≈500 nm）与 70 mT（triangle, L≈350 nm），标度 50×500/350≈71 mT 自洽 📜Q[~]。
- **理论振幅**（Fig. 3e/f + S15）：长腔振幅峰 ~0.1 T、0.2 T 后抑制；短腔振幅峰 0.45 T、弹道截止 0.8 T（> 测量上限 B_max=0.6 T，与"单极振荡持续全程"一致）📜Q[~]。

### 2.5 模拟复现 + 灵敏度分析（SI S3–S5）

静电模型（S1–S9）+ 紧束缚 Landauer-Büttiker（S10–S14）用**同一 ni(x) 剖面**复现实验的垂直/对角条纹准周期、取向、幅度对比，以及磁场色散 📜Q。灵敏度分析（S7–S9）：移动掺杂左/右边界 → 腔长变化 → 振荡周期变化（左移增强对角峰 + 增三角形区周期；右边界靠近顶栅 → 竖直条纹周期增）；断开剖面/过光滑剖面 → 与实验失配 → 约束掺杂几何 📜Q。分辨极限：k_F=√(πn)、L=j√(π/n)、L∝n⁻¹/² → ∆L/L∼δn/2n；δn~10¹¹、n~10¹² → ~5% → ∆L≈10–30 nm 📜Q[~]。
