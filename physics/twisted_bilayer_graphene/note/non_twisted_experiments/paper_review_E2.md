## 1. 核心贡献

最早实验展示 BLG 中可电控谷自由度的实验之一。通过非局域输运测量，利用电场诱导的 Berry 曲率产生纯谷流——谷极化电流无需磁场。关键技术：非局域几何区分谷流和电荷流。

## 2. 物理机制 / 实验方法

- 器件：双层石墨烯 + 顶栅/底栅独立控制 $D$ 场和载流子密度
- 非局域输运几何：电流注入和电压检测在不同位置
- 谷霍尔效应：横向谷流产生，纵向电荷流为零
- 栅压控制 Berry 曲率符号 → 谷流方向反转 → 验证谷起源

## 3. 关键结果

1. 非局域电阻信号在 $D \neq 0$ 时出现 → 证明谷流产生
2. 栅压反转 → 非局域信号反转 → 排除热电/接触效应
3. 谷流衰减长度 ~2-3 μm → 谷弛豫长度
4. 温度依赖：谷信号在 100K 以下可观测

## 4. 局限与开放问题

- 非局域信号幅度小 (~Ω)——信噪比低
- 谷流和电荷流的区分依赖模型假设
- 未直接探测边缘态/畴壁态——测量的是体谷霍尔效应

## 5. 与用户研究的相关性

- 非局域输运是验证谷极化的标准方法——TBPM 可计算非局域电阻对标
- 若 DW 项目做谷输运计算，本文提供基准实验数据

### Q1: edge state 实验上如何表征?
非局域输运测量区分谷流和电荷流。电场诱导 Berry 曲率 → 谷霍尔效应 → 纯谷流。通过栅压控制 Berry 曲率符号验证谷流起源。未直接测量边缘态——测量的是体谷输运。
