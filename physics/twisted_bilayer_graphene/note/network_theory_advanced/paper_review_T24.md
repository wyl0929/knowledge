## 1. 核心贡献

建立 moire 系统中量子线网络的**通用散射理论**。将每条畴壁视为量子线，AA 节点用 S 矩阵描述散射。通过控制节点散射相位，网络可支持从手征传播到局域化等多种电子态。这是网络模型的散射理论形式化——为所有网络模型（T9, T12, T15, T29）提供统一的数学语言。

## 2. 物理机制

- 每条畴壁 = 1D 量子线，携带 $N$ 个传播通道
- AA 节点 = 散射中心，用 $S(\theta)$ 矩阵参数化（$\theta$ 为散射相位）
- 网络能带由 $\det[1 - S(\theta) P(E)] = 0$ 决定（$P(E)$ 为传播相位矩阵）
- 散射相位的不同取值对应不同的网络拓扑相：手征传播相、局域化相、临界相
- 理论框架是 Efimkin (T9) 和 Tsim (T12) 的推广——两者是 $\theta$ 取特定极限的特例

## 3. 关键结果

1. 网络态的相图由散射相位 $\theta$ 控制：$\theta=0$ → 连通网络 (T9), $\theta=\pi/2$ → 解耦 1D 链 (T12)
2. 存在中间相区 ($0<\theta<\pi/2$) → 弱耦合通道 → 与 T29 (NQCP) 一致
3. 节点缺陷（缺失连接）导致网络片段化 → 局域化转变
4. 磁场通过 Peierls 相位修改传播相位 → 磁场可调控网络拓扑

## 4. 局限与开放问题

- S 矩阵参数化为唯象——需要从微观模型（连续/紧束缚）导出具体 $\theta$ 值
- 仅考虑单模情况，多模推广待完成
- 无序效应仅定性讨论

## 5. 与用户研究的相关性

- **直接相关**：若需构建畴壁网络 toy model 来理解 TZM vs 网络之争，本文提供了标准散射理论框架
- TBPM 的输运计算可与 S 矩阵网络模型的结果对标

### Q2: 理论如何解释 edge state?
建立 moire 量子线网络的通用散射理论：畴壁 = 1D 量子线，AA 节点 = S 矩阵散射中心。散射相位 $\theta$ 控制网络拓扑相——$\theta=0$ 为连通网络 (T9)，$\theta=\pi/2$ 为解耦 1D 链 (T12)，中间值为弱耦合通道 (T29)。

### Q3: 理论如何与实验结合?
