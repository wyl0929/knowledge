## TL;DR

**本文想解决的问题**：极小扭角 mTBG 在位移场 D 开隙使畴区绝缘后，输运是否由 AB/BA 畴壁的**三角 1D 态网络**承载？

**主结果**：① **巨幅 AB 振荡**（ΔB=0.48 T，振幅 ~50% ρxx、>1 kΩ，持续到 120 K）——相干 1D 回路干涉；② **密度振荡**（Δn≈5×10¹⁰ cm⁻² = 4/A）+ **Hall 正负交替**——隙内窄 miniband 谱（间隔 ~5 meV）。两条独立测量 ΔB→A=0.86、Δn→A=0.80（×10⁻¹⁰ cm²）反推同一三角回路面积，且与 θ→λ=140 nm 自洽。

**结论/意义**：畴壁三角网络承载相干 1D 输运；非魔角极限也有强效应——重构网络态本身是新物理平台。

## 2. 结果与机制（按论文三段：墙 / AB / miniband）

### 2.1 1D 导电网络：墙导电判据

网络形成四步 📜Q（引言）：① 小 θ 应变重构 → 亚微米 AB/BA 三角畴；② 位移场 D 开隙 δ → 畴区绝缘；③ 畴壁承载 1D 态 → 三角网络导电；④ 每畴壁两侧 4 条（2 自旋×2 谷）无能隙 1D 态、谷锁定反向传播、AA 节点劈裂 📜Q。

**墙导电判据（三层对照，排除法）**：① 受控对照——Bernal BLG（无墙）+D→NP 绝缘 vs MTG（有墙）+D→NP 金属；② 排除法——畴区开隙绝缘 → 导电只能走墙；③ 温度反转内控——T>100 K 畴区热激活导电 → 金属签名消失、回到 Bernal 样（SI Note 4）📜Q。⚠️ 此步只证"墙导电"（必要条件），不单独证 1D/相干/拓扑。

> 术语辨析：摘要称 "chiral" 态，正文机制是谷锁定反向传播（helical）——严格是 QVH 畴壁态，非 QH 边缘通道（见 [PHY-BERRY]）。网络基本单元 = 等边三角形，$A=\frac{\sqrt3}{4}\lambda^2$ = 超晶格单胞一半 📜Q。

### 2.2 巨幅 AB 振荡（核心发现）

**现象**：加 D 后所有器件出现随 B 周期强磁振荡；持续到畴区因掺杂/升温变导电（D=0.5 V/nm 时 |n| ≤ 5×10¹¹ cm⁻²、T ≤ 120 K）📜Q。

**机制 = 三角回路 AB 干涉**：电子沿三角回路传播，绕行相位随磁通 $\Phi=BA$ 变化 → ρxx 随 B 周期振荡，ΔB=φ₀/A（机制推导见 [PHY-AB]）。**谐波** ΔB、ΔB/2、ΔB/3 = 1/2/3 个三角畴回路（面积 A、2A、3A）📜Q；其 T 衰减斜率比 ~1:4/3:5/3 = 周长比 3λ:4λ:5λ，独立验证谐波归属（退相干见 [PHY-AB]）📜Q。**排除 SdH**：振荡持续到数 T 才被 SdH 淹没，且活到 120 K（SdH 早已热抹平）——判据逻辑见 [PHY-SDH]。**数值自检**：若主振荡是 SdH，周期应按 $\Delta B\approx B^2\Delta(1/B)$ 从 1 T 处 0.48 T 拉长到 4 T 处 ~7.7 T，实测 0.48 T 恒定 → 确凿 B 周期 💭I（推导见 [PHY-SDH]）。

> **"巨幅"来源**：~50% ρxx 意味着干涉项与背景同量级（|t₁|≈|t₂|），环路几乎串联全部输运通道 💭I（与 E10 弱振荡的差别见 §7）。

### 2.3 密度振荡、miniband 与 Hall 反转

- **密度振荡**：固定 D 扫 n，零场 ρxx(n) 振荡 + ρxy(n) 隙内多次变号；不随接触配置/D 变（排除介观涨落）📜Q。机制 = 隙内窄 miniband 连续填充（refs 14,15 网络模型），周期 Δn=4/A（每畴一电子 × 4 重简并，域计数见 [PHY-MB]）📜Q。
- **Hall 反转**：0.3 K 隙内 ρxy ~±250 Ω（B=40 mT）、50 K 平均反号 ~±3 kΩ；skipping-orbit 类比（沿畴内侧反向环绕 → 空穴样），**不来自现有模型**、需理论佐证 📜Q——ρxy 正负震荡 vs LL 单调见 [PHY-MB]。
- **Discussion 三问**（作者自设谜题）：① miniband 在 B 严格周期、在 n 不完全周期（AB/BA 简并解除 → 拍频）；② AB 活到 120 K 但 miniband 间隔 5 meV（Brown-Zak 类比：miniband 对 B 一致响应）；③ Hall 平均反号（skipping-orbit，开放）📜Q。

> **SI Note 5 摘要**（miniband 谱理论依据）📜Q：① 魔角理论（两层只旋转、晶格不畸变）不适用 θ≪1°（应变大）；② 重构产生宏观 AB/BA 畴 + 原子级 sharp 畴壁；③ D 在畴区开隙 δ、在畴壁出 1D 态；④ 三角网络用 ref 12（Efimkin & MacDonald 2018）描述为隙内近等间距"次级 miniband 谱"；⑤ 该模型未计入带边费米速度变化 → 偏离严格周期；⑥ 实验预期：ρxx 在每个 miniband 间 Dirac 中性点（DOS→0）出峰，ρxy 变号频率 = 2×ρxx 峰数（中性点 + van Hove 各一次）。

## 3. 实验方法

### 3.1 器件
tear-and-stack 制备，名义 θ=0–0.1°、实测 ≤0.25°；双 hBN 封装；双栅 Hall bar（顶金属栅 + 底少层石墨栅）；4 器件行为一致，主样品 θ≈0.10°（迁移率 ~10⁴ cm²/V·s）📜Q。

### 3.2 静电学（SI Note 1 原式）
$$n=\frac{1}{e}(C_{tg}V_{tg}+C_{gg}V_{gg}),\qquad D=\frac{1}{2\varepsilon_0}(C_{tg}V_{tg}-C_{gg}V_{gg})$$
电容独立 Hall 标定；测固定 D 沿 D=const 线扫 n；锚点 D=0.5 V/nm → δ≈50 meV（引 ref 20）📜Q。

### 3.3 测量
低频锁相（6–30 Hz、0.3 K 时 10 nA、高温 100 nA）📜Q。观测量 ρxx、ρxy；AB 振荡叠在大平滑背景上，两种去背景：Δρxx（直接减单调背景，单 trace）vs d²ρxx/dB²（二阶导，密度二维图，不移极值）——数学细节见 [PHY-AB]。FFT 对 ρxx(B) 做，分离 ΔB、ΔB/2、ΔB/3。⚠️ 背景绝对值/拟合方法原文未给，只有相对量（>1 kΩ ≈ 50% zero-B）可引。

Δn=5±0.5×10¹⁰ cm⁻² → A=0.80±0.09×10⁻¹⁰ cm² [±]；隙内 ~10 振荡（|n|<3×10¹¹，正文自述）📜Q；miniband 数 M≈δ/ε≈50/5=10（δ≈50 meV；M≈δ/(v_DW h/6λ)，SI Note 6）📜Q；ε≈5 meV（正文"average width"）📜Q；消失温度 >20 K；ΔE=2ε=10 meV → v_DW≈10⁶ m/s（≈石墨烯 Dirac 速度，提取链见 [PHY-MB]）📜Q。

### 4.5 Hall 效应

### 4.6 证据链与论证结构（三支柱 + 双轴判别）

| 支柱 | 轴 | 证什么 | 数据 |
|------|-----|--------|------|

**双轴墙/体判别**：密度轴（D 开隙 + NP 金属性）与磁轴（AB 非 SdH）各排除一次体导电 → 通路钉在 1D 墙。**支柱②③交叉验证**：Δn→A = ΔB→A 锁定同一回路面积。**多器件 θ² 标度验证**（SI Note 2）：Δn = 5 / 8±1 / 28±4（×10¹⁰ cm⁻²）对 θ = 0.10° / 0.13° / 0.24°，比值 1:1.69:5.76 = θ² 之比（Δn=4/A=16θ²/(√3a²)∝θ²）📜Q [±]；另两器件 θ(ΔB) vs θ(Δn) 亦吻合（0.235±0.01/0.245±0.025；0.133±0.04/0.131±0.08）📜Q [±]。**完整认定链**：存在性 → 相干+1D → 谱量子化 = "1D 墙网络"的完整可辨识。

## 5. 主要结论
1. 小扭角 MTG + D → AB/BA 畴壁三角网络支持相干 1D 输运，AB 振荡达 ~50% ρxx（远超 2D 体系）📜Q。
2. ΔB→A 与 Δn→A 独立互验锁定三角回路面积 A≈0.8–0.86×10⁻¹⁰ cm²（λ≈140 nm、θ≈0.10°）📜Q。
3. 隙内多个窄 miniband（间隔 ~5 meV），电子/空穴型交替致 Hall 符号反复反转 📜Q。
4. 作者保守表态：Hall 反转"不来自任何现有模型"，需理论佐证 📜Q。
5. **畴壁原子级 sharp**：v_DW≈v 满足 sharp 墙判据 w < v/√(γ₁δ) → 反证畴壁原子级 sharp（宽墙反例：抛物线型非拓扑通道 → miniband 数变多 → v_DW 被低估）📜Q（SI Note 6）。
