## TL;DR

**本文想解决的问题**：双层石墨烯的**褶皱（corrugation）**能否诱导出 AB/BA 堆叠孤子（畴壁），并在其中承载**拓扑 gapless 边缘态**？（问题在"结构（应变）能否替代栅压/堆叠缺陷产生畴壁"）

**主结果**：① 首次证明褶皱可在 AB-与 BA-堆叠 Bernal 畴之间产生 **incommensurate 堆叠孤子**（中心六角晶格 vs 两侧三角晶格）📜Q；② STS 观测孤子内 **gap 内非零隧穿电导** + 定能 LDOS **1D 导电通道**（gap 内近能量无关）+ TB 计算复现 → **拓扑 gapless 边缘态**（gap ~170 meV [~]）📜Q；③ 原子分辨 STS 映射揭示 **√3×√3R30° 谷间散射**（FFT 内六峰）→ 谷混合，可解释畴壁电导 **< 4e²/h** 📜Q。

**结论/意义**：作者用 "demonstrate, for the first time" 强措辞；但**拓扑性**是"实验谱 + TB 计算一致"级别（未直接测 valley Chern 数），且**无输运验证**。核心价值 = 提供一种**可被外部应力调控**的畴壁生成途径（vs 天然 AB-BA 畴壁难控）📜Q。

## 2. 结果与机制（按论文论证结构：结构识别 → 谱学 → 1D 通道 → 谷间散射）

### 2.1 褶皱→堆叠孤子（结构识别）

样品为 Rh 箔上**常压 CVD** 生长的双层石墨烯（segregation 机制，冷却速率调厚度，refs 10,13）📜Q。热膨胀失配在石墨烯内产生面内应变 → 1D 准周期褶皱（ripples）📜Q。褶皱处上下层相对滑移改变局域堆叠序：**两侧 AB/BA 三角晶格 vs 中心六角晶格** → incommensurate 堆叠孤子（Fig. 1c；Fig. S4 判 AB/BA）📜Q。作者强调此孤子与天然 AB-BA 畴壁（refs 14,22,27）不同：**可由外部应力生成与调控**，是更可控的畴壁途径 📜Q。

### 2.2 孤子内电子态（谱学 + TB 计算）

沿褶皱线 STS 谱（Fig. 2a）：AB/BA 两侧域 gap **~170 meV**（Rh 箔有效电场诱导）[~]📜Q；孤子内两个特征——① 若干**峰**（准局域量子阱态，类比单层褶皱，refs 9-13）；② **gap 内非零隧穿电导**（拓扑边缘态，refs 18,19）📜Q。TB 计算（最近邻层内+层间 hopping，褶皱同宽同曲率）复现谱主特征；**曲率对电子结构无显著影响**；同堆叠（AB-AB 或 BA-BA）时边缘态**消失**（Fig. S6）📜Q。

### 2.3 1D 导电通道（能量分辨）

定能 STS map（Fig. 3a,b）：gap 内能量（-15 mV）沿孤子见清晰 1D 通道；gap 外（300 mV）LDOS 近均匀。gap 内孤子 LDOS **近能量无关** → 1D 性质 📜Q。理论空间分布（Fig. 3c,d）与实验吻合。

### 2.4 亚晶格选择性 + 谷间散射（原子分辨）

原子分辨 STS（Fig. 4a）：边缘态波函数幅值 AB 域主要位于顶膜 A 亚晶格、BA 域 B 亚晶格 → 两侧**三角晶格**、孤子中心**六角晶格**，与理论（Fig. 4b）吻合 → 证实谷投影拓扑模 📜Q。另一关键特征：**√3×√3R30° 超结构**（red diamond）+ FFT 内六峰 = 谷间散射的明确证据（[PHY-QPI]）📜Q。谷间散射**归因于褶皱内面内应变而非原子缺陷**（缺陷 "clearly absent"）→ 谷混合不可避免、且可被褶皱调控 📜Q。

### 2.5 4e²/h 量子化与谷混合修正

无谷间散射时，反向通道只在另一谷 → 无背散射（谷-动量锁定，类比 QSH 螺旋态 📜Q）。据电子结构（Fig. 2b）：K 与 K′ 谷**每自旋各两条拓扑边缘态** → 无谷混合时量子化电导 **4e²/h**（2 谷 × 2 自旋 = 4 通道）📜Q。但反向谷投影通道间背散射**不被任何对称性完全禁止**（晶格尺度缺陷/形变必然触发；e-e 相互作用与无序增强配对背散射，ref 36）→ 实测谷混合**降低**电导 → 解释近期畴壁实验的 **< 4e²/h**（refs 14 Ju 2015、15 Li 2016）📜Q。

> 术语注：引理论时用 "valley-projected **chiral** edge modes"（refs 18,19 语境）📜Q；做 QSH 类比时用 "**helical** / valley-momentum locking" 📜Q——chiral vs helical 辨析见 [PHY-BERRY]。

## 3. 实验方法

### 3.1 样品 / 器件
常压 CVD 生长于 Rh 箔（segregation 机制，冷却速率调厚度）📜Q；Raman I2D/IG mapping（Fig. 1a）确认主要覆盖双层 📜Q；Bernal 双层由原子像三角晶格 + 大 gap 双重识别 📜Q。

### 3.2 静电学
**无外加栅压/栅极**。gap 由 Rh 箔衬底产生的**有效电场**诱导（衬底破缺 Bernal 双层反演对称）——AB/BA 两侧 gap **均匀**（"uniform interlayer potential difference"）📜Q。能隙来源/band bending 机制见 [PHY-EF]。⚠️ 与 E3（EFW，双分裂栅主动开隙）对比：本文 gap 是**衬底固定场**，无电学调谐旋钮 💭I。

### 3.3 测量
STM/STS。成像参数（Fig. captions）：Fig. 1b `V_sample=-300 mV, I=0.4 nA`；Fig. 1c `V_sample=180 mV, I=13 pA`；定能 STS map 用 **-15 mV / 300 mV**（Fig. 3）；原子分辨 STS map **15 mV**（Fig. 4a，6.5 nm × 4.5 nm）📜Q。FFT 对原子分辨 STS map 做，分离谷内（Bragg 外六峰）vs 谷间（内六峰）📜Q。⚠️ **测量温度未在正文声明**（`NEEDS_VERIFICATION`；旧 review 的 "77 K" 为跨论文错误——"77 K" 仅出现在 ref [12] Yan 2012 标题中，非本文测量条件）。Methods 在 SI（Fig. S1），本文 SI 缺失 → 生长/针尖细节均 `NEEDS_VERIFICATION`。

## 5. 主要结论
1. **首次**证明褶皱可产生 incommensurate 堆叠孤子（"demonstrate, for the first time"）📜Q。
2. 孤子承载**拓扑 gapless 边缘态**（gap 内非零电导 + 1D 通道 + TB 复现）+ 准局域量子阱态 📜Q。
3. 原子分辨映射揭示**谷间散射**（√3×√3R30°）→ 谷混合不可避免、可由褶皱调控 → 解释畴壁电导 **< 4e²/h** 📜Q。
4. 提供**可设计/可调控**的畴壁生成途径（应力调控，vs 天然畴壁难控）📜Q。
