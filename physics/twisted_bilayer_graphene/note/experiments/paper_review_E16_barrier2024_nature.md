## 1. 核心贡献

**P1 精读优先级**——首次展示 QH 边缘态可承载 1D 邻近超导。在石墨烯 QH 区域边缘通过超导接触产生 Andreev 反射。这是「拓扑边缘态 + 超导」混合界面的里程碑实验。

## 2. 物理机制 / 实验方法

- 器件：hBN 封装石墨烯 + 超导接触 (MoRe 或 NbTiN)
- QH 区域：垂直磁场 1-14T → 手征边缘态
- 微分电导 $dI/dV$ 测量 — Andreev 反射特征
- 超导能隙 $\Delta \sim 1$ meV → 亚能隙电导增强

## 3. 关键结果

1. QH 边缘态 + 超导接触 → 亚能隙电导增强 1.5-2×（Andreev 反射特征）
2. 交叉 Andreev 反射（CAR）：两个超导接触间的非局域关联信号
3. 边缘态手征性导致 Andreev 反射的不对称（正负磁场不等）
4. QH 填充因子 $\nu$ 控制边缘态数目——Andreev 信号随 $\nu$ 阶梯变化

## 4. 局限与开放问题

- 超导能隙 $\Delta \sim 1$ meV — 远小于 QH 能隙 (~10 meV)
- Andreev 反射概率 < 10% — 界面透明度低
- 当前仅为常规超导——拓扑超导 (Majorana) 仍未实现
- 实验复现性待确认（超导-QH 界面极难制备）

## 5. 与用户研究的相关性

- **P1 精读**——DW 项目可能的最前沿实验对标
- TBPM 目前不包含超导——此为远期方向
- 当前：理解 QH 边缘态如何与超导耦合，为未来扩展 TBPM 做准备

### Q1: edge state 实验上如何表征?
QH 边缘态 + 超导接触 → 微分电导中的 Andreev 反射特征 $dI/dV > 0$。亚能隙电导增强、CAR、正负磁场不对称。QH 填充因子 $\nu$ 控制边缘态数目 → Andreev 信号阶梯。区分边缘超导 vs 体效应：超导信号仅在有 QH 边缘态时出现。
