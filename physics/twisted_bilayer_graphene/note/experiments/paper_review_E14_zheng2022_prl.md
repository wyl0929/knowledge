## TL;DR

**本文想解决的问题**：低角 TBG 中，理论（Ramires–Lado 2018, ref [11]）预言的"层间电场在 AB/BA 畴壁处产生赝朗道能级（PLL）+ 电子 Kagome 晶格"——**在真实结构重构下是否还成立**？（写"问题"不写"主题"）

**主结果**：
1. PLL 在**全部**研究角度（0.075° ≤ θ < 1.2°）稳健存在，可被针尖诱导的层间电场**开关**（W 针尖无场→无 PLL；Au 修饰 W 针尖有场→出现 PLL）📜Q。
2. PLL 强局域在 DW **中心**（正文 Fig.2f：~130 meV 📜Q[~]），与局域在 DW **两侧**的拓扑 helical 边态**空间分离共存**。
3. tiny-angle（θ<0.2°）下重构使 DW 呈**三角网络**（非 Kagome）；magic angle 附近（~0.88°–1.07°）直接成像出**样品级电子 Kagome 晶格**，晶格常数可由 θ 调控 📜Q。
4. 强**电子-空穴不对称**：PLL 仅在空穴侧，电子侧（-120/-200/-400 meV）无 PLL/Kagome，归因重构局域应变 📜Q。

**结论/意义**：在 TBG 中实现了"稳健新平带 + 电子 Kagome 晶格"，为 moiré 体系中探索奇异关联相开辟新方向。作者措辞强度为"demonstrate / directly imaged / open a new direction"📜Q——**但 PLL 的身份（=赝朗道能级）是"与理论一致"而非唯一证明**（见判别表 D7 与 [前提与限定]）。

## 2. 结果与机制（按论文自身的论证结构）

### 2.1 结构与针尖电场的"开关"（D1 的舞台）

- 样品：转移技术叠加两层 CVD 石墨烯得 TBG，θ 由 moiré 波长 `D_m = a/[2sin(θ/2)]`（a = 0.246 nm）反推📜Q。
- 针尖二值：W 针尖与石墨烯功函数差 Δw≈0 → 无有效电场📜Q；Au 修饰 W 针尖（把针尖插入/提起 Au 电极→包 Au 纳米线）Δw 大 → 针尖下方产生层间电场📜Q（SI §3）。
- 效应：Au 针尖使 AB/BA 区开隙（~50 meV 📜Q[~]，Fig.2f），gapped AB/BA 谷 Chern 反号 → DW 处拓扑 helical 边态（能量在隙内，~30 meV，局域 DW 两侧）📜Q；同时 DW 出现新平带（PLL，~130 meV，DW 中心）📜Q。

### 2.2 两类 DW 态的空间分离（D2/D3）

| 特征 | PLL（DW 中心态） | 拓扑 helical 边态 |
|------|-----------------|------------------|
| 空间分布 | DW **中心**最强 | DW **两侧**亮 |
| 典型能量 | 130/230/258/260/290/380 meV（空穴侧，随 θ↑） | ~30 meV（隙内） |
| 来源 | 层间电场在 DW 界面产生的局域规范场 → 赝朗道平带 | AB/BA 谷 Chern 反号的界面 helical 态 |

定能 map 是判据：230 meV → 仅 DW 中心（S8a）；30 meV → DW 两侧（S8b）📜Q。作者结论："the coexistence of the topological helical network and localized PLL"📜Q。

### 2.3 层间电势差的估计（提取链，详见 §4）

隙 ~50 meV → 位移场 D ≈ 0.5 V/nm → 层间电势差 U ≈ 0.165 V（据 biased-bilayer [34] 的隙-D 关系）📜Q[~]。代入理论 [11]：θ=0.2°、U=0.165 V → PLL ≈ 0.135 eV，"与实验 130 meV 吻合"📜Q[~]（⚠️ 角度 0.12° vs 0.2° 的松匹配，见更正日志）。

### 2.4 电子-空穴不对称（D6）

重构引入的局域应变 → 强电子-空穴不对称 [39,40]，**抑制电子侧 PLL**📜Q。S17：-120/-200/-400 meV 定能图（θ~1.07°/0.98°/0.8°）无 PLL/Kagome📜Q。

### 2.5 Kagome 仅 magic angle（D8）

- 重构在 θ<1.8° 发生，但**不完全改变** magic angle 附近 DW 的 Kagome 结构📜Q。
- tiny-angle：DW 三角网络（连接 AA 点）📜Q；magic angle（~1.07°/0.98°/0.88°）：380 meV 定能图直接成像样品级 Kagome📜Q（S9/S16 扩展到 1.15°/0.8°/0.7°）。
- 晶格常数可调：θ 连续变化 → Kagome 晶格常数连续可调📜Q（作者列为三大优势之一）。

### 2.6 与 AA 平带的并存

magic angle 样品中 AA 区另有平带（近魔角 ~1.08° 时 FWHM 最小、呈单峰；偏离魔角呈双峰）📜Q（Fig.3a/S15）。作者强调电子 Kagome 晶格中"有其他电子态（AA mode）穿透"📜Q——区别于原子 Kagome 晶格。

## 5. 主要结论

1. PLL 是低角 TBG 中**稳健存在**的新平带，可被层间电场开关，局域在 AB/BA 畴壁（DW）中心📜Q。
2. PLL 与拓扑 helical 边态在 DW 内**共存但空间分离**（中心 vs 两侧）📜Q。
3. 重构抑制 tiny-angle 的 Kagome（变三角网络），但 magic angle 附近保留样品级电子 Kagome 晶格，晶格常数可由 θ 调控📜Q。
4. 重构局域应变引入**强电子-空穴不对称**，抑制电子侧 PLL📜Q。
5. PLL 能量随 θ 单调增，与刚性旋转理论定性一致；定量差异归因重构（理论未含）📜Q。

| **PLL 身份非唯一证明** | 无 B_ps 提取、无朗道量子化拟合；"=赝朗道能级"靠能量匹配 + 趋势一致（D7 弱判别）💭I |
| **n=1/n=2 无谱学序列** | n=2 未观测，归因峰宽+背景；**不存在**可提取的 PLL 序列/B_ps |
| **130 meV vs 230–258 meV 张力** | 主文与 SI 的 tiny-angle PLL 能量差 2 倍，未解释；可能基底/等效电场差异 |
| **电子侧机制** | 仅给经验结论（归因应变），无定量应变-不对称模型 |
| **针尖电场不可控/局域** | 针尖 Δw 无法连续扫描 U；无真正双栅对照；与器件栅控的可重复性未交叉验证 |
| **无输运** | 全谱学，无 dG/dn、无 AB/FP、无磁场——Kagome 平带的拓扑/关联后果未被输运检验 |
| **SI 图题基底矛盾** | Fig.S2–S5 图题写 "on WSe₂"，但 §2/§3 标题与主文写 "on h-BN"（caption 疑似笔误）⚠️ |
