## TL;DR

**本文想解决的问题**：极小扭角 m-TBG（0.06°–0.35°）中，畴壁（DW）的电子结构长什么样？应变能否作为调控畴壁态（DW-S↔DW-M）的参数？

**主结果**：① 系统局域谱学刻画 m-TBG 三种堆叠位型——AA 位 ~−100 meV 隧穿谱峰（强局域态）、AB/BA 畴区 5 个均匀谱峰（0 ~ −100 meV）＋ −60 meV 谷（CNP）、畴壁 −120 meV 峰；② 两种畴壁的谱学区分——DW-S（剪切型，低对比形貌）有 −120 meV 应变敏感共振、CNP 移到 −40 meV；DW-M（混合剪切-拉伸型，亮形貌）无该峰、仅 −40 meV 谷；③ 应变驱动 DW-S→DW-M 转变——TB（θ=0.35°、ε=0.3%）下 DW-S 出 −180 meV 峰、DW-M 无峰，无应变时两型皆 −180 meV，即应变消除剪切共振、驱动"剪切→混合"重构。

**结论/意义**：作者称 "demonstrate deterministic strain control of domain wall states"、"establish strain as a control parameter for domain wall states"（确定性/参数，保留原措辞）📜Q。⚠️ 注意"strain control"是通过**样品本征应变梯度（εxx=0.06%–0.9%）的空间测量 + 理论对照**实现，**非原位应变装置**（无弯曲衬底/压电驱动，见 §3.3 与 §6）。

## 2. 结果与机制（按论文自身论证：全局谱 → 畴壁谱 → 稳健性 → TB 验证）

### 2.1 全局结构 + 三种堆叠位型的谱（Fig. 1）

强晶格弛豫重塑局部原子几何 📜Q（引言）：AA 区（原子垂直对齐）收缩，AB/BA 区（Bernal 堆叠）扩展为三角畴，畴壁网络生成。STM 形貌显示畸变 moiré 三角、强重构与应变；AA 收缩后经**长度不一的准 1D 畴壁**相连；约一半 moiré 三角的畴壁很弱/接近探测极限 📜Q（Fig. 1b + 正文）。

三种位型的隧穿谱 📜Q（Fig. 1d + 正文）：
- **AA**：~−100 meV 处的隧穿谱峰（局域化态，归因晶格弛豫，与既往重构 m-TBG 报道一致）[~]；
- **AB/BA**：数个本征锐峰（0 ~ −100 meV），空间均匀；−60 meV 处 dip 状特征 [~]；
- **畴壁**：dark DW 有 −120 meV 峰（DW-S），bright DW 无此峰（DW-M）[~]。

**CNP 估计**：由 AA 峰与 AB/BA 谷位置估计 CNP ~ −60 meV [~] 📜Q；AA/AB/BA 区 CNP 移位（蓝虚线标注）= 不同局域电子掺杂，与 hBN 支撑石墨烯既往测量一致（[PHY-EF]：局域 CNP 移位即局域掺杂/band bending 的谱学指征）📜Q。

**与魔角 TBG 的区别** 📜Q：m-TBG 无显著"remote band"（远程带）特征，平带峰在 AA 位显著展宽（Fig. S5，SI 缺失未读原文）。

### 2.2 两种畴壁的谱学区分（Fig. 2，核心）

畴壁按边界相对蜂窝晶格的取向分为**拉伸（tensile）**与**剪切（shear）**两类 📜Q（引言）；本文进一步区分出：
- **DW-S（剪切型）**：形貌**极低对比**（Fig. 1b 黄虚线样品）；谱有 **−120 meV 强峰** ＋ CNP 从 AB/BA 区 −60 meV 移到畴壁处 **−40 meV** 📜Q（Fig. 2e）；
- **DW-M（混合剪切-拉伸型）**：形貌**亮条纹**（高对比）；谱**无 −120 meV 峰**，有 −40 meV 处特征谷（CNP 移位与 DW-S 相似）📜Q（Fig. 2g）。

单个 moiré 三角形内：**一条边是 DW-S，其余两条边是 DW-M**（受不同应变条件）📜Q（正文，Fig. S8–S11）。原子结构分析：畴壁边界与 Burger vector 夹角 **β = 90°（DW-S 纯剪切）vs <90°（DW-M 混合剪切-拉伸）**（Fig. S10）📜Q。同三角形内长短 DW-M 的 dI/dV 谱相似（Fig. S11），说明尽管局域应变环境不同、DW-M 电子结构一致 📜Q。

### 2.3 扭角/应变稳健性（Fig. 3）

覆盖 θ = 0.065°–0.225° 的两块区域 📜Q（正文）：
- **DW-S**：−120 meV 峰在全程稳健，能量变化仅 **±5 mV** [±]，并伴随 −40 meV 附近尖锐 dip 📜Q；
- **AB/BA**：5 个特征峰（0 ~ −100 meV）在 θ = 0.06°–0.11° 内 "essentially unchanged"（显著均匀性）📜Q；
- **AA**：对扭角/应变**敏感**得多——Fig. 3f 五个不同扭角的 AA 位，特征 LDOS 峰随扭角增大从 **−110 mV 连续移到 −50 mV** [~] 📜Q。

### 2.4 TB 计算验证应变驱动转变（Fig. 4）

样品 moiré 图案横跨数百 nm，超出原子模拟极限 📜Q；作者认定影响电子性质的相关因素是**晶格弛豫 + 应变**，故构造 **θ=0.35° + 单轴异质应变 ε=0.3%** 的 m-TBG 模型并做弛豫 📜Q（正文 + Fig. 4 caption）。弛豫结构出 DW 网络、两种原子构型（DW-S/DW-M）📜Q。

LDOS 计算（∝ dI/dV）关键对照 📜Q（Fig. 4c/d）：
- **有应变**：DW-S 出 **−180 meV 强峰**，DW-M 只有弱低能共振（Fig. 4c 虚线框内）[~]；
- **无应变**：两种 DW **都出 −180 meV 峰**（Fig. 4d）[~]；
- 弛豫后 AB 区（AB1/AB2/AB3/AB）LDOS 行为相似，rigid 情形 AB 区差异明显 → 弛豫增强 AB 均匀性 📜Q；
- 应变驱动结构转变，把 moiré 原胞从**六角扭曲为准矩形**，匹配实验 📜Q。

**实验-理论对应** 📜Q（正文 + 结论）：① 实验 DW-S（低对比、−120 meV）↔ 理论剪切 DW（−180 meV）；② 实验 DW-M（亮、无峰）↔ 理论混合 DW（无峰）；③ **−180 vs −120 meV 能量差**来自掺杂效应 + 扭角 + 应变差的组合（作者归因，未定量分解）。应变通过驱动剪切→混合转变**消除特征共振**，确认应变介导的畴壁重构 📜Q。

## 3. 实验方法

### 3.1 器件
干法清洁转移（tear-and-stack 变体）📜Q：单层石墨烯先机械剥离到干净 SiO₂/Si；hBN 片（PDMS 印章上）在光学显微镜下对准石墨烯；拾起一半石墨烯（PDMS/hBN/石墨烯）；另一半旋转到目标扭角后拾起完成双层；翻转后 hBN/tBLG 转移到**镀金衬底**；**石墨 flake 桥接 tBLG 与金衬底**保证电接触。hBN 支撑，偏压 Vb 加在针尖与 tBLG 之间、经石墨电极 📜Q。

### 3.2 谱学
商品 UHV-STM（USM-1200, Unisoku），**基温 4.2 K**、光学显微镜联用；**基压 1.0×10⁻¹⁰ Torr**；器件 **170°C** UHV 除气后转入 STM 📜Q。STS 用标准锁相放大，**调制频率 973.0 Hz**；dI/dV 谱 = 关反馈回路、扫 DC 偏压采集 📜Q。

### 3.3 应变/扭角提取（关键，纠正旧 review 错误）
⚠️ **无原位应变装置**（无弯曲衬底、无压电驱动器）。θ 与应变张量由**每个 moiré 三角形的原胞周期反推**（SM Sec. 2）📜Q；全样品 θ 从 0.06° 渐变到 0.35°，单轴应变 **εxx = 0.06%–0.9%**、剪切应变（Fig. S4）也一并计算 📜Q。所谓"strain-tunable"= 在样品**本征应变梯度场**上逐点测量结构/谱，而非单器件连续调应变。

### 3.4 测量参数（Fig. caption）
形貌 set point：Vb=−2000 / −1000 mV、It=20 pA；谱学 set point：Vb=−200 mV、It=200 pA 📜Q。扫描尺寸：500×500、760×500、220×350、350×350、500×350、180×90 nm 📜Q。

| ② 两种畴壁 | 空间轴（单三角形内 + β 角） | DW-S/DW-M 类型区分 | Fig. 2, Fig. S10/S11 |
| ③ 应变驱动转变 | 理论对照（ε 开/关） | 应变消除剪切共振 → 剪切→混合 | Fig. 4 |

**类型判定的三方一致**：形貌对比（亮/暗）↔ 谱（峰有/无）↔ TB β 角（90°/<90°）——三者独立指向"剪切 vs 混合"同一结论 📜Q。**转变的因果链**：空间应变梯度上 DW-S/DW-M 分布（实验）＋ TB 应变开/关对照（理论）——应变消除共振是**计算对照**确立，实验层面是**空间相关**（无原位应变扫参）💭I。

## 5. 主要结论

1. 用 STM + TB 建模**确定性应变调控** m-TBG 畴壁态（θ 0.06°–0.35°）📜Q（结论段原词 "deterministic strain control"）。
2. m-TBG 电子性质**与魔角 TBG 显著不同**（无远程带、AA 平带峰展宽）📜Q。
3. 发现 **−120 meV 应变敏感电子共振**，专属于剪切型畴壁 DW-S 📜Q。
4. 应变驱动畴壁**剪切→混合（DW-S→DW-M）转变**，通过原子尺度谱学直接可视化 📜Q。
5. 应变确立为**工程 1D 畴壁、操控电子/输运/光学性质**的关键调参 📜Q。
