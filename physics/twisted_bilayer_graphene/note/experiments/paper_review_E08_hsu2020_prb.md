## TL;DR

**本文想解决的问题**：能否用**可扩展**的纳米应变工程，在**单层石墨烯**中于**室温**下可控地诱导巨赝磁场、谷极化与受保护的 1D 拓扑通道？（动机：此前赝磁场研究都依赖机械剥离微米片或 STM 原子级组装，不可扩展 📜Q 引言）

**主结果**：
- ① **巨赝磁场**：单层石墨烯铺在图案化纳米结构（Pd 四面体 / SiO₂ 纳米锥阵列）上诱导整体反演对称性破缺，形貌反演给出**最大 ~800 T**（单四面体，Fig 2C）📜Q[~]；双四面体 ~600 T（Fig 3C）📜Q[~]；STS 赝朗道能级间隔（Eq 3）独立确定 |B_S|，与形貌反演**双重一致**（Fig 2H/3H）📜Q。
- ② **谷极化**（**模拟**，非实测）：平行褶皱产生交替符号的赝磁场通道 → K/K′ 费米子空间分离（valley splitter，Fig 5A/B），条件 d < l_B 📜Q。
- ③ **周期 1D 拓扑通道**（**模拟**，非实测）：平行褶皱作为谷极化手征模的受保护传播通道（Fig 5C）📜Q。
- ④ **自发局域时间反演破缺**：应变区点谱零偏（n=0 朗道能级）处**约一半峰、一半隙** → 两个零模统计等概率（fig S8）📜Q。

**结论/意义**：室温、可扩展的纳米应变工程是操纵单层石墨烯拓扑态（谷电子学）的新途径。⚠️ 措辞注意——作者对"谷极化/拓扑通道"只声称 "verify the feasibility"（可行性论证，基于实测应变图案 + MD 模拟），**非直接实验测量**；实验直接测量的只有赝磁场（形貌 + 谱学）与零偏峰/隙统计。

## 2. 结果与机制（按论文自身论证结构）

### 2.1 应变 → 规范势 → 赝磁场（机制，引言 + Eq 1–2）

单层石墨烯晶格畸变对 Dirac 费米子产生两个效应 📜Q（引言）：① 有效**标量势 Φ**（改变 p_z 轨道间距/夹角 → 修正跃迁能 → 散射 + 局域电荷密度变化，band bending 概念见 [PHY-EF]）；② 有效**规范势 A**（与倒空间 Berry 联络相关，耦合谷/赝自旋自由度）。赝磁场 **B_S(r) = ∇ × A(r)**，K 与 K′ 谷符号**相反** → 全局时间反演对称保持、整样品总通量为零 📜Q（Eq 2 ±号 + "the total flux integrated over the entire sample is zero"）。

应变张量（Eq 1）：由高度变化 h(x,y) 与面内位移 u 给出 u_xx, u_xy, u_yy；强 z 轴褶皱时高度项主导（figs. S1–S3）📜Q。规范势（Eq 2，取 x 沿 zigzag 方向）：A_x = ±β/a₀ (u_xx − u_yy)、A_y = ∓2β/a₀ u_xy，其中 a₀ ≈ 0.142 nm、β = 2–3（磁通量子单位）、± 对应 K/K′ 📜Q。

### 2.2 巨赝磁场的双重实验确定（Fig 2–3）

- **单 Pd 四面体**（Fig 2）：100 nm × 100 nm 区域 AFM/STM 形貌 → 应变张量（fig S5）→ B_S 图（Fig 2C），**最大 ~800 T**（由形貌信息计算）📜Q[~]。原子分辨 STM（3 nm × 3 nm inset）显示四面体尖端附近强结构畸变 📜Q。
- **谱学独立验证**：dI/dV 谱沿 Fig 2C 黑线 cut，朗道能级 E_n = sgn(n)√(2 e v_F² ℏ |n B_S|)，间隔由 |B_S| = [(E_{n+1})² − (E_n)²]/(2 e v_F² ℏ) 确定（Eq 3，机制见 [PHY-SDH]）📜Q。⚠️ **E_n ∝ √|n|，能量上非等间距**（E_n² 才等间距），旧 review "等间距特征"表述已修正。Fig 2H 中形貌反演 |B_S(r)|（红线）与 STS 朗道能级分离（黑菱形）整体一致 📜Q。
- **点谱**（fig S6，同一 Fig 2C 图）：高应变位置 α, β, γ, δ 的 |B_S| ~600 T，朗道能级 n = 0, ±1, ±2, ±3 显式标出；其中一条点谱用 |B_S| = 592 T 拟合（Lorentzian LL 叠加背景 Dirac 谱）📜Q[~]。⚠️ 注意：~600 T 是点谱位置的值（单四面体图内），**不是** ~800 T 最大值处。
- **双 Pd 四面体**（Fig 3）：形貌反演最大 ~600 T（Fig 3C），比单四面体小——因为相近高度位移铺展到更大横向尺度，(∂h/∂i)(∂h/∂j) 减小 📜Q[~]。谱学与形貌反演定量一致（Fig 3D,E,H）📜Q。

### 2.3 平行褶皱 = 谷劈裂器 + 拓扑通道（Fig 4–5，矩形纳米锥阵列）

SiO₂ 纳米锥阵列两种晶格 📜Q（Fig 4）：**三角晶格** → 石墨烯褶皱沿三个等价方向随机分布（Fig 4A bottom）；**矩形晶格** → 褶皱一般良好对齐、彼此平行（Fig 4B bottom）。每根延展褶皱产生**四条平行、相对均匀的赝磁场通道**（沿通道方向均匀、垂直通道方向交替变号，Fig 4D bottom）📜Q。

- **谷劈裂（valley splitter）**：K/K′ 看到的赝磁场符号相反 → 垂直入射的谷简并费米子通过平行通道后 K 与 K′ **空间分离**，横向分离随越过褶皱数增加而增大；条件 = 相邻褶皱平均间距 **d < 弹道长度 l_B** 📜Q。l_B 由电导 G、迁移率 μ、载流子密度 n₂D 经 G = (2e²/h) k_F l_B = n₂D e μ（Eq 4，原文关系式）与 k_F = (n₂D π)^{1/2}（原文）→ l_B = (ℏ/e)√(π n₂D) μ（推导，数值可复现下式）；对典型 n₂D = 10¹⁰–10¹² cm⁻²、μ ~ 10⁵ cm²/V·s（本文 PECVD 石墨烯），l_B = 120 nm–1.2 μm 📜Q[~]。
- **拓扑通道（valley propagator）**：平行褶皱作为手征 Dirac 费米子（K 或 K′）的受保护传播通道，偏离通道方向小角度入射的谷极化费米子被**准直**（collimated）📜Q（Fig 5C，模拟）。⚠️ 此节为**理论模拟**（semi-classical 轨迹 + MD），由 J.-Q.W. 开发（作者贡献 📜Q），非输运实测。

### 2.4 自发局域时间反演破缺 + 两个零模（Discussion）

赝磁场虽不破坏全局 TRS，但 K/K′ 规范势 A 与 A* 符号相反 → 产生特殊零模（ref 36 Herbut）📜Q：Dirac 费米子在整个样品上离域、却在实空间对赝自旋投影交替局域/反局域 → **局域自发 TRS 破缺**。经验上表现为 n = 0 隧穿电导峰在石墨烯两个不等价子格上**交替出现/缺失**（分子石墨烯 STS 已证，ref 11）📜Q。本文发现：所有应变区点谱的两种零模**统计等概率**——零偏 (V=0) 处要么电导峰、要么电导隙（fig S8A 零偏电导图 + fig S8B 直方图）📜Q。此为应变规范势导致局域 TRS 破缺的**支撑证据**（"supporting evidence" 📜Q）。

### 2.5 器件概念与应变超导展望（Discussion）

- **valley Hall 晶体管概念**（fig S9A）：长轴平行于褶皱的 valley Hall 器件构型 → 背栅电压下可测强非局域电阻与 VHE，类比 h-BN 上剥离单层石墨烯的 VHE（ref 10）📜Q。谷劈裂器（Fig 5A/B）+ 谷传播器（Fig 5C）组合可得高谷极化电流；注入强自旋轨道材料可得自旋极化电流（fig S9B，自旋电子学）📜Q。
- **应变诱导超导展望**（ref 39 理论）：周期 ripple 应变拓扑平带 + 电子关联可稳定手征 d 波超导；条件 (J/t)~1 下需 (h/L) ≥ 0.05 且 h²/(L a₀) ≥ 1 📜Q。本文典型 h = 20 nm、L = 300 nm → (h/L) ≈ 0.067、h²/(L a₀) ≈ 9.39，两条件均满足 📜Q[~]——但需强电子关联前提成立、且石墨烯热膨胀系数为负（降温应变减小）📜Q，超导未实测。

## 3. 实验方法

### 3.1 样品与纳米结构制备

- **石墨烯**：PECVD 生长，近无应变、大面积（~1 cm²）单层 📜Q[~]；polymer-free 转移（ref 34）📜Q。
- **Pd 四面体 NC**：湿化学法（ref 33）合成——7.6 mg Pd(acac)₂ + 16.5 mg Fe(acac)₂ + 50.0 mg PVP + 10.0 ml DMF，30-ml 瓶，超声 5 min，120 °C 油浴 10 h，离心乙醇清洗；Si 衬底丙酮/异丙醇各 10 min + 100-W O₂ 等离子 5 min 清洁，1500 RPM 旋涂 1 min，再 O₂ 等离子 5 min 📜Q。典型四面体底 ~30 nm；所得 NC 尺寸 50–70 nm、高 40–60 nm（Fig 1B,C）📜Q[~]。
- **SiO₂ 纳米锥阵列**（fig S4）：e-beam 光刻图案化 ~50 nm 直径圆盘于 300-nm 氧化层 Si 衬底 → 15-nm Ni 掩模 → C₄F₈/O₂ RIE 刻蚀 Si 纳米柱 → BOE ~20 s 去除 Ni 盘；典型纳米锥 ~40 nm 直径、~20 nm 高 📜Q[~]。（三角/矩形晶格阵列分别用 e-beam 或 FIB 光刻 📜Q。）
- **堆叠**：h-BN 单层（机械剥离或 CVD）+ PECVD 石墨烯依次转移到纳米结构上；h-BN 的作用 = 最小化 Si 与石墨烯声子耦合 + 电荷杂质影响 📜Q。石墨烯/BN 对分离的 NC 贴合良好；NC 靠得足够近时石墨烯在 NC 间形成褶皱 📜Q。

### 3.2 静电学

单层石墨烯、**无栅压实测**（器件概念中才引入背栅 V_g）；标量势 Φ → 局域电荷密度变化（band bending，概念见 [PHY-EF]）📜Q。本文无双栅 n/D 换算、无输运。

### 3.3 STM/STS 测量

室温（正文 "at room temperature" 多次）📜Q；自制 STM，真空 1.6 × 10⁻⁶ torr；Pt/Ir 针尖，典型隧穿结电阻 2 GΩ 📜Q[~]。观测量：形貌（AFM + STM）、dI/dV vs V 谱（V = E/e）；赝磁场由谱学朗道能级间隔（Eq 3）提取，与形貌反演对照。**非常规预处理**：dI/dV 用"相对无应变石墨烯 Dirac 谱的差值"呈现（Fig 2D caption）📜Q。

## 5. 主要结论

1. 室温、可扩展的纳米应变工程（单层石墨烯 + 图案化纳米结构 + 整体反演对称破缺）可诱导**巨赝磁场（最大 ~800 T）**，空间分布可控 📜Q[~]。
2. 赝磁场由**形貌反演与 STS 赝朗道能级间隔双重独立确定**，二者一致 📜Q。
3. 平行褶皱产生**交替符号赝磁场通道** → 可作 valley splitter（d < l_B 时谷分离）与**受保护传播的拓扑通道**（valley propagator）📜Q（⚠️ 模拟）。
4. 应变区点谱零偏**峰/隙统计各半** → 支撑"应变规范势导致的局域 TRS 破缺 + 两个零模" 📜Q（⚠️ 支撑证据）。
5. 方法论意义：把赝磁场工程从不可扩展（剥离片/原子组装）推进到可扩展（PECVD 大面积 + 纳米加工），并提示应变诱导超导的可行性 📜Q（⚠️ 超导未实测）。

| 应变张量 → 规范势 | u_xx, u_xy, u_yy（Eq 1）→ A_x = ±β/a₀(u_xx−u_yy)、A_y = ∓2β/a₀ u_xy（Eq 2）📜Q |
