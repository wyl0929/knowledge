# [METHOD] 实验论文阅读法与笔记模板

> **本文档只讲实验论文**。理论论文另见 [`theory_paper_reading.md`](theory_paper_reading.md)——二者**不互相引用对方的框架词汇**(实验论文用"系统辨识/黑箱/四层变量/判别表", 理论论文用"演绎结构/白箱/推导链/结论清单", 不混用)。
> **公共规范**(目的层、类型分诊、三层分离、证据分级、三档分级、验收)见入口 [`paper_reading_methodology.md`](paper_reading_methodology.md)。
>
> **一句话**: 实验论文 = **系统辨识记录**(转旋钮→记输出→反推内部结构); 读论文 = **元辨识**(重建作者的辨识链条); 记笔记 = **按辨识结构重构**(4 块), 不是 IMRaD 镜像。
>
> 证据基础: E10 Rickhaus 2018(20+ 轮问答, 日志 `Rickhaus2018_E10_log.jsonl`)与 E12 Xu 2019(30 轮, 日志 `Xu2019_E12_log.jsonl`)两次完整精读复盘。全版(含控制论建模、术语映射表)见 `systems_science/case/15_case_study_paper_reading_system_identification.md`。

## 1. 基本建模: 为什么实验论文是"系统辨识"

- 实验论文天然是**系统辨识记录**: 作者转旋钮、记输出、反推器件的未知内部结构; 读论文就是**元辨识**——重建这条"旋钮→观测→反推"链条。
- **符号先分层再读(四层)**: **L1 旋钮**(Vtg/Vbg/B/T)→ **L2 导出量**(n/D)→ **L3 模型量**(E_F/Δ/k_F/v_DW)→ **L4 观测量**(G/ρxx/ρxy/导数)。符号歧义的根源: 四个不同层的量共用了同一个字母(E10 的 n 家族教训)。
- **逐层传递函数**: 静电学 / 能带 / 输运三层映射, 每层只回答"输入→输出→公式", 不跨层。

## 2. 五步阅读协议

| 步 | 做什么 | 产出 | 时长锚点 |
|---|---|---|---|
| **Step 0 黑箱三要素** | 读摘要+图, 写下 `{输入旋钮 \| 输出观测量 \| 声称结论}` | 三要素一行 | 5 min |
| **Step 1 变量依赖图** | 每个符号问"由谁算出? 决定谁?", 钉死四层 | 依赖图 | 深读前**一次做完** |
| **Step 2 逐层传递函数** | 每层只记"输入→输出→公式" | 三层映射表 | — |
| **Step 3 可辨识性提问** | 每个结论问三句 + 机制五问(§3) | 判别实验表 | **含金量所在** |
| **Step 4 闭环自适应** | 复述→回原文核对→只在歧义处深挖 | 修正记录 | — |
| **Step 5 三层标注** | 每句话标 📜Q原文 / 推导 / 💭I推断, **从第一遍就做** | 证据分级 | — |

### 2.1 Step 3 的两类提问(互相补充)

**① 可辨识性提问**(判别逻辑类): 这个结论靠哪组数据唯一确定? 竞争解释是什么? 被什么数据排除?

**② 机制溯源五问**(机制理解类, 见 `mechanism_questions.md`): 机制从何而来? 量怎么定义? 怎么从观测量提取? 为什么随 X 变/不变? 与邻近概念(LL/赝朗道/Berry 相位/FP)差在哪一条观测上?

> E10 暴露的障碍 = 符号歧义/量分层/事实推导不分/竞争解释 → 催生五步协议; E12 暴露的**新**障碍 = 机制理解盲区 → 催生五问模板。两类提问合起来: 同时问"**谁幸存**"(可辨识性)和"**为什么这样运作**"(机制)。

## 3. 两个 worked examples(判别实验表)

**E10 (Rickhaus 2018)**:

| 判别 | 判据 | 排除谁 | 确立谁 |
|---|---|---|---|
| 1D vs 2D | FP 在 n 上等间距(k_F∝n) vs 抛物线(k_F∝√n) | 2D 体态 | 1D 通道 |
| AB vs 充电 | n-B 图正负两斜率并存 vs 单斜率 | 单电子充电 | AB 干涉 |
| QVH vs QH | 振荡从 QH 区连续到 B=0 | QH 边缘通道(需 B) | QVH 畴壁态(B=0 已存在) |

**E12 (Xu 2019)**:

| 判别 | 判据 | 排除谁 | 确立谁 |
|---|---|---|---|
| 体 vs 墙 | D 开隙畴区绝缘但 NP 仍金属(Bernal 对照) | 畴区/体导电 | 通路在墙(**必要条件**) |
| AB vs SdH | 低场 B 周期 + 50% 振幅 + 120 K 存活(LK 热阻尼) | SdH | AB 干涉(1D 回路) |
| miniband vs 介观涨落 | 零场 ρxx(n) 振荡不随接触配置与 D 变 | 随机介观涨落 | 确定性 miniband 填充 |
| 谐波归属 | ΔB/ΔB/2/ΔB/3 + 衰减斜率比 1:4/3:5/3 | 其他回路几何 | 1/2/3 三角畴回路 |
| ΔB 与 Δn 独立互验 | ΔB→A=0.86 与 Δn=4/A→A=0.80 | 单一测量偶然 | 回路面积唯一 |
| Hall 反转 vs 现有模型 | ρxy 多次变号(LL 只单调) | 现有模型 | skipping-orbit 类比(开放) |

E12 附加结构: **三支柱 + 双轴判别**(存在性→相干+1D→谱量子化), 且**主结果与判别表一一对应**(判别表是证据、主结果是结论, 笔记中必须显式映射)。

## 4. 两个深层洞察

1. **微分观测 = 高通滤波**: E10 测 dG/dn、E12 测 d²ρxx/dB², 都是在输出端压低低频背景、放大高频振荡——读者"读主干、滤背景"与作者是同一个操作。
2. **论文最强的论证都是可辨识性论证**: 结论的强度来自"候选模型集里唯一幸存", 而非"直接观测"。读者的任务就是找出每个结论背后的判别实验。

## 5. 辨识结构的控制论基础: 11 组件(可选深读)

一次完整的辨识由 11 个组件构成; **模型结构**不是独立组件——它是候选模型集 M 的参数化形式(1D vs 2D、网络 vs 孤立、手征 vs 螺旋), 并入组件 5。

| # | 控制论组件 | 实验文献对应 | E10 (Rickhaus) | E12 (Xu) |
|---|---|---|---|---|
| 1 | 被辨识系统 (plant) | 样品器件 + 未知内部电子结构 | 腔内输运通道的几何与拓扑性质 | AB/BA 畴壁三角网络的输运性质 |
| 2 | 输入 u(激励) | L1 旋钮 | Vtg/Vbg/B/T | Vtg/Vgg/B/T |
| 3 | 输出 y(观测) | L4 观测量 | G、dG/dn_in | ρxx、ρxy、d²ρ/dB²、FFT 谱 |
| 4 | 噪声/扰动模型 | 热展宽、无序(Dingle)、陷阱电荷、介观涨落、平滑背景 | 1.5 K 锁相; SiO₂ 陷阱; "大而平滑背景" | LK 热阻尼; UCF; 单调背景(数值未给) |
| 5 | 候选模型集 M(含模型结构) | 竞争解释集 | {1D,2D}×{AB,充电,QH,QVH} | {墙,体}×{AB,SdH,UCF,miniband}×{网络,单通道} |
| 6 | 估计器 (estimator) | 测量 + 信号处理链 | 锁相 + 数值求导 dG/dn | 锁相 + 去背景 + FFT |
| 7 | 参数估计 | 周期/振幅 → 物理参数 | ΔB→A=11200 nm²、Δn→L_tot=870 nm、n₂→θ=0.42° | ΔB→A=0.86、Δn=4/A→A=0.80、ΔE→v_DW≈10⁶ m/s |
| 8 | 可辨识性 (identifiability) | 判别实验(排除竞争解释) | 1D/2D、AB/充电、QVH/QH 三类 | 六条判据 + 双轴判别 + 三支柱 |
| 9 | 模型验证/判别 | 自洽交叉验证 | L/D 依赖与模型一致; 408≈400 nm 几何对照 | ΔB→A 与 Δn→A 独立互验; 谐波衰减比 |
| 10 | 实验设计(激励设计) | 扫什么轴、沿哪条线、扫多大范围 | 双栅正交旋钮(共模/差模)独立调 n 与 D | 固定 D 沿 D=const 线扫 n; 宽 B 范围(**持续激励**) |
| 11 | 不确定性量化 | 误差棒 + 定性保留 | ΔB=0.37 T 无误差棒(读图); "good indications" | ±0.02 T / ±0.5×10¹⁰ / ±0.04×10⁻¹⁰ cm²; 背景只给相对量 |

**组件的功能不对称**(为什么不能平铺成 11 个节):

| 角色 | 组件 | 在笔记中的待遇 |
|---|---|---|
| **结论(收益)** | 可辨识性 #8、模型验证 #9、参数估计 #7 | 论文的含金量与 report 素材, 必记 |
| **前提** | 候选模型集 #5、噪声 #4、实验设计 #10 | 限定结论适用范围; 作为判别表"前提与限定"记 3–5 行, **不写独立大节** |
| **坐标** | 系统 #1、输入 #2、输出 #3 | 消歧义用, TL;DR 一句 + 四层变量表 |
| **手段** | 估计器 #6、不确定性 #11 | 只记非常规部分, 多数细节 grep 找回 |

## 6. 笔记模板: 11 组件坍缩为 4 块

```
头部表格(编号/期刊/DOI/PDF/精读日期)
┌ 块1 TL;DR ────────── 被辨识系统(#1): 本文想辨识什么 —— 问题句式, 2–4 句
├ 块2 四层变量表 ───── 输入 u(#2) / 输出 y(#3) / 中间态 —— 一行一符号, 钉死歧义
├ 块3 判别表(置顶) ─── 可辨识性(#8, 核心) + 候选模型集 M(#5) 并入"排除谁"列
│                      · 主结果 ↔ 判别表映射(显式, 每条主结果由哪几条判别确立)
│                      · [前提与限定] 噪声/扰动(#4) + 判别性扫轴(#10) + M 边界声明 —— 3–5 行
└ 块4 数据/提取链 ──── 参数估计(#7) + 模型验证互验链(#9) + 不确定度标注(#11)
支撑节(非辨识组件) —— 局限与未解决 / 与其他工作的关系 / 对后续的影响
                      / 理论模型映射(供计算对标) / 目的接口(三问引用式 + 增量价值)
                      / 反向核对 pass / 更正日志
```

- **块3 的[前提与限定]是模板的修正点**: 噪声源与抑制、判别性扫轴、候选集 M 的边界声明各 1–2 行。它们限定判别结论的适用范围, 防"封闭世界假设"(判别表只在**未声明的候选集**里完备)。不写独立大节——前提混入正文就是本末倒置(E10 "推导塞进实验方法"的教训)。
- **三档分级(11 组件按重读价值归类)**: A 必记(可辨识性 #8、候选集 #5、验证 #9、参数估计 #7, 全粒度); B 简记(系统 #1、输入输出 #2/#3、噪声 #4、实验设计 #10, 表格化/3–5 行); C 不记或移出(估计器细节 #6、制备细节、不确定度 #11——标准件不记, #11 折叠为数字旁标注)。
