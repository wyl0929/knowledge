# [METHOD] 读文献与记笔记方法论 — 入口与公共层

> **本文档是入口, 不是全量**。它只做三件事: ① 目的层(为什么读/为什么记)—— 读任何论文之前; ② 类型分诊(读摘要 1 分钟判实验/理论/综述)→ 路由到专属文档; ③ 公共记录层规范(三层分离 / 资产接口分离 / 三档分级 / 证据分级 / 验收)—— 两类论文**共享**的记笔记规则。
>
> **实验与理论的具体阅读法与笔记模板已拆分为两份独立文档, 二者互不影响(不互相引用对方的框架词汇)**:
> - **实验论文** → [`experiment_paper_reading.md`](experiment_paper_reading.md)(系统辨识五步 + 4 块模板)
> - **理论论文** → [`theory_paper_reading.md`](theory_paper_reading.md)(演绎结构 + 5 块模板)
>
> 辅助: 机制理解提问模板 `mechanism_questions.md`; 理论阅读案例/范本 `theory_paper_reading_case_T05.md`; QC 唯一权威见 paper-reading SKILL 的 `LITERATURE_QC_PROTOCOL.md`。

## 0. 目的层: 先问两个"为什么"

### 0.1 为什么必须先问

理解层解决的是**"准确"**(忠实重建论文的论证链条、消除符号歧义、找到支撑结论的证据)。但**"高效"离开目的是没有定义的**——"哪里该深读"不只由"难懂"决定, 更由"这里是否回答我的问题"决定。E10 花一天读一篇 6 页论文的直接原因: 目的层缺位时, 理解层全程满负荷运转。

读者是控制器, 目标函数缺一项:
$$J=\underbrace{\|e\|}_{\text{理解误差}}+\underbrace{r(\text{目的收益})}_{\text{本次补上}}$$
目的 = 先验/采样策略(决定预算分配); 理解层决定精度; 记录层决定复用。

### 0.2 读文献的目的(每篇可多重, 阅读前先标注)

| 目的 | 阅读策略 | 笔记侧重 |
|---|---|---|
| ① 服务项目问题(如 Phase S 三问) | 只精读命中问题的链条, 其余略读 | 目的接口(三问引用式) |
| ② 建立领域地图 | 粗读为主, 记谱系位置 | 卡片/registry |
| ③ 学表征/计算方法 | 精读 SI 器件与方法节 | shared 讲义(方法类) |
| ④ 找缺口(开放问题) | 精读 Discussion/limitations | gap 表 |
| ⑤ 交叉验证已有笔记 | 定向核对, 不比对新内容 | QC 更正日志 |

### 0.3 记笔记的目的(决定笔记必须满足的要求)

| 目的 | 笔记必须满足 |
|---|---|
| 外部记忆(免重读原文) | 证据分级 + 数字可 grep 溯源 |
| 理解压缩(重读成本低) | 功能结构图, 非线性摘抄 |
| 项目接口(能组装进报告) | 目的接口节 + 数字可直接引用 |
| 素材库(写报告时取用) | 数字全部过 QC 反向核对 |
| 元认知(记录当时的疑问与判断) | 疑问清单([METHOD-Q]) |

### 0.4 Phase S 的实例

目的 = 回答导师三问(Q1 如何表征 / Q2 理论如何解释 / Q3 理论-实验对应)。因此: 阅读预算集中在**直接命中问题的链条**(实验论文的判别实验与可观测量、理论论文的推导链与预言), 无关材料细节、无关谱系开环略读; 笔记末尾挂"Phase S 三问(引用式)"接口节。

## 1. 类型分诊(读摘要 1 分钟, 决定走哪份文档)

| 类型 | 判据 | 走哪份文档 |
|---|---|---|
| **实验** | 有器件/样品、测量、数据图、(误差棒) | [`experiment_paper_reading.md`](experiment_paper_reading.md) |
| **理论** | 有模型/哈密顿量、推导、无实验数据 | [`theory_paper_reading.md`](theory_paper_reading.md) |
| **综述/其他** | survey/review 性质, 无单一模型也无单一实验 | ⚠️ 未定义(暂按谱系/观点地图处理, 或回 research-onboarding) |

⚠️ 当前方法论只覆盖前两类; 综述/其他(R1–R4 类)需要第三种变体, 待定义。

> 分诊的意义: **实验论文 = 系统辨识记录(黑箱溯因), 理论论文 = 演绎系统(白箱演绎)**。这是两类不同的知识活动, 阅读法与笔记模板必须分开, 不能把一方的框架(如"四层变量/判别表")硬套到另一方——这正是拆分两份文档的原因。

## 2. 公共记录层规范(两类论文共享)

> 以下规则对实验、理论论文**同样成立**, 与"走哪份文档"无关。它们定义"笔记必须满足的质量底线"。

### 2.1 三层分离: 按"复现范围"决定内容去向

| 层 | 内容 | 位置 | 判据 |
|---|---|---|---|
| 论文事实 | 本文说了什么、测了什么/推了什么(📜Q) | 单篇 `paper_review_*.md` | 只在本篇出现 |
| 共享讲义 | 多篇复现的通用物理/方法 | `note/shared/physics/`([PHY-*] 锚点) | 复现于 ≥2 篇 |
| 方法模板 | 阅读提问/笔记规范 | `note/shared/method/`([METHOD-*]) | 与具体论文无关 |

review 只写"本文代入"后的具体数字, 通用推导用锚点引用, 不复制讲义。

### 2.2 资产/接口分离: "论文自身信息"与"对我有何帮助"

| | 论文自身信息(资产) | 对我有何帮助(接口) |
|---|---|---|
| 稳定性 | 持久 —— 论文不变它不变 | 可变 —— 项目结束目的就换 |
| 组织 | 按论文自身的论证结构(忠实重构) | 按项目问题(投影) |
| 位置 | 正文 | 尾部接口节 |

原则: **接口不进入正文、不重塑正文**——否则笔记变成一次性的(Phase S 之后对新 Phase 失效)。接口节可随项目增删, 资产不动。外部对应: Zettelkasten 的"文献笔记 vs 永久笔记"分离。

### 2.3 三档分级: 决策规则(为什么不必全记)

对每个内容块问一句: "**三个月后我会引用它、或它会改变我对某个结论的信任吗?**" 会 → 记(A/B 档); 不会 → 不记(留 📜Q 位置索引, 需要时 grep 原文)。

全记的三个害处: ① 重读收益递减(标准件细节重读概率≈0); ② 稀释核心(把含金量高的结论/判别淹没了); ③ 前提混入正文(把噪声/扫轴写成与结论平级的大节, 本末倒置)。

### 2.4 证据分级 + 不确定度标注 + 硬规则(完整规范见 paper-reading SKILL `LITERATURE_QC_PROTOCOL.md` v1.1)

- **证据分级(来源轴)**: **📜Q** = 原文直接支持(附位置)——唯一可进报告正文的等级; **推导** = 由原文公式合成(须标「推导」); **📊F** = 读图提取(标「读图估算」); **💭I** = 推断/常识补全(不得进交付物正文)。
- **不确定度标注(可信度轴, 与来源轴正交)**: 来源轴回答"数字从哪来", 可信度轴回答"数字有多可信"——`[±]` 原文误差棒 / `[~]` 原文 =/≈ 但无误差棒 / `[读图]` 图·色标提取 / `[相对]` 仅相对量。
- **硬规则**: ① 禁止无源数字(必须能 grep 到原文); ② 禁止跨论文迁移数据; ③ 禁止常识脑补(原文没有的参数/条件不得补写, 不确定写 `NEEDS_VERIFICATION`); ④ 单位与对象须与原文一致; ⑤ 原文未给的量只引相对量。
- **三层防线**: 写作时分层标注 → 写完后 Agent 反向核对(数字 vs 原文)→ 人类抽检(只查 📊F/💭I + 矛盾处 + 核心结论)。

### 2.5 验收判据(采自 `how_to_read_paper.md`)

三个月后重读笔记, 若不能回答以下三问, 笔记不合格: ① 能不重读原文就引用吗? ② 它能回答当前项目的哪个问题? ③ 我当时的疑问(及其解答)还在吗?
