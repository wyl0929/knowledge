# [METHOD] 理论论文阅读法与笔记模板

> **本文档只讲理论论文**。实验论文另见 [`experiment_paper_reading.md`](experiment_paper_reading.md)——二者**不互相引用对方的框架词汇**。实验论文用"系统辨识/黑箱/四层变量/判别表", 理论论文用"演绎结构/白箱/推导链/结论清单", 二者是**两类不同的知识活动**, 不混用、不"换轴"。
> **公共规范**(目的层、类型分诊、三层分离、证据分级、三档分级、验收)见入口 [`paper_reading_methodology.md`](paper_reading_methodology.md)。
>
> **一句话**: 理论论文不是"系统辨识"(黑箱溯因), 而是**演绎系统**(白箱演绎)——研究对象是作者自写的理想模型, "未知"不在模型内部而在**解的性质**; 阅读 = 顺推导链走 + 每步问假设/合法域; 笔记 = 按五块(模型白箱/推导链/结论清单/假设-结论依赖图/接口)。
>
> 证据基础: T1 Martin 2008(`note/theory/paper_review_T01_martin2008_prl.md`)与 T5 San-Jose & Prada 2013(`note/theory/paper_review_T05_sanjose2013_prb.md`)两篇精读; T5 阅读过程复盘 + 可复用检查清单见 `theory_paper_reading_case_T05.md`。

## 1. 本质定位: 白箱演绎, 不是黑箱溯因

> 2026-09-08 修正: 早期曾把"系统辨识"框架"换轴"套到理论论文, 这是**启发式类比**——它保留了"输入→输出→判别"的纪律, 但**逻辑类型不对**, 会误导读者去找"黑箱/反推量/可辨识实验"(理论论文里都不存在)。下表为根本定位:

| | 实验论文 | 理论论文 |
|---|---|---|
| 研究对象 | 真实器件 = 黑箱(内部未知) | 理想模型 = **白箱**(作者自己写的) |
| 知识怎么建立 | 溯因: 观测→反推内部 | **演绎: 假设→推导→预言** |
| "未知"在哪 | 器件内部结构 | 模型的**解的性质**(内部已知, 不需反推) |
| 验证方式 | 数据排除竞争解释 | 自洽核对 + 极限对照 + 与已知结果核对 |
| 结论性质 | 事实(受测量误差限定) | 定理/估算/预言(受**假设**限定) |
| 核心风险 | 测错、解释错 | **假设失效** + 封闭世界(集外候选) |

**理论论文的"结构"是演绎结构**:

$$\{\ \text{假设/条件}\ \}\ \xrightarrow{\ \text{推导链}\ }\ \{\ \text{预言/定理}\ +\ \text{合法域}\ \}$$

对应的三组"工具"是理论论文自己的, 不是实验工具的换名:
1. **模型定义 + 假设清单**(实验论文的黑箱三要素在这里**不适用**——没有黑箱, 只有作者明写的模型);
2. **参数分册**(区分"作者设定的自由参数" vs "推导所得的量" vs "固定常数" vs "预言量")——动机是"区分设定 vs 推导", 不是"反推"; **不存在"反推量 θ̂"这一层**;
3. **内部验证 + 概念区分**(见 §5)——实验论文的"判别实验/判别表"(数据排除竞争解释)在这里**不存在**, 别硬找。

## 2. 阅读逻辑: 顺推导链走 + 每步三问

**理论论文的节是按演绎顺序组织的, 是一条链, 不是并列主题。** 典型四层:

| 层 | 角色 | 这一步的"输入→输出" |
|---|---|---|
| 前提定理层 | 继承/复述已知结果 | 输入=已知物理(对称性、体-边对应…); 输出=本文依赖的前提定理 |
| 模型层 | 定义理想系统 | 输入=哈密顿量/作用量 + 参数; 输出=模型的谱/相图结构 |
| 推导层 | 核心推演 | 输入=模型 + 额外近似; 输出=判据/预言 |
| 边界层 | 测试假设的失效 | 输入=某条假设; 输出=该假设被破坏时的行为 |

**每一步问三句**:
1. 这一步的**输入**和**输出**是什么?
2. 它用了哪个**假设/近似/定理**?
3. 这个输出的**性质**(定理/估算/预言)与**合法域**(哪个假设失效会推翻它)是什么?

> 例(San-Jose 四部分即一条链): ① Band topology(前提定理层: 偏压 AB/BA→谷陈数反号→界面 2 模) → ② Continuum theory(模型层: 4×4 哈密顿量 + 大/小角度两区) → ③ U↔TPH 判据(推导层: 一维突变界面 + 两分量近似 → Eq.(1)) → ④ atomic defect(边界层: 谷守恒假设被打破 → 可编程)。读 = 顺链走 + 每步三问, 而非把四节平铺成"四个主题"。

## 3. 笔记模板: 5 块

```
头部表格(编号/期刊/DOI/PDF/精读日期)
┌ 块1 模型白箱 ──────── 哈密顿量/作用量 + 参数分册 + 显式假设清单
├ 块2 推导链 ────────── 每步"输入→输出→所用假设/定理→合法域", 顺论文演绎顺序
├ 块3 结论清单(分层) ── 每条标"定理 / 估算 / 预言", 注明依赖假设 + 可检验性
├ 块4 假设-结论依赖图 ─ 哪个假设失效 → 哪个结论崩塌(含金量所在)
└ 块5 接口 ──────────── 可检验性 / 设计原则 / 后续文献修正
支撑节 —— 局限与未解决 / 与其他工作的关系 / 对后续的影响
          / 理论模型映射(供计算对标) / 目的接口(三问引用式 + 增量价值)
          / 反向核对 pass / 更正日志
```

**各块说明**:

- **块1 模型白箱**: 因为模型是"白箱"(作者明写), 笔记要**完整写下哈密顿量 + 参数含义 + 显式假设清单**(而不是像实验论文那样"反推内部")。假设清单 = 本文一切结论的"前提集合"。
- **块2 推导链**: 每步只记"输入→输出→所用近似→合法域", **不重推代数**。合法域**跟着推导记**并汇总进块4。
- **块3 结论清单(分层)**: 理论结论必须按**性质**分层, 不能平铺(见 §4)。
- **块4 假设-结论依赖图**: 理论论文三个月后最可能被引用的是"何时失效", 不是推导本身。这是**含金量所在**。
- **块5 接口**: 哪些预言可被实验检验、哪些是设计原则、后续文献怎么修正(时间倒挂标 💭I)。

> **落地范本**: `note/theory/paper_review_T05_sanjose2013_prb.md`(2026-09-08 按五块重写)。

## 4. 结论分层: 定理 / 估算 / 预言

理论论文的结论不能平铺, 必须按**性质**分三类, 每条标"依赖假设 + 可检验性":

| 类 | 性质 | 例子(T5) |
|---|---|---|
| **定理式主张** | 数学/拓扑论证的产物, 受假设限定 | 每谷每自旋 2 条 TPH 模; $C_K^{AB}=-C_K^{BA}$ |
| **估算** | 经验/近似判据, 非严格定理 | Eq. (1); $U\sim90$ meV ↔ $L_M\gtrsim290a_0$; 100 nm ↔ ~45 meV |
| **预言** | 待实验验证, 保留作者动词强度 | 可编程拓扑电路(propose / could be used to) |

配套规则:
- **保留作者动词强度**: propose / estimate / believe / find / show, "show" 在理论论文 = 数学构造, 非实验证实; 标 📜Q(预言)。
- **"没写什么"与"写了什么"同等重要**: 原文未讨论的量(如 T5 未讨论量子化电导)→ 笔记显式声明"不引入 4e²/h"(防跨论文迁移, 可审计)。
- **全文无 ±**: 理论论文数字均为解析/数值估算, 统一 📜Q[~]; 📊F 几乎不出现, **「推导」等级成为主角**。

## 5. 内部验证 与 概念区分(理论论文的"证据", 非"判别")

理论论文**没有**实验论文那种"数据排除竞争解释"(溯因)。它的"证据"是两类**性质不同**的东西, 别混:

**(a) 内部验证(一致性核对)**:
1. 解析↔数值互验(如 T5 的 Eq.(1) 判据线与 DOS 谱 crossover "roughly correlates");
2. 极限对照/负对照(如 T5 的 θ=4° 大角度同旋钮无网络);
3. 与已知结果的量级核对(如 T5 的界面模衰减 λ 与 Martin 2008 的 $\xi\sim a/\sqrt{\varphi_0}$)。

**(b) 概念/图景区分(分类, taxonomy)**:
- 螺旋 vs 手征(有/无时间反演不变性)、弱保护 vs 强保护(mod 2 是否缺省)、平台 TBG vs h-BN。
- 这是"**分类**", 不是"排除竞争解释"——理论论文没有后者。

> ⚠️ 不要再用"判别表/论证判别表"这类实验溯因词汇——它会把"分类"误当成"可辨识性"。

## 6. 理论论文特有陷阱(六个)

| 陷阱 | 表现 | 检测 |
|---|---|---|
| **后世语言污染** | 用后来的语言重述原文(Chern/Z₂/"闭合-重开相变") | 措辞级 grep 证伪 → 标"后世语言 💭I" |
| **常识脑补参数** | 给原文没有的数值(如 t⊥≈0.4 eV) | 数值+eV grep → 删除 |
| **推演当原文** | 从"每谷 2 模"推演 4e²/h 当原文结论 | 标 [推导]💭I⚠️; 计数核对谷×自旋×方向 |
| **预言写成事实** | "We demonstrate" = 数学构造非实验证实 | 保留 propose/predict/may have implication, 标 📜Q(预言) |
| **OCR/公式破碎** | pdftotext 把分数 α=(1/6)γ⊥/εM 拆成 "16 γ⊥"、根号位移 | `-raw` 复核 + **公式自洽反推**双确认 |
| **符号家族歧义** | 同字母不同层(γ⊥≠l⊥); εM 是两锥相交能量不是能隙 | 符号分册钉死 + 结构要点注 |

## 7. worked examples

### 7.1 T1 Martin 2008(演绎链示例)

推导链: 4-component BLG 哈密顿量 →(V≪t⊥) 2-band 二次色散约化 → 能谱 Eq.(3) → 准经典 $H_{qc}$ → 波方程(二阶)→ 解析/数值解 → 拓扑荷 $N_3=\pm2$ 论证。

五条概念区分: ① 拓扑 vs 普通约束(φ=sgn x 出零模 vs φ=tanh²(x/4) 无零模); ② BLG 手征准粒子 vs Dirac 费米子(零模源自二次色散); ③ helical vs chiral(TR 由谷恢复); ④ 数目=拓扑真空荷 vs 偶然($N_3=\pm2$ 与 2 支跨零互验); ⑤ 零电荷 vs 分数电荷(对称性→密度 x-无关常数)。

## 8. 增量经验(T5 精读复盘, 2026-09-08)

1. **"合法域地图"是理论论文的方法节**: 跟推导的收益低于画出"每层推导何时失效"地图(T5: 两分量近似 U<γ⊥ / 谷守恒 / θ≳0.35° 简单图景下限 / mod 2 缺省 / L_M 公式 θ<30°)。合法域跟着推导记, 散落 = 重读时找不到。
2. **措辞级限定句必须逐字保留**: "mod 2 is absent in our case (N=2) since we consider only valley-preserving perturbations, hence 'weak' topological protection"——弱/强保护、N=2、预言动词都是结论的组成部分, 不是修辞。
3. **已有笔记时的重读 = 全量数字反向核对 + 找"无公式的悬空量"(如 α 只有名字无公式)+ 找"被引理由写错的行"(如引文分组)**; 不必重写, 增量修正 + 更正日志即可。
