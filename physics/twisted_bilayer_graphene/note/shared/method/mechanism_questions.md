# [METHOD-Q] 读实验论文的"机制理解提问"模板

> 与 `systems_science/case/15_case_study_paper_reading_system_identification.md` 的 Step 3「可辨识性提问」互补。
> 15_case_study 的 Step 3 问"**哪个模型幸存**"（排除竞争解释）；本文档补问"**这个机制怎么运作、这个量怎么定义/提取**"（理解深度）。
> 模板从 E12（Xu 2019）阅读对话提炼；判别逻辑类实例 → 15_case_study Step 3 的第二个 worked example；机制理解类 → 新维度。

## 机制溯源五问（读到一个"机制主张"或"导出量"时依次问）

1. **从何而来？** 这个机制/能级/周期是哪个物理过程产生的？（闭合回路驻波？朗道量子化？静电？）
2. **量怎么定义？** 这个符号是群速度还是费米速度、是面密度还是线密度？（如 $v_{DW}$ = 群速度，非经典漂移速度）
3. **怎么提取？** 从哪个观测量、经哪条公式反推？（如 $v_{DW}$ 从 miniband 间距 $\varepsilon=\delta/M$ 反推）
4. **为什么随 X 不变/变？** 周期对 D/B/θ 的依赖揭示它是几何、静电还是磁场效应？（如 Δn 只含 λ 不含 D → 几何量子化）
5. **与邻近概念怎么区分？** 它和最容易混淆的概念（LL/赝朗道、Berry 相位、FP）差别在哪一条观测上？
