## 1. 问题一：理论文章如何高效准确地阅读？

### 1.1 与实验论文的对照总表（速查）

| 维度 | 实验论文 | 理论论文（T05 实证） |
|---|---|---|
| 被辨识对象 | 器件 + 未知电子结构 | **模型/哈密顿量及其解** |
| 元辨识任务 | 重建"旋钮→观测"链 | 重建"**假设→推导→预言**"链 |
| 判别表判据 | 数据排除竞争解释 | **论证/对称性/极限对照/自洽互验** |
| "判别实验"的对应物 | 控制变量实验 | **负对照 + 解析↔数值互验**（见 §1.2） |
| 数字性质 | 有误差棒/无误差棒 | **全是 ≈/∼ 估算，全文无 ±** |
| 证据分级主角 | 📜Q + 📊F | 📜Q + 「推导」；📊F 几乎不出现 |
| 结论强度 | 数据支撑的论断 | **预言 ≠ 事实**，须保留作者动词 |
| 方法节 | 器件/测量链 | **合法域清单**（每层推导何时失效） |

### 1.2 高效：读三个点，而不是跟推导

1. **读"负对照"**。理论论文最强的可辨识性论证常藏在参数区间的对照里：T05 的 $\theta=4°$ 大角度算例（同一旋钮 $U$ 下仅平移 Dirac 锥、无网络）就是整个"网络是小角度特有现象"论证的负对照——找到它，论证骨架就完成了一半。类比 E12 实验论文的 Bernal 对照。
2. **读"自洽互验"**。解析判据与数值谱的互相印证 = 理论论文内部的"验证链"：T05 的 Eq. (1) 虚线边界与 DOS 谱 crossover "roughly correlates"（作者原话）就是全文最值钱的一处自洽。**笔记必须把这个互验单独记下来**（review §4.5 交叉验证行）。
3. **读"合法域地图"（validity map）**。理论论文的"方法节"不是器件而是**每层推导的适用范围**：T05 一张合法域地图 = {两分量近似需 $U<\gamma_\perp$；连续模型谷守恒 → 吸附原子处失效故用 TB；简单图景止于 $\theta\sim0.35°$；$\mod2$ 缺省 = 只考虑谷守恒扰动；$L_M$ 公式需 $\theta<30°$}。**跟推导的收益远低于画出这张地图**——三个月后你会引用的是"什么时候失效"，不是代数细节。
4. **读"预言强度表"**。把每个结论标上作者动词即可一次锁定引用价值：T05 的 propose（可编程电路）/ estimate（45 meV）/ believe（ideal platform）是预言；find/show 是论证内结果。**不逐句纠结的诀窍 = 先扫动词**。

### 1.3 准确：理论论文特有的四个险点（T05 全部实证）

| 险点 | T05 实证 | 检测手段 |
|---|---|---|
| **后世语言污染** | 笔记不写 Z₂/"闭合-重开"；"weak" 保护必须带引号且配原文理由 | 措辞级 grep（"Z2/TI/重开" 均无命中） |
| **常识脑补参数** | 全文唯一 eV 数值是 $\gamma_\perp\approx0.33$ eV，不脑补 $t_\perp\approx0.4$ eV | 数值+eV grep 全文 |
| **推演当原文** | 本文**未**讨论量子化电导 → 笔记显式声明"不引入 4e²/h"（比被动避免可审计） | 计数核对（谷×自旋×方向）后仍不写 |
| **预言写成事实** | "we have shown" = 数学构造非实验证实；propose/estimate/believe 原词保留 | 动词清单 + 📜Q(预言) 标注 |

另两个理论论文特有的准确性问题（本次新发现，实验论文少见）：

5. **OCR/文本提取陷阱**：满篇公式在 `pdftotext -layout` 中会被拆碎——$\alpha=(1/6)\gamma_\perp/\varepsilon_M$ 变成 "16 γ⊥"、$\lambda=\sqrt{U\gamma_\perp}/(2v_F)$ 的根号位移成 "$U\sqrt<\gamma_\perp$"。对策：`-raw` 复核 + **公式自洽反推**（$\lambda R=-\ln0.05$ 与 Eq. (1) 的 $z^2$ 因子互验，两处独立确认同一公式才算过）。
6. **符号家族歧义比实验论文更隐蔽**：$\gamma_\perp$（层间耦合）≠ $l_\perp$（耦合长度）；$\varepsilon_M=88\,\text{meV}\cdot\theta$ 是**两锥相交能量，不是能隙**；$\Delta K$ ≠ $|K|$；$U/2$ 是每层对角项。理论笔记的"四层变量表"必须把这类**非旋钮常数与同名导出量**分栏钉死（review §1 的符号说明行）。

### 2.2 [前提与限定] 是理论笔记的含金量所在

理论论文三个月后最可能被引用的不是结论而是**边界**。T05 范本的[前提与限定]块（review §1）包含三行：
- 扰动清单：谷间散射（开关的来源+脆弱点）/ 弹性畸变（smooth 则不破坏反而增强）/ 谷守恒前提；
- 判别性扫轴：$\theta$ 轴（4°→0.2°）、$U$ 轴（0–180 meV）、$\varepsilon$ 轴（$|\varepsilon|<|U|/2$）；
- 候选集 M 边界声明：应变重构/真实无序/多体关联/**魔角平带物理未建模**（封闭世界假设风险显式化）。

> 记录规则：每层推导的合法域**跟着那层推导记**（如 Eq. (1) 旁写"两分量近似，$U<\gamma_\perp$"），再汇总进[前提与限定]。合法域散落=重读时找不到"何时失效"。

### 2.3 数字与证据：换标注样式，不换硬规则

- 全文声明"无 ±"→ 所有数字统一 📜Q[~]，附位置（节/Eq./Fig. caption）。
- **"无数字"本身要记录**：review §4.3 显式声明"本文未讨论量子化电导（不引入 4e²/h）"——理论笔记里"没写什么"与"写了什么"同等重要（防止跨论文迁移）。
- 反推量 θ̂ 通常为空，但要记**作者代入的估算**（$U\sim90$ meV 是作者选的"现实值"而非推导结果）。
- 三层分离照旧：通用推导晋升 shared（valley Chern→[PHY-BERRY]、通道计数→[PHY-LB]），本文特有（Eq. (1) 判据、常数 $z=20.76$、$l_\perp\approx7.3a_0$）留 review。

### 2.4 一个范本细节：review 与 T9（下一篇理论论文）的接口

S-Q2-T5 成功判据之一是"网络概念与 T9 的承接关系清晰"。范本做法（review §7 + 增量价值行）：
- §7 显式一行："T9 Efimkin 2018 = 本文网络范式的系统化/严格化（S 矩阵）"，并标 💭I（时间倒挂，非本文引用）；
- 增量价值行写清**分工**："T05 多什么（判据 Eq. (1) + 可编程开关概念）、少什么（无 S 矩阵/网络能带定量）"。
> 这样 T9 精读时起点就是"补 S 矩阵严格化"，而不是重新读一遍网络概念——**理论系列阅读的接力棒接口**。

## 6. 方法论迭代（2026-09-08）：理论论文不是"系统辨识"，而是"演绎系统"

> 本次讨论的根本修正（已回写 `theory_paper_reading.md` §1，为 §4 的根本定位）。一句话：**理论论文的研究对象是白箱（作者自写的理想模型），不是黑箱（真实器件），所以严格说没有"黑箱三要素 / 四层变量 / 可辨识实验"**。

- **本质区别**：实验论文 = 黑箱溯因（观测→反推内部）；理论论文 = 白箱演绎（假设→推导→预言）。"未知"不在模型内部，而在**解的性质**。
- **三个实验工具重新定位**：① 黑箱三要素 → 改为"模型定义 + 假设清单"；② 四层变量 → 降级为"参数分册"（自由参数/推导量/固定常数/预言量），**删掉"反推量 θ̂"这一层**（理论论文里是空的）；③ 可辨识实验/判别表 → 不存在，对应物是"内部验证"（自洽互验/极限对照/量级核对）与"概念/图景分类"，两者都不是溯因排除。
- **阅读逻辑** = 顺演绎链走 + 每步三问（输入输出? 用了什么假设? 输出的性质与合法域?）。San-Jose 四部分是**一条演绎链**（前提定理 → 模型 → 推导 → 边界），不是并列四主题。
- **笔记结构** = 五块（模型白箱 / 推导链 / 结论清单分层 / 假设-结论依赖图 / 接口），取代"四层变量表 + 判别表"。
- **代价与残值**：早期"辨识类比"保留的思维纪律（输入→输出→判别、区分设定 vs 推导、逐条标证据）仍然有效，被吸收进五块结构；被丢弃的只是"黑箱/反推/可辨识实验"这套**词汇与定位**。
