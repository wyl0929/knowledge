# [PHY-QPI] FT-STM / 准粒子干涉（QPI）：q 空间谷内 vs 谷间散射判据

> 复现于所有"STM 散射 / 准粒子干涉"文献（Rutter 2007 起源；Verbakel 2021 E13 谷保护判据；通用 QPI）。本文档讲通用物理；各 review 只写"本文代入"后的具体数字。

## 1. FT-STM / QPI 原理

STM 形貌 / STS 测的是实空间 LDOS。存在散射源（缺陷、畴壁、AA 节点）时，入射波与散射波叠加干涉 → 驻波 → LDOS 空间调制。对实空间图做 2D FFT → q 空间功率谱，**每个峰对应一个被激发的散射通道**：

$$q_{\text{peak}} = k_f - k_i$$

峰**位置** → 散射波矢（哪种散射）；峰**有无/强弱** → 该通道是否被激发（散射发生与否）。FT 谱本质是散射通道的"普查"。

## 2. 石墨烯两类散射在 q 空间的分离（关键）

布里渊区有两个不等价谷 K、K′。两类散射落到 q 空间不同区域、互不重叠：

| 散射类型 | 初末态 | q 特征 | 石墨烯倒空间位置 |
|---|---|---|---|
| **谷内散射** | K→K 或 K′→K′ | 小 q（forward）或 Bragg 附近 | Γ 附近 / 1×1 斑 |
| **谷间散射** | K↔K′ | 特定大矢量 ΔK | (√3×√3)R30° 超结构斑 |

两个特征倒格矢（Verbakel 2021 原文公式）：

$$|b| = \frac{4\pi}{3a} \approx 2.95\ \text{Å}^{-1}\ (\text{1×1 斑}),\qquad |\Delta K| = \frac{4\pi}{3\sqrt{3}\,a} \approx 1.70\ \text{Å}^{-1}\ (\text{intervalley 斑})$$

⚠️ **符号约定（量怎么定义，[METHOD-Q] 第 2 问）**：文中 "a" 取 1.42 Å（C–C **键长**），此时 |ΔK|=|b|/√3=|K|（Γ→K 距离）。若改用晶格常数 a₀=2.46 Å，则 |b|=4π/(√3 a₀)、|ΔK|=4π/(3 a₀)，数值等价。别把键长与晶格常数混写进同一式。

## 3. 谷保护判据（有/无，非强度比）

- 缺陷（空位 / 吸附原子）诱导谷间散射 → FFT 出现 (√3×√3)R30° 斑（**阳性**）📜Q。
- 谷保护的 1D 态拓扑压制 intervalley backscattering → FFT 只有 1×1 斑、**无** (√3×√3)R30° 斑（**判据**）📜Q。
- 判据是**二元"有/无"**，非谷内/谷间强度比——论文措辞 "fully absent" 是定性判断。

### 3.1 为什么原子尺度点缺陷打破谷保护（机制）

谷保护的本质是**动量失配**（非对称性保护）：翻谷 K→K′ 需要散射势提供大动量 $|\Delta K|\approx1.70$ Å⁻¹，而平滑（长波长）势的 $V(q)$ 集中在 $q\approx0$ → $\langle K'|V|K\rangle=V(\Delta K)\approx0$ → 谷守恒。

- **原子尺度点缺陷**（空位 / 吸附原子如 H）= 强局域散射势（宽度 ~1 键长）→ $V(q)$ 近似白谱、在 $|\Delta K|$ 非零 → intervalley 散射打开。
- 畴壁态是 **helical（谷锁定反向传播）**：背散射 = 反向 = 必然翻谷。平滑势给不出 $\Delta K$ → 免背散射（保护）；点缺陷给出 $\Delta K$ → 背散射通道打开 → 通道局域化/有隙。
- 类比：QSH 螺旋边缘态背散射翻"自旋"（磁性杂质破坏）；这里背散射翻"谷"（原子缺陷破坏）。**谷保护是"软"保护**（靠势平滑），故单个缺陷即破坏——比自旋保护脆弱 💭I。

### 3.2 intervalley 斑的几何识别（如何确定它是 intervalley 斑）

| 判据 | 内容 | 等级 |
|------|------|------|
| 倒空间几何唯一 | 斑在 $|b|/\sqrt3\approx1.70$ Å⁻¹、相对 1×1 转 30° = (√3×√3)R30° 的倒空间定义 = $|\Delta K|$ 预测 | 💭I（推导） |
| 内/外六角 caption | 外=1×1（2.95 Å⁻¹）、内=(√3×√3)R30°（1.70 Å⁻¹），虚线标出 | 📜Q |
| 缺陷相关性 | pristine 只有 1×1，加单个缺陷才出现该斑 → 缺陷诱导散射，非本征结构 | 📜Q |
| 单缺陷→散射非超格 | 单个缺陷不可能构成 √3×√3 吸附超格 → 只能是 QPI 散射 | 💭I |
| 文献先例 | Rutter 2007（ref 24）已确立该指纹，本文为引用 | 📜Q |

> 结论强度：几何匹配 + 缺陷相关性 + 文献先例的**强推断**（非"直接看到谷翻转"），仍属散射谱解读（间接）。

## 4. 前提与注意

- 需**原子分辨 + 缺陷-free** 样品；单个缺陷即可引入 intervalley 散射 → 破坏"无峰"判据（封闭世界局限）。
- 局域探针证据（散射通道普查），非输运测量；"无峰" = 测量分辨率内无，非绝对零。
- 室温可做（散射空间分析不依赖能谱分辨率，热展宽主要影响 STS 能谱而非 FFT 峰位）。
