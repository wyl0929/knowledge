# [PHY-AB] AB 干涉：双路径干涉、几何相位、退相干与观测

> 复现于 E10/E12/E15、T15 等所有"量子干涉输运"文献。本文档讲**通用物理**；各 review 只写"本文代入"后的具体数字。

## 1. 双路径干涉：为什么相位差会让 ρxx 变化

电子从入口到出口有两条路（顺/逆时针），幅度 $t_1,t_2$，总透射是相干叠加：

$$T=|t_1+t_2|^2=\underbrace{|t_1|^2+|t_2|^2}_{\text{非相干背景}}+\underbrace{2|t_1||t_2|\cos\Delta\varphi}_{\text{干涉项}}$$

$$\Delta\varphi=\underbrace{\frac{e}{\hbar}\oint\mathbf A\cdot d\mathbf l=2\pi\frac{BA}{\Phi_0}}_{\text{AB 相位}}+\underbrace{k(L_1-L_2)}_{\text{动态相位}},\qquad \Phi_0=\frac{h}{e}$$

扫 B → $\cos(2\pi BA/\Phi_0)$ 振荡 → 电导 $G=(e^2/h)T$ 振荡 → $\rho_{xx}\propto1/G$ 振荡，**B 轴上等间距**，周期 $\Delta B=\Phi_0/A$。

**关键分解**：非相干项 = 平滑"单调背景"，干涉项 = 振荡残差 $\Delta\rho_{xx}$（减背景/求导后看到的量）。**"巨幅 ~50%"** 意味着 $|t_1|\approx|t_2|$、干涉项与背景同量级——即环路几乎串联起全部输运通道（Xu 2019 的 AB 振荡达 ρxx 的 ~50%，是"干涉主导输运"而非"背景上的小纹波"）📜Q。

磁场只当"相位旋钮"，**不要求形成朗道能级**，B→0 即已存在（对比 SdH，见 [PHY-SDH]）。

## 2. 谐波与回路几何

FFT 峰 $\Delta B$、$\Delta B/2$、$\Delta B/3$ = 分别包围 1、2、3 个闭合回路（面积 $A$、$2A$、$3A$）。周期与回路面积一一对应：$A_p=\Phi_0/(\Delta B/p)$。

**⚠️ FFT 峰高 ≠ 路径概率/占比**：峰高 = 该谐波的干涉振幅 $A_p\propto 2|t_1||t_2|\,e^{-pL/L_\phi}\times N_p$（$N_p$ = p 畴回路数），把**本征透射 × 退相干因子 × 回路计数**三者卷积在一起且随 T 变。论文只用峰高的**位置**（→ 面积）与**随 T 的衰减斜率**（→ 周长），不反推路径权重；相干叠加图景下"电子走路径 p 的概率"本就不是良定义量。

## 3. 退相干：AB 振幅 $\propto e^{-L/L_\phi(T)}$

**相位相干长度** $L_\phi=v_F\tau_\phi$（$\tau_\phi$ 退相干时间，由非弹性散射 e-e/e-ph 决定）。相位被非弹性散射随机化是**泊松过程**（速率 $1/\tau_\phi$）：传播距离 $\ell$ 不失相的概率 $P(\ell)=e^{-\ell/L_\phi}$。

两路各走半环 $\sim L/2$、各带失相因子 $e^{-(L/2)/L_\phi}$，**乘积**得干涉项：

$$2|t_1||t_2|\underbrace{e^{-L/2L_\phi}\,e^{-L/2L_\phi}}_{=e^{-L/L_\phi}}\cos\Delta\varphi\;\Rightarrow\;\text{AB 振幅}\propto e^{-L/L_\phi}$$

第 $p$ 次谐波绕 $p$ 圈、周长 $pL$ → $e^{-pL/L_\phi}$，故高次谐波衰减更快。这给出**谐波归属的独立验证**：衰减斜率比 = 周长比（Xu 2019 的 L=3λ:4λ:5λ → 1:4/3:5/3 📜Q）。

**为什么非弹性散射失相**：相位相干丢失 = 电子"走哪条路（which-path）"信息泄漏进环境。非弹性散射（e-e、e-ph）交换能量——① 能量/波矢改变 → 两路相位演化不同步；② 更深层：散射出的声子/另一个电子**携带了"哪条路"信息** → 电子与环境纠缠 → 对环境求迹后干涉项消失。**弹性散射不失相**（静态无序只改方向、无能量交换、不漏路径信息）——这是 AB 振荡能在扩散金属中存活的原因。$T=0$ 无声子/无 e-e 相空间 → $\tau_\phi\to\infty$；$T$↑ → $L_\phi\downarrow$ 💭I。

**低 T 饱和与 T→0 外推**：$e^{-L/L_\phi}$ 只在 $L\gtrsim L_\phi$（每圈多次失相）成立；低温 $L_\phi\gg L$ 时 $e^{-L/L_\phi}\to1$，振幅饱和到本征值 $A_0=2|t_1||t_2|N_p$。故 Fig. 2b 低 T 端偏离指数直线是**预期行为**（从"退相干受限"跨到"完全相干"）。外推 $T\to0$ 给出**本征干涉振幅**（最接近"路径权重"的量），但仍非经典概率（需 $|t_1|=|t_2|$ 对称 + 几何计数 $N_p$）。

## 4. 去背景：Δρxx 减背景 vs d²ρ/dB²（高通滤波）

设 $\rho_{xx}(B)=\rho_{bg}(B)+A\cos(2\pi B/\Delta B+\varphi)$（$\rho_{bg}$ 平滑单调背景）：

- **Δρxx（直接减背景）**：$\Delta\rho_{xx}=\rho_{xx}-\rho_{bg}=A\cos(\cdot)$——保留振幅与相位（单位 kΩ），但需先拟合背景，适合单条 trace。
- **d²ρ/dB²（二阶导）**：$\dfrac{d^2\rho_{xx}}{dB^2}=\rho_{bg}''-A\!\left(\dfrac{2\pi}{\Delta B}\right)^2\cos(\cdot)$——只要 $\rho_{bg}''$ 小/平滑就正比于 $-\cos$。**二阶导仍是 $\cos$ 而非 $\sin$，故极值不移位**（一阶导 $\propto-\sin$ 移 π/2、极值变零点）。代价：振幅放大 $(2\pi/\Delta B)^2$ 倍、单位变 kΩ/T²，不再直接对应电阻。

同义对照：E10 用 $dG/dn$（对密度一阶导）锐化 FP 纹波；Xu 2019 用 $d^2\rho/dB^2$（对磁场二阶导）锐化 AB 纹波——同一"微分=高通滤波"思想在不同轴上的版本。

**⚠️ 背景绝对值常未给出**：论文通常只给相对量（振幅/零场电阻 ≈ 50%），不给背景的函数形式或数值 → 减背景后的绝对 Δρxx 不可精确复现，引用时用相对量 💭I。
