### QA-20260619-001：QAHE 详细介绍

**用户问题：** 详细介绍一下 QAHE

**回答摘要：**
QAHE（量子反常霍尔效应）是在零外磁场下、由材料内禀磁性与能带拓扑联合产生的量子化霍尔效应。与常规 QHE 需要外加 $B$ 场不同，QAHE 的量子化来源于自发磁有序 + 非零 Chern 数（$C \neq 0$）。

**人话解释：**
- 常规 QHE：加磁场 → 电子在磁场中画圈 → Landau 能级 → 边缘态 → 量子化霍尔电导
- QAHE：材料自己带磁性 → 电子"感觉"到一个内禀的有效磁场（通过能带 Berry 曲率） → 即使没有外磁场，也有边缘态和量子化霍尔电导
- QSHE：没有磁性、没有外磁场，但 SOC 很强 → 上自旋电子走左边，下自旋电子走右边 → 总电荷霍尔电导为零，但自旋霍尔电导量子化

**关键判断：**

| 维度 | QAHE 事实 |
|------|---------|
| 物理起源 | 能带 Chern 数 $C \neq 0$ + 磁性破缺 $\mathcal{T}$ |
| Hall 电导 | $\sigma_{xy} = C \cdot e^2/h$（零外场下量子化） |
| 理论奠基 | Haldane 模型 (PRL 61, 2015, 1988)：六角晶格 + 复次近邻跃迁 + 交错子晶格势 |
| 首次实验 | 薛其坤组, Science 340, 167 (2013)：Cr 掺杂 (Bi,Sb)₂Te₃ 薄膜, T~30mK |
| 核心瓶颈 | 观测温度极低（<1K），磁性掺杂引入强无序，拓扑能隙 ~meV |
| 与用户工作的关系 | tbplas Kubo-Bastin (PRL 114.116602 例 2) 完全胜任 QAHE 计算；user 若在 graphene DW 加磁性衬底，工具链可直接复用 |
| 与 ABC trilayer 的关系 | ABC trilayer + B → 常规 QHE（非 QAHE）；ABC trilayer + 磁性衬底 + 无 B → 理论上可能是 QAHE 候选 |

### QA-20260619-002：Chen et al., Nature 579, 56 (2020) — ABC Trilayer Graphene QAHE

**用户问题：** 详细介绍一下 Chen et al., Nature (2020) 的 ABC QAHE 工作

**回答摘要：**
Chen et al. (2020) 在 ABC trilayer graphene + hBN 莫尔超晶格中首次实验观测到轨道铁磁 Chern 绝缘体，实现零磁场下 $C = \pm 2$ 的 QAHE，且通过位移场 $D$ 可逆切换 Chern 数符号。这是 ABC trilayer 体系中关联驱动 QAHE 的首个报道。

**关键实验参数：**

| 量 | 值 | 含义 |
|---|:---:|------|
| 莫尔周期 | ~15 nm | hBN 与 graphene 1.8% 晶格失配 |
| 莫尔带带宽 | ~10–20 meV | $U \gg W$ → 关联主导 |
| 测量温度 | 0.1–10 K | QAHE 平台需 $T < 2$ K |
| 位移场 $D$ | $\pm 0.5$ V/nm | 电场 tunable QAHE |
| Hall 电阻 | $h/2e^2$ | $\sigma_{xy} = 2e^2/h$, Chern $= \pm 2$ |
| 载流子密度 | $\sim 10^{12}$ cm⁻² | 莫尔带部分填充 |

**关键判断：**
- 物理机制：**关联驱动的轨道磁性**（非磁性掺杂、非 SOC）→ 平带中电子自发谷极化+自旋极化 → $C = \pm 2$
- 与用户项目的关系：用户研究的 bulk ABC trilayer（非莫尔）是 $B \neq 0$ 的常规 QHE；Chen 2020 证明同一材料在莫尔极限下可进入 QAHE。两者互补——用户的 bulk 输运是"非关联基线"，Chen 2020 是"关联极限的 QAHE"
- 迁移路径：在用户 ABC model 中添加 hBN 莫尔势 → 用 tbplas Kubo-Bastin 计算 $\sigma_{xy}(D)$ → 检测是否出现 $C = \pm 2$（这是很自然的未来方向，但需要先完成 Phase 1 bulk baseline）

**完整引用：**
> Chen, G. et al. *Tunable correlated Chern insulator and ferromagnetism in a moiré superlattice.* **Nature 579**, 56–61 (2020). DOI: 10.1038/s41586-020-2049-7

### QA-20260619-003：Filling Factor $\nu$ 的定义与计算

**用户问题：** filling factor $\nu$ 是什么？实验上如何计算？在我的计算中如何计算？莫尔超胞中 ABA/ABC 区域 LDOS 不同时如何算？

**回答摘要：**
$\nu$ 是每个磁通量子 $\Phi_0 = h/e$ 对应的电子数（常规 QHE），或每个莫尔超胞的电子数（莫尔关联体系）。两种定义用同一符号但分母不同。用户 tbplas 计算中应通过全局 DOS 积分得到 $N_e(\mu)$，再除以 $N_\Phi = BA/\Phi_0$ 得到 $\nu(\mu)$。空间不均匀不影响全局 $\nu$ 的定义。

**人话解释：**
- 常规 QHE：$B=15$T 时，每 nm² 大约有 0.0036 个磁通量子。如果电子密度恰好是这个数的 6 倍，$\nu=6$，Hall 电导恰好是 $6e^2/h$
- 莫尔体系：一个莫尔超胞约 15nm×15nm。如果每个超胞里有 1 个电子，$\nu_{\text{moire}}=1$，可能出现关联绝缘态
- 两者用了同一个符号但分母不同——就像"百分比"和"千分比"都用 % 符号，但基数不同

**关键判断：**

| 场景 | $\nu$ 定义 | 分母 | 公式 |
|------|:---:|------|------|
| 常规 QHE ($B\neq0$) | 每 $\Phi_0$ 的电子数 | $N_\Phi = BA/\Phi_0$ | $\nu = N_e h / (eB A)$ |
| 莫尔体系 ($B=0$) | 每莫尔胞的电子数 | $N_{\text{moire}} = A/A_{\text{moire}}$ | $\nu_{\text{moire}} = N_e/N_{\text{moire}}$ |
| 莫尔体系 ($B\neq0$) | 两者需要区分使用 | — | $\nu_{\text{QHE}}$ 用于 QHE 平台；$\nu_{\text{moire}}$ 用于关联态填充 |

**用户计算中的实操：**

```python
# 超胞参数
m = cfg["tbpm"]["m"]           # 512
a = 0.246                       # nm
area_sc = m**2 * a**2 * np.sin(np.pi/3)  # nm²
Phi0 = 4135.7                   # T·nm²

# 常规 QHE ν
B = cfg["model"]["B_values"][0]  # 15 T
N_Phi = B * area_sc / Phi0

# 全局 DOS → 积分得 N_e(μ)
eng_dos, dos = ...  # 来自 TBPM
N_e = cumtrapz(dos, eng_dos, initial=0)

# ν(μ) 横轴
nu_array = np.interp(eng_hall, eng_dos, N_e / N_Phi)

# 绑图
plt.plot(nu_array, sigma_xy)
plt.axhline(y=6, linestyle='--', label='ν=±6')  # ABC trilayer 第一平台
plt.axhline(y=10, linestyle='--', label='ν=±10')
```

**用户的具体数值：**

| m | B (T) | $A_{\text{sc}}$ (nm²) | $N_\Phi$ | 预期 $\nu=\pm6$ 的 $N_e$ |
|---|:---:|---:|:---:|:---:|
| 256 | 15 | $1.57\times 10^4$ | 57 | 342 |
| 512 | 15 | $6.29\times 10^4$ | 228 | 1368 |
| 512 | 31 | $6.29\times 10^4$ | 472 | 2832 |

**莫尔超胞中 ABA/ABC 区域 LDOS 不同时的处理：**
- $\nu$ 是全局量，用**整个超胞的 DOS 积分**即可，不需要区分 ABA vs ABC 区域
- 全局 DOS 是各处 LDOS 的加权平均：$\text{DOS}(E) = \int \text{LDOS}(\mathbf{r},E)\,d^2r$
- 若需局域分析（如"畴壁左侧的局域填充"），可定义 $\nu_{\text{local}}(\mathbf{r}) = \int_{-\infty}^\mu \text{LDOS}(\mathbf{r},E)\,dE / n_\Phi$，但这非常规用法

**实验上如何确定 $\nu$：**

| 方法 | 原理 | 适用 |
|------|------|:---:|
| Hall 电阻直接读取 | $R_{xy} = h/(\nu e^2)$ → $\nu = h/(e^2R_{xy})$ | 输运实验 |
| 栅极电压换算 | $\nu = C_g(V_g-V_0)h/(e^2B)$ | 有栅极的样品 |
| SdH 振荡频率 | $\Delta(1/B) \to n \to \nu = nh/eB$ | 量子振荡 |
| DOS 积分（计算） | 见上 | 你的 tbplas 计算 |

**ABC trilayer 的 $\nu$–$\sigma_{xy}$ 对应关系：**
$$\sigma_{xy} = 4\left(N + \frac{3}{2}\right)\frac{e^2}{h} \quad\Longleftrightarrow\quad \nu = 4N + 6$$
平台序列：$\nu = \ldots, -10, -6, 0, +6, +10, +14, \ldots$

### QA-20260619-004：Hartree-Fock 平均场 + e–e 相互作用 — TBPM 和 Continuum 实现

**用户问题：** 详细说说平均场 (Hartree-Fock) 在 e–e interaction 的计算，TBPM 如何加入这部分？石墨烯的 continuum model 如何加入这部分？

**回答摘要：**
HF 将多体 e–e 相互作用替换为"有效单粒子势 + 自洽密度矩阵 $\rho$"。TBPM 适合加 on-site Hubbard U（每次迭代用 $\rho$ 修改 sample 的 on-site 能量 → 传播 → 得新 $\rho$ → 收敛）。Continuum model 天然适合 HF（Hilbert 空间小，直接对角化 + Fock 交换自能），适合快速扫 $U$–$\nu$ 相图。

**关键判断：**

| 维度 | HF 事实 |
|------|---------|
| 核心替代 | $c^\dagger c^\dagger c c \to \langle c^\dagger c\rangle c^\dagger c$（四算符 → 二算符，$\rho_{ij} = \langle c_i^\dagger c_j\rangle$） |
| Hartree 通道 | $V_H = U\sum_i \langle n_{i\uparrow}\rangle n_{i\downarrow}$ — 经典静电，对角 |
| Fock 通道 | $\Sigma_x(i,j) = -U\rho_{ij}$ — 交换，非对角 |
| 自洽条件 | $\rho_{\text{new}} = f(H_{\text{HF}}[\rho_{\text{old}}])$，迭代到 $\|\Delta\rho\| < 10^{-4}$ |
| Stoner 判据 | $D(E_F) \cdot U > 1$ → 自发极化 |
| 莫尔体系 $U$ 典型值 | 10–30 meV（平带 $W \sim 10$–$20$ meV → $U/W \sim 0.5$–3） |

**TBPM + HF 实操方案：**

```python
# 核心循环：TBPM 传播 → 得 ρ → 构造 HF 势 → 再传播
for it in range(max_iter):
    # ① HF on-site 势
    V_HF_up = U * rho_dn
    V_HF_dn = U * rho_up
    # ② 修改 sample 的 on-site 能量（需 tbplas API）
    for i in range(n_orb):
        sample.set_onsite(i, V_HF_up[i] if spin=="up" else V_HF_dn[i])
    # ③ TBPM 传播 → calc_charge_density 或 DOS 积分 → ρ_new
    # ④ 线性混合: ρ = mix*ρ_new + (1-mix)*ρ
    # ⑤ 收敛判据
```

**关键挑战：**
- TBPM 每次传播只能得 DOS/LDOS，难以直接得全密度矩阵 $\rho_{ij}$（需要多随机向量 + 时间演化近似）
- 自洽 × TBPM 计算量极大 → 建议先用对角化（$m \leq 32$）验证
- tbplas 无内置 HF → Python 层自洽循环

**Continuum Model + HF 方案：**

```python
# ABC trilayer continuum + HF 示意
for ik, (kx_i, ky_i) in enumerate(k_mesh):
    H0 = build_continuum_H0(kx_i, ky_i)  # BM-like Hamiltonian
    Sigma_F = -(1/N_k) * sum_q V(q) * rho(k+q)  # Fock 自能
    H_HF = H0 + Sigma_F
    E, V = eigh(H_HF)
    # 填充 ν * N_moire 个最低能态 → 更新 ρ
```

**优势**：Hilbert 空间 ~10²–10³（vs TB ~10⁵），对角化极快，适合扫相图。

**HF 如何给出 band splitting：**
收敛的 $\rho$ → 自旋上/下的有效势不同 → 对角化后 $E_{n\uparrow}(\mathbf{k}) \neq E_{n\downarrow}(\mathbf{k})$ → Stoner 劈裂 $\Delta = U(n_\uparrow - n_\downarrow)$。当 $\Delta > W$ 时体系进入铁磁/QAHE 相。

**关键文献：**
- Bultinck et al., PRX 10, 031034 (2020) — 莫尔石墨烯 HF 数值实现细节
- Xie & MacDonald, PRL 124, 097601 (2020) — ABC trilayer + hBN 的 HF 相图
- Liu et al., PRX 11, 021065 (2021) — 自洽 HF + TB 的实践指南
