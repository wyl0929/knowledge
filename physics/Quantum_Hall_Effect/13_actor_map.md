# 13 Actor Map / 作者与研究组地图

Last updated: 2026-06-10

## 研究组谱系概览

### 理论先驱（1980s-1990s）

**von Klitzing 组 (Max Planck, Stuttgart)**
- 核心贡献：1980 年发现 IQHE（1985 诺奖）
- 关键词：Si MOSFET, 量子化霍尔电阻, 精密计量
- 当前状态：von Klitzing 已退休，其工作已成为教科书内容

**Tsui / Störmer / Laughlin (Bell Labs → Princeton / Columbia / Stanford)**
- 核心贡献：1982 年发现 FQHE（Tsui/Störmer），1983 年 Laughlin 波函数解释
- 1998 年诺贝尔物理学奖
- 研究脉络：Tsui → Princeton，Störmer → Columbia，Laughlin → Stanford
- 持续影响：Laughlin 波函数和复合费米子图像是 FQHE 的两个支柱

**Thouless / Kohmoto / Nightingale / den Nijs (TKNN)**
- 核心贡献：1982 年将霍尔电导与 Chern 数联系起来（TKNN 公式）
- Thouless 获 2016 年诺贝尔奖（拓扑相变）
- 意义：第一次将"拓扑"引入凝聚态物理

**Haldane (Princeton)**
- 核心贡献：1988 年提出 Haldane 模型——零净磁通下的 QAHE 理论模型
- 2016 年诺贝尔物理学奖
- 关键词：Haldane 模型, Chern 绝缘体, 零场量子霍尔效应

### 当代活跃组（2010s-至今）

#### 拓扑绝缘体与 QAHE

**薛其坤组 (Tsinghua / 南方科大)**
- 核心贡献：2013 年首次实验实现 QAHE（Cr-(Bi,Sb)₂Te₃，30 mK）
- 持续产出：提高 QAHE 温度、轴子绝缘体、高 Chern 数体系
- 关键词：MBE 生长, 磁性拓扑绝缘体, 输运测量
- 与用户相关性：★★★ — 实验组，但其理论合作者（张首晟、方忠、戴希等）的计算方法可借鉴

**张首晟组 (Stanford, 已故 2018)**
- 核心贡献：QSHE 理论预言 (2006, BHZ 模型)，拓扑绝缘体理论框架
- 关键词：BHZ 模型, 拓扑绝缘体, 拓扑超导体
- 影响：其学生和合作者遍布全球拓扑领域

**Molenkamp 组 (Würzburg)**
- 核心贡献：2007 年首次实验观测 QSHE（HgTe/CdTe 量子阱）
- 持续方向：拓扑绝缘体量子阱、拓扑-超导异质结
- 关键词：MBE, HgTe, 非局域输运

**方忠 / 戴希组 (中科院物理所)**
- 核心贡献：拓扑材料高通量计算、拓扑材料数据库、Weyl 半金属
- 关键词：DFT, Wannier 函数, 拓扑不变量
- 与用户相关性：★★★★★ — 计算方法（Wannier 插值 + Berry 曲率）最具参考价值

#### 石墨烯与二维材料 QHE

**Geim / Novoselov 组 (Manchester)**
- 核心贡献：2005 年石墨烯中半整数量子霍尔效应（2010 诺奖）
- 持续方向：二维材料异质结、魔角石墨烯
- 与用户相关性：★★★★ — 石墨烯紧束缚计算直接相关

**Kim 组 (Harvard) / Dean 组 (Columbia)**
- 核心贡献：石墨烯摩尔超晶格中的 Hofstadter 蝴蝶、拓扑相
- 与用户相关性：★★★

#### FQHE 当代前沿

**Halperin (Harvard)**
- 核心贡献：FQHE 边缘态理论、Halperin 多层波函数
- 关键词：边缘 CFT, 分数统计

**Read (Yale) / Moore (UCSB)**
- 核心贡献：非阿贝尔统计理论、Moore-Read Pfaffian 态
- 关键词：$\nu=5/2$, 拓扑量子计算

**Eisenstein 组 (Caltech)**
- 核心贡献：双层二维电子气中的激子凝聚、复合费米子实验
- 关键词：Coulomb drag, 双层 FQHE

#### 计算方法与数值模拟

**Vanderbilt 组 (Rutgers)**
- 核心贡献：Wannier90 代码、Berry 相位计算方法
- 与用户相关性：★★★★★ — Wannier90 可与 TB 模型接口

**Marzari 组 (EPFL)**
- 核心贡献：最大局域化 Wannier 函数、高通量材料计算
- 与用户相关性：★★★★

**Sinova 组 (Mainz)**
- 核心贡献：反常霍尔效应理论、自旋霍尔效应
- 关键词：Berry 曲率, 内禀 vs 外禀机制
