## 缺口总表

### GAP-01: 高温 QAHE 材料

| 维度 | 内容 |
|------|------|
| 缺口描述 | 当前 QAHE 实验温度 (< 1 K) 与实用化要求 (~ 300 K) 差距巨大，需要寻找内禀磁性更强、Chern 数更高的材料 |
| 状态 | **confirmed** — 领域共识缺口 |
| 依赖论断 | CL-03 (QAHE 可实现), CL-06 (高温候选材料) |
| 概念边界依赖 | QAHE vs QHE 区分 |
| 当前已知 | MnBi₂Te₄ 家族 ~5-10 K；Cr-(Bi,Sb)₂Te₃ ~1 K |
| 用户切入点 | 紧束缚 + Berry 曲率高通量扫描候选材料，估算 Chern 数和能隙对磁序的依赖性 |
| 竞争 | 全球大量组在做（中科院物理所、Stanford、Princeton 等） |
| 风险 | 材料预测 → 实验实现路径长；DFT 精度不足时需更精确方法 |

### GAP-02: 无序对拓扑相的定量影响

| 维度 | 内容 |
|------|------|
| 缺口描述 | 无序在 QAHE/QSHE 中到底是"破坏者"还是"创造者"（拓扑安德森绝缘体）？定量理解不足 |
| 状态 | **suspected** — 有零星证据但无系统性图像 |
| 依赖论断 | CL-07 (无序影响不完全理解), CL-04 (Chern 数计算) |
| 概念边界依赖 | 拓扑边缘态 vs 平庸边界态 |
| 当前已知 | 弱无序保持拓扑相（自洽 Born），强无序诱导局域化；Anderson 拓扑绝缘体在特定模型中存在 |
| 用户切入点 | ⭐⭐⭐⭐⭐ — TBPM 天然适合大尺寸 + 无序模拟，可直接用 Kubo 公式算霍尔电导 vs 无序强度的相图 |
| 竞争 | 中等 — 方法上 TBPM 有独特优势（尺寸 + 效率） |
| 风险 | 需要确信输运计算收敛（有限尺寸效应） |

### GAP-03: TBPM 框架下的拓扑不变量计算

| 维度 | 内容 |
|------|------|
| 缺口描述 | TBPM 已广泛用于 DOS 和输运计算，但尚未标准化拓扑不变量（Chern 数、$\mathbb{Z}_2$、Wilson loop）的计算模块 |
| 状态 | **confirmed** — 方法层面的缺口，不是物理gap |
| 依赖论断 | CL-04 (Chern 数可算), CL-05 ($\mathbb{Z}_2$ 计算要求) |
| 当前已知 | FHS 方案 (k 空间离散), Wannier 插值方案均存在成熟代码 |
| 用户切入点 | ⭐⭐⭐⭐⭐ — 在现有 TBPM 代码基础上添加 Berry 曲率计算模块 |
| 可操作性 | high — 1-2 周可实现 Chern 数基本版本 |

### GAP-04: 非阿贝尔统计的直接验证

| 维度 | 内容 |
|------|------|
| 缺口描述 | $\nu=5/2$ FQHE 态是否支持非阿贝尔任意子仍未被实验直接证实 |
| 状态 | **suspected** — 强理论证据但缺实验 smoking gun |
| 依赖论断 | CL-02 (FQHE 拓扑序) |
| 用户切入点 | ❌ — 需要实验平台（anyon interferometry），不适合计算切入 |
| 说明 | not-a-gap FOR USER — 确认不是用户的合理切入方向 |

### GAP-05: 石墨烯基拓扑异质结的设计空间

| 维度 | 内容 |
|------|------|
| 缺口描述 | 石墨烯 + 衬底 SOC + 磁性邻近效应 → QAHE/QSHE 的可能性空间中，系统性的紧束缚研究不足 |
| 状态 | **suspected** — 有零散 DFT 研究但系统 TB 扫描少 |
| 依赖论断 | CL-03, CL-06 |
| 用户切入点 | ⭐⭐⭐⭐⭐ — graphene.py + Peierls 替换 + SOC + 交换场 → 直接计算拓扑相图 |
| 竞争 | 中等 — 大多做 DFT，TB 参数扫描有独特价值 |
| 风险 | 需要验证 TB 参数对 DFT 的保真度 |

### GAP-06: 分数陈绝缘体的零场实现

| 维度 | 内容 |
|------|------|
| 缺口描述 | 摩尔超晶格中零磁场分数态（分数陈绝缘体）是 2023-2024 热点，理论理解远落后于实验 |
| 状态 | **weak** — 太新，gap 轮廓尚不明 |
| 依赖论断 | 需要从 FQHE 和 Chern 绝缘体同时借用的论断（多重依赖，不稳定） |
| 用户切入点 | ⚠️ tentative — 若用户有 TB 模型 + 精确对角化经验可以切入；目前距离较远 |

### NOT-A-GAP: IQHE 的理论理解

- **为什么不是 gap**：单粒子图像下的 IQHE 已经完备，40 年验证
- **用户不应花时间在此**：除非作为代码验证的 benchmark

### NOT-A-GAP: FQHE 的多体数值方法

- **为什么不是 gap FOR USER**：精确对角化/DMRG 不是用户的现有资产；虽是真 gap（方法局限），但对用户是不可操作的
