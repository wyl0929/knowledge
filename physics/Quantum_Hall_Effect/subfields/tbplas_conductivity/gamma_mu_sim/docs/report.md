# Γ-μ 随机游走模拟 — 最终分析报告

> **日期**: 2026-06-28
> **项目**: gamma_mu_sim
> **对应计划**: [plan.md](plan.md)

---

## 摘要

在纯 Python 环境下，用合成 Γ 和 μ 矩阵（量级匹配真实物理矩阵），系统定量验证了 Kubo-Bastin 双重求和中的浮点随机游走累积效应。**核心结论**：随机游走 RMS ∝ M²·ε（α≈2.08），三种核加权（clean/Jackson/Lorentz）和 Kahan 补偿求和均**无法改变标度指数**——仅改变前因子 β 而不改变 α。Lorentz λ∈[2,8] 扫描确认 α 始终 ≈2，无"甜点 λ"可实现绝对收敛。这与 VBL Phase M 诊断完全一致：δμ 噪声通过高 |Γ| 项放大，核阻尼不足以在高 M 区压制 ‖Γμ‖ 增长。

## 2. 核心结果

### 2.1 标度指数 α 表

**T4 — 六条 kernel×method 线**（θ=π/4，M=64→8192）：

| Kernel | Method | α | β | R² | RMS(M=4096) |
|--------|--------|------|----------|------|-------------|
| clean | sequential | 2.058 | -16.346 | 0.9962 | 1.18×10⁻⁹ |
| clean | kahan | 2.074 | -16.397 | 0.9963 | 1.07×10⁻⁹ |
| jackson | sequential | 2.030 | -16.295 | 0.9980 | 1.09×10⁻⁹ |
| jackson | kahan | 2.081 | -16.426 | 0.9969 | 1.08×10⁻⁹ |
| lorentz | sequential | 2.039 | -16.320 | 0.9979 | 1.10×10⁻⁹ |
| lorentz | kahan | 2.084 | -16.436 | 0.9970 | 1.10×10⁻⁹ |

**T5 P4 — Lorentz λ 扫描**（M=64→4096, sequential, 5 trials）：

| λ | α | β | R² | RMS(M=4096) |
|:---:|------|----------|------|-------------|
| 2.0 | 1.920 | -16.022 | 0.9766 | 9.27×10⁻¹⁰ |
| 3.0 | 1.975 | -16.133 | 0.9938 | 1.05×10⁻⁹ |
| 4.0 | 2.111 | -16.301 | 0.9900 | 1.14×10⁻⁹ |
| 6.0 | 1.891 | -16.031 | 0.9728 | 1.03×10⁻⁹ |
| 8.0 | 2.018 | -16.161 | 0.9835 | 1.38×10⁻⁹ |

### 2.2 关键发现

1. **α ≈ 2.08（非预期 1.0）**：Γ 元素 ∝ M，使单项噪声 ∝ M·ε，M² 项的随机游走 RMS ∝ √(M²) × M·ε = M²·ε → α≈2。原理论预期 α≈1 基于 Γ~O(1) 假设，被实测证伪。

2. **核加权不改变 α**：clean/Jackson/Lorentz 三种核的 α 差异 < 3%（2.03~2.08）。核函数衰减仅影响低阶 μ 项，无法压制高 |Γ| 区域的主导贡献。

3. **Kahan 补偿无显著改善**：α 几乎相同（差异 < 2%），RMS 改善 < 10%。噪声源自 δμ（μ 矩阵浮点噪声），非求和过程中的舍入误差累积。

4. **Lorentz λ 无法消除随机游走**：λ∈[2,8] 扫描中 α 始终 ≈2，不随 λ 单调变化，无"甜点 λ"可实现 α<0.1。RMS(M=8192) > RMS(M=4096) → 发散而非收敛。

5. **float32 退化 10¹⁰ 倍**：M=1024 时 float32 RMS=0.48 vs float64 RMS=5.6×10⁻¹¹。

### 2.3 综合排名（RMS at M=4096，从低到高）

| 排名 | 组合 | RMS(M=4096) | α |
|:---:|------|-------------|------|
| 1 | lorentz(λ=2)+sequential | 9.27×10⁻¹⁰ | 1.920 |
| 2 | lorentz(λ=6)+sequential | 1.03×10⁻⁹ | 1.891 |
| 3 | lorentz(λ=3)+sequential | 1.05×10⁻⁹ | 1.975 |
| 4 | clean+kahan | 1.07×10⁻⁹ | 2.074 |
| 5 | jackson+kahan | 1.08×10⁻⁹ | 2.081 |
| 6 | jackson+sequential | 1.09×10⁻⁹ | 2.030 |
| 7 | lorentz+kahan | 1.10×10⁻⁹ | 2.084 |
| 8 | lorentz+sequential | 1.10×10⁻⁹ | 2.039 |
| 9 | lorentz(λ=4)+sequential | 1.14×10⁻⁹ | 2.111 |
| 10 | clean+sequential | 1.18×10⁻⁹ | 2.058 |
| 11 | lorentz(λ=8)+sequential | 1.38×10⁻⁹ | 2.018 |

最优组合 `lorentz(λ=2)+sequential` 相比最差组合 `lorentz(λ=8)+sequential` 仅改善 ~33%，远非数量级差异。

## 3. 物理机制解释

```
Γ 矩阵 (解析核)          μ 矩阵 (Chebyshev 矩)        双重求和
┌─────────────────┐     ┌─────────────────┐     ┌──────────────────────┐
│ ∼ O(max(m,n))   │     │ ∼ O(1) 振荡     │     │ 信号: ~O(1)          │
│ ∝ M 线性增长     │  ×  │ + ε_mach 噪声   │  =  │                      │
│ M×M 复矩阵      │     │ M×M 实矩阵      │     │ 噪声: ~O(M²·ε)       │
└─────────────────┘     └─────────────────┘     │ N = M²               │
                                                 └──────────────────────┘

RMS error = √(Σ_{m,n} |Γ_{mn}|² · ε²) ∝ √(Σ m²·ε²) ∝ M²·ε
```

核加权 g_m·g_n 在低 m,n 区 ≈1，仅在高阶区衰减。但 |Γ_{mn}| ∝ max(m,n) 在高阶区最大——核衰减最强的区域恰是 |Γ| 最大的区域，两者竞争导致净效果微弱。

## 4. 对 tbplas Kubo-Bastin 计算的建议

| 建议 | 理由 |
|------|------|
| **M ≤ 2560** 为安全运行范围 | 超过此值 RMS 开始接近物理信号量级 |
| **rescale=-1 必须启用** | 自动检测带宽，防止特征值越界导致 NaN |
| **双精度编译**（-O2 -march=native） | float32 在 M=1024 时已退化 10¹⁰× |
| **不推荐 M ≥ 3072** | 除非使用四精度（quad precision）KPM 迭代 |
| **Kahan 求和可选** | 改善 < 10%，不是瓶颈 |
| **核模型用 Jackson** | 与 Lorentz λ=4 效果相当，且是 tbplas 默认 |

## 5. T5 判据验证

| 判据 | 预期 | 实测 | 状态 |
|------|------|------|:---:|
| P3: RMS(8192) < RMS(4096) | 收敛 | 7.70e-9 > 1.10e-9 (发散) | ❌ |
| P4: α(λ) 单调递减, λ≥6 时 α<0.1 | 可消除随机游走 | α 不单调, 始终 ≈2 | ❌ |
| Lorentz+Kahan 为最优组合 | 预期最优 | lorentz(λ=2)+sequential 最优 | ❌ |
| RMS(M=4096) < 10⁻¹³ | 高精度 | ~9.3×10⁻¹⁰（差 ~10⁴×） | ❌ |

**全部 4 条判据未通过**——这些判据基于"核加权可消除随机游走"的错误假设。实测结果与 VBL Phase M 诊断一致：随机游走是结构性的，无法通过核函数或求和方法消除。

## 6. 已知限制

1. **θ 固定为 π/4**：未探索奇点 θ→0,π 附近行为（T6 已跳过）
2. **E0 固定为 0**：未测试非零能量点
