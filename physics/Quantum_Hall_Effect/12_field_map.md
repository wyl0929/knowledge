# 12 Field Map / 领域地图

Last updated: 2026-06-10

## 1. One-Sentence Field Definition / 一句话定义

### 一句话解释

量子霍尔效应研究的是：在低温、强磁场下的二维电子系统中，为什么电流会"贴着边走"而不耗散能量，以及这种现象背后隐藏了什么普适的物理规律。

### 研究者版本

量子霍尔效应研究二维电子气在垂直强磁场下的拓扑量子输运现象，核心对象是霍尔电导的精确量子化 $\sigma_{xy} = \nu e^2/h$、拓扑边缘态的鲁棒性，以及多体关联导致的分数激发。输入是材料、磁场、温度和维度，核心方法是拓扑能带理论、量子场论和量子输运模拟，目标是从拓扑序的角度统一理解这些现象并寻找新材料平台。

## 2. Field Boundary / 领域边界

- **Studies / 研究什么**：二维系统中磁场或自旋-轨道耦合导致的拓扑非平庸电子态、霍尔电导量子化、拓扑边缘态输运、拓扑相变、分数激发统计。
- **Does not primarily study / 主要不研究什么**：三维体输运、非量子区间的经典磁输运、纯自旋电子学器件工程、超导机理（尽管 FQHE 和超导有深层数学联系）。
- **Adjacent fields / 相邻领域**：拓扑绝缘体、拓扑超导体、自旋电子学、量子计量学、量子计算（拓扑量子计算）、二维材料物理。
- **Common false equivalence / 常见错误等同**：QHE ≠ 任何有霍尔信号的系统；拓扑边缘态 ≠ 任何边界态；FQHE ≠ IQHE 的简单推广。

## 3. Position in the Larger Chain / 在更大链条中的位置

```text
固体能带理论 / 量子场论（上游）
  → 二维电子气 + 强磁场（抽象对象/模型）
  → 拓扑不变量计算 + 量子输运测量（本领域核心环节）
  → 精密计量标准 / 拓扑量子比特 / 低功耗电子学（下游应用）
```

### 为什么困难

量子霍尔效应的理论涉及拓扑、强关联和规范场论的交叉；实验需要 mK 级低温和超高迁移率样品；数值模拟在 FQHE 区面临指数墙。

## 4. Subfield Topology / 子方向图谱

### 4.1 整数量子霍尔效应 (IQHE)

- **研究问题**：朗道能级量子化 → 霍尔电导平台的单粒子图像
- **基本模型**：二维自由电子气 + 垂直磁场 → 朗道能级 $E_n = \hbar\omega_c(n + 1/2)$
- **典型证据**：von Klitzing (1980) Si MOSFET 中 $\sigma_{xy}$ 平台 → 1985 年诺贝尔奖
- **核心公式**：$\sigma_{xy} = \nu e^2/h$，$\nu = n\phi_0/B$（填充因子）
- **当前难点**：已是成熟领域（> 40 年），基础问题已解决
- **与用户工具的连接**：✅ 紧束缚 + Peierls 替换 + 无序 → TBPM 可直接计算朗道能级和霍尔电导

### 4.2 分数量子霍尔效应 (FQHE)

- **研究问题**：电子-电子相互作用导致分数填充处的不可压缩量子液体
- **基本模型**：Laughlin 波函数 $\Psi_m = \prod_{i<j}(z_i - z_j)^m e^{-\sum|z_k|^2/4l_B^2}$，复合费米子理论
- **典型证据**：Tsui, Störmer, Gossard (1982) $\nu=1/3$ 平台 → 1998 年诺贝尔奖
- **核心概念**：分数电荷准粒子 $e/m$、分数统计、拓扑序、边缘 CFT
- **当前难点**：5/2 态的非阿贝尔统计验证、FQHE 在新型材料中的实现、多体数值方法
- **与用户工具的连接**：⚠️ 距离较远——需要精确对角化/DMRG，非 TBPM 可及

### 4.3 量子反常霍尔效应 (QAHE)

- **研究问题**：零外磁场下实现量子霍尔效应
- **基本模型**：磁性拓扑绝缘体薄膜，$H = H_{\text{TI}} + J \vec{S}\cdot\vec{\sigma} + \lambda_{\text{SOC}}$
- **典型证据**：薛其坤组 (2013) Cr-(Bi,Sb)₂Te₃ 中 30 mK 零场量子化 → 2018 年国家自然科学一等奖
- **核心判据**：Chern 数 $C = \frac{1}{2\pi}\int_{\text{BZ}} \Omega(k) d^2k \neq 0$
- **当前难点**：提高实现温度（目前 ~ 100 mK 到 ~ 1 K），寻找高 Chern 数和高温材料
- **与用户工具的连接**：✅✅ 极佳匹配——TB 模型 + Berry 曲率 + 无序 + 输运 = TBPM 升级路径

### 4.4 量子自旋霍尔效应 (QSHE)

- **研究问题**：时间反演对称性保护的螺旋边缘态
- **基本模型**：Bernevig-Hughes-Zhang (BHZ) 模型，Kane-Mele 模型
- **典型证据**：Molenkamp 组 (2007) HgTe/CdTe 量子阱中非局域输运
- **核心判据**：$\mathbb{Z}_2$ 不变量 $\nu = 0,1$
- **当前难点**：边缘态的自旋去相位、体态残留电导、室温 QSHE
- **与用户工具的连接**：✅ 可行——需要实现 $\mathbb{Z}_2$ 计算（Wilson loop 方法或自旋 Chern 数）

### 4.5 拓扑能带理论

- **研究问题**：从能带结构计算拓扑不变量，预测拓扑材料
- **基本方法**：Berry 联络 $A(k) = i\langle u_k|\nabla_k|u_k\rangle$，Berry 曲率 $\Omega(k) = \nabla_k \times A(k)$
- **计算方案**：Fukui-Hatsugai-Suzuki 离散化、Wannier 函数插值、Wilson loop
- **当前难点**：高通量筛选 + 机器学习驱动的拓扑材料发现
- **与用户工具的连接**：✅✅ 极佳——TBPM 框架天然支持紧束缚 + Berry 曲率计算

### 4.6 新型 QHE 平台

- **石墨烯 QHE**：半整数 $\nu = 4(n + 1/2)$，室温可见（Novoselov/Geim, 2005）
- **谷霍尔效应**：石墨烯中谷自由度的输运
- **三维量子霍尔效应**：层状材料中沿面外方向的量子化
- **高阶拓扑绝缘体**：角态而非边缘态的拓扑保护
- **与用户工具的连接**：✅ 石墨烯 QHE 与用户已有 graphene.py 直接相关

## 7. Core Assumptions & Bottlenecks / 核心假设与瓶颈

### 核心假设（可能被突破）

1. **二维性**：QHE 要求二维——三维 QHE 是否可能？(已有初步实验)
2. **强磁场**：QAHE 试图打破此假设——已实现但温度极低
3. **低温**：热涨落不破坏量子相干——室温 QHE/QHE 类效应可能吗？
4. **无能隙边缘态必然存在**：体-边界对应假设——高阶拓扑中可能打破

### 当前瓶颈

1. **QAHE 温度**：从 mK 到室温还有 4 个数量级
2. **FQHE 非阿贝尔统计验证**：anyon braiding 实验极其困难
3. **拓扑材料高通量筛选**：DFT 精度 vs 计算成本
4. **无序效应**：TBPM 层面的无序-拓扑相互作用定量理解不足

说明这条链条在哪些地方会断：模型不准、工具不成熟、指标不够、实验昂贵、规模化困难等。
