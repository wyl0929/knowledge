# 01 Research Overview / 研究总述报告

Last updated: 2026-06-10

## 1. 一句话理解这个方向

- **初学者版一句话**：量子霍尔效应说的是二维电子在强磁场下"集体齐步走"——电导不连续变化，而是锁定在精确的量子化台阶上，且这个锁定不受材料细节影响。
- **研究者版一句话**：二维电子气在垂直强磁场下的霍尔电导呈现以 $e^2/h$ 为单位的精确量子化平台，其物理根源是单粒子能带的拓扑不变量（IQHE, Chern 数）或强关联拓扑序（FQHE），不依赖于样品几何、无序程度等微观细节。

## 2. 这个方向在更大链条中的位置

```text
量子力学基础 + 固体能带理论
  → 二维电子气 + 强磁场 → 朗道量子化（单粒子能级重构）
  → 拓扑不变量（Chern 数 / Z₂ / 拓扑序）+ 边缘-体对应
  → 量子化输运测量（霍尔电导精确平台）
  → 计量学标准 / 拓扑量子比特 / 低功耗电子学概念验证
```

量子霍尔效应将**拓扑**——一个数学概念——转化为**实验可测的整数**。它不是"某种材料恰好有某种性质"，而是"只要满足拓扑非平庸的条件，某些可观测量必须取某些值"。这种必然性是物理学中最接近"定理"的东西。

## 3. 核心物理图景

### 3.1 IQHE：单粒子的拓扑

二维自由电子气在垂直磁场 $B$ 下，能谱重组为朗道能级 $E_n = \hbar\omega_c(n + 1/2)$。每个朗道能级的简并度 $g = BA/\phi_0$（$\phi_0 = h/e$ 为磁通量子）。填充因子 $\nu = n_e \phi_0 / B$。

当 $\nu$ 为整数时，费米能级位于能隙中，体态绝缘。边界上出现 $|\nu|$ 条手征边缘态通道，每条贡献 $e^2/h$ 的电导。

**TKNN 的深刻洞察**（1982）：$\sigma_{xy}$ 等于占据态的 Berry 曲率在布里渊区的积分——即第一 Chern 数 $C$：

$$\sigma_{xy} = \frac{e^2}{h} C, \quad C = \frac{1}{2\pi} \int_{\text{BZ}} \Omega(\mathbf{k}) d^2k \in \mathbb{Z}$$

其中 Berry 曲率 $\Omega(\mathbf{k}) = \nabla_\mathbf{k} \times \mathbf{A}(\mathbf{k})$，Berry 联络 $\mathbf{A}(\mathbf{k}) = i \langle u_\mathbf{k} | \nabla_\mathbf{k} | u_\mathbf{k} \rangle$。Chern 数只取整数，且在能隙不闭合的前提下连续形变哈密顿量不改变它——这解释了量子化平台的普适性和鲁棒性。

### 3.2 FQHE：多体的拓扑序

当 $\nu$ 为分数（如 $1/3, 2/5$），电子间库仑排斥力 $\sim e^2/(\epsilon l_B)$ 迫使它们形成不可压缩的量子液体。

**Laughlin 波函数**（1983，$\nu = 1/m$）：

$$\Psi_m = \prod_{i<j} (z_i - z_j)^m \exp\left(-\sum_k \frac{|z_k|^2}{4l_B^2}\right)$$

- $(z_i - z_j)^m$ "推开"每对电子，压低库仑能
- 激发是"加 $1/m$ 个电子"——分数电荷准粒子
- 准粒子交换产生非平庸的分数统计相位

**复合费米子图像**（Jain, 1989）：每个电子"绑上"偶数个磁通量子 → 复合费米子在等效减弱磁场中填整数个朗道能级 → 对应原始电子的分数填充。

### 3.3 QAHE：Haldane 蓝图 → 实验现实

无磁场时，时间反演对称性要求 $\Omega(-\mathbf{k}) = -\Omega(\mathbf{k})$，故 $\int \Omega = 0$——Chern 数为零。

**Haldane 的巧妙设计**（1988）：六角晶格上加次近邻跃迁 $t_2 e^{i\phi_{ij}}$，破缺时间反演但每个原胞净磁通为零 → 非零 Chern 数，无需朗道能级。

**2013 年实验实现**：薛其坤组在 Cr-(Bi,Sb)₂Te₃ 拓扑绝缘体薄膜中，利用磁性掺杂 + 能带反转 → $C=1$ → 零场下 $\sigma_{xy} = e^2/h$。当前限制：温度 ~30 mK–1 K。

### 3.4 QSHE：时间反演保护的"双车道"

边缘态是两股反向自旋流——净电荷流为零，净自旋流非零。不变量是 $\mathbb{Z}_2$（$\nu=0$: 平庸，$\nu=1$: 非平庸）。

## 4. 方法脉络

### 4.1 Chern 数计算（你的入口）

**FHS 离散方案**（Fukui-Hatsugai-Suzuki, 2005）：在 k 空间网格上定义 link variable $U_\mu(\mathbf{k}) = \langle u_{n\mathbf{k}} | u_{n\mathbf{k} + \hat{\mu}} \rangle / |\cdots|$，plaquette 上的 Berry 曲率 $F_{12} = \ln[U_1 U_2 U_1^* U_2^*]$，则 $C = \frac{1}{2\pi i} \sum_{\mathbf{k}} F_{12}$。优点：不需要 k 导数（数值噪声大），自动保证整数输出。

**实现注意**：k 网格 $30\times30$–$60\times60$；占据态波函数相位连续性由 FHS 天然处理；能隙过小时 Chern 数不定义。

### 4.2 $\mathbb{Z}_2$ 计算

- **Wilson loop / Wannier 电荷中心**（Soluyanov-Vanderbilt, 2011）：Wilson loop 本征值随 $k_x$ 的演化 → 奇数交叉 → $\nu=1$
- **自旋 Chern 数**（$s_z$ 近似守恒时）：$C_s = (C_\uparrow - C_\downarrow)/2$，奇数 ↔ $\nu=1$

### 4.3 Kubo 公式 + 无序

TBPM 框架中用随机波函数 + 时间演化 + 电流-电流关联函数计算 $\sigma_{xy}(E_F, W)$。

## 5. 当前领域边界与张力

### 张力 1：拓扑保护 vs 热涨落
拓扑是基态性质（$T=0$ 完美成立）。升温 → 热激发穿过能隙 → 平台模糊。QAHE 能隙和磁序居里温度共同决定可观测温度——目前 ~1 K–10 K，离室温 4 个数量级。

### 张力 2：清洁极限 vs 真实无序
拓扑保护的"免疫"对象是不闭合能隙的微扰。实际无序可能闭合能隙、诱导杂质态、破坏磁性。TBPM 在此问题上有天然优势。

### 张力 3：理论分类 vs 材料实现
拓扑能带理论已完成非空间群对称性下的完整分类（拓扑量子化学）。但翻译成实际材料 → 实验观测，每一步都有巨大 drop-off。

## 6. 对你而言的关键要点

1. **IQHE 已封闭**——用它验证工具链，不要做理论"创新"
2. **QAHE 材料-温度问题是你的黄金切入点**——TB + Berry 曲率是现有工具的最小扩展
3. **无序-拓扑相互作用是你的差异化优势**——TBPM 的大尺寸 + 无序在拓扑领域很少被利用
4. **FQHE 不适合计算切入**——多体方法栈完全不同
5. **石墨烯是你的天然试验田**——graphene.py 加磁场、SOC、交换场是直通路径
6. **Chern 数计算的代码量很小**（FHS 核心 ~50 行）——值得立刻动手
