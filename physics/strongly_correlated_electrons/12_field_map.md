# 12 领域地图 / Field Map

Last updated: 2026-06-14

## 1. 领域在更大知识链条中的位置

强关联电子物理处于以下链条的中间层：

```text
上游（基础物理问题）
  └─ 量子多体问题：大量相互作用粒子的集体行为
      └─ 本领域的核心问题：
           当电子-电子相互作用不可视为微扰时，物质的电子态是什么？
           涌现出哪些准粒子、序参量和集体激发？
          └─ 下游（解释与预测）
              ├─ 解释非常规超导、莫特绝缘体、重费米子等实验现象
              ├─ 预测新关联相和量子临界行为
              └─ 指导新材料设计与功能调控
```

在凝聚态物理内部，强关联是连接"能带论成功"与"能带论失效"的关键桥梁。能带论（单粒子图像）解释了金属、绝缘体、半导体的基本区别和拓扑物态；强关联则解释了为什么很多过渡金属氧化物、稀土化合物、有机导体的行为完全偏离能带预测。

## 2. 核心问题链

强关联领域的核心问题链不是一条线，而是围绕同一个"根困难"展开的三条问题线：

### 问题线 A：从莫特绝缘到非常规超导

```text
Mott 绝缘体（电子因关联而局域化）
  └─ 掺杂 -> 关联金属 / 奇异金属（非费米液体输运）
      └─ 进一步降温 -> 非常规超导（赝能隙、d 波配对）
          └─ 问题：莫特绝缘、奇异金属、赝能隙、超导之间的因果链是什么？
          └─ 代表体系：铜氧化物（cuprates）、有机超导体、魔角石墨烯
```

### 问题线 B：局域磁矩与巡游电子的博弈

```text
局域 f/d 电子磁矩 + 巡游 s/p 电子
  └─ 近藤效应：局域磁矩被传导电子屏蔽 -> 重费米子液体
  └─ RKKY 相互作用：磁矩间通过传导电子间接耦合 -> 磁序
      └─ 问题：近藤屏蔽 vs RKKY 磁序的竞争 = Doniach 相图
      └─ 量子临界点：磁序消失的零温连续相变
          └─ 量子临界点附近：非费米液体、非常规超导常出现
          └─ 代表体系：CeCu6-xAux、YbRh2Si2、CeCoIn5
```

### 问题线 C：几何阻挫与量子自旋液体

```text
反铁磁交换 + 几何阻挫（三角晶格、kagome 晶格等）
  └─ 经典磁序被抑制
      └─ 量子涨落占主导 -> 可能的量子自旋液体基态
          └─ 问题：自旋液体是否真实存在？如何实验检测？
          └─ 分数化激发（自旋子、Majorana 费米子）如何计算和观测？
          └─ 代表体系：κ-(BEDT-TTF)2Cu2(CN)3、α-RuCl3、herbertsmithite
```

## 3. 理论方法谱系

强关联理论的方法可以沿两个坐标轴组织：

### 坐标轴 1：局域 ↔ 巡游

```
完全局域（原子极限）
  ├─ 原子多重态理论
  ├─ 晶体场理论
  ├─ 超交换微扰论（Anderson 超交换）
  └─ 海森堡模型（自旋自由度）
      |
  局域+巡游混合
  ├─ Anderson 杂质模型 + 近藤效应
  ├─ 近藤晶格模型
  ├─ 周期性 Anderson 模型
  ├─ Hubbard 模型（局域 U + 巡游跳跃 t）
  ├─ t-J 模型（大 U 极限下的 Hubbard 模型投影）
      |
  完全巡游（弱关联极限）
  ├─ 费米液体理论
  ├─ 无规相近似（RPA）
  └─ GW 近似
```

### 坐标轴 2：分析方法 ↔ 数值方法

```
分析方法（精确或受控近似）
  ├─ 精确解 / 严格结果
  │   ├─ 一维：Bethe ansatz、Luttinger 液体、共形场论
  │   ├─ 无限维：DMFT 严格
  │   └─ Lieb-Schultz-Mattis 定理等
  ├─ 隶粒子方法（slave boson / slave fermion）
  │   ├─ 平均场 -> 有效单粒子图像
  │   └─ 规范涨落修正
  ├─ 玻色化 / 共形场论（一维）
  ├─ 全息对偶（AdS/CFT，无准粒子体系的强耦合描述）
  └─ 场论重整化群（RG）

数值方法（可控误差、体系受限）
  ├─ 精确对角化（ED）：小团簇（≲ 20-40 格点）
  ├─ 量子蒙特卡罗（QMC）
  │   ├─ 行列式 QMC（DQMC）：有限温，费米子符号问题
  │   ├─ 辅助场 QMC（AFQMC）：基态，符号问题
  │   ├─ 连续时间 QMC（CT-QMC）：杂质问题，无符号问题
  │   └─ 世界线 QMC：玻色子/自旋体系较好
  ├─ 张量网络 / DMRG
  │   ├─ 密度矩阵重整化群（DMRG）：一维/准一维极精确
  │   ├─ 矩阵乘积态（MPS）、投影纠缠对态（PEPS）：二维拓展
  │   └─ 多尺度纠缠重整化（MERA）：临界体系
  ├─ 动力学平均场（DMFT）+ 团簇扩展
  │   ├─ 单格点 DMFT：局域关联精确，空涨落忽略
  │   ├─ 团簇 DMFT（CDMFT / DCA）：部分恢复空间关联
  │   └─ 图解扩展（DΓA、DF、dual fermion）：体系性加入非局域修正
  ├─ DFT+DMFT：第一性原理 + 强关联
  └─ 机器学习辅助方法（NEEDS_VERIFICATION）
```

## 5. 核心假设地图

每个理论框架都带有关键假设，了解这些假设是判断计算结果可信度的前提：

| 理论框架 | 核心假设 | 假设失效时的后果 |
|---------|---------|---------------|
| 费米液体理论 | $U \ll W$，准粒子权重 $Z > 0$ | 不能描述非费米液体、奇异金属、莫特绝缘体 |
| DMFT | 空间涨落可忽略（无限维严格） | 低估二维反铁磁涨落；不能描述 d 波超导的节点准粒子 |
| 隶玻色子平均场 | 规范涨落可忽略 | 高估金属态的稳定性；不能描述真正的分数化 |
| DMRG/MPS | 基态纠缠熵面积律成立 | 一维精确；二维需要指数大的键维数，不可行 |
| DQMC | 费米子行列式可正化（无符号问题） | 符号问题时误差指数爆炸，实际无法计算 |
| DFT+DMFT | DMFT 关联自能局域，DFT 提供非关联部分 | 当非局域关联主导时（如低维关联体系）不准确 |
| AdS/CFT 全息 | 大 N、强耦合极限 | 对实际凝聚态体系的定量预测尚未建立 |

## 6. 实验-理论-计算三角

强关联领域的推进高度依赖三条腿的互动：

```text
         实验
        /    \
       /      \
  理论 —————— 计算

实验发现现象（铜氧化物高温超导、重费米子量子临界等）
  └→ 推动理论提出新概念（Mott 物理、非费米液体、自旋液体）
      └→ 计算提供定量检验
          ├─ 模型计算检验理论机制是否自洽
          ├─ 第一性原理计算（DFT+DMFT）连接真实材料
          └─ 计算结果反哺实验、指导新材料搜索
```

当前状态：三条腿都有各自成功，但**端到端的闭环（从材料到模型到定量预测到实验验证）仍未完成**。这是整个领域的核心挑战之一。

## 7. 当前领域焦点问题 (2024–2026)

以下基于领域的一般发展趋势，具体论文和结果标注 NEEDS_VERIFICATION：

1. **魔角石墨烯与莫尔超晶格中的强关联**：转角二维材料提供了前所未有的可调性（载流子浓度、带宽、拓扑），是当前最活跃的强关联实验平台。核心问题包括超导配对对称性、关联绝缘态的起源、与铜氧化物的异同。

2. **Kagome 晶格关联与拓扑**：Kagome 金属（如 AV₃Sb₅ 家族）中电荷密度波、超导与拓扑能带的相互作用。问题在于：电子关联在多大程度上驱动了这些序？

3. **镍基超导体**：无限层 nickelate（NdNiO₂ 等）的发现为铜氧化物之外的高温超导提供了新平台。与铜氧化物的异同仍在热烈讨论中。

4. **量子自旋液体的实验确认**：α-RuCl₃ 中的 Majorana 费米子证据（热霍尔效应）、Kitaev 材料家族的拓展。核心挑战是"排除其他解释"。

5. **数值方法的符号问题突破**：受限路径积分蒙特卡罗（CP-AFQMC）、神经量子态（NQS）、量子计算模拟等方面的进展。NEEDS_VERIFICATION：具体最新突破和基准结果。

6. **非费米液体的分类与图谱**：是否存在普适的非费米液体类别？奇异金属的输运标度律是否有统一解释？全息对偶和 SYK 模型在这个问题上提供了新视角。
