## QA-001: tbplas 处理电子相互作用的路径（2026-07-24）

### Q: 基于单电子态的 tbplas 是否只能通过自洽计算来处理强关联/多体相互作用？

**短答**：对，自洽计算是把电子相互作用"翻译"成单粒子框架能处理的形式的最自然路径——但不是唯一路径。

### 详细分析

#### tbplas 的本体：单粒子传播子引擎

tbplas 的核心能力：给定单粒子紧束缚哈密顿量 H₀，用 TBPM/KPM 计算 DOS、电导率、Berry 曲率等。它不构建 Fock 空间，不做 Slater 行列式的线性组合——这是它与 DMRG/ED/QMC 等真多体代码的本质区别。

#### 五条路径的光谱

| 路径 | 自洽？ | tbplas 适配度 | 关联强度适用范围 | 说明 |
|------|:---:|:---:|:---:|------|
| **Hartree-Fock / DFT+U** | ✅ 是 | ★★★★★ | 弱–中 | n_i↑ n_i↓ → ⟨n⟩n 平均场解耦；tbplas 每次迭代算电荷密度/态密度；Python 驱动外层循环 |
| **隶粒子平均场** | ✅ 是（鞍点） | ★★★★ | 中 | c = f b† 解耦后得重正化单粒子 H_eff（带宽被 ⟨b⟩ 压低）；丢失规范涨落 |
| **DMFT（tbplas 做晶格求解器）** | ✅ 是 | ★★★★ | **中–强** | tbplas 替代 k 空间求和算 G_loc(ω)；天然适合无序+磁场+大超胞；需外层杂质求解器（CT-QMC/ED） |
| **GW / RPA 微扰自能** | 可选 | ★★★ | 弱–中 | tbplas 算 G₀ + 极化函数；Σ = G₀W₀；对真正 U/W≳1 的体系微扰前提不成立 |
| **ED / DMRG / QMC** | — | ❌ 不可行 | 任意 | 需要 Fock 空间 + 完全不同的代码架构（ITensor, TRIQS, ALF 等）；不是"加层自洽"能解决的 |

#### 关键判断

1. **静态平均场（HF）是起步最快的**：Python 驱动自洽循环 + tbplas 做每次 DOS/电荷密度计算。一小时内可以跑通概念验证，看到 U 增大 → 能隙打开 → 莫特绝缘体的平均场图像。

2. **DMFT 是真正有区分度的路线**（对应 Project P1）：tbplas 在 DMFT 中的独特价值在于它可以自然处理**无序 + 磁场 + 输运**的组合参数区间——这些在标准 DMFT 代码（TRIQS, w2dynamics）中很难做。对应 Gap Table 中 **G3（强关联输运）和 G7（关联+无序+外场）** 两个高匹配度的 confirmed/suspected gap。

3. **Claim 8 的提醒**：对强关联问题，"算得快"不如"方法对"。tbplas + DMFT 的价值不在于比 DMRG 快，而在于能处理 DMRG/QMC 难以处理的参数区间。

4. **"自洽"在两种路径中含义不同**：HF 自洽找的是静态平均场不动点；DMFT 自洽找的是晶格-杂质映射的不动点（含频率相关的量子涨落）。
