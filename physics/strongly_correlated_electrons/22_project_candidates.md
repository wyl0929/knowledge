# 22 候选项目卡片 / Project Candidates

Last updated: 2026-06-14

## 说明

本文件列出从 gap table 和用户资产匹配中衍生出的候选研究项目。每个项目包含：核心问题、方法、基线、成功/失败判据、与用户资产的匹配度。

项目的排列顺序代表推荐的优先级。

## 项目 P1：TBPM + DMFT 混合方法计算关联电子输运

### 核心问题

能否用 TBPM（紧束缚传播法）作为 DMFT 的晶格格林函数求解器，计算强关联模型（如 Anderson-Hubbard 模型）在磁场下的电导率和霍尔效应？

### 为什么是好的切入点

- 用户的 TBPM 代码和 MPI 并行经验是现成的；
- DMFT 自洽循环中最耗时的步骤是晶格格林函数计算（对 k 空间求和），TBPM 在这个问题上天然有优势——它是实空间的、O(N) 标度的传播方法，天然适合大规模和含无序的体系；
- 强关联输运计算（Gap 3）是 confirmed gap，而关联+无序（Gap 7）与用户背景高度匹配；
- 这个问题天然可以"先弱后强"：先从非相互作用的 Anderson 模型验证 TBPM 的输运计算准确性（已有已知答案），再逐步加入 DMFT 自能和相互作用。

### 已有 baseline（用户需要对照的已知结果）

| baseline | 体系 | 已知结果 | 验证方式 |
|---------|------|---------|---------|
| B1 | 无相互作用 Anderson 模型 | 标度理论预言的金属-绝缘体转变临界无序强度、电导率分布 | 用 TBPM+Kubo/微正则方法复现 |
| B2 | 半满单带 Hubbard 模型 (DMFT) | DMFT 预言的莫特转变临界 U（~1.5W for Bethe 晶格）和态密度三峰结构 | TBPM 做晶格格林函数，与标准 DMFT（如 TRIQS）对比自能收敛 |
| B3 | 量子霍尔效应 IQHE | 整数量子化的霍尔电导平台 | TBPM 计算磁场下 Chern 数和边缘态输运，对比已知结果 |

### 方法框架

```
输入：
  紧束缚哈密顿量 H₀(k)（用户现有）
  + 在位 Hubbard U（强关联）
  + 无序势 V_disorder(r)（可选项）
  + 磁场（通过 Peierls 相位）

DMFT 自洽循环：
  1. 猜测初始自能 Σ(ω) = 0
  2. 晶格格林函数 G_lat(ω) = Σ_k [ω - H₀(k) - Σ(ω)]⁻¹  ← TBPM 在这一步替代 k 求和
  3. 局域格林函数 G_loc(ω) = (1/N) Σ_k G_lat(k, ω)
  4. 杂质模型求解：从 G_loc 减去 Σ 得到 Weiss 场 G₀⁻¹ = G_loc⁻¹ + Σ
     用精确对角化（小 U）或 CT-QMC 求解 → 新的 Σ(ω)
  5. 回到 2，迭代至 Σ 收敛

TBPM 处理 k 求和的方式：
  G_lat(r=0, ω) ≈ (1/N_rand) Σ_{|φ₀> random} <φ₀| (ω-H)⁻¹ |φ₀>
  其中 H = H₀ + Σ(ω)（在实空间表示）
  用 TBPM 传播 |φ(t)> = exp(-iHt)|φ₀>，傅里叶变换得到 G_loc(ω)
```

### 成功/失败判据

**阳性结果**：
- 在非相互作用极限（U=0）下，TBPM 计算结果与已知的 Anderson 局域化标度理论一致（偏差 ≤ 5%）。
- 在相互作用极限（U>0, DMFT 自洽）下，电导率 σ_xx 随 U 的变化定性合理：U 增大 → σ_xx 减小，能复现 DMFT 预言的金属-绝缘体转变趋势。
- 在磁场+无序+相互作用组合下，能产生非平庸的霍尔电导率（区别于纯单粒子图像）。

**阴性结果**：
- TBPM 的随机态采样误差淹没了 DMFT 自洽循环中的自能修正（即方法噪声 > 关联效应）。
- 或：DMFT 自洽在 TBPM 的有限精度下不收敛。

**止损条件**：
- 如果尝试了 ≥ 3 个不同参数集（U, W, T）后，TBPM+DMFT 自洽结果仍与标准 DMFT 参考结果定性不符，则停止，转用标准 DMFT 代码学习 benchmark 再评估。

### operational_status：proposed（尚未执行 Operationalization Gate 的完整验证，以下为初步草案）

## 项目 P2：魔角石墨烯平带的紧束缚建模 + DMFT 关联分析

### 核心问题

能否用用户的石墨烯紧束缚代码生成魔角转角石墨烯的有效紧束缚哈密顿量，然后将低能平带投影为 Hubbard 类模型，用 DMFT 或精确对角化计算关联相的态密度和相图？

### 方法与步骤

```
步骤 1: 紧束缚模型构造
  使用 Bistritzer-MacDonald 连续模型或已有的紧束缚参数化，
  生成魔角 (θ ≈ 1.05°) 石墨烯的实空间哈密顿量。
  用户现有石墨烯紧束缚代码可以直接用于构造层内部分，
  层间耦合需要扩展（MoSe₂/WSe₂ 等封装效应可选择加入）。

步骤 2: 平带 Wannier 函数投影
  将低能（~ 10 meV 附近的平带）投影到 Wannier 函数基，
  得到有效 Hubbard 模型：H_eff = Σ t_ij c_i† c_j + U Σ n_i↑ n_i↓
  这一步可以从 DFT 文献中获取已有参数作为交叉验证。

步骤 3: 关联求解
  用 DMFT（TRIQS / w2dynamics）或精确对角化求解 H_eff，
  计算态密度 DOS(ω)、双占据率作为 U 和填充因子的函数。
  与实验 STM 谱和输运数据做定性对比。
```

### 已有 baseline

- MacDonald 组和 Andrei 组的实验+理论联合论文中的相图和态密度。
- 文献中已有的 DFT+DMFT 对魔角石墨烯的计算结果。

### 成功/失败判据

**阳性结果**：得到与实验（STM dI/dV 谱）定性一致的态密度特征（如平带劈裂、Hubbard 子带的填充依赖性）。
**阴性结果**：构造的有效模型无法复现已知的关联绝缘态填充序列（ν = ±2, ±3）。
**止损条件**：如果模型参数（U/t 等）与文献公认值差异 > 50% 且无法调和，则检查紧束缚参数化是否有系统误差。

### 与用户资产匹配度

| 资产 | 匹配 |
|------|:---:|
| 石墨烯紧束缚代码 | ⭐⭐⭐⭐⭐ |
| MPI 并行 | ⭐⭐⭐ |
| TBPM | ⭐⭐（可在步骤 3 用于计算态密度） |
| DMFT 知识 | ⭐（需要学习，但 P1 会建立此能力） |

## 项目 P3：Kitaev 模型中无序对 Majorana 输运的影响

### 核心问题

在 Kitaev 蜂窝模型中加入键无序（bond disorder）或格点空位，Majorana 费米子的热/自旋输运如何被影响？能否用数值结果解释 α-RuCl₃ 中热霍尔效应实验的不一致？

### 方法

- 对 Kitaev 模型进行精确对角化，加入不同类型的无序；
- 计算热霍尔电导率 κ_xy 和纵向热导率 κ_xx 作为无序浓度的函数；
- 使用 TBPM 方法（如果可以将 Majorana 费米子映射为自由费米子）做大规模计算。

### 基线

- Kitaev 原始论文中的精确解（纯体系，无无序）的 Majorana 谱和边缘态。
- 已有的 α-RuCl₃ 热霍尔实验数据。

### 成功/失败判据

**阳性结果**：发现无序在特定浓度下压制/恢复了特定输运特征，能解释至少一个实验矛盾。
**阴性结果**：无序的影响是平庸的（单调压制所有特征），不能解释实验差异。

### 与用户资产匹配度

| 资产 | 匹配 |
|------|:---:|
| 精确对角化 | ⭐⭐⭐ |
| TBPM（给费米子体系） | ⭐⭐ |
| MPI | ⭐⭐⭐ |
| 领域背景（自旋液体） | ⭐（需要较多学习） |

## 项目 P4：一维 Hubbard 模型作为强关联数值方法的 testbed

### 核心问题

在用户最熟悉的计算框架（Python + MPI + 紧束缚）中，从零开始实现一维 Hubbard 模型的计算工具链（精确对角化 → DMRG 初步 → DMFT），以建立对强关联方法的"手感"。用 Bethe ansatz 的精确解作为基准。

### 为什么值得做

- 一维有精确解——用户永远不会在"对不对"上迷失。
- 一维 Hubbard 模型几乎每一种数值方法都有实现，可以作为学习 benchmark。
- 从一维开始建立的代码框架（哈密顿量构造、格林函数计算、自能迭代等）可以直接复用到 P1 和 P2 的三维/二维部分。

### 基线

- Lieb-Wu Bethe ansatz 精确解（基态能量、电荷/自旋 gap、Luttinger 参数）。
- 已有的 DMRG benchmark（如 ITensor 自带的 Hubbard 示例）。

### 成功/失败判据

**阳性结果**：ED/DMRG 计算的一维 Hubbard 模型基态能量与 Bethe ansatz 偏差 < 1%；电荷 gap 的有限尺寸标度与已知结果一致。
**止损条件**：如果 ED（小团簇，N ≤ 12）结果与精确解偏差 > 5%，说明哈密顿量构造或对角化实现有 bug，回退修正。

## 推荐路线图

```text
              P4 (一维 testbed, 1–2 周)
                  |
                  v
         P1 (TBPM+DMFT 输运, 1–3 月)
            /            \
           v              v
    P2 (魔角石墨烯)    P3 (Kitaev+无序)
       (2–4 月)          (3–6 月)
```

- **P4 → P1** 是最自然的路径：先用一维建立"我能怎么算强关联"的信心和代码基础，再从最契合用户现有资产的 P1 切入。
- **P1 → P2** 把 DMFT 管道复用到用户已有的石墨烯代码上。
- **P3** 是更高风险的探索方向，建议在 P1 完成后再评估是否值得投入。
