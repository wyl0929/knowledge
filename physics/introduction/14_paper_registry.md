# 14 Source Registry / 来源与阅读入口注册表

Last updated: 2026-08-30

## 使用说明

本文件记录物理学入门的 seed sources 与关键阅读入口：以"改变了学科地图"的经典文献为主，辅以少量近期观测里程碑和导读入口。

质量规范（v1.3 文献 QC 协议）：

- 每条来源标注证据分级：**📜Q**（quote，引自来源本身公认内容）、**💭I**（inference，AI 综合或领域常识，标"推断"）；
- 卷期页码与 DOI 本包统一不填写（未逐一核对，防止编造），需要时再按引文数据库补全；
- Status 取值：`seed`（凭记忆收录，待核验）；`skimmed`（本次已通过网络数据库核验题名/年份/venue）；`parsed` / `verified` / `archived` 留待后续精读升级；
- 不确定内容标 `NEEDS_VERIFICATION`。

Field / 领域：物理学入门

## 来源类型

- `foundational theory`：基础理论或经典概念来源；
- `recent study`：近期研究或历史性观测里程碑；
- `review`：综述、教材或导读；
- `journal / venue`：期刊、学会或预印本平台。

## 证据角色

- 概念定义 / 领域入口 / 代表论证 / 近期趋势 / 第一手阅读对象 / 方法资源。
