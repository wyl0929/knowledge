# USER BRIEF / 本次需求说明

Last updated: 2026-08-30

## 这份文件的作用

这里保存用户对本 field pack 的特殊要求。内容可以直接用自然语言书写。生成或更新本包中的任何主体文档前，agent 都必须先读取本文件。

本文件与其他文件的区别：

- `10_self_inventory.md`：记录本次使用的 profile 或用户背景快照；
- `USER_BRIEF.md`：记录本次调研的目标、重点、写作方式和回避事项；
- `90_QA.md`：保存后续自由讨论，默认不自动成为持续要求；
- `99_update_log.md`：保存修改历史。

## 用户原始需求

> 在 physics 下写一个物理学入门的包

原始调用：`/research-onboarding 在 physics 下写一个物理学入门的包`

## 当前有效要求

- 包定位：物理学入门，面向第一次系统接触物理学的读者；属于兴趣了解，不需要研究选题。
- 不生成 gap table、资产匹配、项目候选和 MVP；不主动把兴趣了解推向研究规划。
- 不结合用户个人背景；不假设用户拥有任何代码、数据、硬件或实验资源。
- 主体中文；重要术语先中文解释，再括注英文。
- 希望有一条清晰主线：经典物理 → 现代物理（相对论 + 量子）→ 当代前沿与开放问题。
- 希望看到：最小例子、少量核心公式（带变量解释）、分层阅读路径。
- 简略处理：各分支的前沿技术细节点到为止；公式只保留最能帮助理解的少数几条。
- 暂时不需要涉及：研究选题、gap 分析、项目孵化、MVP。
- 派生子方向：默认不派生；后续若想深入某一分支（如量子力学、凝聚态），再按需创建。
- 与 physics/ 目录下已有 pack 的关系：本包是 physics/ 的入门层；已有的量子霍尔效应、强关联、多层石墨烯等 pack 属于凝聚态物理前沿层，可在阅读路径中作为"深入一步"的指针，但不把入门包写成凝聚态专题。

## 内容侧重点

- 希望重点展开：物理学是什么（方法、目标、与数学/化学/工程的边界）；学科主线与分支谱系；代表思想与人物；理论—实验—计算三种工作方式；开放问题与边界感；分层阅读路径。
- 希望简略处理：各分支的技术细节与前沿进展；公式推导过程。
- 暂时不需要涉及：研究选题与项目孵化。

## 写作与呈现偏好

- 语言与风格：主体中文，先直觉后术语，像研究者给新人讲"这个领域到底怎么回事"；避免百科腔与清单腔。
- 期望深度：可读但不浅；核心概念给公式或流程并解释变量。
- 是否需要公式 / 流程 / 例子：需要少量核心公式（如牛顿第二定律、麦克斯韦方程组简式、薛定谔方程）并解释变量；需要文字流程图；需要一个贯穿全文的最小例子。
- 是否需要阅读清单：需要，按"入门 → 主干 → 分支 → 前沿"分层给出。
- 是否需要派生子方向：暂不需要，后续按需。

## 与父方向的继承关系

本包不是子方向包，无父方向；它是 physics/ 目录的入门层，向下可派生各分支包。
