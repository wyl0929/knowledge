# 20 研究缺口表 / Gap Table

Last updated: 2026-06-14

## 说明

本文件列出强关联电子领域中的研究缺口（gap）。分类：

- **confirmed**：有明确证据表明是真实缺口，多个独立来源一致确认
- **suspected**：有很强迹象是缺口，但可能已有部分进展或解释存在争议
- **weak**：可能是缺口，但也可能是已解决或伪问题
- **not-a-gap**：看起来像缺口但实际不存在（已有解决或问题设置本身就是伪问题）

每个 gap 必须解释：现有工作链条哪里承重不足，以及最小验证方式。

---

## Gap 1：二维掺杂 Hubbard 模型的基态相图

- **类别**：confirmed
- **问题描述**：半满附近掺杂的二维 Hubbard 模型是高温超导理论的"标准模型"。然而，其基态相图（条纹相、d 波超导、费米液体、可能的配对密度波相之间的竞争和边界）在定量上仍然存在争议——不同方法（DMRG、DQMC、DMFT 及其扩展、变分蒙特卡罗）给出的相边界不一致。
- **现有工作链条的承重不足处**：
  - DMRG 最精确但限于窄条带（宽度通常 ≤ 6–8 格点），相边界可能受有限宽度影响。
  - DQMC 有符号问题，低温大团簇不可行。
  - DMFT 忽略非局域空间涨落——而二维超导和条纹序恰好是空间非均匀的。
  - Cluster DMFT / DΓA 等扩展方法各有近似，结果彼此不完全一致。
- **为什么重要**：如果连标准模型的基态相图都不确定，就谈不上"证明"或"证伪"强关联机制对高温超导的解释。
- **最小验证**：选择一种方法（如 DMRG），固定宽度并系统外推到热力学极限；或在特定参数区间（如弱耦合极限）用 fRG 等互补方法进行交叉验证。
- **用户相关性**：中。用户如果要进入这个核心问题，建议先选一个方法并复现已知 benchmark 结果（如半满反铁磁序、弱掺杂条纹周期），再推进到争议区域。

## Gap 2：非费米液体的统一分类框架

- **类别**：suspected
- **问题描述**：实验上观察到了多种非费米液体（奇异金属、边缘费米液体、Luttinger 液体等），理论上有多种产生 NFL 的机制（量子临界、规范场涨落、SYK 模型、全息对偶）。但这些 NFL"种类"之间是否有统一的分类原则（类似于朗道费米液体的对称性+准粒子框架）还不清楚。
- **现有工作链条的承重不足处**：
  - 不同 NFL 的理论处理往往使用完全不同的数学框架。
  - 实验上"这是哪一种 NFL"的诊断工具严重不足（通常只能看电阻率的温度指数）。
  - 缺乏可计算的"序参量"来区分 NFL 相。
- **最小验证**：选择一个具体模型（如反铁磁量子临界点附近的 Hubbard 模型），用 DQMC/DMFT 精确计算多种物理量（单粒子谱、输运、热力学），与不同 NFL 理论的预测对比。
- **用户相关性**：低-中。这是一个偏基础理论和实验诊断的方向，不适合作为计算起步项目。但如果用户的计算方法可以用于计算大规模输运性质，可能会提供关键的数值数据。

## Gap 3：强关联电子体系中的输运性质计算

- **类别**：confirmed
- **问题描述**：大多数强关联数值方法（DMRG、DMFT、QMC）擅长计算热力学和单粒子谱，但在计算输运性质（电导率、热导率、霍尔系数、热电系数）方面有显著困难。输运涉及电流-电流关联函数，在大多数数值方法中噪声大、需要解析延拓、或需要 Kubo 公式的精确评估。
- **现有工作链条的承重不足处**：
  - DMFT 的输运计算忽略了顶点修正（除非用 DΓA 等扩展），而顶点修正在强关联体系中可能很重要。
  - DMRG 可以算实频率动力学关联函数，但有限尺寸效应和边界效应在输运量上尤其严重。
  - QMC 的输运计算需要解析延拓（最大熵或随机解析延拓），在高温到低温的桥梁区域误差大。
- **为什么重要**：输运是实验上最直接可测的量（电阻、霍尔、热电势），也是区分不同理论的关键判据。输运计算的不成熟使得理论与实验的定量对比受到严重限制。
- **最小验证**：选一个"已知答案"的体系（如一维 Hubbard 模型的 Luttinger 液体输运，Bethe ansatz 有精确结果），测试一种输运计算方法（如 DMRG+Kubo），检验其再现已知结果的能力。
- **用户相关性**：高。用户的 TBPM 方法天然适合计算单粒子输运。**潜在切入方向**：在 Hubbard 模型（或其他强关联模型）中测试 TBPM 的输运预测，与 DMFT/DMRG 结果对比，看 TBPM 方法能否在特定参数区间提供更高效的输运计算。但需要注意：TBPM 本质是单粒子传播子方法，强关联需要多体处理。一个可行的方案是：先做 DMFT 自洽得到自能，再用 TBPM 做晶格格林函数的快速输运计算。

## Gap 4：从"可解"模型到"可算"材料的桥接

- **类别**：confirmed
- **问题描述**：强关联领域有两个世界：(1) Hubbard / t-J / Kondo 晶格等模型世界——物理清晰，可以精确计算（在特定极限下），但与真实材料有差距；(2) DFT+DMFT 等第一性原理世界——可以处理真实材料，但 DMFT 的近似控制不如模型世界精确。两者之间的中间地带（既有材料具体性又有计算精度）缺失严重。
- **最小验证**：对一个已知的实验观测（如某种铜氧化物在特定掺杂下的费米面拓扑），同时用模型计算（如 Hubbard 模型+DMRG）和 DFT+DMFT 计算，检查两者的(不)一致性。
- **用户相关性**：中。如果用户希望把 TBPM/紧束缚经验与强关联真实材料结合，这是一个切入点。但 DFT+DMFT 的学习曲线陡峭。

## Gap 5：莫尔体系关联相的多体数值计算

- **类别**：suspected（可能已有部分进展）
- **问题描述**：魔角石墨烯和相关莫尔体系的平带是强关联物理的绝佳平台。但这些体系的第一性原理尺度大（莫尔超胞可达上万个原子），直接用多体方法（DMFT、DMRG）计算面临挑战。目前的策略是构造有效的紧束缚/Hubbard 类模型，但其参数（有效 U、跳跃 t、非局域相互作用等）存在争议。
- **最小验证**：用 DFT 计算 Wannier 函数参数化有效模型，再用 DMFT 或 ED 计算一个可观测量的预测（如态密度），与 STM 实验对比。
- **用户相关性**：高。用户的石墨烯紧束缚代码和 TBPM 可以直接用于构造莫尔体系的紧束缚哈密顿量（在连续模型层面），这是莫尔体系强关联研究的必要输入。

## Gap 6：高温超导的"配对胶水"的直接数值证据

- **类别**：confirmed（最著名的开放问题之一）
- **问题描述**：铜氧化物高温超导的"配对胶水"是自旋涨落、电荷涨落、还是两者的协同、还是某种新的集体模式？经过近 40 年的研究，仍然没有被普遍接受的答案。
- **为什么重要**：不理解配对机制，就无法理性设计更高 Tc 的超导体。
- **最小验证**：不是单个实验/计算能解决的问题。需要多种方法（共振非弹性 X 射线散射 RIXS、角分辨光电子能谱 ARPES、多种数值方法的多体动力学计算）的协同和互相校准。
- **用户相关性**：低。这个问题不适合作为计算 PhD 或新进入者的起步课题——太大、太拥挤、其核心困难是方法瓶颈而非 idea 瓶颈。

## Gap 7：强关联 + 无序 + 外场组合效应

- **类别**：suspected
- **问题描述**：真实材料中，强关联通常与无序、磁场等共存。但大多数数值方法只能处理其中一种复杂性的叠加：DMFT 可以处理关联+无序（通过 CPA/DMFT），但量子干涉效应（弱局域化等）难以纳入；DMRG 可以处理无序但限于一维。
- **最小验证**：在 Anderson-Hubbard 模型中用 DMFT 或 DQMC 系统地计算磁场下的电导率，与已有的金属-绝缘体转变相图进行交叉验证。
- **用户相关性**：高。用户的 TBPM + SLURM 并行天然适合计算无序体系的大规模输运。**切入想法**：Anderson-Hubbard 模型（同时有相互作用 U 和无序 W）中，用 TBPM 处理单粒子传播子部分，结合 DMFT 的局域自能修正，计算磁场下的霍尔电导和纵向电阻率。
