# 02 边界罗盘 / Frontier Compass

Last updated: 2026-06-14

## 这个文件的作用

边界罗盘的目标是让你快速判断：一个强关联相关的 idea 或方向处于知识地图的哪个位置——是已经被充分探索的"内圈"、正在推进的"中圈"、真正的"边界"、还是看起来难但其实不是真问题的"伪 gap"。同时也指出与你的个人背景（计算凝聚态物理、TBPM、石墨烯）最匹配的切口。

## 内圈知识 / 已被充分解决的

这些是强关联领域中已经建立得比较牢固的"常识"，新手不应该在这些方向上寻找原创性贡献：

| 内圈知识 | 为什么是内圈 |
|---------|------------|
| 莫特绝缘体的基本概念：U >> W 时电子局域化 | 已被多种理论方法和实验反复验证 |
| Hubbard 模型在无限维可以精确映射到 Anderson 杂质模型 | DMFT 的数学基础，严格证明已完成 |
| 一维量子多体系统的 Luttinger 液体描述 | Bethe ansatz + DMRG + 玻色化，结论一致 |
| 铜氧化物母体是反铁磁莫特绝缘体 | 大量实验一致确认 |
| 铜氧化物超导配对对称性是 d 波 | 相位敏感实验（三晶结 π 环等）确凿 |
| DMFT 对三维莫特转变的三峰态密度描述 | 被光电子能谱实验半定量确认 |
| DMRG 在一维的精确性和可靠性 | 已和 Bethe ansatz 精确解、共形场论预测对照 |
| 行列式 QMC 在半满时的正确性（无符号问题） | 数学上可证明和实际上已验证 |
| Doniach 相图：近藤屏蔽 vs RKKY 竞争的框架 | 重费米子领域的基本组织原则 |

**对你的含义**：如果你的算出来的结果和这些内圈结论矛盾，大概率是你的代码有 bug，不是你发现了新物理。

## 中圈知识 / 成熟但不完全封闭的

这些方向已有大量工作，baseline 比较清楚，但仍然有新角度、提高精度、或跨领域应用的余地。适合用于学习和建立 benchmark，但不适合作为"重大突破"的靶点：

| 中圈知识 | 已确定了什么 | 还有什么可做的 |
|---------|-----------|-------------|
| 三维 Hubbard 模型的 DMFT 计算 | 相边界、莫特转变的临界 U、关联金属态的性质已较清楚 | 非局域修正（cluster DMFT、DΓA）的定量效应；与特定材料（如 V₂O₃）的参数化定量对比 |
| 重费米子的 DFT+DMFT 计算 | 对多种 Ce/Yb 化合物的有效质量和费米面能给出半定量描述 | 量子临界点附近的输运异常尚不能从 DFT+DMFT 中自然得出 |
| 标准（正方晶格、最近邻跳跃）Hubbard 模型的基态 | 半满反铁磁序、弱掺杂条纹、d 波超导倾向已有多方法共识 | 精确的掺杂-相互作用相边界（如条纹到超导的转变线）仍在争议中 |
| 自旋 Peierls / 一维关联绝缘体 | 激发谱、序参量已清楚 | 非平衡动力学、超快光谱模拟 |
| 魔角石墨烯的连续模型能带 | Bistritzer-MacDonald 模型可以很好地描述平带 | 有效相互作用参数（U/t 值、屏蔽效应）仍在争论中 |

**对你的含义**：这些可以作为你学习强关联方法（DMFT、DMRG 等）的练习场。例如，复现三维 Hubbard 模型的 DMFT 莫特转变曲线是一个很好的"我搞清楚这套工具了"的验证。

## 真正的研究边界 / 开放问题

这些问题目前没有公认答案，投入有可能产生有意义的贡献。但困难程度差距很大：

| 边界问题 | 困难所在 | 是否适合你的背景 |
|---------|---------|:--------------:|
| 二维掺杂 Hubbard 模型的完整基态相图 | 所有已知方法在此问题上有互补短板（符号问题/有限尺寸/局域近似） | 中等——需要掌握 DMRG 或 cluster DMFT 才能有效竞争 |
| 强关联体系的可靠输运性质计算 | Kubo 公式在多数值方法中噪声大或需要难以控制的近似 | **高**——这是 TBPM 可能提供差异化的方向 |
| 魔角石墨烯超导的配对对称性和机制 | 实验尚未确定对称性，理论在 Hubbard 模型与电声子模型之间摇摆 | 中-高——石墨烯紧束缚背景是优势，但需要多体方法补充 |
| 量子自旋液体的明确实验/数值证据 | 真实材料的无序和残余相互作用使"证明"极其困难 | 低-中——需要专门的实验或大规模 DMRG/PEPS 计算 |
| 非费米液体的分类 | 缺少数值上可操作的序参量和诊断工具 | 低——偏理论和基础问题 |
| Kagome 金属中关联、拓扑与电荷序的相互作用 | 新材料涌现快，理论滞后 | 中——如果用户能快速跟进新材料和新计算结果 |
| 强关联拓扑物态（分数 Chern 绝缘体等） | 强关联+拓扑的交叉，理论框架仍在发展 | 中-高——与用户的量子霍尔效应兴趣有天然连接 |
| 关联电子体系的机器学习势函数/有效哈密顿量 | 用 ML 加速强关联计算是新方向 | 中——NEEDS_VERIFICATION，尚未充分发展 |

## 伪 Gap / 看起来难但可能不是真问题

| 伪 Gap | 为什么可能不是真问题 |
|--------|------------------|
| "DMFT 忽略了所有空间涨落所以没有用" | DMFT 是控制近似——在三维和足够高的配位数下是准精确的。问题不在于"忽略了空间涨落"，而在于"在特定维度/参数下忽略空间涨落是否合理"。Cluster DMFT 和 DΓA 已经系统性地恢复了空间涨落。 |
| "QMC 有符号问题所以没法算任何有趣的强关联体系" | 符号问题确实是对体系、参数和温度的筛选器，但不是对所有情况的完全禁令。半满、粒子-空穴对称体系、特定晶格的无符号体系、CP-AFQMC 等都在推进可算边界。关键在于找到适合方法的体系，而不是因为"有符号问题"放弃整个方向。 |
| "DFT 算错了所以做 DFT+DMFT 也没用" | DFT+DMFT 不是简单的"DFT+补丁"。DMFT 自能修正解决了 Kohn-Sham 能带在关联绝缘体和关联金属中最大的定性错误。DFT+DMFT 对多种过渡金属氧化物和重费米子化合物给出了与实验可比的结果。 |
| "需要量子计算机才能解决强关联问题" | 变分量子本征求解器（VQE）等近期量子算法目前距离经典 DMRG/QMC/DMFT 的精度和系统尺寸还有巨大差距。经典方法还在快速进步。量子优势在强关联问题上尚未实现，不应急于宣称"只能等量子计算"。 |

## 你的个人切口

结合用户背景（计算凝聚态物理、TBPM、石墨烯紧束缚、MPI 并行、SLURM 集群）和上述边界判断，三条最有希望的切入路线：

### 切口 1：强关联 + 无序的输运计算（最高优先级）

```
你的资产：TBPM = O(N) 实空间传播子计算 + 天然处理无序 + MPI 并行
边界问题：强关联体系的可靠输运性质计算
具体想法：TBPM+DMFT 混合方法计算 Anderson-Hubbard 模型的电导/霍尔效应
第一步：用 TBPM 复现非相互作用 Anderson 模型的已知标度结果（1–2 天）
```

### 切口 2：魔角石墨烯的有效模型构造（中等优先级）

```
你的资产：石墨烯紧束缚代码
边界问题：魔角石墨烯超导的配对机制
具体想法：用紧束缚代码生成魔角石墨烯的实空间哈密顿量，提取有效 Hubbard 参数
第一步：阅读 Bistritzer-MacDonald 论文，用代码复现魔角平带（~1 周）
```

### 切口 3：强关联 + 拓扑的交叉（备选路线）

```
你的资产：量子霍尔效应 field pack 的知识基础
边界问题：强关联拓扑物态（分数 Chern 绝缘体）
具体想法：在拓扑能带模型中加入 Hubbard U，用 DMFT/ED 研究关联对拓扑相的修正
第一步：在已知的 Chern 绝缘体模型中加 U，用 ED 检查 Chern 数是否被 U 修正
```

## 不建议你现在投入的方向

- ❌ **铜氧化物高温超导的配对机制**：太大、太拥挤、核心困难是方法瓶颈而非 idea 瓶颈。
- ❌ **量子自旋液体的实验证明**：需要专门的实验技能或大规模 PEPS 计算，与现有资产差距大。
- ❌ **全息对偶 / AdS/CFT 在凝聚态的应用**：需要大量场论知识积累，回报周期长。
- ❌ **从零开发新的强关联数值方法**：现有方法的成熟度和社区支持（TRIQS、ITensor、ALPS 等）已经很高，重复造轮子性价比低。
