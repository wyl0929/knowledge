# 13 Actor Map / 人物与机构谱系

Last updated: 2026-06-11

> 代表作者、研究组和机构谱系。分子领域 = 实验 + 理论；子领域 = TBG / TDBG / TMBG / 多层理论。

---

## 1. 核心实验组

### 1.1 Pablo Jarillo-Herrero 组（MIT，美国）

- **贡献**：2018 年发现魔角 TBG 中的关联绝缘态和超导（领域开创者）
- **后续**：TDBG 超导初步报道，TMBG 探索
- **特色**：高质量器件制备（"tear-and-stack" 干法转移），多栅极输运
- **用户相关度**：⭐⭐⭐⭐⭐（领域核心，所有多层方向的实验基准都来自该组）

### 1.2 Andrea Young 组（UCSB，美国）

- **贡献**：TDBG 中位移场调控拓扑相变和 Chern 绝缘体（2019–2021）
- **特色**：量子振荡、压缩率测量，精密输运
- **用户相关度**：⭐⭐⭐⭐

### 1.3 Cory Dean 组（Columbia，美国）

- **贡献**：TBG 的压缩率/量子电容测量，TDBG 相图
- **特色**：热力学探针（penetration field, compressibility）
- **用户相关度**：⭐⭐⭐

### 1.4 Feng Wang 组（UC Berkeley，美国）

- **贡献**：TBG/TDBG 的 STM/STS 研究（局域态密度成像）
- **特色**：纳米尺度光谱，摩尔周期分辨的 STS
- **用户相关度**：⭐⭐⭐

### 1.5 Philip Kim 组（Harvard，美国）

- **贡献**：TBG 输运，TDBG，边缘态输运
- **特色**：多种二维材料异质结
- **用户相关度**：⭐⭐⭐

### 1.6 Dmitri Efetov 组（LMU / ICFO，欧洲）

- **贡献**：大尺寸单晶 TBG 器件（低无序，高质量）
- **特色**：超大单晶畴 (~10 μm)，极低转角无序
- **用户相关度**：⭐⭐⭐

### 1.7 Jie Shan / Kin Fai Mak 组（Cornell，美国）

- **贡献**：TMD 摩尔异质结为主，但也涉及石墨烯摩尔体系
- **特色**：光学探针
- **用户相关度**：⭐⭐

## 2. 核心理论组

### 2.1 Allan MacDonald 组（UT Austin，美国）

- **贡献**：2011 年 Bistritzer-MacDonald 连续模型（领域理论基石）
- **后续**：TBG 超导理论，TDBG 能带理论
- **特色**：物理直觉强，解析与数值结合
- **用户相关度**：⭐⭐⭐⭐⭐（如果写紧束缚代码验证 BM 模型，这是直接参考）

### 2.2 B. Andrei Bernevig 组（Princeton，美国）

- **贡献**：TBG 的拓扑能带理论，手性极限模型，分层 Fock 空间方法
- **特色**：拓扑能带论的数学化处理
- **用户相关度**：⭐⭐⭐⭐

- **特色**：强关联 + 拓扑结合
- **用户相关度**：⭐⭐⭐

## 5. 谱系注意

- **BM 模型学派**：MacDonald → Bistritzer → 大部分转角石墨烯理论家，以连续模型为核心
- **拓扑学派**：Bernevig / Vishwanath / Fu → 强调平带拓扑分类和拓扑序
- **弛豫学派**：Guinea / Jung → 强调晶格弛豫对能带的实际影响
- **强关联学派**：Vafek / Senthil / Vishwanath → DMFT, QMC, 场论

不同学派对"什么是三层/多层转角石墨烯最重要的问题"有不同回答。
