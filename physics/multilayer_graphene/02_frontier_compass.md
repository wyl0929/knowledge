# 02 Frontier Compass / 边界罗盘

Last updated: 2026-06-11

> 明确内圈知识、成熟 baseline、真正边界、伪 gap 和用户个人切口。

---

## 1. 内圈知识（已牢固确立，无需重新验证）

这些是本领域的"常识"，你在读论文和写代码时可以当作已知：

| 知识点 | 为什么可靠 |
|---|---|
| BM 连续模型正确描述 TBG 低能物理（θ < 2°） | 10+ 年多方法交叉验证 |
| TBG 魔角 θ ≈ 1.1° 处存在平带（W ~ 10 meV） | 理论 + DFT + STM 一致 |
| TBG 中存在关联绝缘态和超导 | 10+ 实验组独立验证 |
| 晶格弛豫使 AA 区域层间距增大 ~10–20% | DFT + 力场 + STM 一致 |
| TDBG 中位移场 D 可驱动拓扑相变 | 多组实验 + 理论一致 |
| 摩尔超晶格周期 a_M ≈ a₀/θ | 几何事实 |

## 2. 成熟 Baseline（计算上一个研究生或熟练博士后能在 1–2 周内复现的）

这些是可以直接用你的代码做的，属于"验证性计算"：

| Baseline | 所需方法 | 工作量 |
|---|---|---|
| 连续模型计算 TBG 能带，验证魔角平带 | Python，~200 行 | 1 天 |
| 紧束缚模型计算 TBG 能带，验证与连续模型一致 | 改造 graphene.py | 2–3 天 |
| TDBG 能带 vs (θ, D)，复现已知拓扑相变 | TB + Berry curvature | 3–5 天 |
| TBPM 计算 TBG/TDBG 的 DOS | 现有 TBPM 代码 | 1 天 |
| Hofstadter 谱（磁场下的能带折叠） | TB + Peierls 替换 | 2–3 天 |

## 3. 真正的知识边界（目前没人确切知道答案）

这些是领域正在推进的前沿，也是你的潜在切入点：

### 3.1 实验边界

| 边界问题 | 现状 |
|---|---|
| 螺旋三层转角石墨烯能否在实验上实现并测量？ | 尚无高质量器件 |
| TMBG 和 TDBG 中超导的可重复性和 Tc 上限？ | 初步信号，待确认 |
| 多层（N ≥ 5）转角体系的实验相图？ | 几乎空白 |
| 转角不均匀在多层中是累加还是被平均？ | 无定量实验数据 |

### 3.2 理论边界

| 边界问题 | 现状 |
|---|---|
| 多层转角石墨烯的通用魔角解析条件？ | 只有 TBG 有解析解 |
| 转角无序对平带和关联态的定量影响？ | 缺少大规模模拟 |
| 多层平带的完整拓扑分类（Chern 数序列规律）？ | 部分已知（TDBG） |
| 层间耦合参数在多层中的逐层重整化？ | NEES_VERIFICATION |
| 超导配对对称性（TBG 及多层）？ | 领域最大争议之一 |

### 3.3 方法边界

| 边界问题 | 现状 |
|---|---|
| 如何同时处理大超胞（>10⁴ atoms）和电子关联？ | 多尺度方法待发展 |
| TBPM 在转角体系中的定量可靠性？ | 缺少系统基准 |
| 连续模型和紧束缚的定量对应关系（超胞收敛性）？ | 缺少系统比较 |

## 4. 伪 Gap（看起来是 gap 但其实已经基本解决的）

| 伪 Gap | 为什么不是真 gap |
|---|---|
| "TBG 魔角为什么是 ~1.1°？" | BM 模型已给出解析条件 α ≈ 0.586 |
| "转角石墨烯的平带是否拓扑平庸？" | 已知在磁场或特定条件下携带非零 Chern 数 |
| "多层转角石墨烯的能带能否用连续模型描述？" | Koshino (2019) 已建立统一框架 |
| "TDBG 的拓扑相变是否存在？" | 多组实验已确认 |

## 5. 用户个人切口

基于你的资产（TBPM + TB 模型 + MPI 集群）和本领域边界，以下是**你最有比较优势的切入点**：

### 5.1 🔥 最高优先级切口

**转角不均匀对多层体系平带的定量影响（G-T02）**

- **为什么是你**：TBPM 可以算 10⁶–10⁷ atoms 的超胞 → 可以引入空间缓变的转角分布 → 对角化方法做不到
- **为什么重要**：这是领域的开放问题（见边界 3.2），实验上知道转角不均匀很重要但没人定量算过
- **产出形式**：可投稿的 PRB/PRL 级别文章
- **起始步骤**：在 TB 超胞中实现 $\theta(\mathbf{r}) = \theta_0 + \delta\theta(\mathbf{r})$，计算 DOS 随 $\delta\theta$ 的演化

### 5.2 🔥 高优先级切口

**连续模型 vs 紧束缚的系统基准（G-M03, G-M04）**

- **为什么是你**：你有 TB 代码，连续模型实现轻量，做一个系统比较的障碍很低
- **为什么重要**：建立方法可信度，是所有后续计算的基础。领域缺少这样的基准
- **产出形式**：方法短文或内部技术报告 + 公开基准数据
- **起始步骤**：写 BM 连续模型，选 3–4 个 θ 值，对比连续模型 vs TB vs TBPM 的能带和 DOS

### 5.3 中等优先级切口

**多层平带的拓扑分类（G-T03）**

- **为什么是你**：TB 模型天然可以算 Berry curvature
- **为什么重要**：系统绘制 (θ, D) 空间的 Chern 数相图，目前文献不完整
- **起始步骤**：实现 TB 基下的 Berry curvature 积分，先复现 TDBG 已知结果再扩展

### 5.4 战略上不建议现阶段碰的

- **强关联计算（DMFT/QMC）**：高门槛，建议先用 TB 产出建立 credibility 后再考虑合作
- **螺旋三层实验模拟（无实验数据对标）**：纯理论风险高，建议等实验进展
- **最前沿的超导配对对称性理论**：需要强关联方法，超出当前工具范围

## 6. 红线（停止条件）

如果你在某个方向遇到以下情况，应考虑转向：

1. **连续模型与 TB 在对角化可达的体系上存在不可调和的定性差异** → 不要微调参数到死，记录为 finding，可能本身就是值得发表的"方法比较"结果
2. **TBPM 在可达精度下无法分辨平带的关联特征** → TBPM 可以算 DOS 但不能算关联能隙，这是方法边界，不是失败
3. **转角无序抹平了所有有趣的特征** → 这本身就是一个重要的定量结论（"转角质量需求的判据"）

## 7. 领域的时间感

```
2011 ── BM 模型预言魔角
2018 ── TBG 关联绝缘态 + 超导（领域引爆）
2019 ── TDBG 拓扑相变理论（Koshino）
2020 ── TDBG 实验（Shen, Liu, Cao 三组独立）
2021 ── TMBG 实验爆发 + 多层理论完善
2022–2025 ── 领域深化：相图完善、超导机制争论、转角无序认知
2026 → ── 螺旋三层实验待突破；N≥5 多层待开垦；无序的定量理解仍是 gap
```

你进入的时间点：**TBG/TDBG/TMBG 的基本物理框架已建立，但定量细节（尤其涉及无序和大超胞的问题）仍有大量空白——这正是 TBPM 的优势区间。**
