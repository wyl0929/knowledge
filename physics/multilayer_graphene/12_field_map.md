# 12 Field Map / 领域地图

Last updated: 2026-06-11

> 问题链、方法谱系、成熟度评估与核心假设。

---

## 1. 领域定位

本 pack 涵盖多层石墨烯关联电子态的完整光谱——从转角体系到非转角体系：

```
强关联电子体系 ← → 二维材料范德华异质结 ← → 拓扑物态
        ↑                    ↑                   ↑
        └──── 多层石墨烯：转角与非转角体系 ────┘
                      ↓
            摩尔平带工程 + 能带工程 + 畴壁物理
```

它位于"摩尔量子材料"（moiré quantum materials）和"多层石墨烯量子输运"的交汇处。转角体系是 twistronics 的自然延伸；非转角体系（ABA/ABC TLG）提供了不可或缺的实验 baseline 和平行平台；畴壁物理连接了转角和堆叠两个世界。

## 2. 问题链（Problem Chain）

### 2.1 核心驱动问题

```
Q1: TBG 魔角处为什么出现超导和关联绝缘态？
    ↓ （部分解答：平带 + 强关联，但机制细节仍在争论）
Q2: 三层/多层转角体系中，平带结构如何随构型变化？
    ↓
Q3: 多层体系的关联相图比 TBG 丰富多少？新相有哪些？
    ↓
Q4: 位移场、压强、磁场等多参量调控能产生什么新的拓扑-关联相？
    ↓
Q5: 这些体系能否实现可编程、可调控的强关联模型系统？
    ↓
Q6: 层数继续增加，何时从 2D 摩尔物理过渡到 3D 扭曲石墨（twisted graphite）？
```

### 2.2 子问题链

**平带工程子链**：
- 如何设计转角序列以获得更平、更孤立的能带？
- 多层体系的魔角条件是什么？→ 目前无解析通解
- 平带的拓扑（Chern 数、量子度规）如何随层数和转角变化？

**关联物态子链**：
- 三层/多层中是否存在类似 TBG 的超导？超导 Tc 是否更高？
- 关联绝缘态的对称性破缺模式（谷极化、自旋极化、向列序、层极化）如何确定？
- 是否存在 TBG 没有的新奇量子相（如拓扑超导、手性自旋液体）？

**实验探测量子链**：
- 如何区分摩尔平带关联效应与无序效应？
- 扭转角不均匀（twist angle disorder）在多层中更严重还是被平均化？

## 3. 方法谱系（Methodology Spectrum）

### 3.1 理论方法

| 方法 | 适用体系规模 | 精度 | 优势 | 局限 |
|---|---|---|---|---|
| **Bistritzer-MacDonald 连续模型** | 无限（k·p 展开）| 低能有效 | 解析可解，物理图像清晰 | 忽略晶格弛豫、高能带 |
| **紧束缚模型（TB）** | ~10⁴–10⁵ atoms | 全带结构 | 可含弛豫、无序、磁场 | 原子数大时对角化困难 |
| **TBPM（紧束缚传播法）** | ~10⁶–10⁷ atoms | 谱函数/DOS/输运 | 可算超大超胞的 DOS 和输运 | 无法直接得本征态 |
| **DFT（密度泛函理论）** | ~10³ atoms | 第一性原理精度 | 包含弛豫、电荷转移 | 超胞大小受限（转角太小算不动）|
| **量子蒙特卡洛（QMC）** | ~100 sites（有效模型）| 精确关联 | 关联效应精确 | 符号问题；无法处理大体系 |
| **DMFT/DCA（动力学平均场）** | 热力学极限 | 关联效应近似 | 可处理强关联 + 能带 | 非局域关联近似 |
| **精确对角化（ED）** | ~10–20 摩尔单胞 | 精确关联 | 小体系精确解 | 有限尺寸效应严重 |
| **Hartree-Fock (HF)** | 中等 | 平均场 | 计算量可控 | 忽略量子涨落 |
| **张量网络 / DMRG** | ~数十摩尔单胞 | 高精度关联 | 准一维/柱面几何 | 2D 受限 |

**与本 pack 用户背景的连接**：
- ✅ TB 模型 + TBPM：用户已有代码可直接改造
- ✅ 连续模型：实现轻量，可作为快速扫描工具
- ⚠️ DMFT/QMC：可能需要合作者

### 3.2 实验方法

| 探针 | 测量量 | 在三层/多层中的特殊挑战 |
|---|---|---|
| **电输运** | Rxx, Rxy, 相图 | 需要多个栅极（顶栅+底栅+位移场）|
| **STM/STS** | 局域态密度, 摩尔周期 | 三层以上针尖信号解析更复杂 |
| **量子电容 / 压缩率** | $\partial\mu/\partial n$ | 直接测量态密度和关联能隙 |
| **量子振荡（SdH）** | Fermi 面截面 | 需要高磁场 + 低无序 |
| **光学谱** | 光电导, 等离激元 | 摩尔周期长 → 低能激发需要远红外/THz |
| **ARPES / nano-ARPES** | 能带色散 | 空间分辨 < 摩尔周期才能分辨平带（~13 nm for θ=1.1°）|

## 5. 核心假设与悬而未决的问题

### 5.1 领域共享的核心假设

1. **摩尔平带是关联物理的充分条件**：假定只要平带足够平（$W < U$），就会出现类似 TBG 的强关联现象。→ 在三层/多层中基本得到验证，但并非所有平带都出现超导。

2. **连续模型足够描述低能物理**：Bistritzer-MacDonald 型连续模型假定层间耦合只有第一个壳层傅里叶分量重要。→ 对小角度（θ < 2°）通常成立，但对更大角度或特定堆叠可能失效。

3. **晶格弛豫只在 AA 堆叠区域显著**：转角石墨烯中，AA 区域发生面外弛豫（层间距增大），AB 区域几乎不变。→ 原子模拟（DFT + 分子动力学）支持，但弛豫对平带带宽的定量影响仍在讨论。

4. **无序主要来自转角不均匀（twist angle disorder）**：而非杂质或空位。→ 对 TBG 成立，但多层中转角不均匀是累加还是平均化尚无定论。

### 5.2 三层/多层特有的开放问题

1. **超导配对对称性**：TBG 的超导配对对称性（d-wave? p-wave? s±?）仍在激烈争论中（2026 年仍未完全解决）。三层/多层中配对对称性可能不同。

2. **平带的拓扑分类**：多层体系的平带 Chern 数序列是否可以系统预测？

3. **向列序（nematicity）的来源**：实验观测到 TBG 和 TDBG 中可能存在向列序（旋转对称性自发破缺），其微观起源不明。

4. **层间关联效应的本质**：层自由度（layer pseudospin）中的"铁电"/"反铁电"序是否存在？

5. **超导 Tc 是否有上限**：多层体系的超导 Tc 能否超过 TBG 的最高 Tc（~3–5 K）？理论上，更大的态密度（更多平带）可能提高 Tc，但也可能引入竞争序。

## 6. 子方向概览

### 6.1 实验推进的活跃方向

1. **TDBG 相图完善**：系统扫 $(\theta, D, T, B)$ 四维参数空间
2. **TMBG 超导确认与优化**：提高样品质量，确认超导可重复性
3. **螺旋三层/多层的首次实验实现**：需要新的堆叠/撕裂技术
4. **高压调控**：静水压可调层间耦合 → 原位调魔角

### 6.2 理论推进的活跃方向

1. **多层通用平带条件**：超越 BM 模型的魔角解析理论
2. **强关联模型的数值求解**：DMFT + Hartree-Fock + QMC 的交叉验证
3. **拓扑平带的量子几何效应**：Fubini-Study 度规、Berry 曲率与超流刚度的关系
4. **无序效应的定量理论**：转角不均匀对平带宽度和关联态的定量影响

### 6.3 与本 pack 用户背景（TBPM + 紧束缚）的潜在交叉方向

| 方向 | 用户优势 | 难度 |
|---|---|---|
| 大超胞紧束缚能带 + DOS 计算 | TBPM 天然适合 | ⭐⭐ |
| 转角不均匀对 DOS/输运的定量模拟 | TBPM + 无序超胞 | ⭐⭐⭐ |
| 磁场下的摩尔 Hofstadter 谱 | TB 模型 + Peierls 替换 | ⭐⭐⭐ |
| 弛豫效应在实空间紧束缚中的实现 | 需要弛豫数据（DFT 或力场） | ⭐⭐⭐ |
| 关联效应的 TBPM 级别近似 | 需要 beyond-TB 方法 | ⭐⭐⭐⭐ |

## 7. 领域的基本张力（Tensions）

1. **平带 vs 拓扑**：更平的带通常拓扑更平庸？还是可以兼得？→ 多层体系提供了调和空间
2. **关联 vs 无序**：实验上观察到的绝缘态，多少来自关联，多少来自无序？→ 多层中更复杂
3. **普适性 vs 特异性**：每个构型（TMBG vs TDBG vs 螺旋 TTG）的物理有多大共性？→ 摩尔平带是否存在"普适类"？
4. **模拟可行性 vs 物理真实性**：DFT 太贵，连续模型太粗，紧束缚刚好卡在中间→ 怎样在用户可及的计算资源下做出有物理意义的计算？
