# 20 Gap Table / 缺口表

Last updated: 2026-06-11

> 缺口分类：
> `confirmed` = 多来源确认的知识空缺；
> `suspected` = 有初步证据的疑似缺口；
> `weak` = 推测性缺口，可能是伪缺口；
> `not-a-gap` = 已解决的或根本不是缺口的。

| ID | 描述 | 为什么不是缺口 |
|---|---|---|
| NG-01 | "TBG 魔角为什么是 1.1°？" | BM 模型已给出解析条件，是已解决的问题 |

| NG-04 | "TBPM 可以直接算 Berry 曲率吗？" | ❌ TBPM 是时间演化方法，无法访问本征态。需对角化或别的方法。此为硬限制，非缺口。 |

## 5. 按用户切入优先级的缺口排序

```
用户可立即动手（1–2 周内可产出结果）：
  G-T02  转角不均匀对平带的定量影响    ← TBPM 天然优势，不依赖 diag
  G-M02  公开基准数据集                ← 已有 n=183/472 LDOS 数据
  G-M03  连续模型 vs TB 在超胞上的桥接 ← 方法基准（能带/DOS，不涉及拓扑）
  G-M04  TBPM 在转角体系中的适用性验证  ← 方法基准

用户可中期探索（1–3 月）：
  G-T06  位移场在 TB 中的微观实现       ← 纯模型研究
  G-T07  层间耦合参数的多层重整化       ← 文献调研 + sensitivity analysis
  G-T04  晶格弛豫的逐层效应             ← 已有 rlxd 结构支持

受方法限制（需创新或外部工具）：
  G-T03  平带的完整拓扑分类             ← ⚠️ TBPM 无法算 Berry 曲率，diag 限小体系
  G-M05  大超胞拓扑不变量计算           ← ⚠️ 同上，需探索新方法（如 Wilson loop, 实空间 Chern 标记?）

需要合作或长期投入：
  G-E01  螺旋三层实验
  G-M01  大超胞 + 关联的多尺度方法
  G-T05  超导配对对称性
```
