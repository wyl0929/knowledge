# USER_BRIEF / ABC 三层石墨烯实验文献扫描

Last updated: 2026-07-07

## 调研领域

ABC（菱方/rhombohedral）堆叠三层石墨烯中的关联电子态实验研究，特别是超导（SC）、量子反常霍尔效应（QAH）、分数量子反常霍尔效应（FQAH）、四分之一金属（quarter metal）和 intervalley coherent（IVC）态等。

父方向：多层石墨烯：转角与非转角体系

**⚠️ 注意**：ABC 三层石墨烯（rhombohedral trilayer graphene, RTG）是非转角体系，但其低能物理——特别是与 hBN 衬底对齐形成的摩尔超晶格——与转角体系有深层的物理联系。RTG 被认为是"最简单的摩尔量子材料"：不需要精确控制转角，只需控制 stacking order。它在 2021–2025 年间经历了实验爆发，与转角体系并列成为强关联二维材料的两大主流平台。
