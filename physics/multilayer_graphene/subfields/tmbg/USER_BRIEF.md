# USER_BRIEF / TMBG 子方向调研需求

Last updated: 2026-06-12

## 调研领域

TMBG（Twisted Monolayer-Bilayer Graphene，转角单层-双层石墨烯）

父方向：多层石墨烯：转角与非转角体系

## 调研模式

quick_scan（研究扫描），作为父方向 field pack 的子方向

## 调研重点

- 深入理解 TMBG 区别于 TBG 和 TDBG 的独特物理
- TMBG 的关键实验发现和理论进展
- TMBG 中仍然开放的 gap，特别是用户现有 TBPM/紧束缚计算可切入的
- 可立即动手的最小计算项目

## 写作偏好

- 主体中文，关键术语附英文
- 先直觉后公式
- 明确区分 confirmed fact / suspected / speculation / NEEDS_VERIFICATION
- 继承父 pack 的写作风格和术语体系

## 回避事项

- 不重复父 pack 中已充分覆盖的通用内容（如 BM 模型推导、TBG 基准物理）
- 不展开 TDBG、螺旋三层等其他构型（仅在对比时简要提及）

## 用户背景结合

是。用户为计算凝聚态物理研究者，已有：
- 石墨烯紧束缚代码（`graphene.py`）
- TBPM DOS/输运计算代码
- MPI 并行经验
- 远程 SLURM 集群算力
- 无 DFT/DMFT 经验，无实验合作

## 是否寻找研究选题

是（quick_scan 包含 TMBG 专属 gap 和候选项目卡片）
