# 00 Beginner Guide / TMBG · 入门指南

Last updated: 2026-06-12

> 写给第一次接触 TMBG 的人。先直觉，再术语。
> 如果你还没读过父 pack 的入门指南（`../00_beginner_guide.md`），建议先读那篇，建立 TBG 和三层体系的整体框架，再回来看这篇 TMBG 专论。

---

## 0. 一句话版本

TMBG 是把一片单层石墨烯放在一片双层石墨烯上，再转一个小角度。它只有**一个**转角界面（比螺旋三层简单），但比 TBG 多了一层——这一层带来了额外的自由度：你可以用垂直电场单独调谐那层"多余"的单层，在同一个体系中同时看到类似 TBG 的强关联物理和类似单层石墨烯的 Dirac 物理。

---

## 1. 先建立直觉：TMBG 和 TBG 有什么本质不同？

### 1.1 TBG 的物理：两根 Dirac 锥的"共振"

TBG 由两层石墨烯转角构成。每层在 K 点有一个 Dirac 锥。转角让两个 Dirac 锥在倒空间中彼此旋转。层间耦合把旋转后的 Dirac 锥混合起来，在魔角处恰好产生完全平坦的能带。

这就像两根相同频率的音叉靠近后共振——产生了一个"拍频"。TBG 的魔角就是共振条件。

### 1.2 TMBG 的物理：一根 Dirac 锥 + 一对抛物线能带的"不对称共振"

TMBG 的一面是单层石墨烯——它在低能处是一个 Dirac 锥（$E \propto k$）。另一面是 AB 堆叠（Bernal）双层石墨烯——它在低能处是一对抛物线能带（$E \propto k^2$），而且是**有能隙的**（外加位移场时）。

所以 TMBG 的"共振"是不对称的：

```
TBG:    Dirac + Dirac  → 对称共振 → 平带
TMBG:   Dirac + 抛物线对 → 不对称共振 → 平带 + 残余 Dirac 特征
```

这种不对称性赋予了 TMBG 独特的物理：
- 平带仍然存在（与 TBG 类似的魔角条件，但魔角值略有不同）
- 在平带之外，还残留着来自单层的 Dirac 色散
- 位移场可以独立移动单层 Dirac 点相对于平带的位置

### 1.3 用一张图理解

```
            单层石墨烯                    AB 双层石墨烯
          E ↑  \                        E ↑    /
            │    \  Dirac 锥              │    /  抛物线
            │      \                      │   /
        ────┼────────→ k             ─────┼──────→ k
            │                              │
            │                              │ (有能隙)
            │                              │

               ┌─────────────────────────────┐
               │  转 θ ≈ 1.0°–1.2° 叠在一起    │
               │  层间耦合 ~110 meV            │
               └─────────────────────────────┘
                            ↓
              不对称共振 → TMBG 摩尔平带 + 残余 Dirac
```

## 2. TMBG 的核心参数

### 2.1 构型定义

- **层 1**：单层石墨烯（monolayer）
- **层 2+3**：AB 堆叠（Bernal）双层石墨烯
- **相对转角**：单层相对于双层转 θ
- **转角界面数**：1 个（仅在单层和双层之间）

关键参数：
| 参数 | 含义 | 典型值 |
|---|---|---|
| θ | 转角 | ~1.0°–1.2°（魔角附近） |
| D（或 E）| 垂直位移场 | 0–1 V/nm |
| ν | 填充因子（每个摩尔单胞的额外电子数）| −4 到 +4 |
| a_M | 摩尔周期 | ~13 nm（θ=1.1°） |

### 2.2 魔角

TMBG 的魔角条件与 TBG 类似但不完全相同。原因是：
- AB 双层在低能处的有效 Fermi 速度 $v_F^*$ 与单层的 $v_F$ 不同（抛物线能带的"有效 Dirac 速度"依赖于能量）
- BM 模型推广后，魔角条件取决于层间耦合强度 $w$ 与有效 Dirac 速度的比值 $\alpha \equiv w/(\hbar v_F k_\theta)$

实验和理论表明，TMBG 的魔角在 θ ≈ 1.0°–1.15° 之间（具体取决于层间耦合参数的选择和是否包含弛豫效应）。**NEEDS_VERIFICATION：TMBG 的精确魔角值在不同理论工作中略有差异。**

## 3. TMBG 中发生了什么有趣的物理？

### 3.1 关联绝缘态（Correlated Insulators）

在平带的整数和分数填充处（ν = ±1, ±2, ±3 等），TMBG 表现出电阻急剧增大——电子被库仑排斥"钉"住。这是 TMBG 最早被实验确认的关联现象（Chen et al., Nature Phys. 2021；Polshyn et al., Nature 2020）。

与 TBG 的关联绝缘态相比：
- TMBG 的关联绝缘态在 ν = ±1 处就已经出现（TBG 通常在 ν = ±2 处）
- 这可能与 TMBG 中较弱的谷简并度有关——单层侧的 Dirac 锥打破了部分对称性

### 3.2 超导（Superconductivity）

- **已观测到**：部分实验组在 TMBG 中报道了超导迹象（Tc ~ 2–3 K，Shin et al., PRL 2021）
- **可重复性**：不如 TBG 超导稳定——TMBG 的超导似乎对样品质量更敏感
- **当前状态**：`suspected`——需要更多独立实验组的验证

### 3.3 位移场调控（Displacement Field Tuning）

这是 TMBG 最独特的卖点之一。加垂直电场 D 后：
- 单层侧的 Dirac 点能量可以相对于平带移动
- 平带的带宽和拓扑性质随 D 变化
- 可以在同一个器件中"扫描"从 Dirac 物理到强关联物理的过渡

实验上（Xu et al., Nature Nanotech. 2021），改变 D 可以驱动 TMBG 中的拓扑相变——平带的 Chern 数发生改变。

### 3.4 拓扑（Topology）

TMBG 的平带携带非零 Chern 数（在有限 D 下）。与 TDBG 相比：
- TDBG 的 Chern 数变化更"干净"——对称性更高，拓扑相变更清晰
- TMBG 的 Chern 数变化更"复杂"——不对称性导致更多可能的拓扑相

## 4. TMBG vs TBG vs TDBG：一张对比表

| 特性 | TBG | TMBG | TDBG |
|---|---|---|---|
| 层数 | 2 | 3 | 4 |
| 转角界面数 | 1 | 1 | 1 |
| 低能自由度 | Dirac + Dirac | Dirac + 抛物线对 | 抛物线对 + 抛物线对 |
| 魔角 | ~1.1° | ~1.0°–1.15° | ~1.0°–1.2° |
| 平带数（per spin per valley）| 2 | 3 | 4 |
| 关联绝缘态 | ν=±2 最强 | ν=±1,±2,±3 | ν=±1,±2,±3 |
| 超导 | ✅ 已确立 | ⚠️ suspected | ⚠️ suspected |
| 位移场拓扑调控 | 弱 | 中等 | 强 |
| 实验成熟度 | 最高 | 中等 | 中等（最活跃） |
| 理论成熟度 | 最高 | 中等 | 中等 |

## 5. 如果我想用计算研究 TMBG，从哪入手？

### 5.1 最小起点（1–2 天）

在已有 TBG 连续模型代码基础上，修改为 TMBG：
- 层 1：标准单层石墨烯 Dirac 哈密顿量（旋转 +θ/2）
- 层 2+3：AB 双层石墨烯的 4×4 哈密顿量（旋转 −θ/2）
- 层间耦合：仅层 1↔层 2（最近邻摩尔倒格矢耦合）

验证：在 θ ≈ 1.05° 处应出现平带，带宽 ~10–20 meV。

### 5.2 第二步（2–4 天）

改造紧束缚代码构建 TMBG 超胞：
1. 找近公度周期（commensurate supercell）
2. 构建三层原子坐标
3. 加 Slater-Koster 层间耦合（注意：仅单层与双层之间有转角耦合，双层内部为 AB 堆叠的固定耦合）
4. 对角化 → 能带 → 与连续模型对比

### 5.3 第三步（1 周）

用 TBPM 计算 TMBG 的 DOS 和输运：
- 扫 θ 和 D，绘制平带带宽热力图
- 加无序，研究平带对转角度不均匀的鲁棒性（对应父 pack gap G-T02）
- 计算 Chern 数随 D 的变化（对应父 pack gap G-T03）
