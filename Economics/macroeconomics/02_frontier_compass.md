# 02 Frontier Compass / 边界罗盘

Last updated: 2026-06-19

## 0. 如何使用这篇文档

边界罗盘的目的不是给你一个"今天宏观经济学的最新论文题目列表"，而是帮你建立**对领域成熟度的直觉**——哪些是本科生就该会的常识、哪些是博士生在挣扎的前沿、哪些连最顶尖的学者都还没有答案。

对每个区间，我会标注"如果你从这里切入，你大概在和谁竞争、需要什么级别的工具"。

## 1. 内圈（Inner Circle）：成熟常识与标准工具

**定义**：这些是宏观经济学的基础沉淀，任何受过训练的宏观经济学者都应该掌握。切入这里意味着你在做教科书级别的练习，而不是研究。

### 1.1 内圈知识

- Solow 增长模型的经济学直觉和稳态分析
- IS-LM 模型的基本逻辑（产品市场和货币市场的同时均衡）
- AS-AD 模型的短期/长期区分
- GDP 的三种核算方法及它们为什么等价
- 货币数量论（MV = PY）的基本直觉
- Phillips 曲线的基本含义（及其 1970 年代的失效）
- Taylor 规则的基本形式
- 理性预期（rational expectations）的定义和在模型中的技术使用

### 1.2 内圈工具

- Dynare（标准 DSGE 求解软件）的基本使用
- HP 滤波 / 带通滤波去趋势
- 结构 VAR 的基本识别策略（Cholesky 分解）
- 局部扰动法（first-order perturbation）求解 DSGE

### 1.3 内圈的判断标准

如果你在做以下事情，你大概率在重复造轮子：
- 推导 Solow 模型的稳态而不加新元素
- 用 IS-LM 分析一个没有新摩擦或新机制的政策问题
- 估计 Taylor 规则而不做任何识别创新
- 用三方程 NK-DSGE 产生脉冲响应而不做任何模型比较或实证验证

**这里的价值**：教学和科普，没有研究贡献。

## 2. 中圈（Middle Circle）：成熟但仍有扩展空间的方法

**定义**：这些方法和框架已经是研究生的标准训练内容，但仍有尚未穷尽的实证应用和局部扩展空间。切入这里意味着你在和博士生、初级教授竞争，需要做出可量化的改进。

### 2.1 中圈知识

- 完整的中等规模 NK-DSGE 模型（Christiano-Eichenbaum-Evans 类型）的结构和求解
- DMP 搜索匹配模型的完整推导和校准
- 金融加速器机制（Bernanke-Gertler-Gilchrist）
- Lucas 批判的方法论意义及其在政策评估中的操作含义
- 时间不一致性（time inconsistency）和货币政策规则的关系
- 识别策略：叙事法（Ramey）、外部工具变量（Stock-Watson）、高频识别（Gertler-Karadi）

### 2.2 中圈工具

- Dynare 的高级功能（二阶/三阶扰动、偶尔绑定约束的求解技巧）
- 贝叶斯估计 DSGE（随机游走 Metropolis-Hastings）
- 结构 VAR 的高级识别（符号约束、零/符号约束混合、叙事工具变量）
- 局部投影法（local projections, Jordà 2005）

### 2.3 中圈的判断标准

如果你在做以下事情，你在成熟框架中做增量研究：
- 在标准 NK-DSGE 中加入一个新的摩擦，比较脉冲响应的变化
- 用新的识别策略重新估计财政乘数
- 把金融加速器嵌入一个已有模型，展示其改善了对某个具体事件的解释
- 用新的微观数据（如扫描价格数据、银行交易数据）重新校准 NKPC 的关键参数

**这里的价值**：可发表的增量贡献，但需要清晰的实证识别或理论创新。

## 3. 边界（Frontier）：当前活跃的研究前沿

**定义**：这些是过去 5-10 年才变得活跃的问题，学术共识尚未形成，方法论仍在快速演化。切入这里意味着你在和顶级学者在同一赛道上竞争，但机会也最大——因为大家都还在摸索。

### 3.1 核心边界问题

| 边界问题 | 为什么还在边界 | 当前主要的路线分歧 |
|---|---|---|
| HANK 的政策含义与实证验证 | 模型太新，实证验证远不充分 | 连续时间 vs 离散时间；局部扰动 vs 全局方法 |
| 通胀预期的形成机制 | 理性预期假设在微观数据中被反复拒绝 | 理性疏忽 vs 诊断预期 vs 学习模型 |
| 零利率下限（ZLB）下的最优政策 | ZLB 事件太少，无法统计区分不同策略 | 前瞻指引的效力；财政政策在 ZLB 下的规模 |
| 金融网络与系统性风险 | 网络数据有限，因果识别极难 | 网络结构的外生性 vs 内生性 |
| 气候变化在宏观模型中的纳入 | 时间尺度跨越数量级，不确定性深度（Knightian） | IAM vs DSGE；碳税 vs 数量管制 |
| 市场力量（markups）上升与宏观的关系 | 机制方向不清（markups 上升是结果还是原因？） | 技术 vs 监管 vs 全球化 |
| 非常规货币政策（QE）的传导机制 | 机制多、量化难、退出更难 | 投资组合再平衡 vs 信号渠道 vs 银行借贷渠道 |
| 宏观发展（Macro Development） | 将宏观模型与发展中国家数据嫁接的方法论困难 | 异质性 + 制度 + 市场不完全 |

### 3.2 边界工具

- 连续时间异质性主体模型的全局求解方法
- 机器学习 + 宏观（神经网络求解动态规划、LASSO 选择宏观预测变量）
- 微观行政数据（linked employer-employee data, scanner data）与宏观模型的联合
- 文本分析方法提取宏观预期和政策冲击

## 4. 伪缺口（Pseudo-Gaps）：看起来是缺口、实际不是

### 4.1 "需要一个新的宏观经济范式来替代 DSGE"

**为什么是伪缺口**：DSGE 是一个方法框架，不是一个具体模型。就像量子力学中的哈密顿量一样——你可以不同意具体的哈密顿量形式，但你不能说"我们需要替代哈密顿量方法"。DSGE 框架可以包容非常不同的经济哲学（从 RBC 到 HANK）。真正的问题永远是：**你的 DSGE 模型里放了什么摩擦，为什么？**

**注意**：这不是说 DSGE 没问题——金融部门建模不足、参数校准的主观性、代表性主体的局限都是真问题——但这些是"DSGE 的改进方向"，不是"替代 DSGE 的理由"。

### 4.2 "宏观经济学预测能力太差，需要大数据/AI 来拯救"

**为什么是伪缺口**：宏观经济学本质上受制于非平稳性（经济结构在变化）和小样本（现代宏观经济数据通常只有 50-80 年每季度观测）。这些问题不是"方法不够复杂"导致的，而是"信号不在数据里"。机器学习可以帮助更有效地利用高维数据（如变量选择、非参数脉冲响应），但不能创造不存在的信息。

### 4.3 "异质性主体模型的结论一定和代表性主体模型不同"

**为什么是伪缺口**：许多异质性主体的宏观影响在加总时会"洗掉"（wash out）。只有当异质性与一个非线性传导机制交互时（如借贷约束的偶尔绑定、边际消费倾向与收入冲击的相关性），异质性才会在宏观层面产生质变。HANK 文献的核心贡献正是精确地指出了哪些类型的异质性在什么条件下会产生宏观第一阶影响。

## 5. 用户的个人切口（Personal Entry Point）

基于用户的计算物理背景，以下是三个经过评估的潜在切入点：

### 切口 A：HANK 模型的数值方法（★ 最推荐）

- **在罗盘中的位置**：边界（Frontier）
- **为什么适合你**：HANK 的数值求解本质上是在解耦合的 HJB 方程和 KF 方程——这与物理学中的 Fokker-Planck 方程和随机控制有直接的数学对应。你的 PDE 求解技能几乎可以直接迁移。
- **竞争环境**：这是一个正在快速发展的领域，经济学家中擅长全局数值方法的人相对稀缺——你的计算技能可能构成竞争优势。
- **第一步**：阅读 Achdou et al. (2022)，然后用你熟悉的数值方法（有限差分、谱方法、FEM 皆可）复现他们的基准模型。

### 切口 B：宏观网络中的级联与相变（★★ 次推荐）

- **在罗盘中的位置**：边界（Frontier）
- **为什么适合你**：逾渗理论、网络相变、平均场近似——这些是凝聚态物理学家的日常训练。直接迁移到宏观经济/金融网络的分析中。
- **挑战**：数据获取和法律/制度背景的学习曲线较陡。
- **第一步**：从 Gai & Kapadia (2010) 的简化网络传染模型出发，用逾渗理论的框架重新分析其相变条件。

### 切口 C：Agent-Based Macro 中的涌现现象（★★ 探索性）

- **在罗盘中的位置**：争议区（边界与伪缺口的交界）
- **为什么适合你**：大规模 Agent 模拟和涌现分析是统计物理学家的看家本领。
- **风险**：这个领域在经济学中高度边缘化，发表空间有限，方法论基础受主流怀疑。
- **建议**：如果选择这个方向，需要和主流 DSGE 做系统性的基准对比，否则很难说服经济学读者。

---

## 6. 不建议用户切入的方向

- **纯理论宏观**（如在新古典框架下证明一个新的等价定理）：不符合用户的比较优势
- **纯实证宏观**（如用新的工具变量估计一个已有大量文献的政策效果）：学习曲线太长（需要深厚的制度知识和计量训练），计算优势无法发挥
- **宏观经济预测竞赛**：如前述，这是一个伪缺口——计算能力不是制约因素

---

## 7. 未确认信息（NEEDS_VERIFICATION）

- 学术就业市场对计算宏观/量化宏观的需求情况
- 是否有适合发表的交叉学科期刊（如 *Journal of Economic Dynamics and Control*, *Computational Economics*, *Quantitative Economics*）
- 用户的合作者网络情况（是否有经济学导师/合作者）
