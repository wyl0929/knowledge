# 22 Project Candidates / 候选项目卡片

Last updated: 2026-06-19

## 0. 阅读指南

每张项目卡片包含：一句话描述、对应 gap、baseline 方法、核心指标、可执行的第一步、风险/失败标准和与用户资产的匹配情况。

本项目卡片针对具有计算物理背景（数值模拟、PDE 求解、大规模并行计算）的用户设计，优先选择能将现有计算技能迁移到宏观经济学研究的切入点。

---

## P1: HANK 模型的数值方法基准测试 [priority]

**一句话描述**：用物理学中的 PDE 求解方法（有限差分、FEG、谱方法）去求解标准 HANK 模型，并与主流经济学工具（如 Dynare、Julia 宏观包）的速度和精度做系统对比。

**对应 gap**：GAP-03（HANK 的实证验证）、GAP-06（计算方法的交叉）

**baseline 方法**：Achdou et al. (2022) 的有限差分格式是目前 HANK 数值求解的基准方法。Dynare 的扰动法用于 RA-NK。

**核心指标**：
- 求解精度：脉冲响应函数与高度精细网格解的 $L_2$ 距离
- 求解速度：wall-clock time 到收敛
- 可扩展性：从代表性主体到 1000+ 异质性主体的 scaling

**可执行的第一步**：
1. 复现 Achdou et al. (2022) 的两资产 HANK 模型的基准解
2. 用自己熟悉的数值方法（如谱方法、有限元）重写关键求解步骤
3. 在相同的模型参数下比较精度和速度

**Operationalization Contract**：

| 条目 | 内容 |
|---|---|
| 输入集合 | HANK 模型参数（折现率、风险厌恶、收入过程参数、价格粘性参数、货币政策规则参数） + 数值参数（网格分辨率、时间步长） |
| 目标变换 | 从模型参数 + 冲击过程 → 家庭的 Hamilton-Jacobi-Bellman 方程 + Kolmogorov Forward 方程 → 跨期决策规则 → 加总 → 宏观脉冲响应 |
| 编码/读数 | 有限差分（基准）vs 替代方法（谱方法、FEM）；核心输出：脉冲响应函数（IRF） |
| 指标成立条件 | IRF 的 $L_2$ 偏差 < 1%，wall-clock time 比基准低 ≥ 30% |
| 失败事件 | 替代方法在 sparse grid 上不收敛；或计算时间反而更长 |
| 后选择政策 | 预先注册（preregister）所有待比较的数值方法，不事后挑选 |
| baseline 公平性 | 所有方法在同一硬件、同一语言（Python/Julia）、同一收敛判据下比较 |
| 阳性和阴性结果边界 | 阳性：至少一种替代方法在精度-速度 Pareto 前沿上显著占优；阴性：所有替代方法都不比基准好 → 说明 Achdou 格式已经是接近最优的 |

**operational_status**：specified（需要在正式执行前进一步细化网格参数和收敛判据）

**与用户资产的匹配**：
- 已有技能：PDE 数值求解、Python/C++ 编程、高性能计算
- 缺失资源：需要学习宏观经济学的基本模型结构（Romer 教材前 8 章足够）
- 算力要求：可从单机开始，扩展到 MPI 并行

**风险**：
- 主要风险：经济学数值求解的瓶颈可能与物理不同（稀疏性、非线性性质不同）
- 如果失败：至少获得了 HANK 模型的完整数值实现经验，可以用于后续研究

**stop criteria**：如果 3 个月内不能稳定复现 Achdou 基准解，暂停并重新评估是否缺少关键的宏观背景知识。

## P2: Agent-Based Macro 中的涌现现象——系统性地映射到已知经验规律

**一句话描述**：构建一个最小 Agent-Based 宏观经济模型，系统性地检验其能否"涌现"出公认的宏观经验规律（如 GDP 增长的持久性、通胀的 Phillips 曲线关系、企业规模的幂律分布），并标定哪些微观行为假设对哪些宏观规律是必需的。

**对应 gap**：GAP-06（ABM vs DSGE 互补性）

**baseline 方法**：标准 NK-DSGE 模型对同样经验规律的匹配程度（作为 benchmark）。

**核心指标**：
- 对 N 个公认经验规律（stylized facts）的定性匹配率
- 定量：模型生成的矩（自相关、交叉相关、波动率）与数据矩的距离
- 标定报告：每个宏观规律需要的微观假设集合

**可执行的第一步**：
1. 文献调研：确定 10 个公认的宏观经济经验规律
2. 实现最简单版本的 ABM（N 个企业 + M 个家庭，基本的最优化/启发式规则，简单的价格调整机制）
3. 检验是否能产生 GDP 的内生持久性（GDP 的自相关系数 ~0.9）

**与用户资产的匹配**：
- 已有技能：大规模 Agent 模拟、蒙特卡洛、统计力学中的涌现分析
- 缺失资源：需要了解宏观经济经验规律的标准计量检验方法
- 算力要求：至少需要能够模拟 1000+ Agent 的规模

**风险**：
- 高风险项目：ABM 在经济学中处于边缘地位，发表空间有限
- 方法论风险：保证 ABM 不被变成"参数调到你想要的结果"

**stop criteria**：如果文献调研后发现基准 NK-DSGE 已经在同样经验规律上表现很好（不需要 ABM），则转向 P1 或 P3。

## P3: 用统计物理工具分析宏观经济网络中的级联失效

**一句话描述**：将银行间借贷网络或企业间贸易网络建模为有向加权网络，用统计物理中的逾渗（percolation）和级联失效（cascading failure）工具，分析冲击在网络中的传播条件、爆发阈值和系统性风险。

**对应 gap**：GAP-01（金融部门建模不足）

**baseline 方法**：Gai & Kapadia (2010) 的金融网络传染模型；Acemoglu et al. (2012) 的网络起源与宏观波动。

**核心指标**：
- 级联相变阈值：冲击大到什么程度会导致系统性崩溃？
- 网络结构（度分布、核心-边缘结构、模块性）对稳定性的影响
- 与"代表性银行"模型（忽略网络结构）的政策建议差异

**可执行的第一步**：
1. 获取或构建一个简化的银行间借贷网络（如基于巴西或美国的数据的匿名化网络，或生成式网络模型）
2. 实现 Gai & Kapadia (2010) 的基准传染模型
3. 用逾渗理论的工具计算"巨分量"（giant component）出现/消失的阈值条件

**与用户资产的匹配**：
- 已有技能：凝聚态物理中的无序系统、逾渗理论、网络分析、大规模矩阵对角化
- 缺失资源：金融网络数据（可能需要公开数据集或合成数据）；银行监管制度的背景知识

**风险**：
- 中风险：金融网络的实证数据获取困难
- 理论风险：线性 DebtRank 型模型可能过度简化传染的动态

**stop criteria**：如果 2 个月内无法获取可用的网络数据或验证合成网络的合理性，先转向无数据需求的理论分析。

## 5. 建议的下一步

**强烈推荐 P1**，理由：
1. 与用户现有技能的匹配度最高——几乎可以直接用熟悉的数值方法
2. HANK 是主流宏观经济学公认的前沿方向，发表空间明确
3. 从 P1 积累的 HANK 求解经验可以直接用于后续的原创研究（如 HANK + 金融摩擦、HANK + 气候风险等）
4. P1 提供了一个"学中做"的路径：通过求解模型来理解宏观经济学，比纯阅读效率更高

建议路线：先用 2-3 周通过 Romer 教材 + Achdou et al. (2022) 论文建立基本理解，然后用 1-2 个月完成 P1 的基准复现和数值方法对比。
