# 00 Beginner Guide / 人话入门指南

Last updated: 2026-06-19

## 0. 这篇文档怎么读

这篇文档是给第一次接触宏观经济学的读者看的——你可能已经知道微观经济学里供需曲线怎么画、消费者怎么最大化效用、市场均衡是什么意思，但对"GDP 为什么有时候增长 3% 有时候下降 2%""央行为什么要加息""通胀到底是怎么来的"这些问题还没有系统的理解。

这篇文档的目标不是把宏观经济学所有模型都列完，而是帮你建立最基本的直觉框架：宏观经济学为什么存在、它在调什么旋钮、大家已经做到哪里了、真正卡在哪里。

阅读顺序建议：先读第 1-3 节建立直觉，再读第 4-6 节理解领域版图，最后读第 7-9 节决定自己下一步该看什么、做什么。

## 1. 先用人话说：这个领域到底在研究什么？

### 初学者版一句话

宏观经济学研究的是一个国家或地区的经济整体为什么会增长、为什么会波动、以及政府（央行和财政部）能不能通过调整利率、税收或支出来让经济运行得更好。

### 研究者版一句话

宏观经济学研究加总变量（GDP、消费、投资、就业、通胀、利率、汇率）之间的动态关系，以及这些关系背后的微观基础（个体最优化行为如何加总为宏观现象）和政策含义（货币政策和财政政策能否及如何改善宏观经济表现）。

### 这个领域最容易被误解成什么？

**误解一："宏观经济学就是把微观经济学放大到国家层面。"**

不是。在微观经济学中，你假设市场会通过价格调整达到供需平衡——如果失业了，工资会下降直到所有人都有工作。但现实中，1930 年代大萧条期间美国失业率高达 25%，工资在下降但失业没有消失。宏观经济学存在的核心原因就是：**加总层面的市场失灵（协调失败）不能在微观框架内被理解**。

**误解二："宏观经济学就是预测股市和汇率。"**

不是。宏观经济学的核心任务是**理解和解释**加总变量的波动，而不是预测。事实上，宏观经济学家对短期 GDP 增长的预测能力非常有限——因为经济系统是非平稳的（结构在变化），且样本太小（现代数据通常只有几十年）。

**误解三："宏观经济学家都是凯恩斯主义者或者都是自由市场派。"**

不是。现代宏观经济学是一个方法论的统一体——几乎所有严肃的宏观研究都使用 DSGE（动态随机一般均衡）方法框架。在这个框架内，你可以放价格粘性（新凯恩斯主义）也可以不放（新古典），你可以有金融摩擦也可以没有。分歧在具体机制上，不在最基本的方法上。

## 2. 一个贯穿全文的最小例子：经济体为什么会有"好年份"和"坏年份"？

让我们用一个最简单的经济体来理解宏观经济学关心的核心问题。

### 设定

想象一个封闭的经济体（没有对外贸易），里面只有两类人：
- **家庭**：提供劳动、获得工资、消费产品、储蓄
- **企业**：雇用劳动、生产产品、投资（买机器、建厂房）

还有一个**政府**（央行 + 财政部）和**金融系统**（银行）。

### 这个经济体的一年

在正常年份，一切平稳运行：家庭有工作，企业有利润，银行正常放贷。

但突然——假设由于某种原因（企业家对未来的信心下降了），企业决定减少投资。这意味着：
1. 生产机器的工厂订单减少 → 那些工厂裁员
2. 被裁员的家庭收入下降 → 消费减少
3. 消费减少 → 更多企业销售下降 → 更多裁员
4. 更多人失业 → 消费进一步下降 → ……

**这就是宏观经济学最核心的机制：乘数效应（multiplier effect）和正反馈循环。**初始的一个小冲击，因为"你的支出就是我的收入"这个宏观恒等式，可以被放大成一场全面的衰退。

### 可以调的旋钮

- **央行降息** → 借贷成本下降 → 企业更愿意投资 → 打断负反馈循环
- **政府增加支出**（修桥修路） → 直接创造就业 → 那些工人的收入变成消费 → 间接创造更多就业
- **政府减税** → 家庭可支配收入增加 → 消费增加 → 企业销售增加

### 核心困难

降息有用吗？不一定。如果利率已经降到零（零利率下限 ZLB），央行就没有进一步降息的空间了。而且如果家庭和企业都对未来极度悲观，即使利率为零，他们也不愿意借钱消费或投资——这就是**流动性陷阱（liquidity trap）**。

政府增加支出有用吗？取决于政府借钱会不会挤出私人投资，以及家庭是否预期未来会加税来还债而提前减少消费（**李嘉图等价**）。

你看，即使是这个最简单的经济体，一旦你开始思考"政策有没有用"，立刻就会进入非常深的水域。这就是宏观经济学既迷人又困难的地方。

## 3. 它在更大知识链条中的位置

```text
人类社会的基本经济问题（稀缺资源的配置）
  -> 微观经济学：个体如何决策、市场如何协调
  -> 宏观经济学：加总变量为什么波动、政策如何干预
  -> 计量经济学：如何从数据中识别因果关系
  -> 经济政策制定：央行设定利率、财政部编制预算
  -> 实际经济表现：就业、通胀、增长、不平等
```

宏观经济学是链条中从"理解个体"到"管理整体"的桥梁。如果微观经济学告诉你"每个人在自己的一亩三分地上怎么做到最好"，宏观经济学告诉你"即使每个人都做到了最好，整体经济仍然可能出问题——因为你的最好取决于别人在做什么，而你们无法协调。"

## 3.5 最小数学对象 / 最小流程

### 核心恒等式：GDP 的三种算法

$$
Y = C + I + G + NX
$$

其中：
- $Y$：GDP（国内生产总值）
- $C$：消费（Consumption）
- $I$：投资（Investment，实物资本形成，不是买股票）
- $G$：政府购买（Government spending）
- $NX$：净出口（出口 − 进口）

这条恒等式告诉我们：一个国家一年内生产的所有东西，一定等于被消费 + 被投资 + 被政府购买 + 被外国人买走的总和。这不是一个理论，是**定义**——GDP 的支出法核算。

但更重要的是它隐含的一个关系：**你的支出 = 我的收入**。如果所有人都同时减少支出（消费和投资下降），所有人的收入都会下降——这就是"节约的悖论"（paradox of thrift）：对个体理性的行为（多储蓄应对不确定性）在宏观层面可能是灾难性的（总需求崩溃）。

### 核心动态：Solow 增长模型

$$
\Delta K = sY - \delta K
$$

其中 $K$ 为资本存量（机器、厂房、基础设施），$s$ 为储蓄率，$\delta$ 为折旧率，$Y = F(K, AL)$ 为总产出。

这条方程说的是：资本存量的变化 = 新投资（储蓄转化的） − 旧资本的折旧。当 $sY = \delta K$ 时，经济到达稳态——人均产出不再增长，除非有技术进步（$A$ 增加）。

**这个模型最深刻的洞察**：如果没有技术进步，经济增长最终会停止。资本积累本身不能带来持续增长——这被称为"Solow 残差"。

### 核心短期模型：IS 关系

在最简化的短期分析中，总产出 $Y$ 由总需求决定：

$$
Y = C(Y - T) + I(r) + G
$$

其中消费 $C$ 是可支配收入 $Y - T$ 的函数，投资 $I$ 是实际利率 $r$ 的函数。当央行降息（$r \downarrow$），投资上升（$I \uparrow$），通过乘数效应推动 $Y$ 上升。

### 最小流程

```text
外生冲击（技术变化、信心变化、政策变化）
  -> 影响家庭的消费决策和企业的投资决策
  -> 加总为总需求变化
  -> 价格/工资调整（快或慢，取决于你假设的摩擦）
  -> 新的均衡产出、就业、通胀
  -> 政策制定者观察并进行政策反馈（Taylor 规则）
  -> 反馈影响下一期的家庭和企业决策
```

## 4. 这个领域里的人主要分成哪几派？

### 4.1 时间轴上的两大阵营

宏观经济学最根本的分歧在于：**价格（特别是工资）调整得有多快？**

**新古典派（淡水学派）**：价格调整很快。经济衰退不是因为需求不足，而是因为经济在调整到新的最优状态。失业的人是在"主动选择"更多闲暇（因为工资暂时不够高）。政府不应该干预——波动是有效率的。

**新凯恩斯派（咸水学派）**：价格调整很慢（菜单成本、长期合同、协调失败）。工资不能迅速下降来吸收冲击，导致非自愿失业。央行和政府应该用货币政策（利率）和财政政策（支出/税收）来稳定经济。

**2008 金融危机后的共识**：新凯恩斯派的方法论赢了（DSGE 是所有人的标准工具），但新古典派对"政策有时会做过头"的警惕被纳入了模型。今天的央行经济学家几乎全部使用某种形式的新凯恩斯 DSGE 模型。

### 4.2 方法上的新前沿

**HANK（异质性主体新凯恩斯）派**："代表性主体"假设太粗糙了——富人和穷人对同一政策的反应完全不同。我们需要在宏观模型中保留家庭之间的财富和收入分布。

**宏观金融派**：金融部门不是面纱，而是冲击的放大器。需要把银行、抵押品约束、资产价格波动纳入宏观模型的核心。

**Agent-Based 派**（少数派）：DSGE 的数学约束太强，很多现实中的复杂现象（泡沫、崩盘、突然的范式转换）无法被局部近似捕捉。应该用大规模计算机模拟替代解析模型。

## 5. 关键里程碑：一张简化的思想史地图

| 时期 | 事件 | 为什么重要 |
|---|---|---|
| 1936 | Keynes《通论》出版 | 第一次系统论证：市场经济可能陷入持续的"失业均衡"——这是一个深刻的理论创新 |
| 1937 | Hicks 提出 IS-LM 模型 | 把 Keynes 的文字论证翻译成可操作的数学模型 |
| 1956 | Solow 增长模型 | 解释长期增长的源泉（技术进步，不是资本积累） |
| 1958 | Phillips 曲线 | 通胀和失业的经验替代关系 → 政策 trade-off 的直观框架 |
| 1968 | Friedman 自然率假说 | 预测 Phillips 曲线在长期不存在——被 1970 年代滞胀验证 |
| 1976 | Lucas 批判 | 彻底改变了宏观经济学的方法论：模型必须有微观基础 |
| 1982 | Kydland & Prescott 的 RBC 模型 | 定义了现代宏观的方法标准：DSGE + 校准 + 脉冲响应 |
| 1990s | 新凯恩斯 DSGE 的建立 | 价格粘性的微观基础 + DSGE 方法 = 现代央行的标准工具箱 |
| 2008 | 全球金融危机 | 暴露了标准模型在金融部门建模上的致命缺陷 |
| 2010s- | HANK 和宏观金融的兴起 | 当前最活跃的前沿：异质性、金融摩擦、网络效应 |

## 6. 常见的认知陷阱（避免走弯路）

### 陷阱一："这个模型假设人是理性的，所以它一定是错的。"

所有模型都简化了现实。理性预期假设不是一个关于"人是不是真的很聪明"的声明——它是一个**均衡概念**：在一个稳定的政策环境下，如果人们的预期系统性地错误，他们就会损失钱（或效用），因此存在一种演化压力使预期趋向正确。

**更好的思考方式**：不要问"人是不是理性的"，而是问"理性预期假设在这个具体问题上是否严重扭曲了结论？"

### 陷阱二："经济学不是科学，因为它不能做受控实验。"

宏观经济学确实不能对一国经济做随机对照试验。但：
- 自然实验和政策变化（如某些州提高最低工资、某些国家加入欧元区）提供了变体
- 结构模型（DSGE）允许你做**反事实模拟**——"如果当时央行做了 X 而不是 Y，经济会怎样？"
- 识别策略的进步（叙事法、高频数据、断点回归）使因果推断越来越可信

这和天文学或古生物学是一样的——你不能重演宇宙大爆炸或恐龙灭绝，但你仍然可以做科学。

### 陷阱三："GDP 增长就是一切。"

GDP 是一个不完美的指标——它不衡量不平等、环境退化、健康、教育质量、闲暇、家庭生产的价值。宏观经济学家知道这一点。GDP 之所以被广泛使用，不是因为它"对"，而是因为它在统计上可操作、在国际上可比、且与其他福利指标高度相关（人均 GDP 和预期寿命、识字率、主观幸福感都显著正相关）。

## 7. 如果你有微观经济学基础：关键跳跃是什么？

你从微观经济学带来的最有价值的直觉是：**价格调节供需、均衡是有效率的**。

宏观经济学在此基础上加了三个关键修正：

1. **加总的外部性**：我的消费决策影响你的收入——但我不需要考虑这一点，因为市场没有给我这个信号。这是宏观经济学最核心的市场失灵来源。
2. **价格粘性**：价格（特别是工资）不能迅速调整到出清水平——因为菜单成本、长期合同、效率工资、工会等原因。这意味着非自愿失业可以长期存在。
3. **预期和协调**：我今天的行为取决于我对未来的预期，而未来取决于所有人今天的行为——这是一个不动点问题，可以有多个均衡（自我实现的乐观和悲观）。

## 8. 入门的实用建议

### 8.1 如果你想快速建立直觉（1 周）

1. 看 Blanchard *Macroeconomics* 的前 9 章（短期波动）
2. 关注每个模型的三个问题：核心假设是什么？外部冲击从哪里来？政策能做什么？
3. 不要纠结于数学推导——先建立经济直觉

### 8.2 如果你想系统学习（1-2 月）

1. 通读 Romer *Advanced Macroeconomics*
2. 每个模型自己用手推导一遍核心方程
3. 下载 Dynare（免费），运行一个标准 NK-DSGE 模型的示例，改参数看脉冲响应怎么变

### 8.3 如果你是物理/计算背景，想要"做"宏观而不是"读"宏观

1. 从本 field pack 的 **P1 项目**切入：复现 Achdou et al. (2022) 的 HANK 数值求解
2. 这是一个"以做代学"的路径——通过编写代码来求解模型，你会比纯阅读更深地理解模型的机制

## 9. 一页纸总结

| 问题 | 简短答案 |
|---|---|
| 宏观经济学研究什么？ | 加总变量（GDP、通胀、失业）的波动、增长和政策干预 |
| 为什么需要宏观经济学？ | 微观层面的理性行为可以在宏观层面产生非理性的结果（协调失败） |
| 最重要的模型是什么？ | Solow（长期增长）、IS-LM/AS-AD（短期波动）、NK-DSGE（现代标准） |
| 最核心的政策工具是什么？ | 货币政策（央行调整利率）、财政政策（政府支出和税收） |
| 最根本的理论分歧是什么？ | 价格调整的速度和充分性（新古典 vs 新凯恩斯） |
| 当前最活跃的前沿是什么？ | HANK（异质性主体）、宏观金融、网络与系统性风险 |
| 我可以怎么切入？ | 如果你有计算背景：从 HANK 的数值方法切入（P1 项目） |
