# 12 Field Map / 领域地图

Last updated: 2026-06-19

## 0. 如何使用这篇地图

这篇文档用"问题链 → 方法谱系 → 概念坐标轴"的结构展开宏观经济学。如果你是第一次接触，建议先读第 1 节理解这个领域为什么存在，再读第 2 节掌握主流路线的 trade-off，最后用第 3 节的坐标轴定位自己想深入的方向。

## 1. 问题链：宏观经济学要解决什么？

### 1.1 这个领域在更大知识链条中的位置

```text
人类社会的基本经济问题（稀缺性）
  -> 微观经济学：个体如何做决策、市场如何协调
  -> 宏观经济学：加总变量为什么波动、如何用政策干预
  -> 计量经济学/实证方法：如何从数据中识别因果关系
  -> 经济政策制定（央行、财政部）
  -> 实际经济表现（增长、就业、通胀、不平等）
```

### 1.2 为什么宏观经济学是绕不过去的一层？

微观经济学告诉你"市场在理想条件下会达到有效率的结果"。但现实世界中，我们反复看到：
- 大量失业和闲置产能并存（大萧条、2008 金融危机）
- 通胀和失业同时高企（1970 年代的滞胀）
- 货币政策有时候有效、有时候完全无效

**微观经济学无法回答这些问题**，因为它假设价格总是调整到市场出清——而这个假设在宏观层面常常不成立。宏观经济学存在的理由就是：理解和应对**加总层面的协调失败和市场失灵**。

### 1.3 核心问题链

```text
Q1: 什么决定了长期经济增长和生活水平？
  -> Q2: 为什么经济会围绕长期趋势波动（经济周期）？
    -> Q3: 货币和财政政策能做什么、不能做什么？
      -> Q4: 政策制定者如何应对不确定性和模型误设？
        -> Q5: 金融系统在放大还是吸收冲击？
```

每个问题对应一个主要的子方向。

## 2. 主流路线谱系

### 2.1 第一轴：价格灵活性（方法论/哲学轴）

```text
价格完全灵活 ←————————————————————————→ 价格粘性 + 多种摩擦
(新古典/RBC)                            (新凯恩斯)
实际经济周期理论                           NK-DSGE 模型
长期中性（货币不影响实际变量）               短期非中性（货币政策有效）
```

### 2.2 第二轴：微观基础的深度（方法轴）

```text
简化加总关系 ←————————————————————————→ 完全微观基础
(旧凯恩斯 IS-LM)                         (DSGE 模型)
直观、可解析、但缺少微观纪律                 微观一致、但可能过度复杂
                                          受 Lucas 批判保护
```

**Lucas 批判（Lucas Critique, 1976）**：任何基于历史统计关系的政策评估都是不可靠的，因为当政策变化时，经济主体的预期和行为也会变化，导致原来的统计关系不再成立。这一定理从根本上改变了宏观经济学的方法论——所有严肃的宏观模型现在都要求有微观基础（即从个体的最优化行为推导出加总关系）。

### 2.3 第三轴：异质性程度（前沿轴）

```text
代表性主体 ←————————————————————————————→ 异质性主体
(RA-NK/RBC)                              (HANK: Heterogeneous Agent NK)
解析解可能                                需要数值方法
忽略了分配效应                             可以研究不平等与宏观的互动
```

## 3. 核心子方向详述

### 3.1 经济增长理论（Long-Run Growth）

**它是什么**：研究什么决定了各国长期人均收入水平的差异。

**为什么重要**：一个年均增长率 2% vs 3% 的经济，经过 50 年会相差 1.6 倍——增长率的微小差异会产生巨大的福利后果。

**核心模型链**：
1. **Solow-Swan 模型（1956）**：外生技术进步驱动的增长，资本积累有递减回报。关键预测：没有技术进步的持续增长是不可能的；穷国应该比富国增长更快（条件收敛）。
2. **内生增长理论（Romer, Lucas, 1980s-）**：技术进步本身是经济活动的内生结果（R&D、人力资本积累、干中学）。
3. **统一增长理论（Unified Growth Theory）**：解释人类从马尔萨斯停滞到持续增长的转型。

**成熟度**：核心框架成熟（Solow 模型是本科标准内容），但"为什么有些国家不增长"仍然是开放问题。

**关键方程（Solow 模型）**：
$$
\Delta K = s Y - \delta K
$$
其中 $K$ 为资本存量，$Y = F(K, AL)$ 为总产出（$A$ 为技术水平，$L$ 为劳动），$s$ 为储蓄率，$\delta$ 为折旧率。资本到达稳态 $sY = \delta K$ 后，人均产出只能由技术进步 $A$ 驱动增长。

### 3.2 经济周期理论（Business Cycles）

**它是什么**：研究 GDP、就业、消费、投资等加总变量为什么会出现持续的、准周期的波动。

**为什么重要**：经济衰退造成巨大的福利损失（失业、企业倒闭、人力资本折旧）。理解波动的来源是设计稳定政策的前提。

**主流路线**：

| 路线 | 核心波动来源 | 关键机制 | 政策含义 |
|---|---|---|---|
| RBC（实际经济周期） | 技术冲击（TFP 波动） | 跨期替代（劳动供给对工资变化的响应） | 波动是有效率的，政策不应干预 |
| NK（新凯恩斯） | 技术冲击 + 货币/需求冲击 | 价格粘性 + 垄断竞争 → 总需求外部性 | 货币政策可以且应该稳定经济 |
| 金融加速器 | 金融冲击 + 抵押约束 | 资产价格下跌 → 抵押品价值下跌 → 借贷能力下降 → 投资下降 | 金融监管 + 宏观审慎政策 |
| 异质性主体（HANK） | 多源冲击 | 分配效应 + 边际消费倾向异质性 | 财政政策（转移支付）可能更有效 |

**成熟度**：RBC 和 NK 的基准模型已经非常成熟（标准 DSGE 工具包），但 2008 金融危机暴露了标准模型在金融部门建模方面的严重不足。HANK 是当前最活跃的前沿。

### 3.3 货币政策与通胀理论

**它是什么**：研究央行如何设定利率（或货币供给）来影响通胀、产出和就业。

**核心框架演变**：
1. **IS-LM 模型（Hicks, 1937）**：最经典的短期分析工具，描述产品市场（IS）和货币市场（LM）的同时均衡。简单直观但缺少微观基础。
2. **Phillips 曲线（1958, 修正版）**：通胀与失业之间的经验替代关系。原始版本已在 1970 年代被证伪（滞胀），现代版本将预期通胀纳入。
3. **Taylor 规则（1993）**：描述央行如何根据通胀缺口和产出缺口调整名义利率的经验方程，已成为现代央行政策分析的基准。
4. **新凯恩斯 Phillips 曲线（NKPC）**：从企业定价的微观基础推导出的通胀动态方程，是现代 DSGE 模型的核心组成部分。

**关键命题**：
- 长期货币中性：货币供给的变化在长期只影响价格水平，不影响实际产出
- 短期非中性：由于价格粘性，货币政策在短期可以影响实际经济活动
- 通胀预期至关重要：如果公众预期高通胀，这种预期会自我实现（预期陷阱）

### 3.4 财政政策与政府债务

**它是什么**：研究政府支出和税收如何影响宏观经济。

**核心争论**：
- **财政乘数（fiscal multiplier）**：1 元政府支出能产生多少元的 GDP？估计值从 0.5 到 2.0+ 不等，取决于经济状态（衰退期乘数通常更大）、货币政策反应、开放程度。
- **李嘉图等价（Ricardian Equivalence）**：如果家庭是理性的、没有借贷约束，政府用债务还是税收来为支出融资没有区别——两者等价。这是一个基准定理，实际偏离程度很大。
- **债务可持续性**：政府债务/GDP 比率什么时候是不可持续的？取决于利率 r 与增长率 g 的关系：如果 r < g，债务可以永久滚续（但这不意味着不需要担心）。

### 3.5 劳动力市场与失业

**它是什么**：研究失业的原因以及劳动力市场与宏观经济波动的互动。

**核心框架**：
- **搜索匹配模型（DMP, Diamond-Mortensen-Pissarides, 2010 诺奖）**：失业不是"过剩供给"，而是工人和岗位之间的匹配过程需要时间和资源。均衡失业率取决于匹配效率和制度因素（失业保险、最低工资、工会）。
- **效率工资理论**：企业主动支付高于出清水平的工资以提高生产率（减少偷懒、降低离职率、吸引更好的工人）→ 产生均衡失业。
- **失业的波动**：什么解释了失业率在经济周期中的大幅变动？工资粘性 + 劳动力需求波动是主流解释。

## 5. 成熟度总结

| 子方向 | 成熟度 | 开放问题程度 |
|---|---|---|
| Solow 增长模型 | mature（教学级） | 低 |
| 内生增长 | mature | 中等（制度、文化与增长的因果方向） |
| RBC 基准模型 | mature | 低（但几乎所有实证研究都拒绝其核心预测） |
| NK 基准模型（代表性主体） | mature | 中等（金融部门建模不足） |
| Taylor 规则 / 通胀目标制 | mature（央行实际使用） | 低-中等 |
| NKPC 的实证表现 | 争议中 | 高（"缺失的通胀"之谜） |
| HANK 模型 | emerging（前沿活跃） | 高 |
| 金融加速器 / 宏观金融 | emerging | 高 |
| 劳动力市场搜索匹配 | mature（诺奖级） | 中等 |
| 零利率下限（ZLB）环境 | emerging | 高（日本经验的推广） |

## 6. 与用户背景的连接点

用户作为计算物理研究者，以下几个连接点可能特别有价值：

1. **DSGE 的数值求解**：扰动法（perturbation）、投影法（projection）、值函数迭代——这些与物理中的微扰论、谱方法、自洽场迭代有结构和精神上的共通
2. **异质性主体模型（HANK）**：需要在个体维度上做高维数值求解，类似于统计物理中的分布函数演化
3. **Agent-Based Macroeconomics**：与统计物理/复杂系统密切相关的非主流路线，用大量异质性主体的计算机模拟替代解析 DSGE
4. **时间序列分析**：谱分析、滤波（HP 滤波、带通滤波）与物理中的信号处理共享数学工具
