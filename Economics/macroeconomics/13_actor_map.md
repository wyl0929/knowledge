# 13 Actor Map / 代表作者与研究组谱系

Last updated: 2026-06-19

## 0. 本篇文档的作用

标注宏观经济学发展过程中最重要的研究者、研究组和机构谱系。这不是完整的"谁是谁"列表，而是帮助用户在阅读文献时快速定位一个作者的学术血统、核心立场和方法偏好。

## 1. 谱系地图

### 1.1 凯恩斯传统 → 新凯恩斯主义

```text
Keynes (1936, 通论)
  -> Hicks (1937, IS-LM 形式化)
  -> Samuelson, Modigliani, Tobin (新古典综合派, MIT-Penn)
    -> Fischer, Taylor (1980s 新凯恩斯微观基础)
      -> Mankiw, Romer (David), Blanchard (1980s-90s 菜单成本等)
        -> Gali, Gertler, Woodford (1990s- NK-DSGE 基准)
          -> Nakamura, Steinsson (2000s- 微观价格证据)
```

## 3. 理解一个学者立场的小技巧

在阅读宏观经济学文献时，可以从以下几个维度快速定位一个作者的立场：

1. **他们认为价格粘性重要吗？** → 新凯恩斯 vs 新古典
2. **他们用什么方法？** → DSGE（主流）、VAR（实证宏观）、Agent-Based（异端）、自然实验（应用微观/宏观交叉）
3. **他们认为 2008 金融危机改变宏观经济学了吗？** → "需要加入金融部门" vs "基准模型基本没问题"
4. **他们是否认为不平等应该进入宏观模型？** → HANK 派 vs 代表性主体派
