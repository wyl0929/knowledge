# 02 Frontier Compass / 边界罗盘

Last updated: 2026-08-30

## 使用说明

本文件是决策罗盘，不是第三篇综述。每个边界问题都必须说明：它到底在问什么，为什么不是已经成熟的 baseline，最小验证怎么做，以及对用户意味着什么。

## 0. 这个文件的用途

回答：在"美国涉台政治传播"这个方向上，哪些是内圈常识、哪些是成熟 baseline、哪些是真正卡住的问题、哪些是伪边界，以及用户从哪里切入。它把 12（领域地图）、14（文献注册表）、20（缺口表）、21（资产匹配）、22（项目卡片）综合成一张"下一步该往哪走"的罗盘。

## 2. 中圈：成熟 baseline 与不可忽视的工具

| Baseline / 工具 / 方法 | 已经解决什么 | 还解决不了什么 | 新项目如何正确使用它 |
|---|---|---|---|
| Entman 四功能 + Matthes & Kohring 元素编码 | 框架编码的信度与效度规范 | 跨平台短文本（推文）的编码等价性 | 作为编码手册骨架；对推文做不可编码率预检 |
| 第一层媒介间议程设置（Granger/VAR/网络法） | 议题显著性的跨媒介流向检验 | 帧层面语义结构的流向 | 作为方法基线；帧层面是用户增量 |

| STM/BERTopic | 议题结构随协变量（平台/时期）的演变 | 语义框架（topic≠frame） | 演变机制的 topic 层；框架层另走编码管线 |
| LLM 批量编码（Gilardi 2023 支持） | 大规模文本标注的成本问题 | 立场漂移、可复现性、期刊接受惯例 | LLM 全量 + 人工子样本锚定 + α 报告 |

| Wayback Machine / Media Cloud | Yahoo News 历史页面的候选获取路径 | 快照密度与收录覆盖未验证 | MVP 第 1 周三路探测的直接对象 |

## 3. 边界：当前真正卡住的问题

### Boundary Question B-001：涉台专属框架清单是否存在且稳定？

**一句话解释：** 美国新闻里谈台湾，用的框架是不是能脱离"涉华总框架"单独立清单？

**为什么重要：** 它是 P1 描述层贡献的支点（G1）；如果涉台框架只是涉华框架的机械复用，P1 的"框架建构"叙事要改写。

**已有工作做到哪里：** 涉华威胁框架编码成熟（Ooi 2017、Yuan & Fu 2020）；以台湾为主体的系统编码未被命中。

**还不清楚什么：** 涉台专属框架（战略模糊、协防义务、民主盟友、危机管理）的清单与稳定性。

**为什么难：** 需要长时段系统取样（数据约束 B-003）+ 归纳/演绎平衡 + 专家复核。

**最小验证：** 佩洛西事件 100 条试点编码，检查专属框架占比与通用框架覆盖比例。

**证据状态：** suspected

### Boundary Question B-002：帧层面跨平台流向能不能测、流向是否随事件类型变化？

**一句话解释：** 新闻与社交之间，到底是谁在给谁递"说法"，还是只是同一个事件把两边同时点燃？

**为什么重要：** 用户研究问题三的核心；第一层议程流向的结论不能自动迁移到语义框架层。

**已有工作做到哪里：** Wang & Guo 2018 在科技议题上做了帧层面 intermedia frame setting；涉台事件未见。

**还不清楚什么：** 涉台事件中的流向方向、时滞、以及事件类型（访问/军售/选举/危机）的调节作用。

**为什么难：** 高精度时间戳 + 连续窗口 + 帧层面编码成本三重约束；数据可得性（B-003）是前置条件。

**最小验证：** 试点事件双平台框架序列逐小时 Granger + GDELT 热度对照。

**证据状态：** suspected

### Boundary Question B-003：2017–2026 全时段双平台回溯取样有没有诚实可行的方案？

**一句话解释：** 研究设计要 9 年，数据世界只给得起碎片——怎么拿碎片拼出可发表的研究？

**为什么重要：** 它是所有分析的总闸门（G6）；处理不好，整个设计在"数据可得性"这环静默缩水。

**已有工作做到哪里：** 数据批判文献记录了 API 关闭（RIP Twitter API）；替代路径各有短板，无标准方案。

**还不清楚什么：** Wayback 对 news.yahoo.com 的快照密度、公开推文数据集的覆盖与许可、商业历史 API 的成本合规。

**为什么难：** 平台政策持续变化；成本与许可不可控；学界无统一做法。

**最小验证：** MVP 第 1 周对佩洛西事件做三路探测（Wayback/Media Cloud/第三方 API）。

**证据状态：** confirmed（官方路径不可行）+ suspected（替代路径覆盖）

### Boundary Question B-004：三阶段框架差异中，政府期效应与事件效应怎么分离？

**一句话解释：** 拜登期出了佩洛西访台，特朗普一期没有——框架变化里有多少是"换总统"，多少是"出大事"？

**为什么重要：** 用户研究问题二"演变机制"的诚实边界（G3、C6）；这是本设计最大的内生性风险。

**已有工作做到哪里：** 政策话语侧有战略模糊→清晰的叙事研究；媒体框架侧未见事件-阶段分离设计。

**还不清楚什么：** 同类型低烈度事件跨阶段的框架稳定性；事件固定效应模型能解释多少方差。

**为什么难：** 事件供给不可控（观察设计）；需要预先注册的事件选择规则防选择偏差。

**最小验证：** 三阶段各取同类型事件对比框架分布（G3 最小验证）。

**证据状态：** suspected（空白）+ confirmed（混淆风险本身是设计事实）

### Boundary Question B-005：跨平台编码等价性（新闻长文本 vs ≤280 字符推文）

**一句话解释：** 用同一本编码手册去编新闻和推文，编出来的"差异"可能是真的平台差异，也可能是尺子不一样。

**为什么重要：** 所有"跨平台框架分布比较"的效度前提（G4）；Operationalization Gate 的测量核心。

**已有工作做到哪里：** 双平台比较研究存在（Valenzuela 2017 等），但编码等价性检验不常见。

**还不清楚什么：** 四功能元素在推文中的可编码率；是否需要平台变体手册。

**为什么难：** 短文本信号稀疏；手册迭代需要双平台试点与留出验证。

**最小验证：** 双平台各 50 条试编码，比较不可编码率与信度。

**证据状态：** suspected

## 4. 伪边界：看起来像创新但可能不是

| 方向 | 为什么看起来有吸引力 | 为什么可能不是好 gap | 更好的改写 |
|---|---|---|---|
| "用 X 数据揭示美国公众对台态度" | 数据便宜量大、即时 | 概念越界（C2）+ Amrullah 2023 已做情绪版 | "描述平台舆论场中的涉台框架结构，并与民调做对照（P3）" |
| "没有任何研究涉及美国涉台政治传播" | 搜索未命中 | 涉华框架、涉台 Twitter、IAS 各有成熟工作；搜索非穷尽 | "在涉台×帧层面×跨平台×三阶段交叉区提供系统描述" |
| "自训大模型做涉台帧检测" | 显得技术硬核 | 数据瓶颈不在算力；自训引入不可复现与立场偏差 | "LLM API 批量编码 + 人工锚定 + 信度报告" |
| "抓取 X 全量历史推文" | 与官方 API 难度类似 | 反爬风险、合规问题、技术脆弱（snscrape 衰退） | "可得子集 + 明示边界 + 前瞻采集" |
| "用 Yahoo News 代表美国媒体立场" | 品牌知名度高 | 聚合器内容混源（C4） | "代表美国公众可见的聚合新闻流（含来源标签）" |

## 6. 三条下一步路线

### Route A：保守路线（先验证数据可行性，再谈研究）

- 目标：用 1–2 周证明"佩洛西事件双平台取样可行"，把 B-003 从疑云变成事实。
- 第一周动作：三路探测脚本 + X 数据集/API 确认（23 MVP 第 1 周）。
- 成功信号：Yahoo ≥100 条、X ≥100 条可编码文本到账。
- 止损信号：两平台均 <30 条 → 转入时段重定义预案，不硬撑。

### Route B：中等路线（消歧 MVP 全链路，本包推荐）

- 目标：一个月跑完 23 MVP 全链路（取样+手册 v0.1+双编码+试点图），把 P1 的 operational_status 从 provisional 升到 metric_checked。
- 第一周动作：同 Route A + 起草 codebook v0.1。
- 成功信号：人-人 α ≥ .67、人-机 α/F1 达标、试点图可读（结果 A）。
- 止损信号：α 两轮迭代 < .60 → 手册简化预案（结果 C）。

### Route C：激进路线（直接铺开三阶段全量）

- 目标：跳过试点，直接 9–12 个事件全量取样与编码。
- 第一周动作：写全量采集计划与预算。
- 成功信号：全时段样本 1 个月内建成且信度达标。
- 止损信号：任一环节（数据/编码）在扩量后崩坏 → 回退 Route B。**风险提示：扩量后失败成本远高于试点，不推荐作为第一步。**
