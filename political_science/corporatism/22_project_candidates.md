### PC1：法团主义核心逻辑的跨领域可迁移性研究

```yaml
status: provisional
gap_connection: G3
```

**核心问题**：法团主义的"垄断代表+制度化协商+退出威胁交换"逻辑，哪些要素可以从劳资领域平移到其他领域（央地利益协调、气候治理）？哪些不能？为什么？

**方法**：比较案例设计。选择 2-3 个"类法团主义"的非劳资安排：
- 南网（央地利益协调）→ 来自央地 field pack
- 德国煤炭退出委员会（环境治理）→ 需新增案例
- 可能第三个案例（爱尔兰社会伙伴关系中的社区-志愿支柱？）

在每个案例中检验四个要素是否成立：
1. 垄断代表权是否存在
2. 退出威胁是否真实
3. 权利-义务是否打包
4. 国家是"架构师"还是"参与者"

**成功标准**：提出一个"法团主义逻辑可迁移的条件集合"——至少识别出 2-3 个必要条件。

**与用户资产匹配**：⭐⭐⭐⭐⭐（直接延续央地 field pack 的讨论，种子分析已有）

### PC2：中国是否是"政党领导型法团主义"——一个概念评估

```yaml
status: provisional
gap_connection: G1
```

**核心问题**：将 ACFTU、三方会议、全国政协与经典法团主义（社会和国家两种版本）进行系统比较，评估"政党领导型法团主义"这个概念标签在分析上是否有用。

**方法**：概念分析 + 比较案例。构建比较矩阵（维度见 G1），对中国和 2-3 个经典案例（瑞典、奥地利、法西斯意大利）进行打分比较。

**风险**：可能发现中国体制与法团主义的核心定义差异太大，最终结论是"这不是法团主义"——但排除本身也是学术贡献。

**与用户资产匹配**：⭐⭐⭐⭐

### PC3：法团主义的"退出-发声交易"的简单博弈论模型

```yaml
status: provisional
gap_connection: G2 (间接)
```

**核心问题**：能否用一个简单的重复博弈模型形式化"合作如何在长期削弱退出威胁的可信性"（法团主义陷阱）？

**方法**：带状态变量的重复博弈。两个玩家（劳工、资本），劳工可以在每个周期选择"合作"（不罢工）或"对抗"（罢工）。每次合作会降低劳工在下一轮的动员能力（组织肌肉萎缩参数 δ）。分析存在一个临界外生冲击强度，超过它时，劳工发现自己无法有效对抗——但已经太晚了。

**成功标准**：模型产生一个"看起来稳定但实际上脆弱"的均衡——系统在没有大冲击时看起来运行良好，但一个异常大的冲击会导致突然崩溃。

**与用户资产匹配**：⭐⭐⭐⭐（简单 Python 建模，和央地 field pack 的 PC1 路线一致）
