| **证据状态** | `source_checked` |
| **允许结论层级** | `introductory_explanation` |

### C2：社会法团主义和国家法团主义在"组织自主性"和"发言权真实性"上有本质区别

| **证据状态** | `source_checked` |
| **允许结论层级** | `introductory_explanation` |

### C3：法团主义在 1980 年代后衰退的主要驱动力是全球化的不对称效应

| 项目 | 内容 |
|------|------|
| **类型** | `mechanism` |
| **证据基础** | 资本流动性上升 + 劳工流动性基本不变 → 资本的退出威胁急剧上升，劳工的退出威胁下降 → 法团主义谈判天平倾斜。这个机制在比较政治经济学文献中被广泛讨论 |
| **证据状态** | `source_checked`（机制逻辑清晰），但因果效应大小的定量估计仍是 `contested` |
| **允许结论层级** | `introductory_explanation`（不宜声称这是"唯一"或"最主要"的驱动力） |

### C4：法团主义存在"陷阱"——合作导致动员能力在长时段内衰减

| 项目 | 内容 |
|------|------|
| **类型** | `mechanism` |
| **证据基础** | 1970 年代欧洲左翼的理论分析；1980s 英国工会被撒切尔毁灭性打击的部分验证；但北欧工会虽衰退远未被"毁灭"——说明机制的闭合程度因国而异 |
| **证据状态** | `contested`——机制方向有理论和案例支持，但普遍性未确立 |
| **允许结论层级** | `provisional_gap` |

### C5：中国的三方协商机制在形式上符合法团主义定义，但缺少法团主义的核心前提（自主工会 + 合法罢工权）
