# 案例研究：中国——"法团主义而没有劳工"？

Last updated: 2026-07-11

---

## 1. 为什么中国是法团主义理论的"试金石"？

中国案例对法团主义理论的挑战在于：**它在制度外壳上与法团主义高度相似，但在运行逻辑上可能偏离了法团主义的核心定义。**

具体来说：
- 中国有唯一合法的工会（ACFTU）——符合 Schmitter 的"垄断性顶峰组织"
- 中国有三方协商制度（2001-）——符合法团主义的"制度化利益协调"
- 中华全国总工会声称代表全体工人——符合"功能代表"原则
- 但 ACFTU 是党和国家的组成部分——不符合"组织自主性"这个社会法团主义的前提
- 罢工权在中国不合法——缺少"退出威胁"这个法团主义核心交易中的关键筹码

这引出了一个分析性的问题：**当法团主义的形式要件都满足，但其核心前提（自主工会 + 真实退出威胁）缺失时，这个制度还算是"法团主义"吗？如果不是，它是什么？**

---

## 2. 制度架构

### 2.1 中华全国总工会（ACFTU）

| 维度 | 描述 |
|------|------|
| **法律地位** | 《工会法》规定为唯一合法工会组织。ACFTU 拥有"垄断性代表权"——在同一企业内不允许存在第二个工会 |
| **组织结构** | 五级层级：全国总工会 → 省级总工会 → 市级总工会 → 县级总工会 → 基层工会（企业层面） |
| **领导任命** | 全总主席历来由中共中央政治局委员或中央书记处书记级别的干部担任。各级工会干部由同级党委管理，不是工人选举产生 |
| **经费来源** | 2% 工资总额工会经费（企业拨缴），其中 40% 上缴上级工会，60% 留基层。经费来源的稳定性保证了组织存在，但对企业的依赖也约束了其对抗性 |
| **会员规模** | 约 3 亿会员（官方数据），是世界上最大的工会组织 |

### 2.2 三方协商制度（2001-）

2001 年 8 月，劳动和社会保障部（现人社部）、中华全国总工会、中国企业联合会/中国企业家协会（CEC-CEDA）联合建立了**国家协调劳动关系三方会议制度**。此后各省、市、县逐级建立了对应机构。

| 三方 | 组织 | 实际功能 |
|------|------|---------|
| **政府** | 人力资源和社会保障部 | 议程设定、规则制定、最终裁决（三方中最强大的一方） |
| **劳工** | 中华全国总工会（ACFTU） | 传达劳工关切，但在劳资冲突中通常选择的立场是"协调"而非"代表工人对抗雇主" |
| **雇主** | 中国企业联合会/中国企业家协会（CEC-CEDA） | 代表国有企业和大中型民营企业。外资企业和大量小型民营企业的雇主利益并不通过此渠道表达 |

### 2.3 工资集体协商制度

2010 年以来，中国大力推广"工资集体协商"——由工会代表工人与雇主签订集体工资合同，约定工资标准、增长机制和劳动条件。

**运行实态**：
- 覆盖面逐年扩大（官方统计覆盖率超过 80% 的已建工会企业）
- 但签约质量参差不齐——大量合同是"模板化"的（复制粘贴最低工资标准）
- 在非公有制企业中，工会主席通常由企业管理者兼任（如 HR 经理），"协商"变为企业对自己的通知
- 真正的有博弈的集体协商主要集中在少数大型国有企业（汽车、钢铁等）

### 2.4 劳动仲裁与劳动争议处理

| 机制 | 描述 |
|------|------|
| **劳动仲裁** | "一裁两审"制——劳动仲裁前置，不服仲裁才能到法院。名义上是保护工人（免费、快速），实际上增加了维权门槛 |
| **劳动争议趋势** | 2008 年《劳动合同法》实施后，劳动争议案件数量爆炸式增长。但绝大多数案件是个人维权（追讨欠薪）而非集体谈判 |
| **集体劳动争议** | 当工人集体维权时（如罢工、堵路），通常不是通过工会或仲裁解决，而是通过地方政府的**维稳机制**——党委政法委、公安局、信访办介入，以"调解"（实质上的压力和解）终结 |

## 3. 历史路径

| 阶段 | 年份 | 关键事件 | 法团主义含义 |
|------|------|---------|------------|
| **革命工会时期** | 1921-49 | 中共领导的工会运动，1925 年中华全国总工会成立（比新中国成立早 24 年） | 此时的 ACFTU 是真正的"战斗工会"——组织罢工、动员工人 |
| **列宁主义改造** | 1949-78 | 新中国成立，工会被定义为"党联系工人群众的纽带"（列宁"传送带"理论） | 从"战斗工会"到"行政管理工具"的转型 |
| **改革初期的工会恢复** | 1978-92 | 工会恢复活动，但国企改革导致工人利益受损。工会在保护工人（社会主义传统）和服从党的领导之间陷入两难 | 第一次结构性张力——国企下岗潮中工会的无力感 |
| **市场转型与私有部门扩张** | 1992-2000s | 外资和私营企业成为主要就业增长来源。农民工大规模进城——但他们大多不在工会覆盖范围内 | ACFTU 的组织覆盖率从国企扩到私企成为核心挑战 |
| **三方协商制度化** | 2001 | 国家协调劳动关系三方会议制度建立 | 形式上的法团主义外壳正式建立 |
| **劳动合同法时代** | 2008 | 《劳动合同法》实施——最激进的劳工保护立法之一（规定书面合同、限制短期合同、裁员补偿） | 立法过程中的劳资博弈（资方强烈反对但最终被工人和知识分子联合推动通过） |
| **南海本田罢工与工人自组织** | 2010 | 佛山南海本田汽车零部件厂工人自发罢工要求加薪——ACFTU 最初缺席，后来介入协调 | 标志性事件：工人绕过了工会，自行组织罢工——"ACFTU 的代表性危机" |
| **新时代** | 2012- | 加强党对工会的领导，"群团改革"——要求工会"去机关化、去行政化" | 改革方向是将工会从"行政末端"转化为"真正的群众组织"还是更强地整合进党的架构？——方向仍在演化中 |

## 4. 形式上的法团主义相似性

| 法团主义要素（Schmitter 1974） | 中国的对应 |
|------------------------------|-----------|
| 有限数量的垄断性顶峰组织 | ✅ 全总是唯一合法工会，CEC-CEDA 是官方认可的雇主代表 |
| 强制性/非竞争性 | ✅ 法律禁止成立独立工会 |
| 层级化秩序 | ✅ 五级工会体系 |
| 功能分化 | ✅ 还有妇联、工商联、共青团等功能组织（超法团主义网络） |
| 国家承认或颁发执照 | ✅ 工会法授予 ACFTU 唯一合法地位 |
| 代表垄断权换取对领导层选择和需求表达的控制 | ✅/❌ 控制是单向的——国家对工会的控制很强，但工会对工人的控制不一定有效 |

## 5. 实质上的根本差异

### 5.1 组织自主性的缺失

社会法团主义（瑞典、奥地利）和国家法团主义（法西斯意大利）都假设——虽然程度不同——顶峰组织具有**至少部分的组织自主性**：工会领导人虽然可能与政党有历史联系（如瑞典 LO 与社民党），但工会自身是一个独立法人，有其独立的决策程序、财务和动员能力。

ACFTU 不是一个"独立于党和国家的组织"——它是党和国家机构的一部分。全总党组向党中央汇报工作；省级工会主席由省委推荐、全总批准——实质上是党管干部。ACFTU 对工人的代表性是**国家授予的**，而不是从工人的集体行动中**生长的**。

### 5.2 退出威胁的缺失

法团主义的核心交易逻辑——"放弃对抗以换取制度利益"——以**退出威胁的可信性**为前提。工会必须能够说："如果不满足我们的条件，我们就罢工。"然后选择**不使用**这个威胁（作为对制度合作的承诺）。如果谈判破裂，退出威胁必须是真实可用的。

在中国：罢工权不被法律明确保障。集体劳动争议中，工人绕过了工会自行组织停工——但面临法律（聚众扰乱社会秩序）和政治风险。工会没有"放弃罢工"的筹码可以交换——因为它从来不曾合法地拥有它。

### 5.3 代表的双层断裂

中国法团主义最突出的现象是"上层法团主义，基层真空"：

| 层面 | 运作 | 问题 |
|------|------|------|
| **上层**（全国/省级三方会议） | ACFTU 参与三方协商，出席体面的会议，发表工资增长建议 | 这些建议与基层工人的切身利益之间的因果链长而弱 |
| **基层**（企业层面） | 工会主席通常是企业 HR 经理或中层管理人员兼任 | "协商"双方坐在一张桌子上——但他们是同一个人 |
| **中间**（市县） | 市县总工会部分起到协调作用，但在重大劳资冲突中通常被"维稳"机制取代 | 劳动仲裁、法院、信访的"竞争性管辖权"削弱了工会作为工人第一求助对象的地位 |

这种"上层法团主义，基层真空"在经典法团主义（无论是社会版还是国家版）中都没有精确的对应物。在法西斯意大利，工会虽然不代表工人真正利益，但国家有组织地使用暴力确保工人服从。在中国的私营工厂里，国家没有在每个工厂派驻黑衫军——工人有不满，但没有制度化的代表渠道（工会是资方的人），也没有合法对抗工具（罢工不合法），也没有暴力的日常镇压。**这是一种组织真空中的原子化。**

### 5.4 党的三维超越

在经典法团主义的三方架构（国家-劳工-雇主）中，国家是三角中的一角。在中国，**党在三角之上、之外、之内同时存在**：

- **之上**：党中央领导全总、雇主协会和政府部门的党组
- **之外**：当三方协商失败时，党委政法委、维稳办、信访办以"非三方"的身份介入
- **之内**：三方中每一方的党组都向同级党委汇报

这使得"三方协商"在概念上区别于经典法团主义——它更像是一个**党领导下的功能性分工**（党把社会管理任务分配给了不同部门），而不是**国家在调解独立的劳资双方**。

## 6. 学术界的四类定位

| 立场 | 代表学者 | 核心论点 | 对本包的启示 |
|------|---------|---------|------------|
| **列宁主义"传送带"** | 经典马列理论 | ACFTU 的本质不是法团主义组织，而是列宁主义的"传送带"——将党的意志传送到工人、把工人的信息反馈给党 | 用列宁主义而非法团主义框架分析，可以避免"看起来像法团主义"的陷阱 |
| **国家法团主义** | Anita Chan, Jonathan Unger | 1990s 后中国从列宁主义转向国家法团主义——ACFTU 从"群众动员工具"变为"利益协调机构" | 但这个论点的弱点是：ACFTU 并没有真的获得"协调利益"的功能——它仍在管理而非代表 |
| **碎片化威权主义** | Lieberthal, Oksenberg | 中国体制不是法团主义的层级整合，而是条块间碎片化的非制度化谈判——ACFTU 只是碎片之一，不是垄断顶峰 | 解释了为什么三方协商的制度产出在各地区差异极大 |
| **政党领导型法团主义** | 部分中国学者 | 法团主义的三方结构上叠加了党的领导——这是对法团主义的"中国化创新" | 这个概念在分析上是否比"列宁主义传送带"更强，仍有待检验 |

**本包的立场**：标签争议本身反映了中国案例的理论价值——它位于多个理想型的交叉点上，没有一个标签完全适用。与其争论用什么标签，不如逐一检验法团主义的四个核心要素在中国的成立程度：

| 要素 | 在中国成立的程度 |
|------|----------------|
| 垄断性顶峰组织 | ✅ 形式成立 |
| 组织自主性 | ❌ 不成立——ACFTU 是党和国家机构一部分 |
| 退出威胁的可信性 | ❌ 不成立——罢工权不合法 |
| 双向控制（向上代表+向下约束） | ⚠️ 部分成立——向上代表弱（基层真空），向下约束也弱（工人自组织绕过工会） |

**如果四个要素中只成立一个半，那么这个制度更准确的描述可能是：一个拥有法团主义制度外壳的列宁主义-威权混合治理体系。**

## 7. 与新加坡和韩国的三角比较

| 维度 | 中国 | 新加坡 | 韩国（朴正熙时期） |
|------|------|--------|-----------------|
| **工会与政党关系** | ACFTU 是党的组成部分 | NTUC 是 PAP 的有机延伸 | FKTU 是国家创建并控制的工具 |
| **罢工权** | 不合法 | 1968 年后实质取消 | 法律上有，实质无 |
| **控制工具** | 党管干部 + 维稳体制 | HDB/CPF 物质锁定 + 基层网络 | KCIA 暴力镇压 + 发展主义意识形态 |
| **基层代表性** | 弱——私营企业工会主席常由资方兼任 | 中——NTUC 在基层有一定存在但非对抗性 | 弱——工人不信任 FKTU |
| **是否有民主化经历** | 否 | 否 | 是（1987）——国家法团主义在民主化后崩溃 |
| **与经典国家法团主义的距离** | 比法西斯意大利更制度化、更少暴力；但比新加坡更碎片化 | 比中国更精致、更整合 | 比中国更暴力、更赤裸 |
| **理论分类困难** | 法团主义外壳 + 列宁主义内核 + 碎片化执行 | 国家法团主义精致版 + 行政国家特征 | 纯正国家法团主义 → 崩溃 → 冲突性多元主义 |

## 8. 对本包核心论断的贡献

| 论断 | 中国的贡献 |
|------|-----------|
| **C1 退出-发声交易** | 中国展示了"没有退出威胁的假法团主义"——当一方完全没有退出威胁时，三方协商变为两方决策（政府+雇主），劳工成为政策对象而非参与方 |
| **C2 社会/国家法团主义区分** | 中国的案例提示需要在国家法团主义内部进一步区分——是"暴力支撑的国家法团主义"（法西斯意大利、朴正熙韩国）还是"党政整合的国家法团主义"（中国、新加坡的非暴力版） |
| **C4 法团主义陷阱** | 中国的"陷阱"不来自合作导致的动员能力衰减（因为动员能力从未真正存在），而来自**组织真空**——当工人不满积累时，没有工会这个"安全阀"，压力只能通过非制度化渠道（突发性集体停工、信访、网络舆情）释放 |
| **C5 中国的法团主义定位** | 本案例本身就是 C5 的展开——"contested"状态的确证 |

## 9. 未解决的问题

- **群团改革的真实方向**：2015 年以来的工会"去行政化"改革是将 ACFTU 推向真正的利益代表组织（走向法团主义），还是进一步整合进党的治理架构（强化列宁主义传送带）？
- **平台经济与新就业形态**：外卖骑手、网约车司机——中国有数千万"不隶属于任何企业的劳动者"。ACFTU 正在推动将他们纳入工会覆盖——但如果工会在企业层面已经代表性不足，它如何代表"无企业劳动者"？
- **罢工权立法的可能性**：如果中国未来在某个时刻将罢工权有限合法化（如在集体协商破裂时），这将对 ACFTU 和整个劳资制度产生何种冲击？是会走向社会法团主义，还是会像韩国 1987 年一样爆发？
- **农民工的代际变化**：新一代农民工（1990s 后出生）对权利的预期高于父辈，对 ACFTU 的认同低于父辈。这种代际变化如何影响法团主义制度的运行？
