# 20 Gap Table / 研究缺口表

Last updated: 2026-07-11

---

## 缺口清单

### G1：法团主义与中国体制的系统比较缺乏严格的概念框架

| 项目 | 内容 |
|------|------|
| **缺口描述** | 目前"中国是不是法团主义"的争论缺乏一个各方同意的比较基准。"国家法团主义"、"碎片化威权主义"、"政党领导型法团主义"等标签各有一定解释力，但没有被一个统一的分析框架整合。 |
| **类别** | `confirmed` |
| **最小验证** | 发展一个可操作的多维度比较框架（组织自主性、代表的真实性、退出威胁的存在、国家对议程的控制程度），用于比较中国与经典法团主义案例 |
| **与用户资产匹配** | ⭐⭐⭐⭐——你已经在做类似的概念框架工作（维度拆解） |

### G2：法团主义陷阱的跨案例经验检验

| 项目 | 内容 |
|------|------|
| **缺口描述** | "法团主义导致工会动员能力衰减"作为一个理论猜想有意义，但缺乏跨案例的系统经验检验。需要区分"动员能力衰减是法团主义合作导致的"和"动员能力衰减是去工业化和服务业碎片化导致的"。 |
| **类别** | `suspected` |
| **最小验证** | 收集 8-10 个法团主义国家的工会密度和罢工天数的长时段面板数据，控制去工业化变量，检验法团主义参与年限是否独立预测动员能力下降 |

### G3：法团主义分析框架在非劳资领域的可迁移性

| 项目 | 内容 |
|------|------|
| **缺口描述** | 法团主义的核心逻辑（垄断代表 + 制度化协商 + 退出威胁交换）是否可以外推到劳资关系以外的领域？——央地利益协调（南网）、气候治理（绿色法团主义）、平台经济治理？目前只有零星讨论，没有系统的"可迁移条件"分析。 |
| **类别** | `weak` —— 这是一个"有趣的方向"而非"领域公认的缺口" |
| **最小验证** | 用比较案例方法，分析至少两个非劳资领域的"类法团主义"安排（如南网和德国煤炭退出委员会），检验法团主义核心逻辑的哪些要素可以平移、哪些不能 |

### G4：资本退出威胁下降（reshoring）是否正在为法团主义复兴创造条件？

| 项目 | 内容 |
|------|------|
| **缺口描述** | 法团主义的衰退被认为部分源于资本获得了不对称退出威胁。如果当前地缘政治推动制造业回流、供应链本地化，资本退出威胁的下降是否会恢复法团主义的谈判前提？ |
| **类别** | `suspected` —— 逻辑上有趣，时效性太强，无法定论 |
| **最小验证** | 跟踪已发生实质性 reshoring 的行业/地区（如美国 CHIPS 法案后的半导体制造），观察是否出现工资增长压力上升和工会谈判地位改善的迹象 |
