## 1. 内圈知识（Core）——已写入教科书的

| 知识点 | 成熟标志 | 核心内容 |
|--------|---------|---------|
| 委托-代理框架 | 1970s 信息经济学确立，已成标准工具 | 央地关系 = 中央（委托人）委托地方（代理人）执行政策，核心问题是信息不对称和激励不相容 |
| 财政联邦主义第一代 | Oates 1972 "分权定理" | 在偏好异质的辖区，分权提供公共品优于集权；分权程度应与外溢效应匹配 |
| Tiebout 排序模型 | Tiebout 1956 | 居民通过"用脚投票"选择最符合自己偏好的地方政府组合 |
| 联邦制 vs 单一制的制度差异 | 比较政治学常识 | 宪法保障 vs 法律授权；退出权；地方独立执法系统 |
| 中国历代央地制度演变基本史实 | 历史学界基本共识 | 秦汉郡县制 → 唐藩镇 → 宋强干弱枝 → 明督抚 → 清督抚常态化的基本脉络 |

**你的位置**：这些内圈知识你大部分已经通过种子文档和一般阅读掌握了。委托-代理框架和你理解的计算物理中的优化问题有结构同构。

## 3. 真正边界（Frontier）——当前活跃的开放问题

### 3.1 分权的因果效应识别

**问题**：分权（decentralization）到底对经济增长、公共服务、腐败控制有什么因果效应？目前绝大多数研究是跨国相关性分析，内生性问题严重（是好制度导致了分权，还是分权导致了好的结果？）。

**为什么难**：
- 分权程度本身是内生的（国家选择分权程度，不是随机分配的）
- 缺乏好的自然实验
- 分权是多维度的（政治、财政、行政），很难做一个干净的"处理变量"

**状态**：🔥 非常活跃。中国 1994 年分税制改革、印度 1990s 的 Panchayati Raj 改革等被用作准自然实验。

### 3.2 信息技术如何改变央地权力平衡

**问题**：大数据、实时监控、在线审计是否从根本上改变了委托-代理框架中的信息不对称假设？如果是，央地关系的最优制度设计应该怎么调整？

**为什么新**：传统的央地关系理论假设信息是稀缺的、向上的、容易被扭曲的。但信息技术改变了这三个假设。如果中央可以实时、准确地看到地方的行为，那"授权"的理由还充分吗？还是说信息透明反而会让中央过度干预？

**状态**：🔥 新兴热点。目前主要是概念性讨论，缺乏系统的经验研究。

### 3.3 非正式制度在央地关系中的角色

**问题**：正式制度（法律、规章）只描述了央地关系的一部分。地方官员有大量非正式的协商、谈判和变通手段。这些非正式制度是正式制度的"润滑剂"（帮助僵化制度适应地方多样性）还是"腐蚀剂"（削弱中央权威、制造寻租空间）？

**为什么难**：非正式制度天然难以观测和测量。

**状态**：🔶 持续有产出，但进展缓慢。

### 3.4 多层级治理中的"最优层级数"

**问题**：一个国家应该有几级政府？中国有中央-省-市-县-乡五级，美国有联邦-州-县-市四级。层级太多 → 信息扭曲和代理成本；层级太少 → 每个层级管得太宽。存在"最优层级数"吗？如果存在，它取决于什么（国土面积、人口、多样性、技术）？

**状态**：🔸 零星研究，未形成系统理论。

### 3.5 任务型组织的制度演化

**问题**："领导小组"、"指挥部"等临时性集权机构在什么条件下会从临时走向永久？有没有制度设计可以防止这种蜕变？

**为什么重要**：这是你种子文档中现代治理部分的核心主张——"因事而聚，事毕则散"。但这个主张本身是乐观的——历史上大量"临时"机构最终都永久化了（明朝督抚就是最好的例子）。我们需要理解"临时→永久"的机制条件。

**状态**：🔸 有案例研究，缺乏一般性理论。

## 4. 伪缺口（Pseudo-gap）——看似开放但非真问题

| 伪缺口 | 为什么不是真缺口 |
|--------|----------------|
| "集权和分权哪个更好？" | 这是一个被过度简化的问题。答案永远是"取决于条件"。真问题是"在什么条件下何种制度安排产生何种效果"。 |
| "中国应该向美国学习联邦制吗？" | 框架误配。制度移植不考虑路径依赖和历史条件，问题本身就是错的。 |
| "只要加强监督就能解决央地矛盾" | 忽略了监督本身有成本，过度监督会扼杀地方能动性。这是一个优化问题，不是极值问题。 |
| "信息技术让央地矛盾消失了" | 信息透明降低了信息不对称，但没有消除利益冲突。地方仍然可能有不同于中央的利益。 |

## 5. 你的个人切口（Personal Entry Points）

基于你的知识整合者背景，以下是几个结合你已有知识的切入点：

### P1：用控制论语言重述央地关系

你已有的系统科学/控制论知识可以直接映射：
- 央地关系 = 层级控制系统（hierarchical control system）
- 监督 = 反馈回路
- 地方自由裁量权 = 控制器的增益参数
- 信息扭曲 = 传感器噪声
- 条块 = 多输入多输出（MIMO）控制系统

这个映射本身不解决任何政治学问题，但它提供了新的建模语言，可能产生新的洞察。

### P2：历史案例的结构化比较

你对唐/宋/明的分析已经有三案例比较的雏形。可以通过以下方式升级：
- 统一分析框架（如委托-代理模型的三要素：信息、激励、约束）
- 增加更多比较案例（罗马帝国、奥斯曼帝国、莫卧儿帝国）
- 用模糊集定性比较分析（fsQCA）或过程追踪（process tracing）方法

### P3：agent-based 建模

你的计算背景可以直接支持构建央地关系的 agent-based model：
- 中央 agent：分配资源、设定规则、监督
- 地方 agents：执行政策、追求自身利益、可能瞒报
- 环境：外部威胁（需要行动集权）、内部多样性（需要行政分权）
- 研究问题：在什么参数设定下系统表现出"一放就乱、一收就死"的周期行为？

这是一个低门槛、高潜力的计算社会科学项目。
