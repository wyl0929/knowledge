# 20 Gap Table / 研究缺口表

Last updated: 2026-07-08

---

## 使用说明

本文档列出央地关系研究中的知识缺口，区分 confirmed / suspected / weak / not-a-gap。每个 gap 附带最小验证方式。这是 Phase 6（Gap Table）的产出，用于支撑 Phase 8（Project Candidates）。

---

## 缺口清单

### G1：缺乏一个整合"权力流向"和"权力形态"的二维分析框架的形式化

| 项目 | 内容 |
|------|------|
| **缺口描述** | 现有文献中，"集权/分权"通常被当作一维连续变量处理（从完全集权到完全分权）。但用户种子文档指出，宋朝模式（决策集权 + 执行分散）和唐朝模式（决策分散 + 执行集中）在一维轴上可能落在"中间"，但结构完全不同。缺少一个系统的二维分析框架来捕捉这种差异。 |
| **类别** | `suspected` — 直觉上合理，但需要确认是否已有文献做了类似区分 |
| **为什么重要** | 如果这个区分成立，大量用一维度量分权程度并回归到治理绩效的跨国研究可能遗漏了关键的结构维度 |
| **最小验证** | 检索政治学和公共行政文献中关于 decentralization 的多维度量方案（如政治/行政/财政分权的标准区分），确认本包提出的"执行权拆散 vs 打包"是否已被已有框架覆盖 |
| **如果缺口成立** | 可发展为概念性论文或测量方法论文 |
| **如果缺口不成立** | 将本包的语言对齐到已有学术术语，保留其分析启发价值 |

---

### G2：缺乏对"临时性权力集中永久化"的机制条件的系统研究

| 项目 | 内容 |
|------|------|
| **缺口描述** | "领导小组"、"指挥部"等任务型组织声称"因事而聚，事毕则散"，但历史上大量"临时"制度都永久化了（唐朝节度使、明朝督抚）。在什么条件下临时集权会滑向永久？什么制度设计可以防止这种蜕变？现有文献以案例研究为主，缺乏统一的分析框架。 |
| **类别** | `confirmed` — 这是一个真实的知识缺口 |
| **为什么重要** | 任务型组织是现代治理创新中被广泛讨论的工具——如果不能回答"如何防止它变成新的节度使"，这个创新就是不完整的 |
| **最小验证** | 系统收集不少于 10 个"临时机构→永久化"和"临时机构→确实解散"的对比案例，用过程追踪法提取差异条件 |
| **文献连接** | 制度变迁理论中的"路径依赖"（Pierson 2004）、"制度 layering"（Thelen 2004）可以为此提供理论资源 |

---

### G3：信息技术对央地关系的实际因果效应缺乏严格经验研究

| 项目 | 内容 |
|------|------|
| **缺口描述** | 大量讨论声称信息技术（大数据、实时监控、在线审计）正在改变央地关系，但缺乏严格的经验研究来验证：(a) 信息技术是否真的降低了中央的监督成本？(b) 地方是否发展出了新的规避策略？(c) 对治理绩效的净效应是正还是负？ |
| **类别** | `confirmed` — 主要是概念性和案例性讨论，缺乏因果推断 |
| **为什么重要** | 如果信息技术确实改变了委托-代理的基本参数，那么大量基于传统信息不对称假设的央地关系理论可能需要修正。但如果效果被夸大，政策资源可能被错误配置。 |
| **最小验证** | 寻找一个信息技术在央地关系中引入的"自然实验"（如某个在线审计系统在不同省份/领域的渐次推广），做双重差分（DID）分析 |

---

### G4：分权程度的"最优值"缺乏可靠识别方法

| 项目 | 内容 |
|------|------|
| **缺口描述** | 财政联邦主义理论（Oates 1972）给出了分权最优程度的原则（分权收益 = 外溢效应 + 规模经济），但缺乏可操作的经验识别方法。跨国面板回归面临严重的内生性问题。 |
| **类别** | `suspected` — 理论方向清楚，方法瓶颈真实 |
| **为什么重要** | 如果不解决识别问题，"最优分权度"就始终是一个理论概念而非政策工具 |
| **最小验证** | 综述已有尝试解决内生性的文献（工具变量、断点回归、DID），评估哪些方法最有前景 |
| **注** | 这是一个方法困难多于理论困难的问题 |

---

### G5：控制论/系统科学框架对央地关系研究的分析价值未经验证

| 项目 | 内容 |
|------|------|
| **缺口描述** | 将央地关系映射为层级控制系统（反馈回路 = 监督，增益参数 = 地方自主权等）可能在概念上有吸引力，但不清楚这种映射能否产生超出已有政治学方法的洞察。类比本身不是证据。 |
| **类别** | `weak` — 这是一个"可能的切口"而非"领域的缺口"。该方向是否值得投入取决于能否找到最小可验证示例 |
| **为什么重要** | 如果成立，打开了用控制论/系统科学工具（稳定性分析、最优控制、系统辨识）分析治理问题的跨学科路径 |
| **最小验证** | 构建一个极简 agent-based 模型，展示在两个学科框架下对同一治理现象（如"一放就乱，一收就死"的周期性波动）的解释是否有实质差异 |
