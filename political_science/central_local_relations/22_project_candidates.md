### PC1：构建央地关系的控制论模型

```yaml
status: provisional
gap_connection: G5 (控制论映射)
operational_status: not_operationalized
```

**核心问题**：能否用一个形式化的层级控制系统模型重现"一放就乱，一收就死"的周期性行为？

**方法**：
- 将央地关系建模为双层控制系统：
  - 中央层：设定目标值，调整控制增益（监督强度/地方自主权程度）
  - 地方层：执行，产出观测值（可能包含噪声和偏差）
  - 反馈回路：中央根据观测调整控制增益
- 用 Python 数值仿真（ODE 或离散时间系统）
- 分析系统在什么参数区域表现出稳定、振荡、发散等行为

**成功标准**：
- 模型能重现至少两种已知的历史/经验模式（如"监督过强→地方失去能动性→绩效下降"和"监督过弱→地方失控→绩效波动"）
- 模型的相图能给出"稳定区"（治理绩效良好的参数组合）

**风险**：
- 模型可能只是在"重新描述"已知现象，没有产生新洞察
- 政治系统的行为可能过于复杂，低维控制模型无法捕捉关键动态
- 模型参数缺乏经验校准依据

**与用户资产匹配度**：⭐⭐⭐⭐⭐（完美匹配计算物理/系统科学背景，低数据需求）

**推荐第一步**：用一个极简 Python 脚本（< 200 行）建模双层控制系统，观察是否能产生周期性行为。

### PC2：历史案例的结构化比较——什么条件驱动了"临时集权的永久化"？

```yaml
status: provisional
gap_connection: G2 (临时集权永久化)
operational_status: not_operationalized
```

**核心问题**：在什么制度条件下，临时性的权力集中（节度使、督抚、领导小组）会滑向永久化？

**方法**：
- 案例选择：至少 8-10 个"临时集权"的历史/当代案例，包含永久化的（唐节度使、明督抚）和非永久化的（某些确实解散的领导小组/指挥部）
- 用过程追踪（process tracing）或定性比较分析（QCA）方法
- 提取差异条件：任务性质（是否可完成）、制度制衡强度、信息透明度、任期限制执行情况等

**成功标准**：
- 识别出至少 2-3 个区分"永久化"和"非永久化"的充分或必要条件
- 提出的机制条件与已有制度变迁理论（路径依赖、制度 layering）兼容

**风险**：
- 案例可比性存疑（跨越时代和政体）
- "非永久化"案例可能更难找到和记录（成功了就不被注意）
- 方法门槛较高（需要学习 QCA 或过程追踪）

**与用户资产匹配度**：⭐⭐⭐（历史知识有基础，但需要学习方法工具）

### PC3：二维分权框架的概念论文

```yaml
status: provisional
gap_connection: G1 (二维分析框架)
operational_status: not_operationalized
```

**核心问题**：现有文献是否已经区分了"权力流向"和"权力形态"？如果没有，发展一个系统的二维分析框架的学术贡献是什么？

**方法**：
- 系统检索政治学/公共行政中关于 centralization/decentralization 的概念文献
- 如果确认已有框架未充分覆盖"权力形态"维度，提出补充框架
- 用比较案例（至少包括中国唐宋明、美国联邦制、一个欧洲国家）展示框架的分析价值

**成功标准**：
- 明确论证已有文献的覆盖范围和不覆盖范围
- 新框架至少在一组比较案例中显示出比已有框架更强的区分力
- 论文具有可发表的概念贡献

**风险**：
- 检索后发现已有文献已经充分覆盖了该维度（学术上的"重新发明轮子"）
- 概念论文发表难度较高（需要顶级期刊或 resort 到较低层次期刊）

**与用户资产匹配度**：⭐⭐⭐⭐（种子文档已经包含核心洞见，但需要大量文献工作）

### PC4：一个极简的 agent-based 央地关系模型

```yaml
status: provisional
gap_connection: G1 (二维框架) + G5 (控制论映射)
operational_status: not_operationalized
```

**核心问题**：在什么条件下，一个多层级治理系统会自发表现出"一放就乱，一收就死"的周期行为？这种行为的涌现需要哪些最小条件？

**方法**：
- 构建 ABM：
  - 中央 agent：设定监督强度 α 和惩罚力度 β
  - 地方 agents（N=10-50）：各自有私有信息、偏好，可以选择遵从或偏离中央指令
  - 环境：外部冲击随机到达，需要地方做出响应
- 中央根据观测到的绩效调整 α（类似增益参数）
- 观察系统在不同 α-β 参数组合下的长期行为

**成功标准**：
- 模型在特定参数区展现出"中央加强控制→短期绩效改善→长期绩效下降（因为地方失去了能动性）→中央放松控制→短期绩效改善→地方过度冒险→绩效下降→中央再次加强控制"的周期
- 周期行为和参数的关系可以被清晰地可视化

**风险**：
- 参数太多，结果可能是"通过调参制造想要的任何行为"
- 与 PC1 可能重叠（需要决定用 ODE/系统动力学还是 ABM）

**优先级**：如果想走计算社会科学路线，PC1 + PC4 可以合并为两步走——先用系统动力学验证基本逻辑，再用 ABM 增加异质性

**与用户资产匹配度**：⭐⭐⭐⭐⭐（Python 建模能力直接可用）
