# 11 Term Disambiguation / 术语澄清与概念边界

## 1. 最容易被混淆的核心概念

### 1.1 "政治" (politics) ≠ "政府" (government) ≠ "国家" (state)

这是政治学入门最常见的混淆。

| 概念 | 粗略含义 | 为什么容易混淆 |
|---|---|---|
| **政治** (politics) | 关于"谁得到什么、什么时候、怎么得到"（Lasswell 经典定义）的权力分配过程 | 日常语言中"政治"常被等同于"政府做的事" |
| **政府** (government) | 一套制定和执行公共决策的制度机构与人员 | 政府是政治的载体之一，但政治也发生在家庭、公司、国际组织中 |
| **国家** (state) | 在特定领土上垄断合法暴力使用权的制度化政治实体（Weber 定义） | 国家比政府更持久；政府换届但国家（通常）延续 |

**安全理解**：政治是**过程**（权力的分配与竞争），国家是**舞台**（制度化的强制结构），政府是**演员班子**（当前掌权者）。三者相关但不重合。

### 1.2 "权力" (power) 的多种面孔

政治学的核心概念"权力"至少有三个维度（Steven Lukes, 1974）：

- **第一维：决策权** —— A 能让 B 做 B 本来不会做的事（Dahl 的行为主义定义）。这是最直观的权力。
- **第二维：议程设置权** —— A 能阻止某些议题进入讨论（Bachrach & Baratz）。"不让你上桌"也是一种权力。
- **第三维：偏好塑造权** —— A 能让 B 想要 A 想要的东西，B 甚至不觉得自己被操控（Lukes 的激进观点）。这是最隐蔽也最有争议的权力。

**为什么这个区分重要**：不同研究范式关注不同维度的权力。行为主义只看第一维，马克思主义和某些建构主义会看第三维。

### 1.3 "制度" (institution) 的宽窄两种含义

- **窄义（旧制度主义）**：正式的组织结构和法律规则——议会、法院、宪法、选举法。
- **广义（新制度主义）**：稳定的、被反复遵守的行为规则和规范，包括非正式制度——惯例、习俗、话语规范、"我们这儿就是这么做的"。

**关键区分**：新制度主义认为，非正式规则（如腐败文化、官僚惯例）对政治结果的解释力可能超过正式制度。

## 2. 相邻领域边界

### 2.1 政治学 vs 政治哲学 (Political Philosophy)

| | 政治学 | 政治哲学 |
|---|---|---|
| 核心问题 | "实际上发生了什么？为什么？" | "应该发生什么？什么是正义？" |
| 方法 | 经验观察、数据分析、案例比较 | 概念分析、思想实验、规范论证 |
| 典型作品 | 《民主的经济理论》(Downs, 1957) | 《正义论》(Rawls, 1971) |
| 交叉地带 | 规范政治理论 (normative political theory) 处于两者之间 | |

**边界规则**：政治学以经验解释为主，政治哲学以规范论证为主。但二者不是完全分离的——经验发现可以挑战规范假设，规范框架可以指导经验研究的问题选择。

### 2.2 政治学 vs 经济学 vs 社会学

| 学科 | 核心解释变量 | 典型方法论 |
|---|---|---|
| **政治学** | 权力、制度、利益聚合 | 案例比较、制度分析、定量统计、形式模型 |
| **经济学** | 稀缺性、激励、效率 | 数学模型、计量经济学、实验 |
| **社会学** | 社会结构、阶层、文化、网络 | 调查统计、田野调查、网络分析、历史比较 |

**交叉领域**：
- **政治经济学** (political economy)：经济与政治的互动——市场如何塑造权力，权力如何塑造市场
- **政治社会学** (political sociology)：社会结构如何影响政治——阶级、种族、宗教与政治行为
- **理性选择政治学**：把经济学的理性人假设引入政治分析

### 2.3 政治学 vs 法学

法学关注"规则是什么、如何适用"，政治学关注"规则为什么是这样、谁受益"。宪法学与比较政治学的交叉尤其紧密。

## 3. 常见错误等同

| 错误等同 | 为什么错 | 更安全的理解 |
|---|---|---|
| "民主 = 选举" | 选举是民主的必要但不充分条件；存在"选举威权主义"（有选举无实质民主） | 民主是一个多维概念，包含竞争、参与、自由、法治等多个维度 |
| "威权 = 没有制度" | 威权政体同样有复杂制度（如党内选举、派系平衡） | 制度存在与否 ≠ 制度是否民主 |
| "政治学 = 时事评论" | 政治学追求系统性因果解释和理论构建，而非对当下事件的即时判断 | 政治学使用科学方法研究政治现象，但研究对象本身是历史性的 |
| "比较政治 = 比哪个国家好" | 比较方法是控制变量、寻找因果机制的工具，不是打分排名 | 比较政治的核心是通过系统比较发现因果关系 |

## 4. 本领域关键术语速查

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 合法性 | legitimacy | 被统治者认为统治是"对的"或"可接受的"——不只是因为害怕惩罚 |
| 主权 | sovereignty | 对特定领土和人口的最高政治权威 |
| 代表 | representation | 一个人或机构"站在别人的位置上"行动或发言的政治关系 |
| 利益聚合 | interest aggregation | 把分散的个人偏好转化成集体选择的过程（政党是典型工具） |
| 集体行动问题 | collective action problem | 个体理性导致集体非理性——如"公地悲剧"、"搭便车" |
| 路径依赖 | path dependence | 早期选择锁定了后续可能性——"历史重要" |
| 现代化理论 | modernization theory | 经济发展→社会结构变化→民主化的经典假说（有争议） |
|  selectorate theory | 选择人理论 | 领导人靠满足"致胜联盟"来维持权力（Bueno de Mesquita） |

## 5. 概念边界未解决的问题 (NEEDS_VERIFICATION)

- "国家能力" (state capacity) 的精确定义在不同文献中差异很大——有的强调征税能力，有的强调官僚专业性，有的强调领土控制。目前尚无统一的操作化标准。
- "民粹主义" (populism) 是否属于一个独立的政治体制类别，还是只是民主或威权体制中的一种策略——学界仍在争论。
- "政治极化" (political polarization) 的测量——精英极化与大众极化是否同步、是否互为因果——证据方向不一致。
