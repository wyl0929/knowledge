# USER_BRIEF / 本次需求说明

Last updated: 2026-07-19

## 这份文件的作用

这里保存用户对本 field pack 的特殊要求。生成或更新本包中的任何主体文档前，agent 都必须先读取本文件。

## 路由决策

```yaml
detected_mode: quick_scan
selected_profile: general_interest (一般兴趣了解)
domain_archetype: social_science
confidence: high
```

## 用户原始需求

> 政治学的入门, 基本概念和研究范式. 作为 political_science 下的一个 field

## 当前有效要求

按 quick_scan + general_interest_profile 默认规则执行。不强行结合个人计算物理背景，不自动生成 gap table / project candidates / MVP。优先产出可读的入门指南、领域总述、术语澄清、领域地图、代表学者与文献、边界罗盘。

## 内容侧重点

- 希望重点展开：政治学的基本概念体系（权力、国家、制度、代表、合法性等）、主要研究范式（制度主义、行为主义、理性选择、建构主义、马克思主义等）、方法论概览（定量/定性/比较/形式模型）
- 希望简略处理：过于细节的国别政治史、当代政策辩论
- 暂时不需要涉及：中国政治的具体分析（已有独立 field pack 如 central_local_relations）

## 写作与呈现偏好

- 语言与风格：主体中文，重要术语首次出现标注英文；先直觉后术语；先整体链条再子方向
- 期望深度：适合有学术训练但非政治学背景的读者，能建立基本地图和边界感
- 是否需要公式 / 流程 / 作品例子 / 图表：适当使用流程图和比较表格；给出经典作品/学者作为锚点
- 是否需要阅读清单：是，在 paper_registry 和 beginner_guide 中给出入门阅读路径
- 是否需要派生子方向：暂不需要，但保留后续派生可能

## 与父方向的继承关系

本包为 political_science 下的独立 field pack，不继承自任何父包。与 central_local_relations、corporatism、us_two_party_politics 为平行关系。
