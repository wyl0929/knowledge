# 00 Beginner Guide / 人话入门指南

Last updated: 2026-08-17

## 初学者版一句话

把跟人闲聊听到的话，当成**带噪声的测量数据**，用一套固定的记录、编码和交叉验证流程处理，最后得到对当地状况的、标明了可信度的判断。

## 核心直觉：聊天是高噪声信号

你打车、买菜、散步时听到的话，天然是"脏数据"：

- 有人爱抱怨，有人爱报喜，有人只说你想听的；
- 一句话可能是亲身经历，也可能是三手传闻；
- 同一个人今天和明天说的可能不一样；
- 有些话题对方根本不会直说。

但这不代表这些信息没用。恰恰相反：**日常对话里藏着任何问卷都问不出来的东西**——人们对"好工作""公平""希望"这些词的真实理解方式。问题是噪声太大，单靠一条信息几乎无法判断真假。

所以本领域的基本立场是：**不追求单条信息的"真"，而是追求多条信息拼出来的"稳"**。这就像测量一个有噪声的物理量：单次测量没有意义，多次测量取统计特征才有意义——只是这里的"统计"不是数数，而是**分层、编码、交叉验证**。

## 两个引擎：社会学给"语法"，工程学给"工艺"

种子讨论文档提出了一个很好的分工比喻：

| | 社会学理论 | 调研工程方法 |
|---|---|---|
| 回答的问题 | 该听什么、怎么理解、怎么归纳 | 怎么系统采集、降噪、验证 |
| 角色 | 语法 | 工艺 |
| 例子 | 不把对方的话当客观事实，而当主观定义 | 信息卡片、三值编码、信号强度加权 |

只懂理论的人，会聊得很深但不知道自己的判断有多可靠；只懂方法的人，会收集一堆整齐但空洞的数据。两者结合才有效。

## 四个理论透镜（该听什么）

1. **符号互动论**（symbolic interactionism）：人们依据事物对**自己**的意义行动。所以不要把对方的话当客观报告，而要追问："你说的'好工作'指什么？"不同人嘴里的同一个词，含义可能完全不同。

2. **常人方法学**（ethnomethodology）：社会秩序藏在人们习以为常的做法里。所以"废话"不废："你懂的""大家都这样"这类话，恰恰暴露了当地的潜规则和共识。

3. **社会分层与流动**（social stratification and mobility）：把人按职业、收入、教育归类后，**不同阶层对同一件事的感受差异本身就是信息**。"我再苦也要供孩子读书离开这里"这句话同时是经济陈述和政治陈述。

4. **社会资本与信任**（social capital and trust）：关系网络和信任是看不见的基础设施。多个人都说"各扫门前雪""没人出头"，这本身就是关于基层治理状态的证据。

## 一条流水线（怎么做到）

```
预设框架 → 自然提问 → 记录 → 信息卡片 → 编码归纳 → 交叉验证 → 形成判断 → 偏差标注
```

- **预设框架**：先把"经济政治状况"拆成可观察的小问题（就业、物价、办事、信任……），否则聊完发现只覆盖了两三个维度。
- **自然提问**：把框架问题翻译成日常话题。不问"你怎么看政府"，问"最近菜价涨了吗""办事方便吗"。
- **记录**：事后记关键词、原话、情绪，**包括对方的回避和沉默**。
- **信息卡片**：每条信息一张卡，写上来源、维度、原话、情绪、可信度。例如：`01 | 出租车司机，男，45岁 | 就业 | "以前晚上能跑十几单，现在五六单都难" | 无奈 | 高`。
- **编码归纳**：把卡片强制归入"事实 / 评价 / 传闻"三类，再看频率与强度。
- **交叉验证**：A 说 vs B 说、言论 vs 行为、聊天 vs 实地观察。一条信息只有被独立信源支持时才值得信任。
- **形成判断**：用"现象—模式—解释"的思路推进，并**给每条判断标证据强度**。
- **偏差标注**：诚实写下"我这些信息主要来自爱聊天的人，老人和不上街的人我没覆盖到"。

## 一个最小例子：出租车司机的话怎么处理

1. 司机说："以前晚上能跑十几单，现在五六单都难。"
2. 三值编码：这是**事实陈述**（他的亲身经营经历），不是评价或传闻。
3. 信号强度加权：亲身经历，权重高。
4. 交叉验证：再问另一位司机、看打车软件夜间车次、观察晚上街上的人流。三条独立线索都指向同一方向时，才升级为"夜间出行需求下降"的判断。
5. 偏差标注：司机群体只是"出行需求"的一个传感器，他们的收入还受平台抽成、油价影响——不能直接等同于全城消费水平。

## 三个常见误区

1. **把聊天当问卷调查**：闲聊不是标准化访谈。追问"这个词你指什么"比追问"选项 A 还是 B"更自然，信息量也更大。
2. **把"很多人这么说"当证据**：十个人说同一件事，可能只是同一条传闻传了十遍。要问"你自己见过吗"。
3. **把"以前好"当趋势**：回忆会被当下情绪染色。判断趋势要靠可验证的当下指标（关门店铺数、菜价），并且连续观察几个月。

## 一页纸总结

- 聊天 = 高噪声数据：单条不可靠，多条分层编码后可用。
- 两个引擎：社会学理论定“该听什么”，工程方法定“怎么处理”。
- 四个透镜：符号互动论、常人方法学、社会分层、社会资本。
- 一条流水线：框架 → 提问 → 记录 → 卡片 → 编码 → 验证 → 判断 → 偏差标注。
- 三个误区：把聊天当问卷、把重复传闻当证据、把回忆当趋势。
