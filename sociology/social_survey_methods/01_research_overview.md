# 01 Research Overview / 领域总述报告

Last updated: 2026-08-17

## 问题本身：一个双重性质的课题

用户的问题起点非常具体：**希望通过与本地人的日常对话，了解当地的经济与政治状况**。但聊天内容是发散的、碎片化的、带情绪和主观色彩的。目标是把离散的日常对话，转化为对当地状况的可靠判断。

种子讨论文档把这个问题的性质说得很清楚：它**既是社会学课题，也是社会调研的工程学问题**。

- 社会学课题：提供"为什么要这样看"的理论依据——关注日常互动、主观意义、社会结构。
- 工程学问题：提供"具体怎么做到"的操作方法——关注采样、降噪、编码、验证、误差控制。

两者的关系被概括为一句话：**社会学提供"语法"，工程学提供"工艺"。** 这一分工贯穿整个领域：理论决定该听什么、如何理解；方法决定如何系统化地采集、处理和验证信息。

## 语法侧：四个理论透镜

种子文档给出了四个核心理论视角，它们回答"该听什么、如何理解、如何归纳"：

1. **符号互动论**（symbolic interactionism）：人们依据事物对自己的"意义"行动，意义在社会互动中产生。调研含义：不把对方的话当作客观事实，而是当作其主观定义；追问关键概念（"希望""好工作""公平"）的具体含义；避免用自己的价值观误读对方。

2. **常人方法学**（ethnomethodology）：社会秩序隐藏在人们日常、习以为常的对话和行动方法中。调研含义：把日常对话当作正式数据；关注"索引性表达"（"你懂的""大家都这样"）背后的社会共识与潜规则；没有一句话是"废话"。

3. **社会分层与流动**（social stratification and mobility）：社会按经济、权力、声望分层，人们在层级间流动。调研含义：按职业、收入、教育等分层变量归类访谈对象；**不同阶层对同一问题的感受差异本身就是真实图景**；关注代际流动叙事（"我再苦也要供孩子读书离开这里"）。

4. **社会资本与信任**（social capital and trust）：关系网络、互惠规范和信任影响合作与治理成本。调研含义：关注对方的求助网络；测量信任（"邻居可以信任吗"）；"各扫门前雪""没人出头"等反复出现的话语，可能指向社会资本薄弱与基层治理失效。

这四个透镜对应四个不同的社会学流派传统（详见 `13_actor_map.md`），但它们不是四个互斥的理论，而是四个**可以叠加使用的观察过滤器**。

## 工艺侧：六个工程问题

种子文档把调研工程拆成六个经典问题，每个都对应成熟的方法论：

| 工程问题 | 典型表现 | 对应方法论 |
|---|---|---|
| 采样偏差 | 愿意聊的人有特定特征（空闲、爱抱怨、有立场） | 分层采样与配额设计 |
| 信噪比 | 情绪宣泄、二手信息、刻板印象、客套、夸大隐瞒 | 多源交叉验证 + 信号强度加权 |
| 测量误差 | 提问方式、身份、表情影响回答 | 结构化编码与信度控制（三值编码、原话摘录、双人编码） |
| 维度不完整 | 只采到物价、就业，漏掉教育、医疗、信任 | 预设框架 + 维度覆盖检查 |
| 时序与因果 | 横截面数据难以判断趋势；"以前好"是记忆重构 | 时序追踪与重复测量 |
| 隐私与伦理 | 敏感话题导致自我审查、含糊其辞 | 伦理安全与降噪协议（淡化敏感色彩、记录沉默、多对一关联） |

这六个问题不是种子文档的发明，而是调查方法论（survey methodology）与质性研究方法论（qualitative methodology）的公共议题。其中**信号强度加权**（亲身经历 3 / 近距离观察 2 / 泛泛而谈 1 / 二手传闻 0.5）是种子文档提出的具体启发式，属于可检验但尚未标准化的做法。

## 一条可执行的流水线

种子文档给出了八步流程：预设框架 → 自然提问 → 记录 → 信息卡片 → 编码归纳 → 交叉验证 → 形成判断 → 偏差标注。

在更大方法谱系中，这条流水线的位置是：

- 它本质是**质性调研**（qualitative research）的一种轻量变体：非结构化访谈 + 内容编码 + 三角验证；
- 它借用了**调查方法**（survey methodology）的分层抽样思想和覆盖检查；
- 它最终想走向**混合方法**（mixed methods）：从定性走向半定量（指数、评分）。

## 领域成熟度判断

- **成熟且标准化的部分**：分层抽样、三角验证、访谈技术、编码流程、信度效度检验、研究伦理。这些有教科书级的共识（详见 `14_paper_registry.md`）。
- **半成熟、需要本地化的部分**：面向"闲聊碎片"的编码手册、敏感问题的日常话术转译、面向个人的轻量台账格式。
- **开放或快速变化的部分**：矛盾信息仲裁规则、从聊天到半定量指数的映射、LLM 辅助编码的可靠性（NEEDS_VERIFICATION）。

## 用户定位

用户是计算物理背景的跨学科整合者，无社会科学训练。本领域的正确姿势不是补一门社会学学位，而是**把成熟方法组装成自己的调研工具链**，并用小规模试调研快速迭代。用户的工程化思维（噪声、采样、信噪比）与调研工程问题的隐喻天然相通，但需要警惕把隐喻当机制——社会测量的"误差"与社会互动的复杂性并不服从同一套数学。

## 遗留问题（NEEDS_VERIFICATION 汇总）

- LLM 辅助编码在当前场景（低资源方言、隐语、情绪识别）的实测信度与效度；
- 信号强度加权方案的文献依据与校准方法；
- 双人编码一致性阈值（种子文档建议 70%）的文献出处；
- 从非结构化聊天构建指数（消费信心类）的既有研究覆盖情况。

以上遗留问题详见 `20_gap_table.md` 与 `90_QA.md`。
