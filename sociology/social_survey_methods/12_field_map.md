# 12 Field Map / 领域地图

Last updated: 2026-08-17

## 一句话解释

把日常聊天当作高噪声的质性数据，用"理论透镜 + 工程管线"两条腿走路，产出对地方状况的、带证据强度的判断。

## 研究者版本

本领域本质是**质性研究方法论的轻量化应用**：以非结构/半结构访谈（表现为自然聊天）为数据形态，以分层配额控制采样，以编码与三角验证控制信度效度，最终走向半定量的结构化报告。它的特殊性不在方法新颖，而在**场景约束**：调研者不是专业团队，数据源是自发聊天，对象是地方经济政治状况——这要求方法必须足够轻、足够可操作。

## 领域在更大链条中的位置

```
认识论（怎么算"知道"） → 方法论（怎么系统地知道） → 本包：调研方法论的应用组装 → 具体操作工具（问题库/编码手册/卡片）
社会学理论（该看什么） → 本包：理论透镜 → 理解与归纳
```

本包不研究社会理论本身（那是社会学理论研究的任务），也不研究统计推断理论（那是调查方法论的领域），而是站在两者之间的**组装层**：把成熟部件装配成个人可执行的调研流程。

## 两条主线

### 主线 A：社会学理论透镜（语法侧）

| 透镜 | 核心问题 | 成熟度 | 证据类型 |
|---|---|---|---|
| 符号互动论 | 对方话语的主观意义是什么 | 成熟（经典流派） | 互动情境、概念使用方式 |
| 常人方法学 | 日常做法暴露了什么潜规则 | 成熟 | 日常对话中的索引性表达 |
| 社会分层与流动 | 不同阶层的感受差异 | 成熟 | 分层变量 × 话题矩阵 |
| 社会资本与信任 | 网络、规范、信任的状态 | 成熟 | 求助网络、合作意愿、信任表述 |

### 主线 B：调研工程管线（工艺侧）

| 环节 | 核心问题 | 成熟度 | 证据类型 |
|---|---|---|---|
| 采样设计 | 找谁聊、补谁 | 成熟（survey sampling） | 分层配额表 |
| 数据采集 | 怎么聊、记什么 | 成熟（访谈技术） | 原话摘录、情绪与回避记录 |
| 编码 | 归到哪类 | 半成熟（需本地化编码手册） | 三值编码 + 维度标签 |
| 验证 | 一条信息能不能信 | 成熟（三角验证） | 多信源一致性、言论-行为对照 |
| 推断 | 形成什么判断 | 半成熟（现象-模式-解释 + 证据强度标注） | 带权重的结构化判断 |
| 伦理 | 怎么不伤害信源 | 成熟（研究伦理） | 匿名化、多对一关联、沉默记录 |

## 两个概念坐标轴

### 坐标轴 1：结构化程度 × 数据深度

- 左下（低结构化、浅）：随机闲聊——噪声最大，价值最低。
- 右下（低结构化、深）：**本包所在**——聊天式访谈，深度和真实性高，但编码成本高。
- 左上（高结构化、浅）：问卷——标准化、可统计，但问不出深层含义。
- 右上（高结构化、深）：深度访谈 + 严格编码（学术团队做法）——质量最高，成本也最高。

本包的选择是**右下角**：用较低的结构化程度换真实性，再用编码环节补回可处理性。

### 坐标轴 2：理论驱动 × 数据驱动

- 理论驱动端：带着四个透镜去聊，先有框架再收集——维度覆盖好，但有"按图索骥"风险。
- 数据驱动端：先开放地聊，让主题自己浮现（扎根理论立场）——发现意外模式的能力强，但容易跑偏、难覆盖。

本包建议**理论驱动为主、保留开放余量**：预设框架保证维度覆盖，但每个话题下允许对方自由展开，并对"框架外的意外内容"单独建档（否则会错过真正的发现）。

## 各子方向的 trade-off

| 子方向 | 优势 | 代价 |
|---|---|---|
| 聊天式访谈（本包主体） | 低门槛、自然、信息真实 | 噪声大、不可统计推断、覆盖难保证 |
| 半定量化（指数构建） | 可比较、可画趋势 | 引入伪精确、丢失语境 |
| LLM 辅助编码 | 规模化、低成本 | 信度未验证、方言与隐语不可靠（NEEDS_VERIFICATION） |
| 双人编码 | 信度可检验 | 需要合作者，成本翻倍 |

## 关键假设

1. **聚合有效性假设**：单条聊天信息不可靠，但大量分层编码后的聚合模式逼近真实状况。这是本方法论的根基，也是最少被检验的假设。
2. **言语-现实一致性假设**：人们说出来的东西与现实行为足够相关。对敏感话题此假设最弱。
3. **分层代表性假设**：按职业/年龄/区域分层后，配额内的少量个体能代表该层。
4. **记忆叙述可用性假设**：回忆性叙述（"以前……"）可作为趋势信息的弱证据，但需当下可验证指标锚定。

## 瓶颈与为什么困难（可能转化为 gap 的候选）

- 编码手册的判定规则细化程度不足 → 编码信度上不去；
- 矛盾信息的仲裁没有标准算法 → 判断受调研者主观影响大；
- 半定量映射缺乏标准流程 → 容易伪精确；
- 敏感话题自我审查 → 数据系统性缺失，且无法用采样技术完全补偿；
- 单人调研无信度检验手段 → 只能靠交叉验证部分替代。

## 不应过度声称的提醒

- 本方法的产出是**带证据强度的判断**，不是统计估计，更不是"民意代表"；
- "很多人这么说"不是多信源证据；
- 工程隐喻（噪声/信噪比）是启发式，不是数学保证；
- 本包不做规范性政治评价（对错判断），只做描述性与解释性判断（是什么、为什么）。
