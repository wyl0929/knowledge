# 13 Actor Map / 代表学者与流派谱系

Last updated: 2026-08-17

## 说明

本文件按传统组织社会学代表学者。所有条目为社会科学教材级常识；具体著作信息详见 `14_paper_registry.md`。标注 `NEEDS_VERIFICATION` 的为待核验条目。

---

## 1. 学科奠基与古典传统

| 学者 | 贡献 | 位置 |
|---|---|---|
| Auguste Comte（孔德） | 1830 年代命名社会学，主张实证方法研究社会 | 命名者 |
| Herbert Spencer（斯宾塞） | 社会有机体论、社会进化论 | 早期综合者 |
| Émile Durkheim（涂尔干） | 社会事实、自杀论、宗教的社会功能、功能主义源头 | 三大古典之一 |
| Max Weber（韦伯） | 理解社会学、理想型、新教伦理、科层制、价值中立 | 三大古典之一 |
| Karl Marx（马克思） | 阶级与生产方式、经济基础-上层建筑、冲突与变迁 | 三大古典之一 |
| Georg Simmel（齐美尔） | 形式社会学、陌生人、货币哲学、冲突的社会功能 | 古典第四人（通常并列） |
| Alexis de Tocqueville（托克维尔） | 民主、平等与民情的比较研究 | 比较历史社会学先驱 |

| 学者 | 贡献 | 位置 |
|---|---|---|

## 7. 谱系观察

1. **地理脉络**：法德诞生（涂尔干/韦伯/马克思）→ 美国制度化（芝加哥学派、哥伦比亚学派、哈佛）→ 欧洲理论回流（批判理论、福柯、布迪厄）→ 全球化。
2. **中文世界传统**：费孝通（《乡土中国》）一脉的社区研究与"文化自觉"，以及民国社会学（吴文藻、潘光旦等）的传承，本包未展开（NEEDS_VERIFICATION：中文社会学的系统谱系）。
