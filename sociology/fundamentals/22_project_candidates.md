## 2. 方向详情

### E-01：精读一位古典理论家

**给用户看的项目解释**：从涂尔干《自杀论》或韦伯《新教伦理与资本主义精神》中选一本，完整读一遍并做读书笔记。这是入门收益最高的动作。

- **problem**：只有二手介绍会失去对"经典论证长什么样"的第一手体验。
- **existing work**：无数导读与课程；经典文本本身见 `14_paper_registry.md`。
- **gap**：个人化的第一手精读经验不存在，只能自己完成。
- **core idea**：一本精读 + 一份"论证结构图"笔记（前提-证据-结论-反例）。
- **为什么不只是重复造轮子 (why not wheel-reinventing)**：读经典是个人积累，不存在轮子问题。
- **minimal experiment**：两周内读完一本，输出 500 字论证结构图。
- **input**：一本经典著作。
- **output**：论证结构图笔记。
- **expected figures**：无（文字笔记）。
- **Baselines / 基线：** 只读二手介绍。
- **Metrics / 指标：** 能否用自己的话复述该书的论证链并指出一个反例。
- **Risks / 风险：** 半途而废；只读不写。
- **Success criteria / 成功标准：** 完成笔记并能在对话中复述论证链。
- **Stop criteria / 止损标准：** 若两周无进展，换读戈夫曼（最易读）重新开始。
- **priority**：高。

### E-02：社会学想象力写作练习

**给用户看的项目解释**：选一件身边的"个人烦恼"（熬夜、内卷、单身、催婚），用米尔斯的方法把它写成"公共议题"分析短文。把概念地图变成肌肉记忆。

- **problem**：概念学完不用，很快忘。
- **existing work**：米尔斯《社会学的想象力》(1959)。
- **gap**：概念到应用的个人转化。
- **core idea**：每周一篇 800 字"烦恼-议题"翻译练习，用上本包至少两个理论透镜。
- **为什么不只是重复造轮子 (why not wheel-reinventing)**：练习型任务。
- **minimal experiment**：写一篇练习短文，检查是否用上了两个以上概念。
- **input**：身边任一社会现象。
- **output**：分析短文。
- **expected figures**：无。
- **Baselines / 基线：** 不写，只读。
- **Metrics / 指标：** 文中出现的概念数、个人-公共翻译是否成立。
- **Risks / 风险：** 写成牢骚而非分析。
- **Success criteria / 成功标准：** 短文能区分"现象描述、结构解释、理论透镜选择"三层。
- **Stop criteria / 止损标准：** 连续两篇无法写出结构解释层 → 回到 `00_beginner_guide.md` 重读概念小节。
- **priority**：高。

### E-03：一个子领域的专题入门

**给用户看的项目解释**：按兴趣选一个子领域（分层与不平等、文化社会学、城市社会学、经济社会学……），按本 pack 同样的方式建立专题地图。

- **problem**：通识地图之后需要深度。
- **existing work**：各子领域教材与 handbook（NEEDS_VERIFICATION：具体书目未注册）。
- **gap**：个人兴趣方向的专题知识。
- **core idea**：选定方向后，可在 `sociology/` 下派生新的 subfield pack（走 subfield 流程）。
- **为什么不只是重复造轮子 (why not wheel-reinventing)**：派生 pack 有现成模板与流程。
- **minimal experiment**：先读该子领域一篇综述，确认兴趣是否持续。
- **input**：一篇综述文章。
- **output**：兴趣确认/放弃决定。
- **expected figures**：无。
- **Baselines / 基线：** 随机翻书。
- **Metrics / 指标：** 能否说出该子领域两三个核心争论。
- **Risks / 风险：** 兴趣漂移。
- **Success criteria / 成功标准：** 能列出该子领域的地图骨架。
- **Stop criteria / 止损标准：** 一篇综述读不完则放弃该方向。
- **priority**：中。
