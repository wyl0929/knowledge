# 10 Self Inventory / 用户背景快照

Last updated: 2026-08-17

## 快照说明

本文件保存本次 field pack 初始化时使用的 profile 快照。

- Profile source / 背景来源：`research_onboarding_skill/profiles/general_interest_profile.md`（快照日期 2026-05-29）
- 本次调研覆盖项：无。本包按一般兴趣入门执行，不假设用户拥有任何代码、平台、实验资源或研究方向。

## Profile 快照

### 画像定位

这是一个不包含任何个人背景假设的内置 profile。它不是研究型用户画像，也不假设用户拥有任何代码、平台、实验资源、合作者或特定研究方向。

### 适用场景

- 用户只是对某个领域感兴趣；
- 用户只是好奇某个概念是什么意思；
- 用户想先获得可读入门介绍；
- 用户明确表示暂时不考虑做研究、找课题或结合自身资产。

### 使用原则

- 不假设用户拥有任何代码、平台、实验资源或研究背景；
- 不自动生成个人资产匹配；
- 不自动把方向推成项目候选；
- 不强行输出 gap table、project candidates 或 MVP；
- 优先生成易读的 beginner guide、基础 overview、关键概念说明、field map 和 seed paper list；
- 如果用户后续表示想深入研究或寻找切入点，再切换到研究型 profile。

### 输出偏好

- 主体中文；
- 重要术语先解释，再在括号中标注英文术语；
- 适当给出公式、流程或例子；
- 可靠性边界集中说明。

### 不确定内容处理偏好

无法核验的论文、年份、工具状态、指标和判断标注 `NEEDS_VERIFICATION`。

## 与资产匹配

不适用。本包为兴趣入门，不生成个人资产匹配。若用户后续切换为研究型意图，应更新本文件并在 `99_update_log.md` 记录。
