# 13 Actor Map / 作者与研究组地图

Last updated: 2026-08-30

## 使用说明

本文件记录代表设计师、流派、机构谱系和值得关注的社区。设计领域的"actor"主要是设计师与流派，而非论文作者。信息不确定时标 `NEEDS_VERIFICATION`。

Field / 领域：平面设计

## 谱系总览

平面设计的现代史可以粗略画成一条传承链：

```text
包豪斯（Bauhaus, 1919，形式服从功能）
  -> 瑞士国际主义风格（Swiss Style, 1950s，网格 + Helvetica + 留白）
     -> 现代主义标识/海报（Paul Rand, Saul Bass, Massimo Vignelli）
     -> 新浪潮（Wolfgang Weingart，打破网格）
        -> 后现代/数字拼贴（David Carson, Ray Gun）
  -> 极简/扁平/数字设计系统（Material / Apple HIG / Fluent，当代）
```

## 条目：包豪斯（Bauhaus）

- **Actor / Group：** 包豪斯（Bauhaus）
- **人话摘要：** 现代设计教育的源头，主张"形式服从功能"、几何抽象、艺术与技术结合。
- **机构：** Weimar（1919 创立，校长 Walter Gropius）→ Dessau → Berlin，1933 关闭。
- **研究脉络：** 影响几乎全部现代设计；其色彩教学由 Johannes Itten 与 Josef Albers 奠定。
- **关键词：** 形式服从功能、几何、原色、现代主义。
- **代表作品：** Bauhaus 印刷品、Itten 色彩教学体系、Albers 色彩课程。
- **核心贡献：** 确立了"设计是可教学的系统"这一前提，而非师徒手艺。
- **方法：** 基础课（材料/色彩/形式）＋ 工作坊。
- **平台：** 教学机构。
- **与其他团队关系：** 瑞士风格、极简/扁平风的共同祖先。
- **与用户相关性：** 高——几何抽象 + 原色最适合程序化壁纸。
- **关注优先级：** high
- **Last updated：** 2026-08-30（年份细节 NEEDS_VERIFICATION）

## 条目：瑞士国际主义风格（Swiss Style）

- **Actor / Group：** 瑞士国际主义风格（International Typographic Style）
- **人话摘要：** 用网格、无衬线字体、留白，把信息排得像数学一样清楚。
- **机构：** 瑞士（Basel、Zürich 等地的设计学校）。
- **研究脉络：** 1950s 兴起，代表人物 Josef Müller-Brockmann、Armin Hofmann、Emil Ruder。
- **关键词：** 网格系统、Helvetica、不对称版式、客观。
- **代表作品：** Müller-Brockmann 的音乐会海报、Ruder《Typographie》(1967)。
- **核心贡献：** 把"可复现的秩序"变成一套可教学的方法，网格系统是核心遗产。
- **方法：** 栅格设计、基线网格、统一字体、字号对比制造层级。
- **平台：** 印刷海报/刊物。
- **与其他团队关系：** 继承了包豪斯的功能主义，是当代设计系统的精神源头。
- **与用户相关性：** 最高——网格可代码化，是你最该学的方法族。
- **关注优先级：** high
- **Last updated：** 2026-08-30（年份细节 NEEDS_VERIFICATION）

## 条目：Josef Müller-Brockmann

- **Actor / Group：** Josef Müller-Brockmann
- **人话摘要：** 网格系统的代表人物，把版式做成精确的几何秩序。
- **机构：** 瑞士（Zürich）。
- **研究脉络：** 瑞士风格核心人物，著有《Grid Systems in Graphic Design》。
- **关键词：** 网格、海报、客观、秩序。
- **代表作品：** 苏黎世音乐厅（Tonhalle）系列音乐会海报、著作《Grid Systems in Graphic Design》(1981)。
- **核心贡献：** 把网格方法写成可复制的手册，是"版式可复现"的里程碑。
- **方法：** 网格切分、字号层级、留白。
- **平台：** 印刷海报。
- **与其他团队关系：** 与 Armin Hofmann、Emil Ruder 同属瑞士风格。
- **与用户相关性：** 极高——网格是纯算术，可代码复刻。
- **关注优先级：** high
- **Last updated：** 2026-08-30（作品年份 NEEDS_VERIFICATION）

## 条目：Johannes Itten 与 Josef Albers

- **Actor / Group：** Johannes Itten / Josef Albers
- **人话摘要：** 现代色彩教学的两代奠基人。
- **机构：** 包豪斯（后 Albers 任教于美国黑山学院、耶鲁）。
- **研究脉络：** Itten 提出色彩对比体系（七种对比）；Albers 发展《Interaction of Color》实验教学。
- **关键词：** 色彩理论、七种对比、色彩交互。
- **代表作品：** Itten《The Art of Color》(Kunst der Farbe, 1961)；Albers《Interaction of Color》(1963)。
- **核心贡献：** 把"色彩和谐"从玄学变成可教学、可实验的对象。
- **方法：** 色相环、对比实验、同一颜色在不同背景上的观察。
- **平台：** 教学与著作。
- **与其他团队关系：** 包豪斯色彩教学的传承。
- **与用户相关性：** 高——HSL 配色与"颜色因环境而变"的洞见直接支撑壁纸配色。
- **关注优先级：** high
- **Last updated：** 2026-08-30（年份 NEEDS_VERIFICATION）

## 条目：Paul Rand / Saul Bass / Massimo Vignelli（现代主义标识与海报）

- **Actor / Group：** Paul Rand、Saul Bass、Massimo Vignelli
- **人话摘要：** 用极简 + 概念，把标志和海报做到"看一眼就忘不掉"的现代主义大师。
- **机构：** 美国（Rand、Bass 独立事务所；Vignelli 创办 Unimark/Vignelli Associates）。
- **研究脉络：** 把包豪斯/瑞士风格引入美国商业设计。
- **关键词：** 标识、极简、概念、网格。
- **代表作品：** Rand 的 IBM/ABC/UPS 标识；Bass 的电影片头与海报（如《金臂人》）；Vignelli 的纽约地铁地图与《The Vignelli Canon》。
- **核心贡献：** 证明"极简 + 概念"能同时达成识别力与美感。
- **方法：** 几何简化、网格、色彩限制。
- **平台：** 企业标识、电影、公共信息。
- **与其他团队关系：** 瑞士风格在商业场景的延伸。
- **与用户相关性：** 中高——极简 + 几何的思路可直接用于壁纸的"焦点图形"。
- **关注优先级：** medium
- **Last updated：** 2026-08-30（作品年份 NEEDS_VERIFICATION）

## 条目：Wolfgang Weingart 与 David Carson（打破网格）

- **Actor / Group：** Wolfgang Weingart / David Carson
- **人话摘要：** 从"新浪潮"到后现代，故意打破网格、混排字体，制造张力与情绪。
- **机构：** Weingart 任教于 Basel；Carson 曾任 Ray Gun 杂志艺术总监。
- **研究脉络：** Weingart 把瑞士网格推向"破格"；Carson 在 1990s 数字拼贴中放大。
- **关键词：** 新浪潮、后现代、拼贴、字体混排。
- **代表作品：** Weingart 的实验版式；Carson 的 Ray Gun 杂志版式。
- **核心贡献：** 证明规则可以被有意识地打破，但前提是深刻理解规则。
- **方法：** 不对称、叠印、噪点、字体混搭。
- **平台：** 印刷刊物。
- **与其他团队关系：** 是对瑞士风格秩序的反动，也是其延续。
- **与用户相关性：** 低到中——最不程序化，建议先掌握规则再谈打破。
- **关注优先级：** low
- **Last updated：** 2026-08-30（年份 NEEDS_VERIFICATION）

## 条目：Dieter Rams 与 Robin Williams（原则的普及者）

- **Actor / Group：** Dieter Rams / Robin Williams
- **人话摘要：** 把设计原则写成清单，让非专业者也能掌握。
- **机构：** Rams 曾任 Braun 设计总监；Williams 是设计教育作者。
- **研究脉络：** Rams 提出"好设计十原则"；Williams 在《The Non-Designer's Design Book》里提炼 CRAP（对比/重复/对齐/亲密性）。
- **关键词：** 好设计十原则、CRAP、入门。
- **代表作品：** Rams 的十原则；Williams《The Non-Designer's Design Book》(1994)。
- **核心贡献：** 把设计原则压缩成可记忆、可自查的清单，是入门者最高效的入口。
- **方法：** 原则清单 + 正反例。
- **平台：** 著作/产品设计。
- **与其他团队关系：** 吸收现代主义/瑞士风格共识，面向大众转译。
- **与用户相关性：** 极高——CRAP 是入门最快抓手，也是壁纸自检清单。
- **关注优先级：** high
- **Last updated：** 2026-08-30

---

## 条目：当代设计系统（Material Design / Apple HIG / Fluent）

- **Actor / Group：** Google Material Design / Apple Human Interface Guidelines / Microsoft Fluent
- **人话摘要：** 把设计原则沉淀为可执行的间距、颜色、层级规范，是"设计工程化"的成熟形态。
- **机构：** Google / Apple / Microsoft。
- **研究脉络：** 从扁平化潮流发展到系统化规范。
- **关键词：** 设计系统、间距规范、色彩令牌、层级。
- **代表作品：** Material Design 规范、Apple HIG、Fluent Design System。
- **核心贡献：** 证明"设计原则 → 可执行规范"可以工程化、跨团队复用。
- **方法：** 设计令牌（token）、栅格、组件规范。
- **平台：** 数字产品。
- **与其他团队关系：** 继承瑞士网格与极简/扁平风。
- **与用户相关性：** 高——它们的规范可作"达标基准"，也启发程序化壁纸的参数化设计。
- **关注优先级：** medium
- **Last updated：** 2026-08-30
