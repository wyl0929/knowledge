# 01 Research Overview / 研究总述报告

Last updated: 2026-08-30

## 0. 阅读定位

这篇文档是"平面设计"field pack 的主报告。它不是正式综述，也不是 paper registry、gap table、project candidates 的替代品；它把这些结构化材料改写成一篇能从头读到尾的入门报告：先建立直觉，再建立版图，最后走到边界和"你该从哪切入"。

本文面向的是有理工科研训练、但从未系统接触设计的人。所以重要概念都会先讲直觉，再讲术语；分类会写成谱系和 trade-off，而不是清单。

## 1. 一句话理解这个方向

- 初学者版一句话：平面设计是在二维平面上，把文字、颜色、图像和空白安排得有秩序、有重点，好让别人一眼看懂信息、或感受到你要的情绪。
- 研究者版一句话：平面设计研究"给定画布 + 信息目标 + 受众约束，如何组织视觉元素（文字/色彩/形状/图像/负空间）"，使输出在"可读性/可用性"与"审美/情绪"之间达成可预期的平衡；输入是信息与约束，输出是可复制的视觉方案，评价同时含客观维度（对比度、层级、对齐）和主观维度（风格、品味）。

## 2. 这个方向在更大链条中的位置

平面设计处在一条"信息传达"链条的中间层：

```text
有人想传达信息 / 制造体验（上游目标：品牌、通知、氛围）
  -> 视觉语法：人眼如何感知形状、颜色、对比（感知层）
  -> 平面设计：把元素组织成有秩序、有层级的画面（本领域核心环节）
  -> 工具与产出：海报 / 界面 / 图标 / 壁纸 / 包装（下游载体）
  -> 受众是否看懂、是否被触动（反馈回上游）
```

**为什么这一层绕不过去？** 人眼是"选择性注意"的：它会先扫到最大的对比、最亮的地方、最有规律的形状，而不是逐像素读图。如果中间这一层（组织与秩序）没做好，再好的信息也会被埋没——下游的表现就是"看着乱""找不到重点""图标被背景吃掉"。反之，如果这一层做得好，素材再简单也能"一眼就舒服"。

**为什么它难？** 因为它要同时满足两个常常打架的目标：客观的"能用/可读"（对比度、层级、对齐）和主观的"好看/有情绪"（风格、品味）。前者可度量，后者高度依赖语境。真正的设计能力，就是在这两根绳子之间走钢丝。

## 3. 它不只是 X：先纠正常见误解

1. **"设计 = 会用 PS / AI 软件"**。容易误解，因为"学设计"常被等同于"学软件"。但软件是画笔，设计是决策——软件解决"怎么画出来"，设计解决"该画什么、放哪里、为什么"。这个区别影响选题：只学软件的人能复制，不能创造。
2. **"设计 = 艺术，好看就行"**。容易误解，因为两者都产出图像。但艺术（art）偏自我表达、没有必须服务的任务；设计（design）必须有任务和受众。这个区别影响选题：设计评价必须先问"它达成了什么传达目标"，再谈"美不美"。
3. **"设计全凭感觉，没有规律"**。容易误解，因为好作品看起来"自然"。但设计有大量可教学、可验证的规律（对齐、对比、色彩调和、网格）；感觉只是把规律练熟之后的捷径。这个区别影响选题：先学规律，再谈风格，而不是反过来。

## 4. 主流路线谱系

平面设计史不是"一堆流派"，而是一条"秩序 ↔ 表现"的轴。越往左越强调规则、清晰、可复现；越往右越强调打破规则、个性、情绪。

```text
瑞士国际主义（网格、Helvetica、留白）
  -> 现代主义 / 包豪斯（几何、原色、形式服从功能）
  -> 极简 / 扁平 / 数字风（面向屏幕，当代主流）
  -> 后现代 / 新浪潮（打破网格、字体混排、拼贴）
  左 = 秩序、清晰、可复现   ←→   右 = 表现、个性、情绪
```

### 路线 1：瑞士国际主义 / 网格派（Swiss / International Style）

**它是什么：** 用严格网格、无衬线字体（Helvetica）、大量留白，把信息排得像数学一样有秩序。

**为什么重要：** 它是"可复现设计"的起点——第一次把"怎么排才清楚"变成一套可教学的方法。

**常见方法 / 工具：** 栅格系统（列/行/基线网格）、统一字体、字号对比制造层级、左对齐、负空间。

**成熟度：** mature（已经是一个半世纪以来稳定的 baseline）。

**局限：** 冷冰冰、易没个性；教条化会压抑情绪表达。

**和用户背景的关系：** 最高。网格是"坐标约束"，可以直接写进代码。

### 路线 2：现代主义 / 包豪斯（Bauhaus）

**它是什么：** "形式服从功能"，用最少的几何形状（圆/三角/方）和原色，去掉装饰。

**为什么重要：** 它是极简/扁平风的源头，确立了"少即是多"和"诚实材料"的审美坐标。

**常见方法 / 工具：** 几何抽象、限制元素数量、高饱和原色或灰阶、功能优先。

**成熟度：** mature。

**局限：** 元素越少，细节越被放大，越难做好。

**和用户背景的关系：** 高。几何抽象天然可参数化，适合代码生成。

### 路线 3：后现代 / 表现派（Postmodern / New Wave）

**它是什么：** 故意打破网格、混排字体、制造视觉张力，用"乱"表达态度。

**为什么重要：** 它提醒我们规则不是终点，打破规则能制造注意力和情绪。

**常见方法 / 工具：** 不居中、字体混搭、叠印、噪点、拼贴、电子像素。

**成熟度：** mature（作为流派已成熟，但作为技能门槛最高）。

**局限：** 依赖对规则的深刻理解，否则就是纯乱；最不程序化。

**和用户背景的关系：** 低到中。建议先掌握规则，再谈打破规则。

### 路线 4：极简 / 扁平 / 数字风（Minimal / Flat / Digital）

**它是什么：** 面向屏幕的当代主流——扁平色块、留白多、无装饰，靠颜色和间距说话。

**为什么重要：** 小屏幕、多分辨率、快节奏下依然清晰可用；苹果/谷歌/微软的设计系统都走这条路。

**常见方法 / 工具：** 限制配色、大量留白、元素极少、内容优先；设计系统（Material Design、Apple HIG、Fluent）。

**成熟度：** mature（当代默认风格）。

**局限：** 元素少，极度考验色彩和间距功力。

**和用户背景的关系：** 高。扁平风是"程序化壁纸"的最佳画风。

### 关键方法机制展开：网格系统（grid system）

- 直觉：把画布切成隐形的列和行，让所有元素"吸附"到线上，而不是随手漂浮。
- 核心参数化：列数（column）、列宽与列间距（gutter）、页边距（margin）、基线网格（baseline grid，文字行对齐的横线）。一张海报的"骨架"就由这几个数决定。
- 方法流程：定版心（页边距）→ 分列 → 元素宽度对齐到若干列 → 文字基线对齐 → 用留白和字号制造层级。
- 优势：清晰、可复现、可教学；多人协作时版式不会跑偏。
- 局限：灵活度受限；照搬会显呆板。
- 和用户资产的关系：网格就是"约束坐标"，你能用 Python 直接生成网格、把元素对齐到网格点。

### 关键方法机制展开：色彩三属性（HSL）

- 直觉：一个颜色可以用"什么颜色（色相）、多鲜艳（饱和度）、多亮（明度）"三个旋钮描述，比"红/绿/蓝"更接近人眼直觉。
- 核心参数化：色相 hue（角度，0°-360°）、饱和度 saturation（0-100%，0 是灰，100 是纯色）、明度 lightness（0-100%，0 黑 100 白）。
- 方法流程：定主色（选 hue）→ 定明暗与鲜艳度（调 S/L）→ 用色相环位置关系（相邻=类比色，对面=互补色，三等分=三色）选辅助色 → 用 60-30-10 比例分配主/次/强调色。
- 优势：直觉、易程序化（HSL 三个数字就是一个颜色）。
- 局限：HSL 不等于"看起来的和谐"，和谐还受面积、明度对比、文化语境影响。
- 和用户资产的关系：HSL 是纯数值，你能直接写代码遍历/微调色相，批量生成配色。

## 5. 领域已经做到什么程度

| 层面 | 已经成熟的内容 | 仍然不足的地方 | 对新项目意味着什么 |
|---|---|---|---|
| 方法 / 原则 | 四原则（对比/重复/对齐/亲密性）、网格系统、色彩调和、视觉层级 | "好坏"仍无法整体量化；风格化与原创性难复制 | 用成熟原则兜底，不要"重新发明配色理论" |
| 工具 / 软件 | Figma、Illustrator、Photoshop、Canva、以及程序化（Processing/p5.js、Python PIL） | 工具不能替你做"该放哪里"的决策 | 工具只是执行层，决策靠理论 |
| 规范 / benchmark | WCAG 对比度（可测）、栅格与间距规范、设计系统（Material/HIG/Fluent） | 壁纸"多分辨率/图标安全区"没有统一强制标准 | 对比度可以硬性达标，其余靠约定 |
| 系统级应用 | 品牌识别系统、设计系统、模板生态 | 自动/生成式设计仍处于"可控 vs 惊喜"的平衡难题 | 生成式壁纸是可行切口，但别妄想"万能设计 AI" |

关键展开：**对比度是可以算出来的**。WCAG 的对比度公式 $\text{CR}=(L_1+0.05)/(L_2+0.05)$ 让你能客观判断"图标在壁纸上还看得见吗"。这是设计里少数几个能硬性达标的地方——所以它是你（理工背景）最该先抓住的抓手。相比之下，"这套配色高级不高级"没有公式，只能靠积累。

## 6. 代表性工作、研究组与工具生态

（详见 `13_actor_map.md` 与 `14_paper_registry.md`，这里只做坐标式介绍。）

- **包豪斯（Bauhaus, 1919, Weimar/Dessau）**——代表"形式服从功能"这条源头的机构谱系，其色彩教学（Johannes Itten、Josef Albers）几乎奠定了现代设计教育。为什么值得认识：它是几乎所有现代极简风格的祖先。
- **瑞士国际主义风格（Swiss Style, 1950s）**——Josef Müller-Brockmann、Armin Hofmann、Emil Ruder 代表的网格派，把"可复现的秩序"变成一套方法。为什么值得认识：网格系统、Helvetica 都是它的遗产，是你最容易程序化的理论。
- **Josef Albers《Interaction of Color》(1963)**——色彩理论的核心入口。核心洞见：**颜色不是孤立的，它因环境而变**。为什么值得认识：壁纸配色的"打架/和谐"问题，根子在这里。
- **Jan Tschichold《Die neue Typographie》(1928)**——把排版从"对称装饰"拉向"不对称 + 功能"的转折点。
- **Paul Rand、Saul Bass、Massimo Vignelli**——标识与海报的现代主义大师，代表"极简 + 概念"能达到的识别力。
- **设计系统（Material Design / Apple HIG / Fluent）**——当代数字设计的工程化沉淀，代表"设计原则 → 可执行规范"的成熟形态。
- **程序化设计生态（Processing / p5.js / Python PIL & cairo）**——代表"把设计规则写成代码"的工具族，是你最直接的入口。

## 7. 当前领域最关心的问题

设计从"能做出一张图"走向"能稳定、可复现、可迁移地做好"时，遇到的下一层问题：

1. **好坏的可度量性**。之前靠"大师审美"和主观评审；现在数字产品需要大规模、自动化地保证质量，于是"对比度、间距、层级"这类可测指标越来越重要，但"美感"仍无法量化。现有方法用设计系统 + 规范兜底可测部分；没解决的是原创风格与主观品质的自动化。
2. **多分辨率 / 多设备适配**。同一视觉要在手机、平板、桌面、超宽屏上都成立，壁纸尤其如此（16:9、16:10、21:9、4:3、竖屏）。现有方法用响应式布局和"安全区"约定；没解决的是"一张图通吃所有比例"往往意味着牺牲构图。
3. **生成式 / 程序化设计的"可控 vs 惊喜"**。AI 和代码能无限量产图形，但"量产"不等于"设计"——真正难的是让生成结果既稳定达标（对比度、层级）又有审美价值。现有方法用规则约束 + 参数化；没解决的是"随机 ≠ 设计决策"这道坎。

## 8. 主要困难与瓶颈

### 瓶颈 1：好坏难以量化

**普通话解释：** 没有仪器能测"这张壁纸好不好"。

**为什么难：** "能用"可测（对比度、对齐），"好看"高度依赖语境和受众，两者不能合并成一个分数。

**已有 workaround：** 用可测指标（WCAG 对比度、网格对齐、层级）兜底，用"多看多改"积累审美。

**最小验证：** 同一张壁纸，分别只评估"对比度是否达标"和"是否好看"，看两者是否解耦。

**证据状态：** confirmed（"可测"与"主观"分离是设计界的普遍共识）。

### 瓶颈 2：懂理论 ≠ 做得出

**普通话解释：** 背下"对比、重复、对齐、亲密性"四个词很容易，在一张空画布上做出来是另一回事。

**为什么难：** 设计是"在无数可能中做选择"的技能，理论只给原则，不给"这次选哪个"。

**已有 workaround：** 用强约束逼选择（只准 2 色、只准圆形、只准一种字体）。

**最小验证：** 给新手一个"只准 2 色 + 一个形状"的壁纸任务，看成品质量是否显著高于"无约束"任务。

**证据状态：** suspected（"约束降低难度"是设计教学共识，但强度依赖个人，未系统量化）。

### 瓶颈 3：壁纸的"背景性"与"焦点性"冲突

**普通话解释：** 壁纸既是"背景"（不该抢戏），又要有"焦点"（否则无聊），还要给桌面图标留可读空间。

**为什么难：** 这三者互相拉扯：焦点太强就抢了图标，焦点太弱就平淡，图标区太花就"被吃掉"。

**已有 workaround：** 图标安全区留白（左/右侧留低细节区）、焦点放中央/三分点、背景用低对比大面积色。

**最小验证：** 同一壁纸在有/无图标两种状态下截图，看图标可读性和焦点是否同时成立。

**证据状态：** suspected（"图标安全区"是通行做法，但缺少统一的量化规范，NEEDS_VERIFICATION）。

## 9. 入门者最重要的理解框架

用三根坐标轴，帮你以后看任何设计都能快速定位：

```text
Axis 1: 秩序（网格/规则）  <->  表现（自由/情绪）
Axis 2: 手工/直觉  <->  程序化/系统化
Axis 3: 功能传达（可读性）  <->  美学表达（情绪）
```

- **Axis 1 左端**适合信息密集、要清晰可复现的场景（时刻表、说明书、企业系统）；**右端**适合海报、专辑封面等要情绪的场景。trade-off：越秩序越清晰但越冷，越表现越有情绪但越容易乱。
- **Axis 2 左端**适合一次性、少量产出；**右端**适合批量、需要一致性的产出（设计系统、程序化壁纸）。trade-off：手工更灵活更有手感，程序化更一致更可复现。
- **Axis 3 左端**适合界面、标识、图标；**右端**适合品牌、氛围、艺术。trade-off：偏可读则克制，偏情绪则冒险。一张好的壁纸往往同时踩在这根轴的两端：大面积低对比（可读） + 一个高对比焦点（情绪）。

用这三根轴读作品：看到一个设计，先问"它在秩序轴哪一端、手工还是程序、偏功能还是偏情绪"，就能大致判断它为什么这么设计。

## 10. 和用户背景的连接

（依据 `10_self_inventory.md`；本包为兴趣/实践型进入，你的科研资产与设计正交，但有一个关键桥梁。）

- **最匹配的用户资产**：Python / matplotlib / LaTeX。这三样让你天然适合"程序化设计"——把网格、配色、构图写成可复现的代码，而不是手工拖拽。
- **最值得优先看的子方向**：网格系统（可代码化）+ 色彩理论（HSL 可数值化）+ 极简/扁平风（最适合生成式壁纸）。
- **最可能重复造轮子的方向**：重新发明一套"配色理论"或"万能设计 AI"——这些要么已被成熟理论覆盖，要么是远超入门范围的伪 gap（见 `02_frontier_compass.md` 第 4 节）。
- **第一周最小动作**：用 Python Pillow 生成一张 1920×1080 壁纸：纯色背景 + 一个三分法放置的几何形 + 2-3 色，并写下每个设计决策的理由。
- **一个月内可形成的 MVP**：一个"参数化壁纸生成器"——输入主色/情绪/风格，输出一套对比度达标、有焦点的壁纸（对应 `22_project_candidates.md` 的 P-004）。

## 11. 初步候选方向

（详见 `22_project_candidates.md`，这里给可读版本。）

1. **"秩序之网格"几何壁纸**——把瑞士网格系统直接用到壁纸构图，用代码或 Figma 做出严谨的几何版式。第一个实验：画布切 6 列，焦点元素对齐到第 2、5 列交点。baseline：随手摆放。指标：元素是否严格对齐网格、是否有焦点。风险：呆板。
2. **"色彩的呼吸"限制调色板壁纸**——只用 2-4 色（类比色或单色系）做渐变/色块。第一个实验：选一个色相，用 HSL 变明度做一组 5 张同风格壁纸。baseline：随手取色。指标：色相和谐（相邻/同系）、对比度达标。风险：显灰或显脏。
3. **"图标安全区"功能壁纸**——以"图标可读性"为第一约束，左/右留低细节安全区，焦点放中央。第一个实验：把壁纸和桌面图标叠加，验证对比度 ≥ 3:1。baseline：不考虑图标随便做。指标：WCAG 对比度。风险：太克制显平淡。
4. **程序化壁纸生成器（优先）**——用 Python 把上述规则参数化，一键生成一套壁纸。第一个实验：一个脚本输出 3 张不同配色、同构图的壁纸。baseline：手工做。指标：生成稳定、不撞车、对比度达标。风险：随机 ≠ 设计。这是最匹配你资产、也最值得做的方向。
5. **字体排版壁纸**——极简文字层级（一句格言 + 一个焦点大字）。第一个实验：用大字号无衬线 + 大量留白做一张文字壁纸。baseline：文字随意堆。指标：层级清晰（字号/字重对比）、对齐。风险：字库版权与字体选择。

## 12. 推荐阅读 / 实验顺序

### 第一层：建立宏观地图（先读，1-2 天）
- `00_beginner_guide.md`（本包入门）→ 读一本"四原则"级入门书（Robin Williams《The Non-Designer's Design Book》），建立对比/重复/对齐/亲密性的直觉。

### 第二层：理解主流 baseline（2-4 天）
- 网格：Müller-Brockmann《Grid Systems in Graphic Design》看版式案例（不逐页读）。
- 色彩：Albers《Interaction of Color》前几章，做"同一颜色不同背景"实验。
- 字体：Ellen Lupton《Thinking with Type》通读。

### 第三层：进入用户相关切口（1 周）
- 用 Python 复刻一张瑞士网格海报版式（练网格）→ 写 HSL 调色脚本（练色彩）→ 合并成壁纸生成器。

### 第四层：做最小验证（1-2 周）
- 交付 `22_project_candidates.md` 中 P-004 的第一版：3 张不同配色、同构图的 1920×1080 壁纸，并自评对比度与焦点。

## 13. 小结：边界在哪里，下一步验证什么

- **内圈**：四原则、色彩三属性、字体分类、网格、视觉层级、负空间——这些是必须先掌握的常识。
- **中圈**：网格系统、色彩调和、无衬线字体、设计系统（Material/HIG/Fluent）——成熟 baseline，不能假装不存在。
- **边界**：好坏的量化、多分辨率通吃、生成式设计的"可控 vs 惊喜"——真正难、值得继续验证的问题。
- **伪边界**："重新发明配色理论""做一个万能设计 AI"——看似新，实则被覆盖或远超范围。
- **你的切口**：程序化壁纸——把网格 + 色彩 + 构图写成代码，用你的 Python 资产把设计变成可复现流程。
- **下一步验证**：第一张"纯色 + 三分法几何形 + 2-3 色"的代码生成壁纸，是否同时做到"对比度达标、有焦点、不抢图标"。

## 14. 边界与风险

- 本文是 quick_scan 级别，写的是设计领域广泛共识的入门知识；具体年份、书目版本、工具 API 细节需核验。
- "图标安全区"是通行做法，但缺少统一量化规范，相关判断标 suspected / NEEDS_VERIFICATION。
- "适合你走程序化路线"是 recommendation（基于你的 Python 资产），不是领域事实。
- 所有"好看与否"的判断都含主观成分，本文只承诺"清晰、对比、层级"这类可测维度的说法。
