# 02 Frontier Compass / 边界罗盘

Last updated: 2026-08-30

## 0. 这个文件的用途

本文件回答：如果你已经理解了平面设计的基本概念，那么"知识圆圈的边界"大概在哪里？哪些是内圈常识、哪些是成熟 baseline、哪些是真正值得继续验证的前沿、哪些容易重复造轮子？最后落到"你该从哪切入"。

它不是正式综述，也不是 gap table 的替代品；它把 field map、来源注册表、gap table 和 project candidates 综合成一张"下一步往哪走"的决策罗盘。

## 1. 内圈：必须先掌握的基本事实

| Item | 人话解释 | 为什么是基本事实 | 证据状态 |
|---|---|---|---|
| F-001 | 四原则：对比、重复、对齐、亲密性（contrast/repetition/alignment/proximity） | 它们是最小可教学、可迁移的"组织规则"，几乎所有设计判断都回到这四条 | 广泛共识（设计教学通行） |
| F-002 | 色彩三属性：色相/饱和度/明度（HSL） | 一个颜色可由三个旋钮描述，是配色的最小可操作语言 | 广泛共识（色彩理论） |
| F-003 | 字体基本分类：衬线 / 无衬线 / 等宽 | 选字体的第一层决策，影响气质与可读性 | 广泛共识（字体排印） |
| F-004 | 视觉层级：先看什么、后看什么靠对比（大小/明暗/位置）制造 | 设计的第一目标是"传达重点"，层级是实现它的手段 | 广泛共识 |
| F-005 | 负空间（留白）不是"没放东西"，而是主动的设计元素 | 留白决定呼吸感和焦点，是版式的骨架 | 广泛共识 |
| F-006 | 网格系统：用列/行/基线把元素对齐 | 把"怎么排才清楚"变成可复现的方法，是设计的骨架 | 广泛共识（瑞士风格遗产） |
| F-007 | 对比度可以算：WCAG 公式 CR=(L1+0.05)/(L2+0.05) | 让你能客观判断"图标/文字还看得见吗"，是少数可硬性达标处 | 官方规范（W3C，NEEDS_VERIFICATION 精确版本） |

## 2. 中圈：成熟 baseline 与不可忽视的工具

| Baseline / 工具 / 方法 | 已经解决什么 | 还解决不了什么 | 新项目如何正确使用它 |
|---|---|---|---|
| 网格系统（Müller-Brockmann 等） | 把信息排得清晰、可复现 | 情绪、个性、灵活度 | 用它兜底构图，别重新发明"怎么对齐" |
| 色彩调和（色相环关系 + 60-30-10） | 给出"和谐配色"的可靠起点 | "高级感/情绪"这类主观品质 | 用它生成起点，再靠判断微调 |
| 无衬线字体 + 层级（Helvetica/Inter 等） | 可读、现代、跨分辨率稳定 | 独特气质、品牌个性 | 默认用成熟字体，不自己造字 |
| 设计系统（Material / Apple HIG / Fluent） | 把原则沉淀为可执行间距/颜色/层级规范 | 原创风格与主观品质 | 参考它的规范，作为"达标"基准 |
| 程序化工具（Processing/p5.js、Python PIL/cairo） | 把设计规则写成可复现代码 | 审美判断、随机≠设计 | 用它做"参数化壁纸"这类批量产出 |

## 3. 边界：当前真正卡住的问题

### Boundary Question B-001：设计好坏能否部分量化？

**一句话解释：** 能不能把"这张设计好不好"至少部分变成可测指标，而不全靠主观评审？

**为什么重要：** 数字产品需要大规模、自动化地保证视觉质量；壁纸这类"量产背景"尤其需要客观底线（图标可读、对比度达标）。

**已有工作做到哪里：** WCAG 已把"对比度"变成硬指标；设计系统把间距、层级、配色沉淀为规范。可测的部分（对齐、对比、层级）已有成熟方法。

**还不清楚什么：** "美感/情绪/风格"这类主观维度仍无法量化，也无法自动保证。

**为什么难：** 审美是文化、经验、语境的产物，不是待求解方程。

**最小验证：** 同一批壁纸，分别用"可测指标（对比度/对齐）"和"主观评分"评估，看两者相关性——验证"可测维度是否足以兜底功能性质量"。

**证据状态：** suspected（"可测兜底 + 主观审美"的二分是共识，但两者的最佳结合方式仍无定论）。

### Boundary Question B-002：生成式设计的"可控 vs 惊喜"如何平衡？

**一句话解释：** 代码/AI 能无限量产图形，但"量产"不等于"设计"；怎么让生成结果既稳定达标又有审美价值？

**为什么重要：** 这是程序化壁纸（你的切口）的核心难题——参数太死则千篇一律，参数太随机则没有设计。

**已有工作做到哪里：** 参数化系统（用规则约束 + 参数空间）已能稳定产出合规图形；生成式 AI 能产出丰富视觉，但可控性差。

**还不清楚什么：** 如何在"规则约束"和"审美惊喜"之间找到可操作的平衡点，而不是靠调参撞运气。

**为什么难：** 一旦放开随机性，就难以保证对比度、层级这些硬指标；一旦锁死规则，又失去生命力。

**最小验证：** 设计一个"约束式生成器"（配色限制 + 网格对齐 + 少量随机），看它在不违反硬指标的前提下能产出多少"不撞车"的变体。

**证据状态：** suspected（是生成式设计界公认难题，NEEDS_VERIFICATION 具体最新方法）。

### Boundary Question B-003：一张壁纸能否"通吃"所有分辨率？

**一句话解释：** 16:9、16:10、21:9、4:3、竖屏……同一张壁纸在不同比例上都成立吗？

**为什么重要：** 壁纸是"多设备"产物，裁切会毁掉构图。

**已有工作做到哪里：** 响应式布局、安全区约定、关键内容居中放置是通行做法。

**还不清楚什么：** 没有统一的"多比例壁纸设计规范"；"通吃"往往意味着牺牲构图。

**为什么难：** 比例一变，三分点、焦点位置、留白全部失效，只能靠"内容居中 + 边缘可裁"妥协。

**最小验证：** 同一张壁纸在 16:9 与 21:9 裁切后，检查焦点与图标安全区是否仍然成立。

**证据状态：** weak（有通行做法，但缺乏量化规范，偏向工程约定而非可验证边界）。

## 4. 伪边界：看起来像创新但可能不是

| 方向 | 为什么看起来有吸引力 | 为什么可能不是好 gap | 更好的改写 |
|---|---|---|---|
| "重新发明一套配色理论" | 想做出独特风格 | 色彩调和已被成熟理论覆盖，重造基本是重复 | 用现有调和 + 你的参数化生成，做"可复现的配色系统" |
| "做一个万能设计 AI" | AI 风口 + 设计自动化 | 远超入门范围；"随机生成 ≠ 设计决策"，缺乏可控性 | 缩小到"约束式生成器"：固定规则 + 少量随机，先解决可控性 |
| "壁纸越复杂越好看" | 想显得有内容、不单调 | 壁纸是背景，复杂往往抢戏、吃图标，违背"背景性" | 反其道：低细节大面积 + 一个高对比焦点 |
| "凭感觉就能做好设计" | 好作品看起来"自然" | 感觉是练熟规律后的捷径，不是起点 | 先学四原则/网格/色彩，再谈感觉 |

| 用户资产 | 匹配的边界问题 | 第一个可执行动作 | 缺失资源 | 风险 |
|---|---|---|---|---|

## 6. 三条下一步路线

### Route A：保守路线（先读懂 + 最小手作）

- 目标：建立审美与理论直觉，不急于产出。
- 第一周动作：读 Robin Williams《Non-Designer's Design Book》+ Albers 色彩实验（同一颜色不同背景）。
- 成功信号：能用四原则解释"某张图为什么乱/为什么舒服"。
- 止损信号：两周读不完入门书 → 换更短的在线教程，别恋战理论。

### Route B：中等路线（理论 + 手作并行，推荐）

- 目标：边学边做，交付第一张可复现壁纸。
- 第一周动作：读入门书的同时，用 Python 生成 3 张"网格 + 限制配色"壁纸，并写设计理由。
- 成功信号：3 张壁纸对比度达标、有焦点、构图有依据。
- 止损信号：若"写代码"挤占了"学理论"，暂停代码，先补色彩与网格。

### Route C：激进路线（直接上生成器）

- 目标：快速做出"参数化壁纸生成器"（对应 P-004）。
- 第一周动作：跳过完整阅读，直接写一个"输入主色 → 输出一套壁纸"的脚本，再回头用理论检查成品。
- 成功信号：脚本能稳定输出不撞车、达标的一套壁纸。
- 止损信号：成品连续"千篇一律或明显难看"→ 退回 Route B，先固定一种风格做深。
