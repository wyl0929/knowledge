# 11 关键概念与边界说明

Last updated: 2026-08-30

## 概念边界契约 / Concept Boundary Contract

### 用户原始术语

用户使用了"平面设计"（graphic design）和"桌面壁纸"（desktop wallpaper）两个词，并明确要求"理论基础 + 具体壁纸设计方案"。

### 规范工作范围

本 field pack 讨论：**二维视觉传达设计的核心原理**（设计四原则、色彩理论、字体排印、版式构图、网格系统、格式塔知觉、像素/分辨率/对比度），并把这些原理落到**桌面壁纸**这一具体应用（画布规格、多分辨率、配色、构图、图标安全区、风格、工具与导出）。为避免范围失控，把"平面设计"拆成三层：

1. **原理层**（可教学、可迁移的规律）：四原则、色彩三属性、层级、网格、格式塔。
2. **工艺层**（工具与产出规范）：软件/程序化工具、分辨率、色彩空间、导出格式。
3. **应用层**（具体对象）：桌面壁纸（本包焦点）、以及作为对比参照的海报/界面/标识。

### 上位概念、下位概念与相邻概念

- 上位概念：视觉传达设计（visual communication design）、设计（design）。
- 下位概念：字体排印（typography）、色彩（color）、版式/构图（layout & composition）、网格系统（grid system）、品牌与标识（branding & identity）、海报设计、界面设计、图标设计、**壁纸设计**。
- 相邻但不同的概念：纯艺术（fine art）、工业设计（industrial design，偏 3D 产品）、UI/UX 设计（偏交互流程）、插画（illustration，偏叙事/绘画）、摄影、动效设计（motion design）。

### 常见过度等同

1. "平面设计 = 会用 PS/AI"——把工艺层（工具）等同于原理层（决策）。
2. "设计 = 艺术"——忽略设计必须服务任务和受众。
3. "好看 = 好设计"——忽略可用性、清晰度、层级这些可测维度。
4. "壁纸 = 随便一张图"——忽略图标可读性、负空间、多分辨率这些壁纸特有的约束。

### 本包允许使用的表达

- 用"设计四原则"指 contrast/repetition/alignment/proximity（对比/重复/对齐/亲密性）。
- 用"色彩三属性"指 HSL（色相 hue / 饱和度 saturation / 明度 lightness）。
- 用"网格系统"指栅格（列/行/基线网格）与参考线的整体切分方法。
- 用"视觉层级"指靠大小/明暗/位置/留白制造的"先看什么后看什么"。
- 用"图标安全区"指壁纸上为桌面图标预留的低细节、高对比度留白区域（非官方术语，作为通行做法的简称）。

### 本包禁止直接推出的结论

- 不能由"会用工具"推出"会设计"。
- 不能由"颜色好看"推出"对比度达标"（两者独立，需分别验证）。
- 不能由"程序能生成图形"推出"程序在做设计决策"（随机 ≠ 设计）。
- 不能由"某风格流行"推出"该风格适合壁纸"（需回到图标可读性与负空间约束判断）。

### 对下游研究判断的影响

- field map：子方向按"原理层"拆分（色彩/字体/版式/网格/层级/格式塔），并单列"生成式/计算设计"。
- frontier compass：边界落在"好坏量化""生成式可控性""多分辨率通吃"三处。
- gap table：gap 写成"学习/实践缺口"，不做学术研究强声称。
- project title：以"壁纸设计方案"为主，不做"研究型项目"标题。
- MVP success criteria：以"对比度达标 + 有焦点 + 不撞车"这类可测维度为准，不承诺"好看"。

## 0. 阅读说明

本文件比 `00_beginner_guide.md` 更严谨，但仍先解释概念再比较边界。它不是术语表，而是帮助你把"一个词到底指什么、不指什么、和相邻词为什么容易混"搞清楚，从而避免选题误判。

## 1. 核心概念：本领域到底指什么？

### 人话解释

平面设计是"在二维平面上，把文字、颜色、形状、图像和空白安排得有秩序、有重点"的手艺。它的起点不是"美"，而是"传达"——有人要传达信息或制造体验，设计师负责让这个信息在一张平面上"一眼就能被看懂、被感受到"。

### 正式定义或基本模型

平面设计没有唯一公式，但可以用一个"决策模型"描述：

```text
输出画面 = 组织( 文字, 色彩, 形状, 图像, 负空间 ; 约束 = {画布, 信息目标, 受众} )
```

其中"组织"由几个旋钮控制：

- 对比（contrast）：元素之间的差异程度，制造"先看什么"。
- 对齐（alignment）：元素沿隐形的线排布，制造秩序。
- 重复（repetition）：相同元素/样式复用，制造统一感。
- 亲密性（proximity）：相关元素靠近，制造分组。
- 层级（hierarchy）：由以上四者共同产生的"阅读顺序"。
- 色彩（color）：HSL 三属性 + 色相环关系，制造情绪与和谐。
- 负空间（negative space）：空白的主动使用，制造呼吸感与焦点。

### 包含哪些问题

- 如何让信息"一眼读懂"（层级、对比、对齐）。
- 如何让画面"和谐/有情绪"（色彩、风格）。
- 如何在约束下可复现地做出来（网格、设计系统、程序化）。

### 不包含哪些问题

- 3D 产品的造型与结构（工业设计）。
- 交互流程与用户路径（UI/UX，尽管视觉层有重叠）。
- 叙事性手绘/插画技法本身（插画，尽管常作为素材）。
- 纯自我表达、无任务与受众约束（纯艺术）。

### 一个贯穿例子中的位置

```text
信息目标："一张让人专注的桌面壁纸"
  -> 感知层：人眼先扫最大对比 / 最亮 / 最有规律
  -> 本领域核心环节：选配色 + 定构图 + 排元素 + 制造层级 + 留图标安全区
  -> 相邻概念负责：插画（若用插画素材）、UI（若用于系统界面）
  -> 输出：一张 1920×1080 壁纸，图标可读、有焦点、有情绪
```

## 2. 必须掌握的重要概念

### 概念：设计四原则（contrast / repetition / alignment / proximity）

**先用人话说：** 让画面"不打架、有重点、像一家人"的四条基础规则。

**更正式地说：** 对比制造差异（吸引注意、建立层级）；重复制造统一（重复色、形、字重）；对齐制造秩序（元素沿隐形线排布）；亲密性制造分组（相关内容靠近）。

**它解决的问题：** 为什么有些画面"乱"、有些"清楚"。

**它通常输入什么、输出什么：** 输入一堆未组织的元素，输出一个有层级、有秩序、有分组的画面。

**它与哪些概念容易混淆：** 对比 vs 冲突（对比是有目的的差异，冲突是无目的的打架）；对齐 vs 居中（对齐是系统，居中是其中一种）。

**用贯穿例子说明：** 一张壁纸里，背景大面积低对比（亲密性把背景聚成"底"），焦点形状高对比（对比制造"先看这里"），多个形状用同一色系（重复制造统一），文字与形状沿同一条网格线对齐（对齐制造秩序）。

**对选题判断的影响：** 任何"为什么这张图乱"都能先回到这四条排查，再谈风格。

### 概念：色彩三属性与色相环（HSL & color wheel）

**先用人话说：** 一个颜色用"什么颜色 / 多鲜艳 / 多亮"三个旋钮就能说清，比"红绿蓝"更接近直觉。

**更正式地说：** 色相 hue（0°-360° 的角度）、饱和度 saturation（0-100%，灰→纯色）、明度 lightness（0-100%，黑→白）。色相环上相邻=类比色（和谐），相对=互补色（强烈），三等分=三色（均衡）。

**它解决的问题：** 怎么系统地选颜色，而不是随手取色。

**它通常输入什么、输出什么：** 输入一个主色意图，输出一组和谐配色（主色 + 辅助色 + 强调色）。

**它与哪些概念容易混淆：** HSL vs RGB（RGB 是显示器发光的加法三原色，面向"设备如何发光"；HSL 面向"人如何描述颜色"）；HSL vs CMYK（CMYK 是印刷减法的青品黄黑，面向"油墨如何吸收光"）。

**用贯穿例子说明：** 壁纸选一个主色相（如深蓝 215°），用低明度做背景（专注感），用高饱和度、高明度做一个焦点色块（类比色 190° 青），形成"同系但明暗对比"的和谐。

**对选题判断的影响：** 配色翻车（刺眼/灰脏）几乎都能定位到"色相关系或明度对比"选错。

### 概念：字体排印与层级（typography & hierarchy）

**先用人话说：** 字不光要"能读"，还要靠大小、粗细、间距告诉读者"先看哪句"。

**更正式地说：** 字型（typeface）是字体家族的设计，字体（font）是某字重某字号的实例；层级靠字号、字重（粗细）、颜色、间距制造。衬线（serif）显古典/正式，无衬线（sans-serif）显现代/干净，等宽（monospace）显技术感。

**它解决的问题：** 文字多时不乱、有重点、可读。

**它通常输入什么、输出什么：** 输入文字内容，输出一个有主次、可读的排版。

**它与哪些概念容易混淆：** typeface vs font（家族 vs 实例）；行距（leading，行与行间距）vs 字距（tracking，整段字间松紧）vs 字偶距（kerning，特定两字间微调）。

**用贯穿例子说明：** 壁纸若放一句格言，用大字号无衬线 + 大量留白 + 单一字重对比，制造"一句就够"的层级；不建议小字密排（壁纸要扫读，不是阅读）。

**对选题判断的影响：** 字体选择与层级决定"气质"；壁纸这种扫读场景应极简文字。

### 概念：网格系统与负空间（grid & negative space）

**先用人话说：** 网格是画布上隐形的列/行线，让元素"吸附对齐"；留白不是"空着"，而是主动留出的呼吸空间。

**更正式地说：** 网格由页边距（margin）、列数与列间距（gutter）、基线网格（baseline grid）构成；负空间是"没有元素"的区域，但它承担分组、焦点和呼吸功能。

**它解决的问题：** 怎么让复杂版式可复现、不跑偏、有呼吸感。

**它通常输入什么、输出什么：** 输入画布尺寸，输出一套对齐规则（几列、边距多少、基线在哪）。

**它与哪些概念容易混淆：** 网格 vs 参考线（网格是整体切分系统，参考线是单条辅助线）；负空间 vs 空白（空白是被动"没放"，负空间是主动"留着"）。

**用贯穿例子说明：** 壁纸切 6 列，焦点形状跨第 2-3 列、对齐到三分线，右/左侧留一整列低细节作为图标安全区——这就是"网格 + 负空间"在壁纸上的落地。

**对选题判断的影响：** 壁纸的"呼吸感"和"图标可读性"都由网格与负空间决定，不是靠元素数量。

### 概念：格式塔知觉原则（Gestalt principles）

**先用人话说：** 人眼会自动把零散元素"看成整体"，这套自动机制就是格式塔。

**更正式地说：** 接近（相近的看成一组）、相似（相似的看成一组）、闭合（残缺形状自动补全）、连续（沿线条/方向看成连续）、图底（figure-ground，主体与背景的分离）。

**它解决的问题：** 为什么有些图形"自动被读成整体/焦点"。

**它通常输入什么、输出什么：** 输入元素的空间关系，输出"人眼会怎么分组/聚焦"的预判。

**它与哪些概念容易混淆：** 格式塔 vs 装饰（格式塔是知觉机制，不是风格）。

**用贯穿例子说明：** 壁纸上几个分开的圆，若彼此靠近且同色（接近 + 相似），会被自动看成一个"星座/组"而不是散点——你可以用它制造"隐形的焦点"。

**对选题判断的影响：** 控制"元素被看成一组还是散点"，直接影响壁纸的焦点与秩序。

### 概念：像素、分辨率与对比度（pixel / resolution / contrast）

**先用人话说：** 像素是画面最小的色块；分辨率是像素多少/密度；对比度是明暗差异有多大。

**更正式地说：** 1920×1080 是像素尺寸（宽×高）；PPI 是每英寸像素数（密度，与屏幕物理尺寸有关）；对比度 CR=(L1+0.05)/(L2+0.05) 度量明暗差异，WCAG 建议正文文字 ≥4.5:1、大字/图形 ≥3:1。

**它解决的问题：** 壁纸在不同屏幕上清不清晰、图标看不看得见。

**它通常输入什么、输出什么：** 输入目标屏幕（分辨率/比例），输出合适的画布规格与对比度底线。

**它与哪些概念容易混淆：** 分辨率 vs 物理尺寸（像素数 ≠ 英寸大小）；DPI（打印每英寸点数）vs PPI（屏幕每英寸像素数）。

**用贯穿例子说明：** 一张 1920×1080 壁纸在 4K（3840×2160）屏上会被放大，若原图不够大或用了过重压缩，会糊；图标区与背景的对比度若低于 3:1，图标会"被吃掉"。

**对选题判断的影响：** 壁纸是"多设备"产物，导出时必须考虑目标分辨率和对比度底线，这是少数可硬性达标处。

## 3. 容易混淆的概念对比表

| 概念组 | 为什么容易混淆 | 最稳妥的一句话区别 | 如果混淆会怎样误导选题 |
|---|---|---|---|
| 设计 vs 艺术 | 都产出图像 | 设计服务任务与受众，艺术偏自我表达 | 把壁纸当纯艺术做，忽略图标可读性 |
| typeface vs font | 日常都叫"字体" | typeface 是家族，font 是某字重字号实例 | 说不清"用哪个字"，无法落地 |
| 色相 vs 饱和度 vs 明度 | 都描述颜色 | 色相是"什么颜色"，饱和度是"多鲜艳"，明度是"多亮" | 调错旋钮，越调越脏/越刺眼 |
| RGB vs CMYK vs HSL | 都是"颜色空间" | RGB 设备发光、CMYK 印刷吸光、HSL 人脑描述 | 用错空间导致导出偏色 |
| 分辨率 vs 尺寸 | 都涉及"大小" | 分辨率是像素数/密度，尺寸是物理英寸 | 导出尺寸不对，壁纸糊或裁切毁构图 |
| 网格 vs 参考线 | 都是对齐辅助 | 网格是整体切分系统，参考线是单条辅助 | 只画单线，做不出系统版式 |
| 对比 vs 冲突 | 都是"差异" | 对比是有目的的差异，冲突是无目的的打架 | 为"醒目"乱撞色，成品刺眼 |

## 4. 最关键的概念对比展开

### 对比组 1：设计 vs 艺术

**为什么容易混淆**：两者都产出"图"，且都谈"美"。**输入/过程/输出差异**：设计的输入是"任务 + 受众 + 约束"，过程是"为传达而组织元素"，输出必须"达成传达目标"；艺术的输入是"表达冲动"，过程是"探索自我/形式"，输出可以没有明确的外部任务约束。**在壁纸例子中**：设计负责"让图标可读 + 有焦点 + 传达专注情绪"，艺术成分只体现在"选什么风格表达专注"。**混淆的后果**：把壁纸当纯艺术做，可能很美但图标全被吃掉，功能失效。

### 对比组 2：typeface（字型）vs font（字体）vs typography（字体排印）

**为什么容易混淆**：中文里三个都叫"字体"。**差异**：typeface 是"一套字体的设计"（如 Helvetica 整个家族）；font 是"typeface 的一个具体实例"（如 Helvetica Bold 12pt）；typography 是"排印这门手艺"（选字、定字号行距、造层级）。**在壁纸例子中**：选 typeface 是"用衬线还是无衬线"（气质决策），选 font 是"用多大、多粗"（层级决策），typography 是把两者组织成"一句格言的重点"。**混淆的后果**：只纠结"字体好不好看"（typeface 层），却忽略了字号/行距/留白（typography 层），层级做不出来。

### 对比组 3：RGB vs CMYK vs HSL

**为什么容易混淆**：都被叫"颜色空间"。**差异**：RGB 是加法（发光，红绿蓝叠加变白），用于屏幕；CMYK 是减法（油墨，青品黄黑叠加变黑），用于印刷；HSL 是人脑描述（色相/饱和度/明度），用于"选色思考"。**在壁纸例子中**：你在 HSL 里想"深蓝 + 低饱和"（思考），导出 PNG 时用 RGB/sRGB（屏幕），若拿去印刷才涉及 CMYK。**混淆的后果**：在 RGB 里"想颜色"会很绕（红绿蓝不直觉），导出色域错配会偏色。

### 对比组 4：网格 vs 参考线 vs 对齐

**为什么容易混淆**：都用于"对齐元素"。**差异**：网格是"预先切好整个画布的列/行系统"，参考线是"单条辅助线"，对齐是"元素吸附到线"这个动作。**在壁纸例子中**：先画 6 列网格（系统），再在其中拉一条三分参考线（局部），最后让焦点形状对齐到它（动作）。**混淆的后果**：只做"对齐"没有"网格"，版式缺乏系统，元素位置无据可循。

### 对比组 5：对比度 vs 和谐

**为什么容易混淆**：都影响"好不好看"。**差异**：对比度是"明暗差多大"（可测，WCAG 公式），和谐是"颜色放一起是否舒服"（主观，靠调和规律近似）。**在壁纸例子中**：图标区要"高对比度"（可测底线），整体配色要"和谐"（类比色/同系 + 60-30-10）。**混淆的后果**：以为"颜色和谐就够了"，忽略了图标区对比度不够，图标看不清——这是壁纸最常见的翻车点。
