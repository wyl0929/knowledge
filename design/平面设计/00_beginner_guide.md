# 00 Beginner Guide / 人话入门指南

Last updated: 2026-08-30

## 0. 这篇文档怎么读

这篇文档是给第一次接触平面设计的人看的。目标不是把设计史和术语表全塞给你，而是先帮你建立一个直觉：平面设计到底在"调什么旋钮"、为什么有些东西"看着顺眼"而有些"看着乱"、以及你作为一个会写代码的人，能不能把这件事变成可以执行的流程。

阅读顺序：先读第 1-3 节建立直觉，再读第 4-6 节理解领域版图和主流路线，最后读第 7-9 节决定自己下一步该看什么、做什么。

> 全文只用一个贯穿例子：**设计一张 1920×1080 的桌面壁纸**。后文所有理论都会回到这张壁纸的某个具体设计决策上。

## 1. 先用人话说：这个领域到底在研究什么？

### 初学者版一句话

平面设计是在一个二维平面上，把文字、颜色、图像和空白安排得有秩序、有重点，好让别人一眼看懂你想传达的信息、或者感受到你想营造的情绪。

### 研究者版一句话

平面设计（graphic design）研究的是：给定一个画布、一个信息目标和一个受众约束，如何选择并组织视觉元素（文字、色彩、形状、图像、负空间），使输出画面在"可读性/可用性"与"审美/情绪"两个目标之间达成可预期的平衡。它的"输入"是信息与约束，"输出"是可复制的视觉方案，"评价"则同时包含客观维度（对比度、层级、对齐）和主观维度（风格、品味）。

### 这个领域最容易被误解成什么？

1. **"设计 = 会用 PS / AI 软件"**。工具只是画笔，不是设计能力。会用 Photoshop 不等于会设计，正如会用 Word 不等于会写作。软件解决的是"怎么画出来"，设计解决的是"该画什么、放哪里、为什么"。
2. **"设计 = 艺术，好看就行"**。艺术（art）可以纯粹表达自我，设计（design）必须服务于一个**任务和受众**。一张海报好不好，不是看它"美不美"，而是看它有没有在 0.5 秒内让路人抓到重点。
3. **"设计全凭感觉，没有规律"**。这是最大的误解。设计有大量可教学、可验证的规律（对齐、对比、色彩调和、网格），感觉只是在你把规律练熟之后的捷径，而不是起点。

## 2. 一个贯穿全文的最小例子：一张 1920×1080 壁纸

我们用"设计一张桌面壁纸"当贯穿例子，因为它小、边界清楚、而且能同时踩到几乎所有基础理论。

- **输入是什么**：一张 1920×1080 像素（16:9）的画布；一个用途（桌面背景）；一个情绪目标（比如"冷静、专注"）。
- **系统 / 对象是什么**：画布上要被组织的视觉元素——背景色、可能的渐变、几个几何形状、可选的几行文字。
- **人可以调的旋钮是什么**：配色（选哪几种颜色）、构图（元素放在哪里、留白留多少）、对比（明暗差、大小差）、字体（用不用字、用什么字）、层级（先看什么后看什么）。
- **输出或评价指标是什么**：一张壁纸。评价它好不好，可以分成两类——**客观的**：桌面图标放在上面还能不能看清（对比度够不够）、有没有一个视觉焦点、元素是否对齐；**主观的**：颜色是否和谐、风格是否统一、有没有传达出你要的情绪。
- **为什么这个例子代表了领域的核心困难**：壁纸这个例子同时暴露了设计的两个永恒张力——它既要"好看"（主观、情绪），又要"能用"（图标必须可读，也就是客观约束）。真正的平面设计能力，就是学会在这两根绳子之间走钢丝。

## 3. 它在更大知识链条中的位置

平面设计不是孤立的手艺，它在一条"信息传达"链条的中间层：

```text
有人想传达信息 / 制造体验（上游目标：品牌、通知、氛围）
  -> 视觉语法：人眼如何感知形状、颜色、对比（感知层）
  -> 平面设计：把元素组织成有秩序、有层级的画面（本领域核心环节）
  -> 工具与产出：海报 / 界面 / 图标 / 壁纸 / 包装（下游载体）
  -> 受众是否看懂、是否被触动（反馈，重新影响上游）
```

**为什么这一层绕不过去？** 因为人眼不是逐像素读图的，它会先扫到"最大的对比""最亮的地方""最有规律的形状"。如果中间这一层（组织与秩序）没做好，再好的信息也会被埋没——下游的表现就是"看着乱""找不到重点""图标被背景吃掉"。反过来说，如果你懂这一层，哪怕素材很简单，也能做出"一眼就舒服"的东西。

## 3.5 最小数学对象 / 最小公式

平面设计里有两类"可计算"的东西，正好适合你这种有理工背景的人先抓住。

### 公式 1：黄金比例（golden ratio）与三分法

$$ \varphi = \frac{1+\sqrt{5}}{2} \approx 1.618 $$

- $\varphi$：黄金比例，一个约 1.618 的无理数。
- 用法：把画面按 $\varphi$ 或按三等分线切分，把焦点元素放在分割线或其交点上，而不是死板地放正中央。
- 关键含义：它给"舒服的位置"一个可重复的近似规则。你不需要迷信它，但它比"随手放"可靠，也比"永远居中"更有层次。

### 公式 2：WCAG 对比度（contrast ratio）——壁纸可用性的硬指标

$$ \text{CR} = \frac{L_1 + 0.05}{L_2 + 0.05} $$

- $L_1$：较亮一方的相对亮度（relative luminance），$L_2$：较暗一方。
- 用法：桌面图标的颜色和壁纸背景之间的对比度 $\text{CR}$，直接决定图标"看得见还是被吃掉"。W3C 的 WCAG 指南建议正文文字对比度至少 4.5:1，大字/图形至少 3:1。
- 关键含义：**"好看"可以争论，但"看得清"可以算**。一张壁纸哪怕配色再高级，如果图标和背景对比度掉到 2:1 以下，它就是一张失败的功能壁纸。这是设计里少数几个能客观度量的地方，也是你最容易上手的切入点。

### 最小流程（任何一张壁纸都会走一遍）

```text
明确目标与约束（尺寸 / 用途 / 情绪）
  -> 选配色（色相 / 饱和度 / 明度，通常 2-4 色）
  -> 定构图（三分法 / 网格 / 留白与图标安全区）
  -> 排元素（形状、渐变、可选文字）与层级
  -> 检查对比度与对齐
  -> 导出（PNG，sRGB，目标分辨率）
```

## 4. 这个领域里的人主要分成哪几派？

设计史上有几条清晰的谱系，它们不是"对错"之分，而是"秩序 vs 表现"这根轴上的不同落点。

### 路线 A：瑞士国际主义 / 网格派（Swiss / International Style）

**人话解释：** 用严格的网格、无衬线字体（如 Helvetica）和留白，把信息排得像数学一样有秩序。

**它想解决什么问题：** 让复杂信息（时刻表、海报、说明书）在"扫一眼"的层面就清清楚楚、客观、可复现。

**大概怎么做：** 先把画布切成若干列和行，所有文字和图形严格对齐到网格线上，字体尽量统一，靠字号和留白制造层级。

**优点：** 清晰、耐看、可教学、可复现，几乎不会"乱"。

**麻烦：** 做不好会显得冷冰冰、没个性；过于教条时反而压抑情绪表达。

**和用户背景的关系：** 最高。网格本质是一套"坐标约束"，你能直接用代码把网格画出来、把元素对齐到网格点。

### 路线 B：现代主义 / 包豪斯（Bauhaus）传统

**人话解释：** "形式服从功能"，用最少的几何形状（圆、三角、方）和原色，去掉一切装饰。

**它想解决什么问题：** 工业时代怎么做出诚实、可批量、不装腔作势的视觉。

**大概怎么做：** 从几何抽象出发，限制元素数量，颜色用高饱和原色或极简灰阶，强调"少即是多"。

**优点：** 简洁、有力、不过时，和极简/扁平风一脉相承。

**麻烦：** 极简不等于简单，元素太少时每个细节都会被放大，反而更难做好。

**和用户背景的关系：** 高。几何抽象天然适合用代码生成（圆、矩形、直线都是可参数化的）。

### 路线 C：后现代 / 表现派（Postmodern / New Wave）

**人话解释：** 故意打破网格、混排字体、制造视觉张力，用"乱"来表达态度。

**它想解决什么问题：** 当所有东西都太整齐、太"企业化"时，用破坏规则来吸引注意、表达反叛或情绪。

**大概怎么做：** 故意不居中、字体混搭、叠印、噪点、拼贴。

**优点：** 醒目、有个性、情绪强。

**麻烦：** 极难做好——它依赖你对"规则"的深刻理解，否则就是纯粹的乱。

**和用户背景的关系：** 低到中。它最不容易程序化，建议先掌握规则再谈打破规则。

### 路线 D：极简 / 扁平 / 数字风（Minimal / Flat / Digital）

**人话解释：** 面向屏幕的当代主流——扁平色块、留白多、无装饰、靠颜色和间距说话。

**它想解决什么问题：** 在小屏幕、多分辨率、快节奏下依然清晰可用。

**大概怎么做：** 限制配色、大量留白、元素极少、强调"内容优先"。苹果、谷歌、微软的设计系统都走这条路。

**优点：** 干净、现代、跨分辨率友好，和壁纸这种"背景"场景天然契合。

**麻烦：** 元素越少，越考验你的色彩和间距功力。

**和用户背景的关系：** 高。扁平风几乎是"程序化壁纸"的最佳画风。

## 5. 最容易混淆的概念

| 概念 | 一句话解释 | 容易和什么混 | 更稳妥的区别 | 小例子 |
|---|---|---|---|---|
| 设计（design） | 为任务和受众组织视觉元素 | 艺术（art） | 设计有"要解决的问题"，艺术偏自我表达 | 海报要"让人看懂活动信息"，纯绘画不必 |
| 字型（typeface） | 一套字体的设计，如 Helvetica | 字体（font） | typeface 是"字体家族"，font 是某字重某字号的实例 | Helvetica 是 typeface，Helvetica Bold 12pt 是 font |
| 色相（hue） | 颜色的"种类"，红还是蓝 | 饱和度（saturation） | 色相是"什么颜色"，饱和度是"颜色多鲜艳" | 浅粉和大红同色相，不同饱和度/明度 |
| 分辨率（resolution） | 像素总数或像素密度 | 尺寸（尺寸是物理大小） | 1920×1080 是像素数，与屏幕物理英寸无关 | 同一张壁纸在 15 寸和 27 寸屏上物理大小不同 |
| 网格（grid） | 隐形列/行参考线 | 参考线（guides） | 网格是整体切分系统，参考线是单条辅助线 | 12 列栅格 vs 一条居中对齐线 |
| 对比（contrast） | 元素之间的差异程度 | 冲突（clash） | 对比是有目的的差异，冲突是无目的的打架 | 黑白对比是设计，红绿乱撞是事故 |

## 6. 这个方向现在真正卡在哪里？

对入门者来说，真正的瓶颈不是"会不会用软件"，而是下面几个"软"问题：

### 困难 1：好坏难以量化

**普通话解释：** 没有一台仪器能测出"这张壁纸好还是不好"。

**为什么难：** 设计同时服务"能用"和"好看"两个目标，前者可以测（对比度、对齐），后者高度依赖语境和受众。

**现在通常怎么绕：** 用设计原则（对齐、对比、层级）和可测指标（WCAG 对比度、网格对齐）先兜底，再用"多看、多改、多对比"培养审美。

**为什么还没有完全解决：** 因为审美本就不是一个待求解的方程，它是文化、经验和语境的产物。

**对用户意味着什么：** 别指望"学一个公式就能做出好设计"。先抓住可测的那部分（对比度、对齐、配色规则），审美靠积累。

### 困难 2：好设计常常"看不见"

**普通话解释：** 最好的设计让用户感觉不到"设计"的存在，只有糟糕的设计才让人注意。

**为什么难：** 这意味着评价标准是"没有突兀感"，而不是"元素多精彩"，很难自我表扬，也很难一开始就学会。

**现在通常怎么绕：** 反过来学——先看"翻车"案例（图标被背景吃掉、文字贴边、颜色刺眼），建立"什么不能做"的清单。

**对用户意味着什么：** 壁纸尤其如此。壁纸是"背景"，它永远不该抢戏；它的成功是"存在但不打扰"。

### 困难 3：从"懂理论"到"做得出"之间有一道鸿沟

**普通话解释：** 背下"对比、重复、对齐、亲密性"四个词很容易，真正在一张空画布上做出来是另一回事。

**为什么难：** 设计是"在无数可能中做选择"的技能，理论只告诉你原则，不告诉你这次该选哪个。

**现在通常怎么绕：** 用**约束**逼自己：限制配色（只准 2 色）、限制形状（只准圆形）、限制字体（只准一种）。约束越紧，选择越少，越容易起步。

**对用户意味着什么：** 这对你特别有利——你会写代码，可以把"约束"直接写进程序，让每次生成都严格遵守规则。

## 7. 如果我是这个用户，我应该重点看哪里？

结合你的背景（计算物理 + Python/matplotlib/LaTeX）：

- **用户已有资产**：Python 脚本能力、matplotlib 可视化、LaTeX 排版、对"参数化/可复现"的天然偏好。
- **最匹配的领域切口**：**程序化/生成式壁纸**。把"网格系统 + 配色规则 + 三分法"写成一个 Python 脚本，参数化地生成一套壁纸。这正好把你的强项（代码、参数、可复现）翻译成设计领域的核心方法（网格、约束、系统）。
- **不建议一开始投入的方向**：复杂手绘插画、字体库的字形工程、后现代拼贴风（需要大量手感和审美积累，且最不程序化）。
- **第一周最小动作**：用 Python 的 Pillow（PIL）写一个脚本，生成一张 1920×1080 的壁纸——纯色背景 + 一个按三分法放置的几何形状，限制 2-3 种颜色，并写清楚"为什么这么放、为什么选这个色"。哪怕是 30 行代码，也是一次完整的设计决策练习。
- **需要先核验的资源或文献**：Pillow/cairo 的确切 API、WCAG 相对亮度的精确计算公式（用于自算对比度）；具体经典书目的出版年份见 `14_paper_registry.md` 的待核验标注。

## 8. 三个可以继续追的方向

### Direction 1：系统学色彩理论（Albers 式训练）

**为什么值得看：** 色彩是壁纸最直观的旋钮，也是最容易"翻车"的地方（刺眼、灰暗、俗气）。

**最小实验 / 最小阅读动作：** 读 Josef Albers《Interaction of Color》的前几章，做一个练习——把同一个颜色分别放在两个不同背景上，观察它"看起来变了"。

**baseline：** 只凭直觉选色、随手取色。

**成功信号：** 能说出一个颜色"冷/暖、明/暗、饱和/灰"三个属性，并能解释为什么两种颜色放一起会打架或和谐。

**止损信号：** 读完两章仍无法区分"色相/饱和度/明度"，先退回 HSL 色彩模型补基础。

**风险：** 色彩理论书偏学术，容易读不下去；用"动手调色"代替纯阅读。

### Direction 2：用代码复刻一张瑞士风格海报版式

**为什么值得看：** 网格是设计的"骨架"，而网格天然可程序化——这是你最容易把设计"算出来"的地方。

**最小实验 / 最小阅读动作：** 找一张 Müller-Brockmann 的经典海报，用 Python 复刻它的网格：画布切成几列几行，文字块和图形分别对齐到哪条线。

**baseline：** 不画网格、凭感觉摆放元素。

**成功信号：** 你能不看原图，仅凭"列数 + 元素对齐规则"重新生成一个结构相同的新版式。

**止损信号：** 如果发现"网格"概念和"参考线"分不清，先回 `11_term_disambiguation.md` 第 4 节。

**风险：** 变成"临摹"而非"理解"；复刻后要追问"为什么作者用 6 列而不是 8 列"。

### Direction 3：做一套你自己的程序化壁纸生成器

**为什么值得看：** 这是把前面所有理论落地的最终产物，也是你最有差异化的切入。

**最小实验 / 最小阅读动作：** 把 Direction 1 和 2 的成果合并——一个脚本输入"情绪/主色/风格"几个参数，输出一套 1920×1080 壁纸（详见 `22_project_candidates.md` 的 P-004）。

**baseline：** 手工在 Figma 里一张张做。

**成功信号：** 脚本能稳定输出"不撞车、对比度达标、有焦点"的一套壁纸。

**止损信号：** 若连续生成的壁纸都"千篇一律或明显难看"，说明参数空间设计有问题，退回先固定一种风格做深，而不是做"万能生成器"。

**风险：** 陷入"技术炫技"而忽略审美；用"随机参数"冒充"设计决策"。

## 9. 一页纸总结

- 平面设计是"在约束下组织视觉元素，让人看懂、被触动"的手艺，不是"会用软件"也不是"纯艺术"。
- 它卡在信息传达链条的中间层：感知 → 组织 → 载体。这一层做不好，下游就是"乱、找不到重点、图标被吃掉"。
- 核心旋钮只有几个：对比、对齐、重复、亲密性（四原则）+ 色彩 + 字体 + 网格/留白 + 层级。
- 主流路线是"秩序（瑞士/网格）↔ 表现（后现代）"这根轴上的不同落点，极简/扁平是面向屏幕的当代主流。
- 已经有成熟 baseline：网格系统、色彩调和、无衬线字体、设计系统（Material / HIG）；这些不能假装不存在。
- 真正卡住的是"好坏难以量化""好设计看不见""懂理论 ≠ 做得出"这三堵软墙。
- 你（会写代码的人）的最佳切口是**程序化壁纸**：把网格、配色、构图写进代码，用参数代替直觉。
- 第一周建议：用 Python 生成一张"纯色 + 三分法几何形 + 2-3 色"的 1920×1080 壁纸，并写下设计理由。
- 客观可测的部分（对比度、对齐）先兜底，主观审美靠多看多改积累。
- 仍要核验：具体经典书目/年份、Pillow API 细节、WCAG 亮度公式的精确系数。
