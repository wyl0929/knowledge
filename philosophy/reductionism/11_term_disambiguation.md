# 11 关键概念与边界说明

Last updated: 2026-07-17

## 概念边界契约 / Concept Boundary Contract

### 用户原始术语

**还原论**。英文对应词：**Reductionism**。

### 规范工作范围

本 field pack 讨论哲学意义上的还原论——即认为复杂系统（及其现象、规律）可以完全由其组成部分（及其相互作用规律）来解释的立场。

还原论不是一个单一命题，而是一个包含三个层次的概念簇：

1. **本体论还原论（Ontological Reductionism）**：关于"存在什么"的主张——高层实体是否"只不过是"低层实体的组合？
2. **方法论还原论（Methodological Reductionism）**：关于"如何研究"的策略——把系统分解为部分是否是获得知识的最佳（甚至是唯一）途径？
3. **认识论还原论（Epistemological Reductionism）/ 理论还原论（Theory Reduction）**：关于"知识如何组织"的主张——高层科学的理论是否可以从低层科学的理论中逻辑推导出来？

这三个层次经常被混用，但区分它们对于理解还原论争论至关重要。

### 上位概念、下位概念与相邻概念

- **上位概念**：科学哲学（Philosophy of Science）、形而上学（Metaphysics）、认识论（Epistemology）
- **下位概念**：
  - 物理主义（Physicalism）：一切存在的东西都是物理的，或随附于物理的
  - 理论间还原（Intertheoretic Reduction）：如热力学还原为统计力学
  - 说明性还原（Explanatory Reduction）：如用基因解释表型
  - 构成性还原（Constitutive Reduction）：如化学键还原为量子力学
  - 因果还原（Causal Reduction）：高层因果过程可由低层因果过程完全说明
- **相邻但不同的概念**：
  - **突现论（Emergentism）**：主张高层现象不能完全由低层规律推导——是还原论的主要对手
  - **整体论（Holism）**：强调系统作为整体的不可分割性——方法论上反对还原
  - **随附性（Supervenience）**：高层属性由低层属性决定，但未必可还原——是试图在还原论与突现论之间找中间路线的技术概念
  - **取消主义（Eliminativism）**：不仅不可还原，而且高层概念根本不存在——比还原论更激进
  - **多元论（Pluralism）**：不同层次的解释各有自主性，不可互相替代

### 常见过度等同

| 过度等同 | 为什么是错的 |
|----------|-------------|
| 还原论 = "无非是"（nothing-buttery） | 还原论作为一种哲学立场有严格论证；"无非是"是一种修辞姿态，不等于提供了有效的还原 |
| 还原论 = 物理主义 | 物理主义是关于"存在什么"的形而上学立场；还原论是关于"解释关系"的方法论/认识论立场。可以同时是物理主义者但反对还原论（如突现唯物主义者） |
| 还原论 = 科学方法本身 | 科学确实大量使用分析—分解方法，但这不等于科学本身要求所有现象都必须可还原。许多科学实践（如凝聚态物理、系统生物学）明确使用非还原策略 |
| 反还原论 = 反科学 / 神秘主义 | 反还原论立场（如 Anderson、Laughlin）来自一流物理学家，是对科学实践复杂性的严肃反思，不是反科学 |
| 方法论还原 = 本体论还原 | "我们把系统拆开来研究"不等于"系统不过是部分的集合"。前者是研究策略，后者是形而上学主张 |

- "还原论"作为统称，指上述三个层次的立场簇
