# power_reductionism_as_case / 权力还原论——还原论哲学根源分析

Last updated: 2026-07-19

## 定位

本子方向是 `reductionism/` 与 `power_reductionism/` 之间的**薄桥**。它的职责不是重复权力还原论的具体历史实例和叙事分析（那些在 `power_reductionism/`），而是聚焦一个更窄的问题：

> **权力还原论在什么意义上是一种"还原论"？它在方法论和认识论上的还原论根源是什么？**

## 两端分工

| | `power_reductionism/` | `power_reductionism_as_case/`（本包） |
