# USER BRIEF / 本次需求说明

Last updated: 2026-07-17

## 这份文件的作用

这里保存用户对本 field pack 的特殊要求。内容可以直接用自然语言书写。
生成或更新本包中的任何主体文档前，agent 都必须先读取本文件。

本文件与其他文件的区别：

- `10_self_inventory.md`：记录本次使用的 profile 或用户背景快照；
- `USER_BRIEF.md`：记录本次调研的目标、重点、写作方式和回避事项；
- `90_QA.md`：保存后续自由讨论，默认不自动成为持续要求；
- `99_update_log.md`：保存修改历史。

## 用户原始需求

> 什么是还原论？在 philosophy 下创建一个新 field

## 当前有效要求

- 理解还原论的核心概念、思想渊源、主要流派和当代争论
- 纯智识兴趣，不需要结合个人计算物理背景
- 不需要找课题或研究项目

## 内容侧重点

- 希望重点展开：还原论的定义与类型（本体论/方法论/认识论）、思想史脉络、关键人物与论著、还原论与突现论/整体论的争论
- 希望简略处理：过于技术化的科学哲学形式论证
- 暂时不需要涉及：与计算物理的直接关联（用户已明确这是独立兴趣）

## 写作与呈现偏好

- 语言与风格：中文可读风格，术语初次出现时括注英文
- 期望深度：中等——能建立清晰版图，理解核心争论
- 是否需要公式 / 流程 / 作品例子 / 图表：需要关键思想实验和经典案例
- 是否需要阅读清单：是，需要可验证的阅读方向指引
- 是否需要派生子方向：暂不指定，视后续 QA 而定
