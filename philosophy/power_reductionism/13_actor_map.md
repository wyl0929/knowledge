# 13 关键思想家登记

Last updated: 2026-06-19

---

## 说明

本文件登记与权力还原论讨论相关的核心人物。分为三组：
- **A 组（谱系源头）**：权力还原论所挪用或简化的思想来源；
- **B 组（批判者）**：对权力还原论及其思想根源进行了系统批判的学者；
- **C 组（当代分析者）**：对当代媒介中的权力还原论现象进行了分析的学者。

标注 `NEEDS_VERIFICATION` 的条目表示具体出版年份、中译本信息需要进一步核实。

---

## A 组：谱系源头（被挪用或简化的思想家）

### A1. 修昔底德（Thucydides，约前460—前400）

| 维度 | 内容 |
|------|------|
| **身份** | 雅典将军、历史学家 |
| **核心文本** | 《伯罗奔尼撒战争史》 |
| **核心贡献** | 开创了权力政治分析的史学传统；"米洛斯对话"是古典现实主义的奠基文本 |
| **与权力还原论的关系** | 被 YouTube 叙事当作"强者即正义"的古代背书，但修昔底德本人分析了制度（雅典民主 vs 斯巴达寡头）、战略资源和同盟结构等多重因素 |
| **关键区分** | 修昔底德的"权力"是国家间关系的结构性概念，不是个人心理概念 |
| **推荐阅读** | "米洛斯对话"章节（第五卷第84-116节） |

### A2. 尼可罗·马基雅维利（Niccolò Machiavelli，1469—1527）

| 维度 | 内容 |
|------|------|
| **身份** | 佛罗伦萨外交官、政治哲学家 |
| **核心文本** | 《君主论》（1513/1532）、《论李维》（约1517/1531） |
| **核心贡献** | 将政治分析从道德神学中解放出来，建立了基于"实效真理"（verità effettuale）的政治分析方法 |
| **与权力还原论的关系** | 是权力还原论最常引用的"祖先"，但这种引用本身就是对其思想的系统性简化。《论李维》中的共和主义维度被完全忽略 |
| **关键区分** | 马基雅维利的分析单元是国家（lo stato），而非君主个人的私欲 |
| **推荐阅读** | 《君主论》第15-18章 + 《论李维》第一卷 |

### A3. 托马斯·霍布斯（Thomas Hobbes，1588—1679）

| 维度 | 内容 |
|------|------|
| **身份** | 英国哲学家 |
| **核心文本** | 《利维坦》（1651） |
| **核心贡献** | 提出了以"自然状态"为起点的社会契约论；对人类竞争性、权力欲提供了系统的哲学人类学分析 |
| **与权力还原论的关系** | "人对人是狼"被当作权力还原论的人类学"公理"。但霍布斯分析的是 **没有主权者时的自然状态**，而非文明社会的常态 |
| **关键区分** | 霍布斯的目标是从这种"不美好"的人性出发论证主权（利维坦）的必要性——他的结论不是"所以人可以随便争权"，而是"所以我们需要一个强大的公共权力来约束所有人" |

### A4. 托马斯·卡莱尔（Thomas Carlyle，1795—1881）

| 维度 | 内容 |
|------|------|
| **身份** | 苏格兰散文家、历史学家 |
| **核心文本** | 《论英雄、英雄崇拜与历史上的英雄业绩》（1841） |
| **核心贡献** | 19世纪"伟人史观"最系统的阐述者 |
| **与权力还原论的关系** | "历史由少数人驱动"的结构被权力还原论继承，但卡莱尔的"英雄"被替换为"权力动物" |
| **关键区分** | 卡莱尔的核心价值是"真诚"（sincerity）和道德感召力，而非权力技术 |

### A5. 赫伯特·斯宾塞（Herbert Spencer，1820—1903）

| 维度 | 内容 |
|------|------|
| **身份** | 英国哲学家、社会学家 |
| **与权力还原论的关系** | 伟人史观最早的也是最有力的批判者之一 |
| **核心论证** | "在他改造社会之前，社会先造就了他。"——伟人是其时代的社会条件的产物，而非历史的独立驱动者 |
| **推荐阅读** | 《社会学研究》（1873）中关于"伟人"的章节 |

### A6. 加埃塔诺·莫斯卡（Gaetano Mosca，1858—1941）

| 维度 | 内容 |
|------|------|
| **身份** | 意大利政治学家、精英理论创始人之一 |
| **核心文本** | 《统治阶级》（Elementi di scienza politica，1896） |
| **核心贡献** | 论证一切社会都由"有组织的少数"统治（政治阶级）；提出"政治公式"（political formula）作为合法性机制 |
| **与权力还原论的关系** | 精英理论的"少数统治"论断被简化为"顶层的人就是想一直在顶层"——丢失了莫斯卡对组织化统治的分析 |
| **推荐阅读** | 《统治阶级》英译本（The Ruling Class，1939） |

### A7. 维尔弗雷多·帕累托（Vilfredo Pareto，1848—1923）

| 维度 | 内容 |
|------|------|
| **身份** | 意大利经济学家、社会学家 |
| **核心文本** | 《心灵与社会》（Trattato di sociologia generale，1916） |
| **核心贡献** | 精英循环理论；"残基"（residues）与"派生物"（derivations）的区分；精英的"狐狸"与"狮子"类型学 |
| **与权力还原论的关系** | 帕累托本人试图建立关于人类非理性行为的社会心理学分类，而非简单地说"人都贪权"。但他的术语确实容易被通俗化 |

### A8. 罗伯特·米歇尔斯（Robert Michels，1876—1936）

| 维度 | 内容 |
|------|------|
| **身份** | 德裔意大利社会学家 |
| **核心文本** | 《政党社会学》（Zur Soziologie des Parteiwesens，1911） |
| **核心贡献** | "寡头铁律"——民主组织因规模扩大和专业分工的内在逻辑而必然走向寡头化 |
| **与权力还原论的关系** | 米歇尔斯分析的是 **组织逻辑** 的必然性，而非 **领袖个人** 的道德缺陷。这一关键区分在通俗传播中被抹除 |

### A9. 李宗吾（1879—1944）

| 维度 | 内容 |
|------|------|
| **身份** | 中国近代思想家（自号"厚黑教主"） |
| **核心文本** | 《厚黑学》（1917） |
| **核心贡献** | 以讽刺手法系统地将中国历史解读为"脸厚心黑"的权术实践史 |
| **与权力还原论的关系** | 《厚黑学》是传统权谋叙事向现代犬儒主义过渡的关键文本。它既是讽刺（不应被字面阅读），又确实为后来的权力还原论提供了叙事资源 |

## B 组：批判者

### B1. 卡尔·马克思（Karl Marx，1818—1883）

| 维度 | 内容 |
|------|------|
| **身份** | 德国哲学家、经济学家、革命理论家 |
| **核心文本** | 《政治经济学批判》序言（1859）、《德意志意识形态》（1845-46） |
| **核心贡献** | 历史唯物主义——生产力的发展及其与生产关系的矛盾是历史变迁的根本动力 |
| **与权力还原论的关系** | 提供了最系统的替代性框架。核心批判：个人动机（包括权力欲）不是历史的终极解释，而是需要被物质条件解释的对象 |
| **推荐阅读** | 《政治经济学批判》序言（短，约12页，是历史唯物主义的经典表述） |

### B2. 弗里德里希·恩格斯（Friedrich Engels，1820—1895）

| 维度 | 内容 |
|------|------|
| **身份** | 德国哲学家、马克思的合作者 |
| **核心文本** | 《路德维希·费尔巴哈和德国古典哲学的终结》（1886） |
| **核心贡献** | 对"动机驱动历史"观点最清晰的批判。第四章是历史唯物主义方法论的经典阐述 |
| **与权力还原论的关系** | 恩格斯直接回应了"历史由个人动机驱动"的观点——他承认个人动机是历史的直接表象，但拒斥这是最终解释 |
| **推荐阅读** | 《费尔巴哈论》第四章 |

### B3. E.H. 卡尔（E.H. Carr，1892—1982）

| 维度 | 内容 |
|------|------|
| **身份** | 英国历史学家、国际关系学者 |
| **核心文本** | 《历史是什么？》（What is History?，1961） |
| **核心贡献** | 对"伟人史观"和"偶然性崇拜"的经典批判；区分"过去的事实"与"历史事实" |
| **与权力还原论的关系** | 直接批判了将历史简单化为个人意志和偶然事件的观点 |
| **推荐阅读** | 《历史是什么？》第一讲"历史学家与他的事实" |

### B4. 罗伯特·达尔（Robert Dahl，1915—2014）

| 维度 | 内容 |
|------|------|
| **身份** | 美国政治学家、民主理论家 |
| **核心文本** | 《谁统治？》（Who Governs?，1961） |
| **核心贡献** | 对精英理论的经典经验挑战——通过纽黑文案例研究论证：不同政策领域由不同的利益集团主导，不存在单一的"权力精英" |
| **与权力还原论的关系** | 达尔的研究是对"一切政治由少数寡头驱动"的直接经验反驳 |
| **推荐阅读** | 《谁统治？》 |

### B5. 彼得·斯洛特戴克（Peter Sloterdijk，1947— ）

| 维度 | 内容 |
|------|------|
| **身份** | 德国哲学家 |
| **核心文本** | 《犬儒理性批判》（Kritik der zynischen Vernunft，1983） |
| **核心贡献** | 定义了现代犬儒主义——"启蒙了的虚假意识"——作为当代文化的核心病症 |
| **与权力还原论的关系** | 斯洛特戴克的犬儒主义理论是理解权力还原论受众心理的关键框架：受众之所以接受"一切皆权力"，不是因为他们相信这是真的，而是因为这种相信让他们可以免于认真行动 |
| **推荐阅读** | 《犬儒理性批判》（中译本或英译本 Critique of Cynical Reason） |
