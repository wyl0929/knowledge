# 00 入门指南：权力还原论史学——当"一切都是争权"成为一种历史解释

Last updated: 2026-06-19

---

## 先读这一句

**有一种历史解释套路非常流行：不管什么政治事件——变法、战争、清洗、改革、联盟——最后的原因都是"某个人想要权力"。这种解释听起来很"清醒"、很"深刻"，但它在历史学中其实有一个名字，有一段长达两千五百年的渊源，而且受到了来自历史唯物主义、制度主义和科学哲学的严厉批判。**

本指南写给第一次认真思考这个问题的读者。不预设历史学专业知识。

---

## 1. 从一个熟悉的场景开始

你在 YouTube 上看一个关于某段政治史的视频。视频告诉你：

- 某场改革之所以发生，是因为"A 想借改革削弱 B 的势力"；
- 某次人事变动背后，是"C 和 D 的派系斗争"；
- 某项政策的真正目的，是"E 在为自己的连任铺路"。

你看完后觉得"好有道理"——但同时隐隐不安：**是不是所有政治事件都能这样解释？如果是，那这种解释还有信息量吗？**

### 一个思想实验

假设有这样一段对话：

> —"为什么罗马帝国衰亡了？"
> —"因为掌权者都想维护自己的权力。"
>
> —"为什么唐朝建立了科举制？"
> —"因为皇帝想用科举制削弱门阀的权力。"
>
> —"为什么科举制后来又被废除了？"
> —"因为掌权者觉得科举制威胁了他们的权力。"

注意这里发生了什么：**同一种解释（"掌权者想维护权力"）被用来解释了两个相反的历史结果（建立科举制和废除科举制）。** 一个能解释一切的解释，其实什么都没解释。这不是真正的历史分析，而是一种**万能叙事模板**。

---

## 2. 这种史观叫什么名字？

学术上没有单一的"学派"对应这个套路，但可以从多个角度给它贴标签：

| 标签 | 含义 | 适用性 |
|------|------|--------|
| **权力还原论（power reductionism）** | 将宏观历史因果还原为精英个体的权力动机这一单一变量 | ★★★★★ 最精确 |
| **庸俗马基雅维利主义（vulgar Machiavellianism）** | 把马基雅维利复杂的治国术简化为"人人都在抢权力" | ★★★★ |
| **心理主义史学（psychologism in history）** | 用个体心理动机解释一切制度与结构变迁 | ★★★★ |
| **伟人史观的暗黑版** | 卡莱尔"历史是伟人传记"的犬儒翻版——伟人变成了"权力动物" | ★★★ |
| **"宫斗"叙事模板** | 在中国语境下，将一切政治简化为高层人物间的权谋斗争 | ★★★（语境特定） |

本 field pack 统一使用 **权力还原论** 作为核心术语。

---

## 3. 这种史观从哪来？——七条思想脉络

权力还原论不是一个"学派"，而是多条思想线索在当代流行文化中的缝合。下面是简化版谱系（完整版见 `12_field_map.md`）：

```
古典政治现实主义（修昔底德、马基雅维利）
        │
        ├──→ 伟人史观（卡莱尔，19世纪）
        │         │
        │         └──→ 伟人论的暗黑化：英雄变权力动物
        │
        ├──→ 精英理论（帕累托、莫斯卡、米歇尔斯，19-20世纪）
        │         │
        │         └──→ "一切组织必走向寡头"的结构性论断
        │                   │
        │                   └──→ （被通俗化后）变成"一切皆个人争权"
        │
        ├──→ 心理史学（弗洛伊德-埃里克森，20世纪中期）
        │         │
        │         └──→ 用个人无意识解释历史——已边缘化但遗风犹存
        │
        ├──→ 冷战克里姆林学（20世纪中后期）
        │         │
        │         └──→ 从照片站位推断权力斗争——方法论惯性
        │
        ├──→ 中国传统宫廷政治叙事（二十四史中的权斗传统）
        │         │
        │         └──→ （被去语境化后）剥离道德/制度框架，只留权斗
        │
        └──→ YouTube 算法 + 当代犬儒主义
                  │
                  └──→ 高冲突内容 → 高点击 → 算法推荐 → 信息茧房
```

**关键区分**：以上每一脉在其原始语境中都比"一切皆争权"复杂得多。马基雅维利同时是共和主义者；精英理论分析的是组织结构而非个人心理；传统中国史学有天命、德性、制度等多层框架。当代 YouTube 版本是对这些传统的 **去语境化通俗拼接**。

---

## 4. 为什么这种解释这么"好看"？

这不是一个偶然现象。权力还原论的流行有深层原因：

**（1）认知经济性**：人的大脑喜欢简单。一套"争权"模板可以套用在任何政治事件上，不需要学习制度史、经济史或思想史。

**（2）叙事戏剧性**：权力斗争天然有冲突、反转、阴谋、背叛——比"白银流入导致价格革命"好看得多。

**（3）伪深刻效应**：这种叙事给受众"我看穿了"的智识优越感。"他们嘴上说的是理想，但我知道真正的原因就是权力"——这是一种廉价的犬儒姿态。

**（4）自我免疫（不可证伪性）**：如果有人指出某项决策确实出于信念或公益考虑，权力还原论可以立即将其重新解释为"伪装"——任何反证都可以被吸收。这使得它在经验上无法被驳倒。

**（5）算法放大**：YouTube 推荐算法偏好高情绪唤起的内容。"权力斗争"比"制度分析"更能获得点击和推荐。

---

## 5. 怎么反驳这种史观？——三个批判角度

### 5.1 历史唯物主义的批判（你已点出的）

在马克思和恩格斯看来，"政治人物争权"本身是需要被解释的 **结果**，而不是 **原因**。为什么在这个时代争权表现为宗教战争，在那个时代表现为议会斗争？要回答这个问题，必须分析 **生产关系**、**阶级结构** 和 **物质利益**。

恩格斯在《路德维希·费尔巴哈和德国古典哲学的终结》（1886）中的经典表述：

> 历史是这样创造的：最终的结果总是从许多单个的意志的相互冲突中产生出来的……但是，这些意志是由什么驱动的？……应当追问的，不是个别的人的动机，而是使整个阶级、整个民族行动起来的动机。

### 5.2 制度主义的批判

"权力私欲论"假定制度是透明的——权力人物想做什么就能做什么。但比较政治学的全部经验研究表明：**制度约束个人**。同样的政治人物，在总统制和议会制下的行为截然不同。

### 5.3 方法论的批判

- **逆向归因谬误**：看到某人最终获得了权力，就反推"他做的一切都是为了争权"；
- **缺乏比较控制**：如果要验证"权力动机是根本驱动力"，需要比较不同制度、文化、时代——这从未被认真做过；
- **忽略非事件**：那些在权力斗争中失败的人——难道他们不"贪权"吗？要解释为什么有人成功有人失败，就不得不引入权力动机之外的结构性因素。

## 6. 你该从哪里继续读？

按你的兴趣选择：

- **想系统了解史学理论** → 读 E.H. 卡尔的《历史是什么？》（1961），尤其是对"伟人史观"的批判章节；
- **想了解精英理论原文** → 读莫斯卡《统治阶级》（1896）的核心章节，再读达尔《谁统治？》（1961）作为多元主义反驳；
- **想了解马克思主义史学** → 恩格斯《费尔巴哈论》第四章是经典入口；
- **想了解算法/媒介批判** → 此方向在快速发展中，搜索"algorithmic amplification + political narrative"获取最新文献。

详细阅读路径见 `15_primary_materials_and_reading_path.md`。

---

## 7. 一句话总结

**权力还原论是一种认知上便宜、叙事上好看、但在学理上不可靠的历史解释模板。它不是任何严肃史学流派的主张，而是多条思想线索的去语境化通俗拼接。它之所以流行，主要不是因为正确，而是因为好用。**
