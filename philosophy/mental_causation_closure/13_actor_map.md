# 13 人物地图：核心哲学家与研究谱系

Last updated: 2026-06-15

---

## 阅读说明

本文件登记心理因果性/心身问题争论中的核心哲学家、其关键贡献、与 Lowe 论证的关系，以及学派归属。适用于学术汇报中的"研究背景"部分。

---

## 1. 本篇论文的核心人物

### E.J. Lowe (1950–2014)

| 项目 | 内容 |
|------|------|
| **全名** | Edward Jonathan Lowe |
| **身份** | 英国分析哲学家，Durham 大学教授 |
| **主要领域** | 形而上学、心灵哲学、语言哲学、早期现代哲学史 |
| **哲学取向** | 非自然主义、实体二元论倾向、自由意志 libertarianism |
| **核心著作** | *Subjects of Experience* (1996), *The Possibility of Metaphysics* (1998), *Personal Agency* (2008), *A Survey of Metaphysics* (2002) |
| **在本文中的角色** | 作者。辩护交互二元论不受 CCP+NOP 的经验排除 |
| **学术谱系** | 英国分析形而上学传统，受亚里士多德和阿奎那影响（通过现代分析哲学方法） |

### 核心论点标签
- 心理因果性的"不可见性"
- Figure 3.1 因果结构
- 本体论依赖 ≠ 因果依赖
- CCP 因量子力学和自由意志而为假

## 2. 交互二元论谱系

### René Descartes (1596–1650)

| 项目 | 内容 |
|------|------|
| **角色** | 交互二元论的"祖师爷" |
| **核心主张** | 心（res cogitans）和物（res extensa）是两种完全不同的实体；通过松果体交互 |
| **与 Lowe 的关系** | Lowe 继承笛卡尔的心物二元本体论，但提供了更精致的因果模型来回应后世批评 |
| **被批评的弱点** | 松果体模型与动量守恒的冲突 |

### W.D. Hart

| 项目 | 内容 |
|------|------|
| **核心著作** | *The Engines of the Soul* (1988) |
| **核心主张** | 心理能量（psychic energy）可以与非物理的心智互相转换，与物理能量守恒不冲突 |
| **与 Lowe 的关系** | Lowe 在文中引用了 Hart 的能量转换方案作为一种可能的二元论防御策略，但自己的方案不依赖于此 |

### Richard Swinburne

| 项目 | 内容 |
|------|------|
| **核心著作** | *The Evolution of the Soul* (1986), *Mind, Brain, and Free Will* (2013) |
| **核心主张** | 实体二元论 + 自由意志 libertarianism；心的存在由第一人称经验的统一性辩护 |
| **与 Lowe 的关系** | 同为英国实体二元论者，类似哲学气质 |

## 3. 物理主义（攻击方）谱系

### Jaegwon Kim (1934–2019)

| 项目 | 内容 |
|------|------|
| **身份** | 韩裔美国哲学家，Brown University 教授 |
| **核心著作** | *Supervenience and Mind* (1993), *Mind in a Physical World* (1998), *Physicalism, or Something Near Enough* (2005) |
| **核心主张** | "排除论证"（Exclusion Argument）：如果心理≠物理，则心理被物理"排除"因果效力；随附性不能保证心理因果性 |
| **与 Lowe 的关系** | Lowe 的主要论敌之一。Kim 的 CCP+NOP 版本是 Lowe 直接攻击的目标。Lowe 引用了 Kim (1993) 的 CCP 表述 |
| **演变** | 早期主张心理-物理同一论，晚期走向某种"准还原论" |

### David Papineau

| 项目 | 内容 |
|------|------|
| **核心著作** | *Philosophical Naturalism* (1993), *Thinking About Consciousness* (2002) |
| **核心主张** | "物理的完备性"（completeness of physics）；CCP 的经验辩护来自"因果论证"（causal argument） |
| **与 Lowe 的关系** | Lowe 在 CCP 和 CCP* 的讨论中直接引用了 Papineau：CCP* 的概率化表述来自 Papineau (1993: 22)，NOP 的动机分析参考了 Papineau (1998) |

### Andrew Melnyk

| 项目 | 内容 |
|------|------|
| **核心主张** | 物理主义的"证据"论证 |
| **与 Lowe 的关系** | Lowe 在第 3.6 节直接回应了 Melnyk (2003) 对 Lowe 类二元论方案的批评。Melnyk 攻击 Lowe 的假设"不经济""特设""非常不可信" |

## 4. 非还原物理主义谱系

### Jerry Fodor (1935–2017)

| 项目 | 内容 |
|------|------|
| **核心著作** | "Special Sciences" (1974), *Psychosemantics* (1987) |
| **核心主张** | 心理学的自主性；特殊科学的定律不能还原为物理学定律；多重可实现性 |
| **与 Lowe 的关系** | 间接盟友——Fodor 的非还原物理主义也反对 CCP+NOP 对心理因果性的排除，但 Fodor 不走向二元论 |

### Donald Davidson (1917–2003)

| 项目 | 内容 |
|------|------|
| **核心著作** | "Mental Events" (1970) |
| **核心主张** | 变异一元论（anomalous monism）：每个心理事件 token-identical 于某个物理事件，但没有心理-物理定律 |
| **与 Lowe 的关系** | Davidson 是因果过度决定问题讨论的先驱，但他的解决方案（token identity）是 Lowe 明确反对的 |

## 5. 意识与形而上学相关人物

### David Chalmers

| 项目 | 内容 |
|------|------|
| **核心著作** | *The Conscious Mind* (1996) |
| **核心主张** | 意识的"困难问题"；naturalistic dualism（属性二元论）；近年倾向泛心论 |
| **与 Lowe 的关系** | 间接平行——Chalmers 从意识的现象特征角度、Lowe 从因果形而上学角度，都得出"物理主义不完备"的结论。但 Chalmers 不必然走向实体二元论 |

### Colin McGinn

| 项目 | 内容 |
|------|------|
| **核心著作** | *The Problem of Consciousness* (1991) |
| **核心主张** | "认知封闭"（cognitive closure）：心身问题对人类认知能力而言是原则上不可解的 |
| **与 Lowe 的关系** | Lowe 在结尾提及 McGinn 的悲观主义，但明确不赞同；他认为可能通过先验形而上学找到解决路径 |

## 6. 因果理论相关人物

### James Woodward

| 项目 | 内容 |
|------|------|
| **核心著作** | *Making Things Happen* (2003) |
| **核心主张** | 干预主义因果理论：X 是 Y 的原因 iff 存在对 X 的可能干预会改变 Y |
| **与 Lowe 的关系** | `NEEDS_VERIFICATION`——干预主义因果理论如何评估 Lowe 的 Figure 3.1 结构中的 M 是否算"原因"？M 的不可见性是否意味着在干预主义框架下 M 不被识别为原因？这是一个值得学术汇报探讨的前沿问题 |

### David Lewis (1941–2001)

| 项目 | 内容 |
|------|------|
| **核心著作** | "Causation" (1973), *On the Plurality of Worlds* (1986) |
| **核心主张** | 反事实因果理论：c 是 e 的原因 iff 如果 c 没有发生，e 也不会发生 |
| **与 Lowe 的关系** | Lowe 的第 3.4 节讨论了反事实条件句的语义（"if M had not occurred, then P would not have occurred"）。在 Lewis 框架下，这似乎意味着 M 是 P 的原因——但反事实的评估依赖于可能世界的相似性排序，这在涉及心理-物理交互的场景中是否可行？ |

## 7. 学派/传统总结

| 传统 | 代表人物 | 核心倾向 |
|------|---------|---------|
| **剑桥/牛津分析形而上学** | Lowe, Swinburne | 实体二元论、自由意志 libertarianism、先验方法 |
| **美式分析物理主义** | Kim, Papineau, Melnyk | CCP + 排除论证、科学自然主义 |
| **澳洲唯物主义** | Smart, Armstrong | Type-type identity theory |
| **美式非还原物理主义** | Fodor, Putnam, Davidson | 多重可实现性、特殊科学自主 |
| **泛心论复兴** | Strawson, Goff, 晚期 Chalmers | 意识是物质的根本属性 |
| **现象学传统** | Husserl, Merleau-Ponty | `NEEDS_VERIFICATION`——现象学对"活的身体"的论述是否与 Lowe 的因果方案有对话空间？ |

*本人物地图基于 Lowe 论文引用的文献和当代心灵哲学的核心人物推断。未被 Lowe 直接引用的哲学家（如 Woodward, Lewis, 现象学传统）与 Lowe 论证的关系标注 NEEDS_VERIFICATION。*
